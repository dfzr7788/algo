# 算法学习知识库

一个使用 **Obsidian** 整理的中文算法学习知识库，面向算法竞赛学习与日常刷题复习，代码示例以 **C++17** 为主。

记录算法的原理、适用条件、实现方法和练习过程，围绕「理解问题 → 建立模型 → 推导算法 → 证明正确 → 实现与验证」组织内容。希望每次复习时，都能说清一个算法为什么成立、什么时候适用，以及边界该如何处理。

## 内容特点

- **按模块学习**：每个模块有独立导航，梳理学习顺序、前置知识与主题之间的联系。
- **结合推导与实现**：通过手算过程、公式、复杂度分析和 C++ 示例解释算法。
- **从暴力走向优化**：用完整题解展示如何发现重复计算、利用性质并改进方案。
- **关注错误与边界**：整理错误解法、反例和边界检查，帮助定位理解或实现上的问题。
- **配套练习**：提供分阶段题单与综合练习，结合平台题目和自编题训练独立建模。
- **辅助安排优先级**：部分笔记标注难度与重要程度，评分为个人学习建议，具体尺度见模块导航。

## 如何阅读

### 在 Obsidian 中打开

1. 下载仓库 ZIP 并解压，或克隆到本地：

   ```bash
   git clone https://github.com/duyan9030-dotcom/algo.git
   ```

2. 在 Obsidian 中选择「打开本地仓库」，打开下载或克隆得到的 `algo` 文件夹。
3. 从 `算法/算法.md` 或各模块的 `00-*.md` 导航笔记开始阅读。

笔记使用 Obsidian 双向链接（`[[笔记名]]`）连接相关主题，并包含数学公式和代码块。使用 Obsidian 可以沿链接跳转、查看反向链接，并结合关系图梳理知识之间的联系。

仓库内的 `.obsidian/` 保存了现有配置，社区插件列表包括 Waypoint、Folder Notes、Dataview 和 3D Graph。可按需安装或启用，正文笔记可以直接阅读。

### 在 GitHub 中浏览

直接使用上方的模块导航打开 Markdown 文件即可。README 使用标准 Markdown 链接；正文中的 `[[双向链接]]` 与部分 Obsidian 专用语法在 GitHub 中可能显示为原始文本，完整阅读体验建议使用 Obsidian。

## 学习建议

初次学习可以先从基础算法与思想入手，再学习前缀和、差分等经典算法和常用数据结构。之后按需要进入图论、字符串、数学与动态规划；博弈可作为专题学习。各模块内部的学习路线提供更具体的顺序。

每个主题可以按以下步骤练习：

1. **理解前提**：明确输入范围、适用条件与要维护的状态。
2. **手算过程**：用小例子跟踪算法，解释每一步为什么正确。
3. **独立实现**：脱离模板写代码，估算时间与空间复杂度。
4. **验证边界**：检查极值、重复值和其他合法边界，必要时与暴力解对比。
5. **完成练习**：从入门题到应用题，再用综合练习训练自主选择算法。
6. **复盘错误**：记录错误假设、最小反例与修正方法。
