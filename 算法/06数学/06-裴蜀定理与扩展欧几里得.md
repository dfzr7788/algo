## 判断能否到达与构造一组解

在无限整数轴上允许正反走 a、b 步，目标 c 可达当且仅当 $\gcd (a,b)$ 整除 c。裴蜀定理给出 $ax+by=\gcd (a,b)$ 的整数解。任意线性组合都是 gcd 的倍数；反过来把这组解按 c/g 缩放，就生成任意该倍数。

这不等同于“非负次数也一定可达”：6、10 的非负组合无法得到 2；有限空间和二维联动操作也要额外证明。普通马步两种坐标会同时变化，例如 $(1,1)$ 步使 $x+y$ 奇偶不变，即使 $\gcd =1$ 也不能遍历所有格点。倒水问题需明确目标是两壶总水量还是某一壶水量，前者还需 $C\le A+B$，后者需 $C\le \max (A,B)$。

## 递归返回时怎么还原系数

若递归求出 `bx1+(a%b)y1=g`，代入 `a%b=a−⌊a/b⌋b`，得到 $ay1+b(x1-\lfloor a/b\rfloor y1)=g$。因此 $x=y1$，$y=x1-\lfloor a/b\rfloor y1$。

30、18：底层 $6=1\times 6+0\times 0$，回到 $(18,12)$ 得 $(1,-1)$，回到 $(30,18)$ 得 $(-1,2)$，即 $-30+36=6$。若目标 12，再乘 2 得 $(-2,4)$。所有解为 $x=x0+(b/g)t$，$y=y0-(a/g)t$，$t\in Z$。

输入 $1\le a,b\le 10^{9}$、$\lvert c\rvert \le 10^{9}$，有解输出 g x y，无解输出 NO SOLUTION；本程序给一组解，具体系数不唯一。此范围缩放与中间乘积可放入 long long。零系数和更大整数应单独处理或使用更宽类型。

## 正确性与复杂度

系数代换保持等式，递归底层 $a\times 1+0\times 0=a$，故回溯结果正确。时间 $O(\log \min (a,b))$，递归空间同阶。对线性同余 $ax\equiv c \bmod m$，将其写成 $ax+my=c$，仍检查 $\gcd (a,m)|c$，基本周期是 m/g，而不是总是 m。

原练习 [Codeforces 2244C Stepan and Permutation](https://codeforces.com/contest/2244/problem/C) 已核验：允许交换距离 x 或 y 的位置，且 $x+y\le n$；是有限下标空间的应用题，应证明各模 gcd 类连通，不能只套无限轴结论。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

long long extended_gcd(long long a, long long b, long long &x, long long &y)
{
    if (b == 0)
    {
        x = 1;
        y = 0;
        return a;
    }
    long long x1, y1;
    long long g = extended_gcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

int main()
{
    long long a, b, c, x, y;
    cin >> a >> b >> c;
    long long g = extended_gcd(a, b, x, y);
    if (c % g != 0)
    {
        cout << "NO SOLUTION\n";
        return 0;
    }
    x *= c / g;
    y *= c / g;
    cout << g << ' ' << x << ' ' << y << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
30 18 12
```

输出：

```text
6 -2 4
```
