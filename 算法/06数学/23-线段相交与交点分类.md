## 不能只有跨立而没有范围

线段 AB、CD 是闭集，端点接触也算相交。先比较包围盒，若 x 或 y 范围不重合可排除；然后看 C、D 是否位于 AB 的相反侧或线上，以及 A、B 是否位于 CD 的相反侧或线上。

共线但分离的 $[0,1]$ 与 $[2,3]$，所有叉积都为 0，仍不相交，所以范围检查必需。旧笔记“两端点必然在直线两侧”只适用于严格内部非共线交叉，端点接触可能一个叉积为 0，重叠可能全部为 0。

实现比较符号，不能把两个叉积相乘后判断正负，因为即使每个叉积不溢出，它们的乘积也可能溢出。把在闭线段上的端点作为候选：共线时候选去重后，0 个为无交点、1 个为唯一点、2 个以上为重叠线段。

## 唯一交点如何求

当 $r=B-A$、$s=D-C$ 不平行时，$A+tr=C+us$，取叉积得到 $t=((C-A)\times s)/(r\times s)$。用参数方程避免垂直线斜率不存在。例 $(0,0)\to (2,2)$ 与 $(0,2)\to (2,0)$，分母 −8，分子 −4，$t=1/2$，交点 $(1,1)$。

程序输入 q 个测试，每组 8 个整数 $\lvert\text{坐标}\rvert\le 10^{9}$，输出 NONE、POINT x y 或 OVERLAP（重叠端点按 x 再 y 排序）。允许线段退化为点。整数判定精确、坐标输出 6 位小数。与原 AOJ 链接题的输出格式不同，本轮未能读取其完整官方题面，旧链接仅作待核验记录见题单。

## 正确性与边界

非平行线段相交当且仅当互相跨立（含端点），候选点处理平行与退化情况。每组 $O(1)$ 时间、$O(1)$ 空间。共线有唯一端点时也可以是唯一交点，不应笼统说“分母为 0 就一定有无限交点”。跨积为 0 不代表点在线段内部，还要比较坐标界。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Point
{
    long long x, y;
};

long long cross(Point a, Point b, Point c)
{
    return (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x);
}

bool same_point(Point a, Point b)
{
    return a.x == b.x && a.y == b.y;
}

bool less_point(Point a, Point b)
{
    return a.x < b.x || (a.x == b.x && a.y < b.y);
}

bool on_segment(Point p, Point a, Point b)
{
    return cross(a, b, p) == 0 && min(a.x, b.x) <= p.x && p.x <= max(a.x, b.x)
        && min(a.y, b.y) <= p.y && p.y <= max(a.y, b.y);
}

bool strict_opposite(long long a, long long b)
{
    return (a < 0 && b > 0) || (a > 0 && b < 0);
}

void print_point(long double x, long double y)
{
    cout << "POINT " << fixed << setprecision(6) << x << ' ' << y << '\n';
}

void solve()
{
    Point a, b, c, d;
    cin >> a.x >> a.y >> b.x >> b.y >> c.x >> c.y >> d.x >> d.y;
    vector<Point> candidates;
    for (Point p : {a, b, c, d})
    {
        if (on_segment(p, a, b) && on_segment(p, c, d))
        {
            candidates.push_back(p);
        }
    }
    sort(candidates.begin(), candidates.end(), less_point);
    candidates.erase(unique(candidates.begin(), candidates.end(), same_point), candidates.end());
    if (candidates.size() >= 2)
    {
        Point first = candidates.front();
        Point last = candidates.back();
        cout << "OVERLAP " << first.x << ' ' << first.y << ' ' << last.x << ' ' << last.y << '\n';
        return;
    }
    if (candidates.size() == 1)
    {
        print_point(candidates[0].x, candidates[0].y);
        return;
    }
    long long c1 = cross(a, b, c);
    long long c2 = cross(a, b, d);
    long long c3 = cross(c, d, a);
    long long c4 = cross(c, d, b);
    if (!strict_opposite(c1, c2) || !strict_opposite(c3, c4))
    {
        cout << "NONE\n";
        return;
    }
    long double rx = b.x - a.x;
    long double ry = b.y - a.y;
    long double sx = d.x - c.x;
    long double sy = d.y - c.y;
    long double denominator = rx * sy - ry * sx;
    long double t = ((c.x - a.x) * sy - (c.y - a.y) * sx) / denominator;
    print_point(a.x + t * rx, a.y + t * ry);
}

int main()
{
    int q;
    cin >> q;
    while (q--)
    {
        solve();
    }
}
```

教学样例输入（不是平台官方样例）：

```text
3
0 0 2 2 0 2 2 0
0 0 3 0 1 0 4 0
0 0 1 0 2 0 3 0
```

输出：

```text
POINT 1.000000 1.000000
OVERLAP 1 0 3 0
NONE
```
