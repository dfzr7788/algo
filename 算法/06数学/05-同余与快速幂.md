## 模运算保留了什么信息

a≡b mod m 表示 m 整除 a−b，即把整数按余数分组。加减乘在分组后仍能正确运算，除法要检查逆元，指数也不能随便对 m 取模。负数 `%` 是余数而不是数学的标准非负代表：−5%3=−2，先取余，若负则加 m。

例：10/2 mod 3=2，但先取余得到 1/2，普通整数除法会得到 0。只有分母可逆且原式是模意义下的除法时，才能改为乘逆元。原整数式即使整除，分母不可逆时也需先在整数中约分或提高模数。

## 从 b 次乘法到二进制拆分

3^11=3^8×3²×3，因为 11=8+2+1。循环维护 result×a^b 与原目标同余：最低位为 1 就把当前 a 乘入 result，再令 a 平方、b 减半。例 3^11 mod 7：初始 (result,a,b)=(1,3,11)，依次到 (3,2,5)、(6,4,2)、(6,2,1)、(5,4,0)，答案 5。

指数 0 返回乘法单位元；模数为 1 时单位元的余数也是 0，所以初始化为 1%mod。本文约定 0^0=1（空乘积），用于程序模板，不讨论分析学中的不定式。

程序输入 |a|<=10^18、0<=b<=10^18、1<=mod<=10^18，输出一个非负余数。与 [洛谷 P1226](https://www.luogu.com.cn/problem/P1226) 的格式化字符串输出不同。__int128 先转换再乘，支持大模数；复杂度 O(log(b+1)) 次模乘、空间 O(1)。

## 常见错误与扩展

`a*a%mod` 会先溢出再取模；`(x%mod+mod)%mod` 在接近最大整数时加法也可能溢出，用条件加更清楚。本模板范围 10^18，但更大范围不能忽略这个问题。

推广到矩阵和置换，只需要结合律及单位元，不需要交换律。指数降幂见 [[08-欧拉函数与指数降幂]]；离散对数 BSGS、NTT 与原根为后续选学。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

long long power_mod(long long a, long long b, long long mod)
{
    a %= mod;
    if (a < 0)
    {
        a += mod;
    }
    long long result = 1 % mod;
    while (b > 0)
    {
        if (b & 1)
        {
            result = (__int128)result * a % mod;
        }
        a = (__int128)a * a % mod;
        b >>= 1;
    }
    return result;
}

int main()
{
    long long a, b, mod;
    cin >> a >> b >> mod;
    cout << power_mod(a, b, mod) << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
3 11 7
```

输出：

```text
5
```
