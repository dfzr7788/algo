## 模运算保留了什么信息

$a\equiv b \bmod m$ 表示 m 整除 $a-b$，即把整数按余数分组。加减乘在分组后仍能正确运算，除法要检查逆元，指数也不能随便对 m 取模。负数 `%` 是余数而不是数学的标准非负代表：`−5%3=−2`，先取余，若负则加 m。

例：$10/2 \bmod 3=2$，但先取余得到 $1/2$，普通整数除法会得到 0。只有分母可逆且原式是模意义下的除法时，才能改为乘逆元。原整数式即使整除，分母不可逆时也需先在整数中约分或提高模数。

## 从 b 次乘法到二进制拆分

$3^{11}=3^{8}\times 3^{2}\times 3$，因为 $11=8+2+1$。循环维护 $\mathrm{result}\times a^{b}$ 与原目标同余：最低位为 1 就把当前 a 乘入 result，再令 a 平方、b 减半。例 $3^{11} \bmod 7$：初始 $(\mathrm{result},a,b)=(1,3,11)$，依次到 $(3,2,5)$、$(6,4,2)$、$(6,2,1)$、$(5,4,0)$，答案 5。

指数 0 返回乘法单位元；模数为 1 时单位元的余数也是 0，所以初始化为 `1%mod`。本文约定 $0^{0}=1$（空乘积），用于程序模板，不讨论分析学中的不定式。

程序输入 $\lvert a\rvert \le 10^{18}$、$0\le b\le 10^{18}$、$1\le \mathrm{mod}\le 10^{18}$，输出一个非负余数。与 [洛谷 P1226](https://www.luogu.com.cn/problem/P1226) 的格式化字符串输出不同。`__int128` 先转换再乘，支持大模数；复杂度 $O(\log (b+1))$ 次模乘、空间 $O(1)$。

## 常见错误与扩展

`a*a%mod` 会先溢出再取模；`(x%mod+mod)%mod` 在接近最大整数时加法也可能溢出，用条件加更清楚。本模板范围 $10^{18}$，但更大范围不能忽略这个问题。

推广到矩阵和置换，只需要结合律及单位元，不需要交换律。指数降幂见 [[08-欧拉函数与指数降幂]]；离散对数 BSGS、NTT 与原根为后续选学。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

long long power_mod(long long a, long long b, long long mod)
{
    a %= mod;
    if (a < 0)
    {
        a += mod;
    }
    long long result = 1 % mod;
    while (b > 0)
    {
        if (b & 1)
        {
            result = (__int128)result * a % mod;
        }
        a = (__int128)a * a % mod;
        b >>= 1;
    }
    return result;
}

int main()
{
    long long a, b, mod;
    cin >> a >> b >> mod;
    cout << power_mod(a, b, mod) << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
3 11 7
```

输出：

```text
5
```

## ABC450D Minimize Range

[官方题面](https://atcoder.jp/contests/abc450/tasks/abc450_d)

每次可给某个正整数加K，可操作任意次，最小化全体最大值减最小值。N≤2×10⁵。

> [!tip]- 提示一
> 每个数只保留模K的余数，整体范围可平移到足够高的位置。

> [!tip]- 提示二
> 在余数圆环上切掉一个最大空隙，剩下最短覆盖弧。
>
> 复习：[[06数学/05-同余与快速幂]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码对每个数取模并排序，ans先设a[N−1]−a[0]，再枚举相邻位置，取min(ans,a[i]+K−a[i+1])。初值对应切开首尾间隙，其余对应跨过0的覆盖弧，等价于K减最大环形间隙。
>
> **正确性与适用条件。** 任意宽度小于K的合法范围在模K圆环上覆盖全部余数，其补集只能落在某个相邻空隙里，最短弧因此至少为所求。反向把该弧展开为实轴区间，再整体加足够多的K，使每个目标都不小于原值，就可仅靠加K实现。
>
> **手算与边界。** K=10，余数(1,2,9)，直接跨度8；从2到9的空隙7最大，保留9→1→2的弧长3，可实现为(11,12,9)。
>
> **实际复杂度与实现。** 时间O(N log N)，空间O(N)。重复余数无妨，N=1或K=1答案0；证明中整体上移是消除“只能加不能减”的必要步骤。

## ABC460E x + y ≡ x + y

[官方题面](https://atcoder.jp/contests/abc460/tasks/abc460_e)

统计1≤x,y≤N且十进制concat(x,y)与x+y模M相同的有序对，答案模998244353；N≤10¹⁸，2≤M≤10⁹。

> [!tip]- 提示一
> 固定y的位数L后，展开拼接并消去y。

> [!tip]- 提示二
> 条件化成M整除x(10^L−1)，再用gcd得到x必须是某个数的倍数。
>
> 复习：[[06数学/05-同余与快速幂]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码按L=1..19枚举y的十进制范围[lower,upper]，令g=gcd(10^L−1,M)、k=M/g，则cntx=⌊N/k⌋，cnty=min(N,upper)−lower+1，累加二者乘积。p10仅保存10^L模M，不构造实际拼接大整数。
>
> **正确性与适用条件。** concat=x·10^L+y，原条件等价于M|x(10^L−1)。约去g后两个剩余因子互质，等价于k|x。固定L时限制与y的具体值无关，故x、y可独立计数；各位数范围不交，累加即全体有序对。
>
> **手算与边界。** N=12,M=9时10^L−1始终被9整除，k=1，所有12²=144对都满足；M=2时k=2，只能取偶数x，y不限。
>
> **实际复杂度与实现。** 每测试O(log N·log M)时间、O(1)辅助空间。源码用unsigned long long表示最大19位范围，upper最多10¹⁹−1仍可容纳；M≤10⁹使p10乘10小于10¹⁰，模减先加M避免无符号下溢。cntx、cnty先模998244353再乘，乘积小于10¹⁸。
