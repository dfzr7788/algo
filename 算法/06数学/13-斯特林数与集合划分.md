## 哪些盒子可以区分

第二类 S(n,k) 是 n 个不同元素划成 k 个非空、无标号集合的数量；集合内部无序。若 k 个盒子有标号且都非空，则为 k!S(n,k)；盒子有标号且允许空，则直接 k^n。三个模型不能混用。

S(3,2)=3，分别 {1}|{2,3}、{2}|{1,3}、{3}|{1,2}。把最后元素单独成组有 S(n−1,k−1) 种；放入已有 k 组有 kS(n−1,k) 种，所以 S(n,k)=S(n−1,k−1)+kS(n−1,k)。S(0,0)=1，n>0 时 S(n,0)=0。

## 第一类：循环排列的计数

无符号第一类 c(n,k) 是 n 元置换恰有 k 个循环的数量。新元素自成循环给 c(n−1,k−1)；插入旧循环中某元素后面有 n−1 个位置，给 (n−1)c(n−1,k)。所以 c(n,k)=c(n−1,k−1)+(n−1)c(n−1,k)。

n=3 时 c(3,1)=2（两个三元循环），c(3,2)=3（一个交换加一个不动点），c(3,3)=1。总和 6=3!。有符号第一类 s(n,k)=(-1)^{n−k}c(n,k)，本章程序输出的是无符号版本。

程序读 0<=n,k<=2000 与 1<=mod<=10^9，依次输出 S(n,k)、c(n,k) 的余数；用滚动数组，k 从大到小更新，不让本轮状态污染旧行。时间 O(nk)，空间 O(k)，无需模逆元，可用合数模。

## 变体与正确性

递推的两种情况互斥且覆盖所有结果，因此正确。Bell 数 Bn=ΣS(n,k)，表示任意组数的集合划分。满射计数也可容斥为 Σ(-1)^j C(k,j)(k−j)^n，等于 k!S(n,k)。后续可用它对拍第二类实现，不需把所有划分真的保存出来。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 2000 + 5;
long long second_kind[MAXN], first_kind[MAXN];

int main()
{
    int n, k;
    long long mod;
    cin >> n >> k >> mod;
    second_kind[0] = 1 % mod;
    first_kind[0] = 1 % mod;
    for (int i = 1; i <= n; i++)
    {
        for (int j = k; j >= 1; j--)
        {
            second_kind[j] = (second_kind[j - 1] + j * second_kind[j]) % mod;
            first_kind[j] = (first_kind[j - 1] + (i - 1) * first_kind[j]) % mod;
        }
        second_kind[0] = 0;
        first_kind[0] = 0;
    }
    cout << second_kind[k] << '\n';
    cout << first_kind[k] << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
3 2 1000000007
```

输出：

```text
3
3
```
