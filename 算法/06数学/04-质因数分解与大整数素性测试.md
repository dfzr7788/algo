## 从约数枚举到唯一分解

每个 $n>1$ 唯一表示为不同素数幂的乘积 $n=\prod p_i^{c_i}$。试除时不断除尽当前 d，再试下一个；条件用 $d\le n/d$，避免 d*d 溢出。结束后 $n>1$ 就是剩余质因子。单个数最坏 $O(\sqrt n)$，$n\le 10^{12}$ 的少量询问可以考虑；不是所有 $10^{12}$ 规模的多测都足够快。大量 $n\le M$ 的询问可用前章 spf 预处理 $O(M)$，每次按因子次数 $O(\log n)$ 分解。

例：$360=2^{3}\times 3^{2}\times 5$。约数独立选择各指数，因此约数个数为 $(3+1)(2+1)(1+1)=24$；约数和为 $(1+2+4+8)(1+3+9)(1+5)=1170$。模意义下等比数列公式中的 $p-1$ 不一定可逆，可逐项累计或分治计算，不可直接除。

## 大整数为什么不能继续试除

$10^{18}$ 的素数可能需要约 $10^{9}$ 次试除。先用 Miller-Rabin：把 $n-1$ 写成 $d\times 2^{s}$（d 奇数）。素数下 $a^{d}$ 要么是 1，要么反复平方过程中出现 −1；某个底数不满足就能确定合数。单底数满足仅是通过检验，不是素数证明。

原九个小素数底数在 $10^{18}$ 范围内有效，不能扩展为全部64位范围；最小共同强伪素数为3825123056546413051，见[原始论文](https://arxiv.org/abs/1207.0063)。新版采用记录的七底数 $\{2,325,9375,28178,450775,9780504,1795265022\}$，覆盖 $n<2^{64}$，本文输入仍限制为 $n\le 10^{18}$。[底数范围原始记录](https://miller-rabin.appspot.com/)可核对 Jim Sinclair 的 7 底数条目。`a%n=0` 要跳过该底数。

Pollard-Rho 用 $f(x)=x^{2}+c \bmod n$ 生成序列，以快慢指针比较 x、y，计算 $\gcd (\lvert x-y\rvert ,n)$。如果模某真因子先碰撞，gcd 就能暴露因子。$\gcd =n$ 表示这轮失败，应换初值和 c 重试；得到的因子可能是合数，继续递归。这里用固定种子的随机生成器便于复现，本质仍是随机重启算法。

## 完整程序约定与正确性

输入 T，随后 T 个 $1\le n\le 10^{18}$。每组输出因子种类数，随后逐行输出 p 与指数；$n=1$ 输出 0。与 [洛谷 P4718](https://www.luogu.com.cn/problem/P4718) 的 Prime/最大质因子输出不同。

`multiply_mod` 先转换为 unsigned `__int128`，避免相乘溢出；这是 GCC/Clang 扩展，不是 ISO C++17 的标准类型。所有输出因子都经素性检验，递归分裂保持乘积等于原数。

按固定宽度整数操作计，七底数 MR 为 $O(\log n)$ 次模乘。Rho 找因子的常用启发式期望为 $O(\sqrt p)$，其中 p 是小质因子；不能宣称最坏 $O(n^{1/4})$ 或给出确定终止时间。递归分解总时间还取决于各子因子的寻找与重试，空间包括因子结果和 $O(\log n)$ 递归层数。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

using ull = unsigned long long;
mt19937_64 rng(20261013);

ull multiply_mod(ull a, ull b, ull mod)
{
    return (unsigned __int128)a * b % mod;
}

ull power_mod(ull a, ull b, ull mod)
{
    ull result = 1 % mod;
    while (b > 0)
    {
        if (b & 1)
        {
            result = multiply_mod(result, a, mod);
        }
        a = multiply_mod(a, a, mod);
        b >>= 1;
    }
    return result;
}

bool is_prime(ull n)
{
    if (n < 2)
    {
        return false;
    }
    for (ull p : {2ULL, 3ULL, 5ULL, 7ULL, 11ULL, 13ULL})
    {
        if (n % p == 0)
        {
            return n == p;
        }
    }
    ull d = n - 1;
    int s = 0;
    while ((d & 1) == 0)
    {
        d >>= 1;
        s++;
    }
    for (ull base : {2ULL, 325ULL, 9375ULL, 28178ULL, 450775ULL, 9780504ULL, 1795265022ULL})
    {
        ull a = base % n;
        if (a == 0)
        {
            continue;
        }
        ull x = power_mod(a, d, n);
        if (x == 1 || x == n - 1)
        {
            continue;
        }
        bool passed = false;
        for (int r = 1; r < s; r++)
        {
            x = multiply_mod(x, x, n);
            if (x == n - 1)
            {
                passed = true;
                break;
            }
        }
        if (!passed)
        {
            return false;
        }
    }
    return true;
}

ull next_value(ull x, ull c, ull n)
{
    return ((unsigned __int128)multiply_mod(x, x, n) + c) % n;
}

ull find_factor(ull n)
{
    if (n % 2 == 0)
    {
        return 2;
    }
    while (true)
    {
        ull c = rng() % (n - 1) + 1;
        ull x = rng() % (n - 2) + 2;
        ull y = x;
        ull d = 1;
        while (d == 1)
        {
            x = next_value(x, c, n);
            y = next_value(next_value(y, c, n), c, n);
            ull difference = x > y ? x - y : y - x;
            d = gcd(difference, n);
        }
        if (d != n)
        {
            return d;
        }
    }
}

void factorize(ull n, map<ull, int> &factors)
{
    if (n == 1)
    {
        return;
    }
    if (is_prime(n))
    {
        factors[n]++;
        return;
    }
    ull d = find_factor(n);
    factorize(d, factors);
    factorize(n / d, factors);
}

int main()
{
    int t;
    cin >> t;
    while (t--)
    {
        ull n;
        cin >> n;
        map<ull, int> factors;
        factorize(n, factors);
        cout << factors.size() << '\n';
        for (auto [p, exponent] : factors)
        {
            cout << p << ' ' << exponent << '\n';
        }
    }
}
```

教学样例输入（不是平台官方样例）：

```text
2
360
1
```

输出：

```text
3
2 3
3 2
5 1
0
```

## 补充实现

试除与SPF的独立小值程序：输入mode,n。$\mathrm{mode}=1$ 为试除，$1\le n\le 10^{12}$；$\mathrm{mode}=2$ 为先筛到n再分解，$1\le n\le 1000000$。输出因子种类数、各p和指数，最后输出约数个数和约数和。$n=1$ 的空乘积给出1、1。试除 $O(\sqrt n)$，SPF筛 $O(n)$ 后分解 $O(\log n)$，对应空间 $O(\log n)$ 与 $O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000000 + 5;
int spf[MAXN];
vector<int> primes;

void build_spf(int n)
{
    for (int i = 2; i <= n; i++)
    {
        if (spf[i] == 0)
        {
            spf[i] = i;
            primes.push_back(i);
        }
        for (int p : primes)
        {
            if (p > n / i)
            {
                break;
            }
            spf[i * p] = p;
            if (i % p == 0)
            {
                break;
            }
        }
    }
}

vector<pair<long long, int>> trial_factorize(long long n)
{
    vector<pair<long long, int>> factors;
    for (long long p = 2; p <= n / p; p++)
    {
        if (n % p == 0)
        {
            int exponent = 0;
            while (n % p == 0)
            {
                exponent++;
                n /= p;
            }
            factors.push_back({p, exponent});
        }
    }
    if (n > 1)
    {
        factors.push_back({n, 1});
    }
    return factors;
}

vector<pair<long long, int>> spf_factorize(int n)
{
    vector<pair<long long, int>> factors;
    while (n > 1)
    {
        int p = spf[n];
        int exponent = 0;
        while (n % p == 0)
        {
            exponent++;
            n /= p;
        }
        factors.push_back({p, exponent});
    }
    return factors;
}

int main()
{
    int mode;
    long long n;
    cin >> mode >> n;
    vector<pair<long long, int>> factors;
    if (mode == 1)
    {
        factors = trial_factorize(n);
    }
    else
    {
        build_spf(n);
        factors = spf_factorize(n);
    }
    cout << factors.size() << '\n';
    long long count = 1;
    long long sum = 1;
    for (auto [p, exponent] : factors)
    {
        cout << p << ' ' << exponent << '\n';
        count *= exponent + 1;
        long long power = 1;
        long long series = 1;
        for (int j = 1; j <= exponent; j++)
        {
            power *= p;
            series += power;
        }
        sum *= series;
    }
    cout << count << ' ' << sum << '\n';
}
```

教学样例输入：

```text
1 360
```

输出：

```text
3
2 3
3 2
5 1
24 1170
```
