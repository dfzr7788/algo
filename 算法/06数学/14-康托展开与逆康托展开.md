## 从字典序枚举到首个不同位置

给定 $1\ldots n$ 的一个全排列，求它在 $n!$ 个排列中的排名。枚举全部排列太慢。设 $c_{i}$ 是当前位置右侧比 $a_{i}$ 小的数量，严格较小的排列可按第一个不同位置分类，数量为 $\sum c_i(n-i)!$，排名再加 1。每个分类无重复，因为首个不同位置唯一。

原例 [3,4,1,5,2]：第一位能选 1、2，贡献 $2\times 4!=48$；第二位可选未使用的 1、2，贡献 $2\times 3!=12$；第三位无更小，贡献 0；第四位可选 2，贡献 $1\times 1!=1$；总数 61，排名 62。

维护“尚未使用”的频次数组，树状数组 $\mathrm{query}(a_i-1)$ 求更小数量，再 $\mathrm{add}(a_i,-1)$ 删除。若先删 $a_{i}$ 再 $\mathrm{query}(a_i)$ 也等价，但显式查询 $a_i-1$ 更容易看出严格小于关系。不能把排列排名误当成逆序对数，两者权重不同。

输入 $1\le n\le 1000000$，随后合法全排列，输出 1 起始排名 mod 998244353，对应 [洛谷 P5367](https://www.luogu.com.cn/problem/P5367)。最后输出 `(rank0+1)%MOD`，避免原程序 $\mathrm{rank0}=MOD-1$ 时输出 MOD。时间 $O(n \log n)$，空间 $O(n)$。

## 逆向恢复需要精确排名

知道第 R 名，先令 $X=R-1$。首位的零起始序号 $q=X/(n-1)!$，在有序可用元素里取第 $q+1$ 小，再令 `X%=(n−1)!`，重复。原例 $61/24=2$ 余 13，取 3；$13/6=2$ 余 1，取 4；$1/2=0$，取 1；$1/1=1$，取 5；余下 2。

用 vector 删除的入门实现 $O(n^{2})$，$1\le n\le 20$ 时 $n!$ 不超过 `long long` 上限，可以存精确 R。大 n 需要高精度与次序统计。**排名取模后不再能唯一逆展开**；重复值的多重集排列也不能直接用本公式，要扣掉重复对象排列的重数。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000000 + 5;
const long long MOD = 998244353;
int tree[MAXN];
long long factorial[MAXN];
int n;

void add_count(int position, int value)
{
    while (position <= n)
    {
        tree[position] += value;
        position += position & -position;
    }
}

int query_count(int position)
{
    int result = 0;
    while (position > 0)
    {
        result += tree[position];
        position -= position & -position;
    }
    return result;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    factorial[0] = 1;
    for (int i = 1; i <= n; i++)
    {
        factorial[i] = factorial[i - 1] * i % MOD;
        add_count(i, 1);
    }
    long long rank_zero = 0;
    for (int i = 1; i <= n; i++)
    {
        int value;
        cin >> value;
        int smaller = query_count(value - 1);
        rank_zero = (rank_zero + smaller * factorial[n - i]) % MOD;
        add_count(value, -1);
    }
    cout << (rank_zero + 1) % MOD << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
5
3 4 1 5 2
```

输出：

```text
62
```

## 补充实现

逆康托展开完整程序，输入 $1\le n\le 20$ 与 $1\le R\le n!$，R为未取模的1起始精确排名，输出全排列。vector保持剩余元素递增，查找 $O(1)$、删除 $O(n)$，总 $O(n^{2})$，空间 $O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int n;
    long long rank;
    cin >> n >> rank;
    long long fac[21];
    fac[0] = 1;
    vector<int> available;
    for (int i = 1; i <= n; i++)
    {
        fac[i] = fac[i - 1] * i;
        available.push_back(i);
    }
    rank--;
    for (int remaining = n; remaining >= 1; remaining--)
    {
        long long index = rank / fac[remaining - 1];
        rank %= fac[remaining - 1];
        cout << available[index] << (remaining == 1 ? '\n' : ' ');
        available.erase(available.begin() + index);
    }
}
```

教学样例输入：

```text
5 62
```

输出：

```text
3 4 1 5 2
```
