## 为什么普通最短路不能替代

Dijkstra 找总权最小，却不限制走几条边。若必须恰走 K 条边，可做 dp[t][v]=min_u(dp[t−1][u]+w(u,v))，单源 O(Km)，K=10^9 太大。把所有点对恰走 t 步的代价记录为矩阵，将“枚举中转点取最小”作为乘法：

$$
(A\otimes B)_{ij}=\min_k(A_{ik}+B_{kj}).
$$

将长度 a 和 b 的游走在中间点拼接，得到恰 a+b 步的最优代价。min 与加的分配律保证结合律，因此 W^K 即答案。最短游走允许重复点边，不能叫只含不同顶点的简单路径。

## 单位元与小例子

0 步只能在原点，单位矩阵对角线 0，其余 INF。一步矩阵对角线是实际自环代价，**无自环就必须 INF**；偷偷加 0 自环会把恰 K 步变成至多 K 步。

例 1→2 权 3、2→3 权 4、1→3 权 1。一步到 3 最优为 1，两步必须经 2，答案 7。乘法 A_12+B_23 提供 7，而单位元不允许跳过任何一步。

输入 n m K s t，1<=n<=100、0<=m<=10000、0<=K<=10^9，随后 m 条有向边 u v w，点编号 1..n、|w|<=10^9。输出恰 K 条边的最小代价，不可达输出 UNREACHABLE；平行边保留最小权。负边允许，因为步数固定，即使有负环答案仍有限。此处 INF=4×10^18，所有实际代价绝对值<=10^18；最后一轮不再无用平方，避免形成超出 K 范围的块。

## 正确性、复杂度与变体

每次乘法按中点遍历全部可能分段，无遗漏地取最小。O(n³ log(K+1)) 时间、O(n²) 空间；INF 必须先判再相加，不能把“不可达+负边”误认为可达。

至多 K 步可加入 0 自环（保留原更小的负自环，用 min(w_ii,0)）。Max-Plus 改取最大，非对角单位元为 −INF；布尔矩阵乘法用 OR 汇总、AND 拼接，描述恰 K 步可达，均需相应重定义单位元。

原题 [AtCoder ABC445 F](https://atcoder.jp/contests/abc445/tasks/abc445_f) 已核验：完整代价矩阵，求每个起点恰 K 步回到自身的最小代价，应输出结果的所有对角元素，不是本程序单个 s,t 输出。把小边权拆成多个状态可将“固定总权的计数”转为定长游走计数，但维度增大，只适合原图点数也足够小；不能声称适用于 N 很大的图。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100;
const long long INF = 4000000000000000000LL;
long long base_matrix[MAXN][MAXN], result_matrix[MAXN][MAXN];
long long buffer_matrix[MAXN][MAXN];
int n;
long long mod_value;

void multiply(long long a[][MAXN], long long b[][MAXN], long long output[][MAXN])
{
    for (int i = 0; i < n; i++)
    {
        fill(buffer_matrix[i], buffer_matrix[i] + n, INF);
    }
    for (int i = 0; i < n; i++)
    {
        for (int k = 0; k < n; k++)
        {
            for (int j = 0; j < n; j++)
            {
                if (a[i][k] != INF && b[k][j] != INF)
                {
                    buffer_matrix[i][j] = min(buffer_matrix[i][j], a[i][k] + b[k][j]);
                }
            }
        }
    }
    memcpy(output, buffer_matrix, sizeof(buffer_matrix));
}

void matrix_power(long long exponent)
{
    for (int i = 0; i < n; i++)
    {
        fill(result_matrix[i], result_matrix[i] + n, INF);
        result_matrix[i][i] = 0;
    }
    while (exponent > 0)
    {
        if (exponent & 1)
        {
            multiply(result_matrix, base_matrix, result_matrix);
        }
        exponent >>= 1;
        if (exponent > 0)
        {
            multiply(base_matrix, base_matrix, base_matrix);
        }
    }
}

int main()
{
    int m, source, target;
    long long exponent;
    cin >> n >> m >> exponent >> source >> target;
    for (int i = 0; i < n; i++)
    {
        fill(base_matrix[i], base_matrix[i] + n, INF);
    }
    for (int i = 0; i < m; i++)
    {
        int u, v;
        long long w;
        cin >> u >> v >> w;
        base_matrix[u - 1][v - 1] = min(base_matrix[u - 1][v - 1], w);
    }
    matrix_power(exponent);
    long long answer = result_matrix[source - 1][target - 1];
    if (answer == INF)
    {
        cout << "UNREACHABLE\n";
    }
    else
    {
        cout << answer << '\n';
    }
}
```

教学样例输入（不是平台官方样例）：

```text
3 3 2 1 3
1 2 3
2 3 4
1 3 1
```

输出：

```text
7
```
