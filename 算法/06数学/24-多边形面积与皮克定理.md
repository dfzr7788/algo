## 面积不是任意点对的叉积之和

已知简单多边形按边界顺序给出的顶点 $P0\ldots P(n-1)$，可把每条边与原点组成有向三角形。原点在多边形外也可计算，内部的正负区域会抵消：

$$
2S=\left|\sum_{i=0}^{n-1}(x_i y_{i+1}-y_i x_{i+1})\right|,\quad P_n=P_0.
$$

顺时针与逆时针只改变符号，最后取绝对值。顶点不能随意排序，自交多边形这个式子给的是代数面积，不能直接当几何并面积。

例矩形 $(0,0),(4,0),(4,3),(0,3)$，叉积依次 0、12、12、0，二倍面积 24、面积 12。格点边 $(0,0)\to (4,3)$ 仅有两端点，而 $(0,0)\to (4,0)$ 有 5 个整点。

## 边界点与内部点

一个整点端点线段，含两端的整点数量为 $\gcd (\lvert dx\rvert ,\lvert dy\rvert )+1$。多边形逐边只计起点不计终点，防止顶点重复，得到 $B=\sum \gcd (\lvert dx\rvert ,\lvert dy\rvert )$。简单、不自交、无孔洞格点多边形满足皮克公式 $S=I+B/2-1$，所以 $I=(2S-B+2)/2$。

上述矩形 $B=4+3+4+3=14$，$I=(24-14+2)/2=6$，恰为 $x=1,2,3$ 与 $y=1,2$ 的六个内点。有孔洞时常数需要调整，本文模板不适用；非整点坐标也不能用 Pick。

输入 $3\le n\le 200000$、$\lvert\text{坐标}\rvert\le 10^{9}$，保证非退化简单格点多边形，按边界顺序给点。输出二倍面积、B、I。二倍面积累计用 `__int128`，避免逐边 long long 总和溢出；输出二倍值也避免半整数精度损失。鞋带 $O(n)$，边界 gcd 共 $O(n \log C)$，空间 $O(n)$；仅求面积可边读边算保留首尾点、$O(1)$ 空间。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

using i128 = __int128;

void print_integer(i128 value)
{
    if (value == 0)
    {
        cout << 0;
        return;
    }
    string digits;
    while (value > 0)
    {
        digits.push_back('0' + value % 10);
        value /= 10;
    }
    reverse(digits.begin(), digits.end());
    cout << digits;
}

int main()
{
    int n;
    cin >> n;
    vector<long long> x(n), y(n);
    for (int i = 0; i < n; i++)
    {
        cin >> x[i] >> y[i];
    }
    i128 twice_area = 0;
    long long boundary = 0;
    for (int i = 0; i < n; i++)
    {
        int j = (i + 1) % n;
        twice_area += (i128)x[i] * y[j] - (i128)y[i] * x[j];
        boundary += gcd(abs(x[i] - x[j]), abs(y[i] - y[j]));
    }
    if (twice_area < 0)
    {
        twice_area = -twice_area;
    }
    print_integer(twice_area);
    cout << '\n' << boundary << '\n';
    print_integer((twice_area - boundary + 2) / 2);
    cout << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
4
0 0
4 0
4 3
0 3
```

输出：

```text
24
14
6
```
