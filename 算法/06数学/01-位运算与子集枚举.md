## 用途与表示约定

把 n 个对象编号为 $0\ldots n-1$，第 i 位为 1 表示选了它。这样集合交、并、差、对称差分别对应 `A & B`、`A | B`、`A & ~B`、`A ^ B`。补集必须写成 `full ^ A` 或 `(~A) & full`，避免把范围外高位加入集合。适用于 n 较小的指数枚举，不能因为整数有 64 位就认为 $2^{64}$ 个状态可以遍历。

对无符号 x，`x & (0ULL - x)` 取最低位 1，`x & (x - 1)` 删除最低位 1；`x > 0 && (x & (x - 1)) == 0` 判定 2 的幂。树状数组的 lowbit 正是第一种操作。异或满足 $x\oplus x=0$，因此全数组异或可消去出现偶数次的元素。

移位使用 `1ULL << i`，保证 $0\le i<64$。本文仅讨论无符号或非负整数的移位；C++17 中负数右移由实现定义，负数左移可能有未定义行为。无需为了常数改写清晰的普通乘除。

## 为什么可以直接跳到下一个子集

逐个枚举所有整数并检查 `(sub & mask) == sub` 会扫描大量无关状态。改用 `sub = (sub - 1) & mask`：减一借位产生下一候选，按位与删掉 mask 之外的位，得到数值最大的下一个合法子集。

$\mathrm{mask}=10$，即二进制 1010，对应集合 $\{1,3\}$。过程为 1010→1000→0010→0000，即 10、8、2、0。处理空集后必须退出，否则无符号 $0-1$ 再与 mask 会回到 mask。

若 mask 有 k 个 1，枚举含空集的子集为 $O(2^{k})$，额外空间 $O(1)$。枚举所有 n 位 mask 的所有 sub 为 $O(3^{n})$：每个元素只有“不在 mask”“在 mask 不在 sub”“在 sub”三种选择。

## 固定大小的集合与内置函数

Gosper 方法按**掩码数值递增**枚举 k 个 1 的掩码，不是元素序列通常意义下的字典序。设 $c=\mathrm{lowbit}(\mathrm{mask})$，$r=\mathrm{mask}+c$，下一项为 `r | (((r ^ mask) >> 2) / c)`。限制 $0<k\le n<63$；$k=0$ 应单独只输出空集，不能除以 $c=0$。

GCC 的 `__builtin_popcountll` 统计 64 位 1 个数；`__builtin_ctzll` 与 `__builtin_clzll` 的输入不能为 0，`std::__lg` 也不是标准 C++17 接口。前缀异或 $f(n)=0\oplus \ldots\oplus n$ 按 `n%4` 依次为 n、1、$n+1$、0；区间 L..R 用 $f(R)\oplus f(L-1)$，$L=0$ 要单独处理。

$0-1 \mathrm{Trie}$ 与线性基是后续选学；本章不把它们作为已有完整教程。

程序输入 $0\le n\le 20$ 及 $0\le \mathrm{mask}<2^{n}$，按递减顺序逐行输出所有子集，包括空集。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int n;
    unsigned long long mask;
    cin >> n >> mask;
    unsigned long long sub = mask;
    while (true)
    {
        cout << sub << '\n';
        if (sub == 0)
        {
            break;
        }
        sub = (sub - 1) & mask;
    }
}
```

教学样例输入（不是平台官方样例）：

```text
4 10
```

输出：

```text
10
8
2
0
```

## 补充实现

固定大小子集的独立程序：输入 $0\le k\le n\le 20$，按掩码数值递增逐行输出。$k=0$ 单独输出0，否则每次Gosper跳到下一个恰有k个1的状态。时间 $O(C(n,k))$、额外空间 $O(1)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int n, k;
    cin >> n >> k;
    if (k == 0)
    {
        cout << 0 << '\n';
        return 0;
    }
    unsigned long long limit = 1ULL << n;
    unsigned long long mask = (1ULL << k) - 1;
    while (mask < limit)
    {
        cout << mask << '\n';
        unsigned long long c = mask & (0ULL - mask);
        unsigned long long r = mask + c;
        mask = r | (((r ^ mask) >> 2) / c);
    }
}
```

教学样例输入：

```text
4 2
```

输出：

```text
3
5
6
9
10
12
```

## CF2269D — What a SauSaGe! It's All Meat

[官方题面](https://codeforces.com/problemset/problem/2269/D)。数组元素均在 $[0,15]$，可以反复对相邻两个元素同时异或 $3k$，其中 $1\le k\le5$。求能使多少个元素同时成为 3 的倍数，并支持单点赋值；每次询问的操作只是假设，不会写回数组。$2\le n\le2\times10^5$，$0\le q\le2\times10^5$，各测试的 $n$ 之和、$q$ 之和分别不超过 $2\times10^5$。与 Div. 1 的 CF2268B 同题。

> [!tip]- 提示一：从四位二进制找不变量
> 合法掩码为 $3,6,9,12,15$，它们各有偶数个 1。异或这些掩码后，每个位置的二进制 1 的数量的奇偶性如何变化？注意 5、10 也有偶数个 1，却不是 3 的倍数。

> [!tip]- 提示二：上界还需要可达性证明
> 任意一个位置可以达标，不代表全部这样的位点能同时达标：全数组异或也保持不变。尝试选择一组目标值，同时满足逐点奇偶性不变和全局异或不变，再从左到右用相邻操作实现。

> [!example]- 详细题解
> **源码维护什么。** `check(x)` 返回 `__builtin_popcount(x)%2==0`，`ans` 是满足这一条件的位置数。初始化逐项累加；更新 $(p,x)$ 时，先减去 `check(a[p-1])`，再加 `check(x)`，最后把原数组该位置改为 `x`。它维护的是最多能达标的位置数，不是当前数组中已经被 3 整除的个数。
>
> **不变量给出上界。** 令 $\pi(x)$ 为四位二进制中 1 的数量模 2，则 $\pi(x\oplus y)=\pi(x)\oplus\pi(y)$。所有合法掩码的 $\pi$ 都为 0，每个位置的奇偶性保持不变。目标集合 $S=\{0,3,6,9,12,15\}$ 也全部为偶数奇偶性，所以奇数位置永远不能达标，答案至多为源码统计的数量。
>
> **哪些相邻异或可以组合出来。** 所有偶数奇偶性的四位值为 $H=\{0,3,5,6,9,10,12,15\}$。其中 0 对应不操作，5 可用先异或 3 再异或 6 实现，10 可用 3 与 9 实现，其余非零值本来就是合法掩码。因此，可以对相邻两点同时异或任意 $h\in H$。
>
> **目标状态的可达条件。** 假设选定目标数组 $b$，每个 $a_i\oplus b_i$ 都属于 $H$，且 $\bigoplus a_i=\bigoplus b_i$。从左到右处理 $i=1\ldots n-1$：把当前第 $i$ 项与目标 $b_i$ 的差异作为掩码，同时异或第 $i,i+1$ 项，第 $i$ 项就固定为目标值，之后不再改它。当前值的奇偶性始终不变，所以每个掩码都在 $H$ 中。前 $n-1$ 项完成后，全局异或相等自动保证最后一项也正确。这给出了充分性，而不只是逐点可达的猜测。
>
> **构造同时达标的目标。** 若存在奇数奇偶性的位置 $j$，先把所有偶数位置的目标设为 0，其他奇数位置保持原值，再把这些被清零的原值的异或合入第 $j$ 项。这个修正量仍在 $H$ 中，不会改变第 $j$ 项的奇偶性，却补回了全局异或，因而全部偶数位置可以同时归零。
>
> 若全部位置都是偶数奇偶性，令 $X=\bigoplus a_i\in H$。当 $X\in S$ 时，选择目标 $(X,0,\ldots,0)$ 即可；$X=5$ 时选 $(3,6,0,\ldots,0)$，$X=10$ 时选 $(3,9,0,\ldots,0)$。两种例外也满足全局异或为 $X$，每个目标都在 $S$ 中。题目保证 $n\ge2$，所以这些目标总能放下。结合可达性结论，上界一定能达到，源码判定成立。
>
> **手算与更新。** 对 $(5,0)$，两个位置的 `check` 都为 1，虽然目前只有一个 3 的倍数，但同时异或 3 得 $(6,3)$，可以让两个位置都达标。若把第 2 项赋值为 1，`ans` 从 2 变成 $2-1+0=1$；原数组用于后续查询的状态是 $(5,1)$，不能保留上一次假设操作后的 $(6,3)$。从 $(5,1)$ 对两点先异或 3、再异或 6，可得 $(0,4)$，恰好一个位置达标。
>
> **复杂度与边界。** 四位整数的 `popcount` 为常数开销，初始化 $O(n)$，每次更新 $O(1)$，总时间 $O(n+q)$，保存原数组用 $O(n)$ 空间。0 的 1 的数量是 0，因此应计入；$q=0$ 仍要输出初始答案；题面位置从 1 开始，源码使用 `p-1`。不能把“偶数个 1”误写成“数值为偶数”，也不能推广到题目范围外：若只有一个位置且值为 5，就没有可用的相邻操作。

## CF2225D Exceptional Segments

[官方题面](https://codeforces.com/contest/2225/problem/D)

序列1..N中，统计包含位置X且异或和为0的区间数，模998244353；N≤10¹⁸。

> [!tip]- 提示一
> 前缀异或P(t)按t mod4分类，只有哪些值会在不同t上重复？

> [!tip]- 提示二
> 重复的两类是P=0与P=1，分别在X两侧数前缀个数再相乘。
>
> 复习：[[06数学/01-位运算与子集枚举]]。

> [!example]- 详细题解
> **建模与源码主线。** P(t)依次为t、1、t+1、0，对应余数0、1、2、3，另P(0)=0。源码count0(T)=(T+1)/4+1含空前缀，count1(T)=(T+3)/4；左前缀范围0..X−1，右前缀范围X..N，分别按0、1的两类数量相乘后求和。T<0返回0。
>
> **正确性与适用条件。** 除0、1外的前缀值均不在不同下标重复：余0项给4的倍数，余2项给3模4，彼此也不相等。因此所有相同前缀配对都落在两类。左右范围精确编码l≤X≤r，区间与(l−1,r)配对一一对应。
>
> **手算与边界。** N=7,X=6，合法区间为[1,7]、[4,7]，左侧前缀0和3的值均0，右侧只有7为0，得到2。忽略P(0)会漏掉从1开始的区间。
>
> **实际复杂度与实现。** 每测试O(1)时间、O(1)空间。两侧原始计数乘积可达10³⁶，必须分别取模后再乘；使用官方998244353，且右侧数量须减去左侧累计数。
