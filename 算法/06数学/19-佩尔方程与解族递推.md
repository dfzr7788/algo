## 平方限制转为整数方程

标准佩尔方程 $x^{2}-Dy^{2}=1$，D 为正非平方整数，求正整数解。D 为平方时只能因式分解得到平凡解 $(\pm 1,0)$。枚举 y 检查 $Dy^{2}+1$ 是否为平方可能非常慢：$D=61$ 的基本解为 $(1766319049,226153980)$，D 很小也不能保证解小。

基本解可由 $\sqrt D$ 的连分数收敛分数寻找。用统一循环节长度 L 表示：L 偶数时 $(p_{L-1},q_{L-1})$ 为基本解；L 奇数时到 $(p_{2L-1},q_{2L-1})$。负方程 $x^{2}-Dy^{2}=-1$ 有解当且仅当 L 奇数。需要高精度保存 p,q，不能直接用 double 检验是否为完全平方。

## 由基本解生成更大的解

设基本解 $(u,v)$，将 $x+y\sqrt D$ 乘 $u+v\sqrt D$：新解 $x'=ux+Dvy$，$y'=vx+uy$。范数乘法保持 $x'^{2}-Dy'^{2}=1$，标准正解由 $(u+v\sqrt D)^{k}$ 生成。第二阶递推为 $x_{k+2}=2u x_{k+1}-x_k$，y 也相同。$D=2$、$(u,v)=(3,2)$，依次 $(3,2)$、$(17,12)$、$(99,70)$。

以下教学程序只计算 $D=2$ 的第 k 个正解的模值，不冒充任意 D 基本解求解器。$0\le k\le 10^{18}$、$1\le \mathrm{mod}\le 10^{9}$，$k=0$ 输出平凡解 $(1,0)$。将数对当成 $a+b\sqrt 2$，乘法为 $(ac+2bd,ad+bc)$，满足结合律，可直接二进制幂，$O(\log (k+1))$ 时间、$O(1)$ 空间；结果是余数，并非原始大整数解。

## 保留原应用记录：两种平方约束

原记录要求第 k 个正 n，使 $2n+1=a^{2}$、$3n+9=b^{2}$。消元 $2b^{2}-3a^{2}=15$，推出 $b=3c$，得到 $a^{2}-6c^{2}=-5$。取标准单位 $5+2\sqrt 6$，映射为 $(x',y')=(5x+12y,2x+5y)$，同一解族 $x_{j+2}=10x_{j+1}-x_j$。

原两族分别从 $(1,1)$、$(7,3)$ 生成。排除 $x=1$ 对应 $n=0$ 后，x 顺序为 7、17、71、169、703、1673，n 为 24、144、2520、14280、247104、1399464。原 $k=114514$、$\mathrm{mod}=223999$ 的记录保留，2 的逆元直接为 112000（只需模数为奇数，不依赖它是否素数）。

## 扩展选读：为何两族覆盖所有正解

对 $x^{2}-6y^{2}=-5$，乘共轭单位得到 $x'=5x-12y$，$y'=5y-2x$。$x/y=\sqrt{6-5/y^{2}}$，随 y 增大趋近 $\sqrt 6$。$y\ge 5$ 时，$12/5<x/y<\sqrt6<5/2$：左侧来自 $6-5/y^2>144/25$。因此 $x'=5x-12y>0$、$y'=5y-2x>0$；又因 $x/y>2$，有 $y'<y$。y=4 时要求 $x^2=91$，没有整数解，所以每个非种子正整数解都能下降，最终到达 $y\le 3$。逐个检查只有 $(1,1)$ 与 $(7,3)$，得到两族完整性。每族严格递增，且 $(1,1)\to (17,7)$ 位于 $(7,3)$ 与其下一项 $(71,29)$ 之间，正系数转移保持逐项严格大小，所以两族交替。广义 $x^{2}-Dy^{2}=C$ **不能**只找到一个种子就宣称生成全部解。

原题 [洛谷 P16682](https://www.luogu.com.cn/problem/P16682) 本次未能读取官方题面，不能把记录称为已核验平台题解。原线性递推思路有效但固定 k，下面另给可运行的标准教学版本，不声称平台 AC。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

long long mod_value;

void multiply_pair(long long a, long long b, long long c, long long d, long long &x, long long &y)
{
    x = (a * c % mod_value + 2 * (b * d % mod_value)) % mod_value;
    y = (a * d % mod_value + b * c % mod_value) % mod_value;
}

int main()
{
    long long k;
    cin >> k >> mod_value;
    long long x = 1 % mod_value;
    long long y = 0;
    long long a = 3 % mod_value;
    long long b = 2 % mod_value;
    while (k > 0)
    {
        if (k & 1)
        {
            long long nx, ny;
            multiply_pair(x, y, a, b, nx, ny);
            x = nx;
            y = ny;
        }
        long long na, nb;
        multiply_pair(a, b, a, b, na, nb);
        a = na;
        b = nb;
        k >>= 1;
    }
    cout << x << ' ' << y << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
3 1000000000
```

输出：

```text
99 70
```

## 补充实现

小范围D的基本解：输入 $2\le D\le 100$，非平方时用连分数渐近分数依次检验，输出最小正解x y；平方输出SQUARE。此范围基本解可放入long long，检验平方先用`__int128`；m、d、a表示连分数状态。D更大时基本解可能超出64位，应换为高精度，不能直接扩大输入范围。每步保持 $m_{\mathrm{next}}=da-m$、$d_{\mathrm{next}}=(D-m_{\mathrm{next}}^{2})/d$、$a_{\mathrm{next}}=\operatorname{floor}((a0+m_{\mathrm{next}})/d_{\mathrm{next}})$；收敛分数 $P=a\cdot\mathrm{P\_prev}+\mathrm{P\_prevprev}$，Q同理。$D=2$ 依次 $1/1$（范数−1）、$3/2$（范数1），取第一组正范数1。若连分数周期L，至多约2L项找到解；在声明范围内 $O(L)$ 次固定宽度运算；推广到高精度时，乘法代价取决于解的位数，不能按常数时间宣称 $O(\log D)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    long long D;
    cin >> D;
    long long a0 = sqrt((long double)D);
    while ((a0 + 1) * (a0 + 1) <= D)
    {
        a0++;
    }
    while (a0 * a0 > D)
    {
        a0--;
    }
    if (a0 * a0 == D)
    {
        cout << "SQUARE\n";
        return 0;
    }
    long long m = 0;
    long long d = 1;
    long long a = a0;
    long long p2 = 0;
    long long p1 = 1;
    long long q2 = 1;
    long long q1 = 0;
    while (true)
    {
        long long p = a * p1 + p2;
        long long q = a * q1 + q2;
        if ((__int128)p * p - (__int128)D * q * q == 1)
        {
            cout << p << ' ' << q << '\n';
            break;
        }
        p2 = p1;
        p1 = p;
        q2 = q1;
        q1 = q;
        m = d * a - m;
        d = (D - m * m) / d;
        a = (a0 + m) / d;
    }
}
```

教学样例输入：

```text
61
```

输出：

```text
1766319049 226153980
```

## 补充实现：原平方约束记录

保留原平方约束记录的线性递推程序，改为输入 $1\le k\le 1000000$，输出第k个合法n的余数mod223999。原固定 $k=114514$ 可直接作为输入。奇数k在7,71,...族的第 $(k-1)/2$ 项，偶数k在1,17,...族的第k/2项，使用 $x_{\mathrm{next}}=10x-x_{\mathrm{prev}}$。最后 $n=(x^{2}-1)/2$ 乘常数112000，不依赖模数素性。$O(k)$ 时间、$O(1)$ 空间；更大k可按前章二阶递推矩阵加速。此为原模型程序，本次未核验平台题面、未提交。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    long long k;
    cin >> k;
    const long long MOD = 223999;
    long long previous, current, steps;
    if (k % 2 == 1)
    {
        previous = 7;
        current = 71;
        steps = (k - 1) / 2;
    }
    else
    {
        previous = 1;
        current = 17;
        steps = k / 2;
    }
    long long x = previous;
    if (steps >= 1)
    {
        x = current;
        for (long long i = 2; i <= steps; i++)
        {
            long long next = (10 * current - previous + MOD) % MOD;
            previous = current;
            current = next;
        }
        x = current;
    }
    cout << (x * x % MOD - 1 + MOD) % MOD * 112000 % MOD << '\n';
}
```

教学样例输入：

```text
3
```

输出：

```text
2520
```
