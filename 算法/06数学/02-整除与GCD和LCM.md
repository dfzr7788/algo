## 从枚举公因子到辗转相除

$\gcd (a,b)$ 是同时整除 a、b 的最大非负整数。约定 $\gcd (0,b)=b$，$\gcd (0,0)=0$。枚举 $1\ldots \min (a,b)$ 太慢。写 $a=qb+r$，公因子同时整除 a、b 当且仅当同时整除 b、r，所以 `gcd(a,b)=gcd(b,a%b)`。余数一直缩小，到 $b=0$ 时剩余 a 就是答案。

例如 48、18：$48=2\times 18+12$，$18=1\times 12+6$，$12=2\times 6+0$，答案 6。LCM 为 $48/6\times 18=144$。先除后乘减小中间值，**仍需检查最终结果是否溢出**。有零时 LCM 约定为 0，不能先算 $0/\gcd (0,0)$。

程序输入 $0\le a,b\le 10^{18}$，输出 gcd、lcm；lcm 超出 signed long long 输出 OVERFLOW。负数可先取绝对值，但 LLONG_MIN 的绝对值不能用 long long 表示，此模板不接受负数。

## 正确性、复杂度与应用

每轮保持公因子集合不变，终止时 a 的全部公因子就是原集合。两轮内余数至少减半，时间 $O(\log (\min (a,b)+1))$，空间 $O(1)$，按固定宽度整数基本操作计。C++17 `<numeric>` 提供 std::gcd、std::lcm，但 std::lcm 不会自动为不可表示结果做安全检查。

gcd 满足结合律、交换律和幂等性，静态区间可用 [[07-ST表与静态区间查询]]，有修改可用 [[09-线段树]]。一次 gcd 本身有对数代价，不能同时在复杂度表中把它算作常数和对数。

设 $d[i]=a[i]-a[i-1]$，区间 gcd 为 $\gcd (a[l],d[l+1],\ldots,d[r])$。区间加不会改变内部差分，只改变边界。需要另外维护 $a[l]$，不能只查差分区间。

对**正整数**序列，前缀 gcd 每次严格改变都会至少减半，所以不同值 $O(\log \mathrm{maxA})$。若允许前导零，可能先从 0 增长到正数，不能笼统声称非增。

从质因数指数看，gcd 取各指数最小值，lcm 取最大值；当 lcm 很大时可以维护指数而不是实际乘积。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

long long gcd_value(long long a, long long b)
{
    while (b != 0)
    {
        long long r = a % b;
        a = b;
        b = r;
    }
    return a;
}

int main()
{
    long long a, b;
    cin >> a >> b;
    long long g = gcd_value(a, b);
    cout << g << '\n';
    if (a == 0 || b == 0)
    {
        cout << 0 << '\n';
        return 0;
    }
    __int128 result = (__int128)(a / g) * b;
    if (result > LLONG_MAX)
    {
        cout << "OVERFLOW\n";
    }
    else
    {
        cout << (long long)result << '\n';
    }
}
```

教学样例输入（不是平台官方样例）：

```text
48 18
```

输出：

```text
6
144
```
