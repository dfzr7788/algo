## 先把点与向量区分

点 A=(ax,ay)、B=(bx,by)，向量 AB=(bx−ax,by−ay)。点表示位置，向量表示位移；判断相对方向时先减去同一个起点。长度平方为 x²+y²，比开方更精确；需要实际距离时再 sqrt。

点积 u·v=uxvx+uyvy=|u||v|cosθ。正、零、负分别为锐角、垂直、钝角（零向量无角度）。投影参数 t=((P−A)·(B−A))/|B−A|²，直线最近点 A+t(B−A)；线段则先把 t 截断到 0..1。A=B 时线段是一个点，分母为 0，需单独取 |P−A|。

二维叉积 u×v=uxvy−uyvx=|u||v|sinθ，是平面有向面积的标量表示。绝对值等于平行四边形面积；以 AB、AC 为两边的三角形面积为 |AB×AC|/2。cross(A,B,C)>0 表示 C 在有向 AB 左侧，<0 右侧，=0 共线。

## 手算与实现范围

A=(0,0)、B=(4,0)、C=(1,2)：AB·AC=4，AB×AC=8，C 在左侧，三角形面积 4；C 投影到 AB 的参数 4/16=1/4，投影点 (1,0)，距离 2。

程序输入三点 A B C 的整数坐标，|坐标|<=10^9，输出点积、叉积，以及 C 到闭线段 AB 的距离（6 位小数）。差最大 2×10^9，点积与叉积绝对值上界 8×10^18，long long 可容纳；超过范围需要 __int128，先扩宽再相减与相乘。距离计算用 long double，浮点结果按误差比较。

## 正确性与复杂度

点积给出平行方向的分量，叉积给出垂直方向与方向符号；每个操作 O(1)，空间 O(1)。整数输入判断方向不用 EPS；浮点输入建议使用与尺度匹配的容差，但排序比较器不要使用破坏严格弱序的“差小于 EPS 就相等”。求角度 acos 时先排除零向量，再将余弦截断到 [−1,1]。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Point
{
    long long x, y;
};

long long cross(Point a, Point b, Point c)
{
    return (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x);
}

int main()
{
    Point a, b, c;
    cin >> a.x >> a.y >> b.x >> b.y >> c.x >> c.y;
    long long ux = b.x - a.x;
    long long uy = b.y - a.y;
    long long vx = c.x - a.x;
    long long vy = c.y - a.y;
    long long dot = ux * vx + uy * vy;
    cout << dot << ' ' << cross(a, b, c) << '\n';
    long double length_squared = (long double)ux * ux + (long double)uy * uy;
    long double t = 0;
    if (length_squared > 0)
    {
        t = (long double)dot / length_squared;
        t = max(0.0L, min(1.0L, t));
    }
    long double dx = c.x - (a.x + t * ux);
    long double dy = c.y - (a.y + t * uy);
    cout << fixed << setprecision(6) << sqrt(dx * dx + dy * dy) << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
0 0 4 0 1 2
```

输出：

```text
4 8
2.000000
```
