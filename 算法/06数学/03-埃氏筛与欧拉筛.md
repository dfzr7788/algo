| 欧拉筛与最小质因子 | 4/10 | 9/10 | 线性生成并支持批量分解 |

评分为本项目学习路线的主观建议，统一口径见 [[00-数学]]。

## 为什么需要批量筛选

对每个 $2\ldots N$ 的数分别试除，粗略需要 $O(N\sqrt N)$。筛法共享“某素数的倍数为合数”的结果。埃氏筛只在尚未标记的 p 上划去 $p^{2},p^{2}+p$,...；小于 $p^{2}$ 的倍数已经包含更小质因子。

$N=12$：$p=2$ 划去 4、6、8、10、12；$p=3$ 划去 9、12。最后留下 2、3、5、7、11。0、1 都不是素数。

欧拉筛维护递增 primes 与 $spf[x]$（最小质因子）。外层到 i，内层依次产生 $i\times p$，并在 p 整除 i 时立即停止。比如 $i=6$：$p=2$ 生成 12 后停止，不能继续用 3 生成 18；18 应由 $i=9,p=2$ 生成。

## 两种实现与输入约定

下面同一程序提供两个具名筛函数。输入 mode n q，$\mathrm{mode}=1$ 使用埃氏筛，$\mathrm{mode}=2$ 使用欧拉筛；接下来 q 个 k 查询第 k 小素数，k 从 1 开始且合法。$1\le n\le 1000000$，$q\ge 0$。固定数组占用按 MAXN 分配，欧拉筛 spf 可继续用于分解 n：反复取 $spf[n]$ 并除去它。

教学容量没有覆盖 [洛谷 P3383](https://www.luogu.com.cn/problem/P3383) 的 $n=10^{8}$。平台输入也没有 mode，提交时选一种筛并按内存上限重新分配；可用埃氏位图减少空间，不能直接照搬小容量。

## 正确性与复杂度

埃氏筛不会划去素数；任何合数都有不超过其平方根的质因子，因此一定被划去。时间 $O(N \log \log N)$，空间 $O(N)$。欧拉筛每个合数 x 唯一由 $(x/spf[x],spf[x])$ 生成，时间 $O(N)$，空间 $O(N)$。两者都应清空多测状态，不能混用一份含义相反的 isprime 标记。

## 扩展选读：复杂度证明

埃氏筛总标记次数由 $N\sum (1/p)$ 控制，求和仅遍历素数。素数倒数和为 $\log \log N+O(1)$，由此得到复杂度；把整数调和级数证明当成该结论会只得到较弱的 $O(N \log N)$。欧拉筛的 break 保证 $p\le spf[i]$，所以生成数的最小质因子就是 p，唯一性与覆盖性同时成立。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000000 + 5;
bool composite[MAXN];
int spf[MAXN];
vector<int> primes;

void eratosthenes(int n)
{
    fill(composite, composite + n + 1, false);
    primes.clear();
    composite[0] = true;
    composite[1] = true;
    for (int p = 2; p <= n / p; p++)
    {
        if (!composite[p])
        {
            for (int x = p * p; x <= n; x += p)
            {
                composite[x] = true;
            }
        }
    }
    for (int x = 2; x <= n; x++)
    {
        if (!composite[x])
        {
            primes.push_back(x);
        }
    }
}

void euler_sieve(int n)
{
    fill(spf, spf + n + 1, 0);
    primes.clear();
    for (int i = 2; i <= n; i++)
    {
        if (spf[i] == 0)
        {
            spf[i] = i;
            primes.push_back(i);
        }
        for (int p : primes)
        {
            if (p > n / i)
            {
                break;
            }
            spf[i * p] = p;
            if (i % p == 0)
            {
                break;
            }
        }
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int mode, n, q;
    cin >> mode >> n >> q;
    if (mode == 1)
    {
        eratosthenes(n);
    }
    else
    {
        euler_sieve(n);
    }
    while (q--)
    {
        int k;
        cin >> k;
        cout << primes[k - 1] << '\n';
    }
}
```

教学样例输入（不是平台官方样例）：

```text
2 12 3
1
3
5
```

输出：

```text
2
5
11
```
