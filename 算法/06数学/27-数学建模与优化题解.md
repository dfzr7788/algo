## 原扫描线记录：最少单点加一操作

自编教学模型（原笔记未提供平台题号）：长度 n 的 A，只能单点 +1，要求每个相邻和 $(A_i+x_i+A_{i+1}+x_{i+1}) \bmod M=B_i$，求最少总操作 $\sum xi$。$n\ge 1$，$1\le M\le 10^{9}$，$0\le A_i,B_i<M$。

令 $C_i=(B_i-A_i-A_{i+1}) \bmod M$，则 $xi+x(i+1)\equiv C_i$。确定 $x1=v$ 后，后续全部余数确定；每个 xi 都取 $0\ldots M-1$ 的代表即可，因为多加 M 不改变条件，只增成本。

令 $S1=0$，$S(i+1)=(C_i-S_i) \bmod M$，则奇数项 $xi=(S_i+v) \bmod M$，偶数项 $xi=(S_i-v) \bmod M$。目标 $f(v)=\sum xi$，$v\in 0\ldots M-1$。暴力全部 v 再递推为 $O(nM)$。

## 真正变化的是值的跳跃，斜率不变

没有取模跳跃时，每个奇数项斜率 +1、偶数项 −1，总斜率 $d=\text{奇数项数}-\text{偶数项数}$，即 `n%2`。奇数项 $S>0$ 时，在 $u=M-S$ 突降 M；偶数项在 $u=S+1<M$ 时突升 M。不是“这些事件会改变斜率”，而是固定斜率基础上叠加跳变。

初值 $f(0)=\sum S_i$，扫到 v 时 $f(v)=f(0)+dv+\text{累计已发生跳变量}$。收集相同 u 的事件一起更新；对 $u-1$ 先检查旧累计值，再对 u 检查新累计值，还检查 $v=0$ 与 $M-1$。这样即使以后推广到负斜率，也不会漏区间末端。

例 $n=3$、$M=5$、$A=[0,0,0]$、$B=[1,2]$，$C=[1,2]$、$S=[0,1,1]$。$f(0)=2$，总斜率 1；在 $u=2$ 偶数项突升 5，在 $u=4$ 第三项突降 5。$f(v)$ 依次 2、3、9、10、6，最小 2，取 $x=[0,1,1]$。事件算法只访问关键端点。

完整程序输入 n M、n 个 A、$n-1$ 个 B，$n\le 200000$，输出最少操作数；$n=1$ 时无需约束，答案 0。long long 可容纳 $n(M-1)$，不存超大初始 A。每项至多一个事件，排序 $O(n \log n)$，扫描 $O(n)$，空间 $O(n)$。分段一次函数在线性区间极值出现在端点，事件覆盖全部跳变，所以候选充分。

## 第二个模型：从步数方程到排列选择

[AtCoder ABC145 D Knight](https://atcoder.jp/contests/abc145/tasks/abc145_d) 只允许 $(1,2)$ 与 $(2,1)$ 两种移动，目标 $(X,Y)$。设各走 a、b 次，$a+2b=X$、$2a+b=Y$，得到 $a=(2Y-X)/3$、$b=(2X-Y)/3$。只有 a,b 是非负整数时可达，路线数 $C(a+b,a)$；两种移动顺序任意且每步向正坐标，没额外障碍约束。

$X=Y=3$ 得 $a=b=1$，两种顺序，答案 2；$X=1,Y=1$ 给分数，无解。这里不是普通棋盘八方向马步，不能用 gcd 或棋盘搜索模型替代。组合数实现见 [[10-组合数与Lucas定理]]，按该题上界选阶乘表。本节是完整推导，下面程序只对应第一道自编模型。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

long long normalize(long long value, long long mod)
{
    value %= mod;
    if (value < 0)
    {
        value += mod;
    }
    return value;
}

int main()
{
    int n;
    long long mod;
    cin >> n >> mod;
    vector<long long> a(n), s(n, 0);
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
    }
    for (int i = 0; i + 1 < n; i++)
    {
        long long b;
        cin >> b;
        long long c = normalize(b - a[i] - a[i + 1], mod);
        s[i + 1] = normalize(c - s[i], mod);
    }
    long long initial = 0;
    vector<pair<long long, long long>> events;
    for (int i = 0; i < n; i++)
    {
        initial += s[i];
        if (i % 2 == 0)
        {
            if (s[i] > 0)
            {
                events.push_back({mod - s[i], -mod});
            }
        }
        else if (s[i] + 1 < mod)
        {
            events.push_back({s[i] + 1, mod});
        }
    }
    sort(events.begin(), events.end());
    long long slope = n % 2;
    long long jump = 0;
    long long answer = initial;
    int index = 0;
    while (index < (int)events.size())
    {
        long long u = events[index].first;
        answer = min(answer, initial + slope * (u - 1) + jump);
        while (index < (int)events.size() && events[index].first == u)
        {
            jump += events[index].second;
            index++;
        }
        answer = min(answer, initial + slope * u + jump);
    }
    answer = min(answer, initial + slope * (mod - 1) + jump);
    cout << answer << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
3 5
0 0 0
1 2
```

输出：

```text
2
```
