## 为什么重复重排不必模拟K次

一个置换 p 把 1..n 的位置一一映射到自身。沿 p 不断跳，最终构成互不相交的循环。若循环为 [1,3,2]，走 k 次只需位移 k%3。所有循环总长度 n，所以 O(n) 就能得到 p^k，无需 O(nk) 模拟或 O(n log k) 倍增。

例 p=[3,1,2,5,4]，分解为 (1 3 2)(4 5)。k=2 时位置映射为 [2,3,1,4,5]。程序输出每个起始位置经 k 次后的位置；如果题目问物品最终在哪，使用这个前向映射；若问最终数组某位置放什么，必须按题意逆向取值。

## 群、环与域的必要概念

群要求运算封闭、结合、有单位元、每个元素有逆元；有交换律称阿贝尔群。单位元、逆元唯一，消去律成立，(ab)^{-1}=b^{-1}a^{-1}。置换在复合下形成群，复合顺序需先约定，不总交换。

子群是同一运算下仍成群的非空子集，可用 ab^{-1}∈H 判定。有限群子群陪集将群划分成等大小组，由 |G|=|H|[G:H] 得拉格朗日定理。有限情况下说“封闭子集就是子群”必须有非空条件。循环群由一个元素的幂生成，有限循环群同构于模 n 加法群。

环要求加法成阿贝尔群，乘法结合且满足分配律；本文使用带单位元的交换环时会另说明。域的非零元素都有乘法逆元，素数模构成域，合数模如 6 有 2×3=0 的零因子，所以消元和模除法不能无条件做。

## 群作用为何与等价关系有关

旋转/翻转是位置置换，作用于所有染色方案。某个方案能通过允许变换得到的全部方案叫轨道，也就是一个等价类。变换必须包含单位元、可复合、可逆，不能只列出部分旋转后就随意取平均。下一章利用所有变换的不动点计数轨道。

程序输入 1<=n<=200000、0<=k<=10^18 和合法置换 p[1..n]，输出 p^k[1..n]。时间 O(n)、空间 O(n)。一个长 L 循环最少 L−1 次**任意两位置交换**可拆成单点，因此全排列任意交换排序最少 n−循环数；限制交换距离时这个结论不适用。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200000 + 5;
int p[MAXN], answer[MAXN];
bool visited[MAXN];

int main()
{
    int n;
    long long k;
    cin >> n >> k;
    for (int i = 1; i <= n; i++)
    {
        cin >> p[i];
    }
    for (int start = 1; start <= n; start++)
    {
        if (visited[start])
        {
            continue;
        }
        vector<int> cycle;
        int u = start;
        while (!visited[u])
        {
            visited[u] = true;
            cycle.push_back(u);
            u = p[u];
        }
        int length = cycle.size();
        int shift = k % length;
        for (int i = 0; i < length; i++)
        {
            answer[cycle[i]] = cycle[(i + shift) % length];
        }
    }
    for (int i = 1; i <= n; i++)
    {
        cout << answer[i] << (i == n ? '\n' : ' ');
    }
}
```

教学样例输入（不是平台官方样例）：

```text
5 2
3 1 2 5 4
```

输出：

```text
2 3 1 4 5
```
