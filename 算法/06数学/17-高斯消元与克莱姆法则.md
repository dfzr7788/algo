## 把多个等式转为逐列消元

线性方程组 Ax=b 可以用行初等变换求解：交换两行、非零倍乘一行、把一行的倍数加到另一行，都不改变解集。比起代入消去复杂表达式，增广矩阵把所有系数同步记录下来。

对 x+y=3、2x−y=0，增广行 [1,1,3]、[2,−1,0]。第二行减第一行两倍，得 [0,−3,−6]，解 y=2，再回代 x=1。程序每列在剩余行选绝对值最大的主元，减小浮点误差，归一化后消去其他所有行，称 Gauss-Jordan 形式。

## 没有主元不代表立刻无解

例如 x+y=2、2x+2y=4，消去后 0=0，只有一个独立约束，存在自由变量，无穷多解。若右边改成 5，会得到 0=1，无解。需要分别记录 row（已找到主元的行数）和 col，不能假定第 i 列总有主元。

消元后若某行全部系数为 0、常数非零，则无解；否则秩<n 则无穷多解，秩=n 则唯一解。浮点 EPS 是工程判定，本模板面向数值尺度适中的竞赛输入，病态方程不能保证任意高精度。

## 克莱姆法则与行列式

方阵 A 的 det(A)≠0 时唯一解 x_i=det(A_i)/det(A)，A_i 用 b 替换第 i 列。二元方程 a1x+b1y=c1、a2x+b2y=c2：D=a1b2−a2b1，Dx=c1b2−c2b1，Dy=a1c2−a2c1，分别除 D。D=0 时必须另判无解或多解。

克莱姆法则不是必然阶乘复杂度：按排列展开行列式才有 n! 项，消元求一次行列式 O(n³)，分别算 n+1 次可到 O(n⁴)，仍不如直接 O(n³) 消元。求 det 时交换行使符号翻转，上三角对角乘积即 det；有行归一化还需记录除掉的系数。模素数消元用逆元替代浮点除法，合数模不一定可用；异或方程可在 GF(2) 中用 XOR 消元。

输入 1<=n<=100，随后 n 行 n+1 个实数，建议 |系数|、|常数|<=10^4，输出 NO SOLUTION、INFINITE SOLUTIONS 或 UNIQUE 与各变量（6 位小数）。[洛谷 P3389](https://www.luogu.com.cn/problem/P3389) 无唯一解统一输出 No Solution，唯一解两位小数，需调整输出。时间 O(n³)、空间 O(n²)。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100 + 5;
const long double EPS = 1e-10L;
long double a[MAXN][MAXN], answer[MAXN];
int where_column[MAXN];

int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j <= n; j++)
        {
            cin >> a[i][j];
        }
    }
    fill(where_column, where_column + n, -1);
    int row = 0;
    for (int col = 0; col < n && row < n; col++)
    {
        int pivot = row;
        for (int i = row + 1; i < n; i++)
        {
            if (abs(a[i][col]) > abs(a[pivot][col]))
            {
                pivot = i;
            }
        }
        if (abs(a[pivot][col]) < EPS)
        {
            continue;
        }
        for (int j = 0; j <= n; j++)
        {
            swap(a[row][j], a[pivot][j]);
        }
        long double divisor = a[row][col];
        for (int j = col; j <= n; j++)
        {
            a[row][j] /= divisor;
        }
        for (int i = 0; i < n; i++)
        {
            if (i == row)
            {
                continue;
            }
            long double coefficient = a[i][col];
            for (int j = col; j <= n; j++)
            {
                a[i][j] -= coefficient * a[row][j];
            }
        }
        where_column[col] = row;
        row++;
    }
    for (int i = row; i < n; i++)
    {
        if (abs(a[i][n]) > EPS)
        {
            cout << "NO SOLUTION\n";
            return 0;
        }
    }
    if (row < n)
    {
        cout << "INFINITE SOLUTIONS\n";
        return 0;
    }
    cout << "UNIQUE\n";
    for (int col = 0; col < n; col++)
    {
        answer[col] = a[where_column[col]][n];
        if (abs(answer[col]) < EPS)
        {
            answer[col] = 0;
        }
        cout << fixed << setprecision(6) << answer[col] << '\n';
    }
}
```

教学样例输入（不是平台官方样例）：

```text
2
1 1 3
2 -1 0
```

输出：

```text
UNIQUE
1.000000
2.000000
```
