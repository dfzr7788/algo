## 用最短围栏理解凸包

凸包是包含全部输入点的最小凸集合。拉紧包围点集的绳子，接触的是外层顶点；内部点不影响边界。直接检查每两点是否形成支撑边会花 O(n³)，先按 x 再 y 排序，可只维护上下两条边界。

下凸壳从左向右扫，新点加入时看末尾 A、B 与新点 C 的转向。如果 cross(A,B,C)<=0，不是严格左转，就删掉 B；继续直到严格左转，再放入 C。上壳反向同理。弹出不代表扔掉了整个点集，而是 B 对当前下边界不再是必要凸顶点。

例 (0,0),(1,1),(2,0)：加入第三点叉积为 −2，弹出 (1,1)，下壳只剩两端；反向扫描时 (1,1) 属于上壳，最终三角形边界。重复坐标先去重。若全部共线，<=0 策略只保留两端。

## 模板约定与正确性

输入 1<=n<=200000、|整数坐标|<=10^9，输出凸包顶点数，再输出逆时针顺序的顶点，从字典序最小点开始，不重复首点。struct 仅表达几何点，核心逻辑为普通函数，没有矩阵/算法类封装。

点被弹出是因为不满足凸性或处于边界共线上，无需作为极点保留。每个点每次壳扫描入栈、出栈各至多一次，排序 O(n log n)、扫描 O(n)，空间 O(n)。若要求保留所有边界共线点，用 <0 弹出并额外处理全共线和上下壳重复，不能只换符号就宣称所有退化情况已解决。

[洛谷 P2742](https://www.luogu.com.cn/problem/P2742) 求围栏长度，输入实数（最多两位小数）、输出两位周长；本程序输出整数顶点集合，需精确解析成放大 100 倍的整数或使用浮点几何，再沿边计算距离，并不是相同输入输出模板。旋转卡壳、半平面交为后续选学。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Point
{
    long long x, y;
};

long long cross(Point a, Point b, Point c)
{
    return (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x);
}

bool less_point(Point a, Point b)
{
    return a.x < b.x || (a.x == b.x && a.y < b.y);
}

bool same_point(Point a, Point b)
{
    return a.x == b.x && a.y == b.y;
}

vector<Point> convex_hull(vector<Point> points)
{
    sort(points.begin(), points.end(), less_point);
    points.erase(unique(points.begin(), points.end(), same_point), points.end());
    if (points.size() <= 1)
    {
        return points;
    }
    vector<Point> hull;
    for (Point p : points)
    {
        while (hull.size() >= 2 && cross(hull[hull.size() - 2], hull.back(), p) <= 0)
        {
            hull.pop_back();
        }
        hull.push_back(p);
    }
    int lower_size = hull.size();
    for (int i = (int)points.size() - 2; i >= 0; i--)
    {
        Point p = points[i];
        while ((int)hull.size() > lower_size && cross(hull[hull.size() - 2], hull.back(), p) <= 0)
        {
            hull.pop_back();
        }
        hull.push_back(p);
    }
    hull.pop_back();
    return hull;
}

int main()
{
    int n;
    cin >> n;
    vector<Point> points(n);
    for (Point &p : points)
    {
        cin >> p.x >> p.y;
    }
    vector<Point> hull = convex_hull(points);
    cout << hull.size() << '\n';
    for (Point p : hull)
    {
        cout << p.x << ' ' << p.y << '\n';
    }
}
```

教学样例输入（不是平台官方样例）：

```text
5
0 0
2 0
2 2
0 2
1 1
```

输出：

```text
4
0 0
2 0
2 2
0 2
```
