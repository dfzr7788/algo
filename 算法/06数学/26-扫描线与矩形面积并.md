## 从逐格枚举到窄条累计

求轴对齐矩形并面积，不能直接相加面积，因为重叠会重复；坐标达 10^9 时也无法涂满每个格子。按 x 扫描，每个矩形的左边产生 +1 覆盖事件，右边产生 −1 事件。在相邻事件坐标之间，活跃矩形不变，面积增加 Δx×当前 y 方向并覆盖长度。

两个矩形 [0,2)×[0,2)、[1,3)×[1,3)：x 在 0..1 时覆盖长 2，1..2 时并区间 [0,3) 长 3，2..3 时长 2，总面积 2+3+2=7。覆盖两次的交叠区间只计一次。

## 离散化索引与节点维护

收集所有 y 端点排序去重为 ys[0..q−1]。线段树叶子代表的是 q−1 个基本区间 `[ys[i],ys[i+1])`，不是 q 个坐标点。节点 [l,r] 的真实跨度是 ys[r+1]−ys[l]，长度不能用 r−l+1。

cover[node] 记录直接完整覆盖此节点的活跃矩形数。cover>0 时本节点长度就是整个跨度，子节点信息暂时不影响结果；cover=0 时叶长为 0，非叶长为左右子节点之和。对子区间的独立更新仍存子节点状态，因此当前 cover 回到 0 时可立即恢复；这里无需普通 range-add 线段树那种下传 cover。

左边事件更新端点索引 L..R−1，右边同区间 −1。同 x 的事件分组：先用旧覆盖算从 prev_x 到 x 的面积，再一起修改，避免对零宽条作复杂解释。矩形坐标必须满足 x1<x2、y1<y2；程序允许退化矩形并略过。

## 完整程序与复杂度

输入 0<=n<=100000，每行四个 0<=坐标<=10^9，且 x1<=x2、y1<=y2；输出并面积，n=0 为 0。固定树容量 8×100000+20，因为最多 2n−1 个基本区间，树需要约四倍容量。面积<=10^18，用 long long。

排序与每次更新 O(log n)，总 O(n log n)、空间 O(n)。覆盖长度归纳满足“不漏、不重复”的并长度，窄条面积积分得到结果。对应 [洛谷 P5490](https://www.luogu.com.cn/problem/P5490) 同模型，官方要求 n>=1 且矩形严格非退化。

原“扫描线”笔记是相邻同余增量的事件优化，已保留并补齐程序在 [[27-数学建模与优化题解]]；扫描线并不限于几何。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXTREE = 8 * 100000 + 20;
int cover[MAXTREE];
long long covered_length[MAXTREE];
vector<long long> ys;

struct Event
{
    long long x, y1, y2;
    int delta;
};

bool event_less(Event a, Event b)
{
    return a.x < b.x;
}

void pull(int node, int left, int right)
{
    if (cover[node] > 0)
    {
        covered_length[node] = ys[right + 1] - ys[left];
    }
    else if (left == right)
    {
        covered_length[node] = 0;
    }
    else
    {
        covered_length[node] = covered_length[node * 2] + covered_length[node * 2 + 1];
    }
}

void update(int node, int left, int right, int ql, int qr, int delta)
{
    if (ql <= left && right <= qr)
    {
        cover[node] += delta;
        pull(node, left, right);
        return;
    }
    int middle = (left + right) / 2;
    if (ql <= middle)
    {
        update(node * 2, left, middle, ql, qr, delta);
    }
    if (qr > middle)
    {
        update(node * 2 + 1, middle + 1, right, ql, qr, delta);
    }
    pull(node, left, right);
}

int main()
{
    int n;
    cin >> n;
    vector<Event> events;
    for (int i = 0; i < n; i++)
    {
        long long x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        if (x1 == x2 || y1 == y2)
        {
            continue;
        }
        events.push_back({x1, y1, y2, 1});
        events.push_back({x2, y1, y2, -1});
        ys.push_back(y1);
        ys.push_back(y2);
    }
    if (events.empty())
    {
        cout << 0 << '\n';
        return 0;
    }
    sort(ys.begin(), ys.end());
    ys.erase(unique(ys.begin(), ys.end()), ys.end());
    sort(events.begin(), events.end(), event_less);
    long long answer = 0;
    long long previous = events[0].x;
    int index = 0;
    while (index < (int)events.size())
    {
        long long x = events[index].x;
        answer += (x - previous) * covered_length[1];
        while (index < (int)events.size() && events[index].x == x)
        {
            Event e = events[index];
            int l = lower_bound(ys.begin(), ys.end(), e.y1) - ys.begin();
            int r = lower_bound(ys.begin(), ys.end(), e.y2) - ys.begin() - 1;
            update(1, 0, (int)ys.size() - 2, l, r, e.delta);
            index++;
        }
        previous = x;
    }
    cout << answer << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
2
0 0 2 2
1 1 3 3
```

输出：

```text
7
```
