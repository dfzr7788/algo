## 为什么直接相加会重复

统计至少满足一个条件的对象时，相加各条件数量会重复计算交集。两个集合为 $\lvert A\cup B\rvert =\lvert A\rvert +\lvert B\rvert -\lvert A\cap B\rvert$；三个集合再加回三者交集。一般公式为

$$
\left|\bigcup_{i=1}^k A_i\right|=\sum_{\varnothing\ne S\subseteq\{1,\ldots,k\}}(-1)^{|S|+1}\left|\bigcap_{i\in S}A_i\right|.
$$

一个对象恰在 t 个集合中，系数为 $C(t,1)-C(t,2)+\ldots=1$，由 $(1-1)^{t}=0$ 得到，解释了为什么恰好只算一次。

## 整除计数的交集是LCM

$1\ldots N$ 中被 d 整除有 $\operatorname{floor}(N/d)$ 个。被 2 或 3 整除，在 $N=10$ 时为 $5+3-1=7$；交集要求同时整除，所以除以 $\operatorname{lcm} (2,3)=6$，不能总用乘积。如果有 2 和 4，交集除以 4 而非 8。

程序读 $1\le N\le 10^{18}$、$1\le k\le 20$，再 k 个 $1\le d_i\le 10^{18}$，输出至少能被一个 $d_{i}$ 整除的整数数量。枚举非空子集，累积 lcm；如果 $\mathrm{next\_lcm}>N$，则交集为空，直接停止。用 `current/g > N/d` 判断，避免乘法先溢出。结果中间累加用 `__int128`。

时间 $O(k2^{k} \log D)$，空间 $O(k)$；整数 gcd 代价计入 $\log D$。k 很大时指数算法不适用，删去重复和被其他 d 整除的冗余条件能减小实际 k，但不是多项式保证。

## 有界分配的典型变体

要求 $\sum xi=s$ 且 $0\le xi\le u_i$。全体非负解为 $C(s+r-1,r-1)$。令违例集合 $A_{i}$ 为 $xi\ge u_i+1$，对子集 S 将对应变量平移 $u_i+1$，交集数量为 $C(s-\sum _{i\in S}(u_i+1)+r-1,r-1)$，余量负时为 0。统计“全部不违例”从空集起容斥，符号 $(-1)^{\lvert S\rvert}$。本节给模型公式，组合数计算沿用前章条件。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    long long n;
    int k;
    cin >> n >> k;
    long long d[20];
    for (int i = 0; i < k; i++)
    {
        cin >> d[i];
    }
    __int128 answer = 0;
    for (int mask = 1; mask < (1 << k); mask++)
    {
        long long multiple = 1;
        bool empty = false;
        int selected = 0;
        for (int i = 0; i < k; i++)
        {
            if ((mask >> i) & 1)
            {
                selected++;
                long long g = gcd(multiple, d[i]);
                if (multiple / g > n / d[i])
                {
                    empty = true;
                    break;
                }
                multiple = multiple / g * d[i];
            }
        }
        if (!empty)
        {
            long long count = n / multiple;
            answer += selected % 2 == 1 ? count : -count;
        }
    }
    cout << (long long)answer << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
10 2
2 3
```

输出：

```text
7
```
