## 从枚举互质到排除质因子的倍数

φ(n) 是 1..n 中与 n 互质的数的个数，φ(1)=1。一个数不互质，当且仅当它被 n 的某个质因子整除。排除这些倍数，用容斥得到

$$
\varphi(n)=n\prod_{p\mid n}\left(1-\frac1p\right).
$$

例 n=12，排除 2、3 的倍数，12−6−4+2=4，留下 1、5、7、11。实现每种质因子只处理一次，`ans=ans/p*(p−1)` 保持精确整数，不用浮点乘比例。

## 批量计算与指数周期

线性筛中 φ(1)=1，素数 i 的 φ=i−1；生成 i×p 时，若 p|i，新增相同质因子指数，φ(ip)=pφ(i) 并 break；否则新增不同质因子，φ(ip)=(p−1)φ(i)。沿用前章 spf 与 primes 的循环即可得到 O(N) 时间、O(N) 空间的整表。

欧拉定理：gcd(a,m)=1 时 a^{φ(m)}≡1 mod m。互质条件下指数可直接对 φ(m) 取模。例 3^100 mod 10，φ(10)=4，降为 3^0=1。

不互质时不能直接取模：2^4 mod 8=0，φ(8)=4，2^{4%4}=1 是错的。当 b>=φ(m) 时，可用扩展公式 a^b≡a^{b%φ(m)+φ(m)} mod m；当 b<φ(m) 时保留 b。m=1 直接输出 0。

若指数用十进制字符串表示，一边算 b%φ，一边用饱和变量 min(b,φ) 判断是否达到阈值，不能只保存余数。以下程序读 |a|<=10^9、1<=m<=10^9 和非空非负指数字符串（可含前导零），输出余数。

## 正确性、复杂度与应用

互质部分利用群的周期，非互质部分在指数达到阈值后，各质数幂模数中的非互质因子已归零，再由 CRT 合并得到扩展公式。完整严密证明属于扩展选读，阈值条件是使用前提。

试除求 φ 为 O(√m)，扫描 L 位指数 O(L)，快速幂 O(log m)，空间 O(L)。筛 φ 用于许多互质求和；φ 是积性函数，仅在 gcd(a,b)=1 时 φ(ab)=φ(a)φ(b)。还有 Σ_{d|n}φ(d)=n，可按 gcd(k,n) 将 1..n 分类证明。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

long long phi_value(long long n)
{
    long long result = n;
    for (long long p = 2; p <= n / p; p++)
    {
        if (n % p == 0)
        {
            result = result / p * (p - 1);
            while (n % p == 0)
            {
                n /= p;
            }
        }
    }
    if (n > 1)
    {
        result = result / n * (n - 1);
    }
    return result;
}

long long power_mod(long long a, long long b, long long mod)
{
    a %= mod;
    if (a < 0)
    {
        a += mod;
    }
    long long result = 1 % mod;
    while (b > 0)
    {
        if (b & 1)
        {
            result = (__int128)result * a % mod;
        }
        a = (__int128)a * a % mod;
        b >>= 1;
    }
    return result;
}

int main()
{
    long long a, mod;
    string exponent;
    cin >> a >> mod >> exponent;
    if (mod == 1)
    {
        cout << 0 << '\n';
        return 0;
    }
    long long phi = phi_value(mod);
    long long remainder = 0;
    long long capped = 0;
    for (char ch : exponent)
    {
        int digit = ch - '0';
        remainder = (remainder * 10 + digit) % phi;
        capped = min(phi, capped * 10 + digit);
    }
    long long reduced = remainder;
    if (capped == phi)
    {
        reduced += phi;
    }
    cout << power_mod(a, reduced, mod) << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
2 8 0004
```

输出：

```text
0
```

## 补充实现

线性筛φ的独立程序，输入1<=N<=1000000，逐行输出φ(1)..φ(N)。spf数组从进程零状态开始，单组输入；多测应清空。时间O(N)、空间O(N)。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000000 + 5;
int phi[MAXN], spf[MAXN];
vector<int> primes;

int main()
{
    int n;
    cin >> n;
    phi[1] = 1;
    for (int i = 2; i <= n; i++)
    {
        if (spf[i] == 0)
        {
            spf[i] = i;
            phi[i] = i - 1;
            primes.push_back(i);
        }
        for (int p : primes)
        {
            if (p > n / i)
            {
                break;
            }
            spf[i * p] = p;
            if (i % p == 0)
            {
                phi[i * p] = phi[i] * p;
                break;
            }
            phi[i * p] = phi[i] * (p - 1);
        }
    }
    for (int i = 1; i <= n; i++)
    {
        cout << phi[i] << '\n';
    }
}
```

教学样例输入：

```text
6
```

输出：

```text
1
1
2
2
4
2
```
