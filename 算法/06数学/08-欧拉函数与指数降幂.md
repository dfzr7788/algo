## 从枚举互质到排除质因子的倍数

$\varphi (n)$ 是 $1\ldots n$ 中与 n 互质的数的个数，$\varphi (1)=1$。一个数不互质，当且仅当它被 n 的某个质因子整除。排除这些倍数，用容斥得到

$$
\varphi(n)=n\prod_{p\mid n}\left(1-\frac1p\right).
$$

例 $n=12$，排除 2、3 的倍数，$12-6-4+2=4$，留下 1、5、7、11。实现每种质因子只处理一次，`ans=ans/p*(p−1)` 保持精确整数，不用浮点乘比例。

## 批量计算与指数周期

线性筛中 $\varphi (1)=1$，素数 i 的 $\varphi =i-1$；生成 $i\times p$ 时，若 p|i，新增相同质因子指数，$\varphi (ip)=p\varphi (i)$ 并 break；否则新增不同质因子，$\varphi (ip)=(p-1)\varphi (i)$。沿用前章 spf 与 primes 的循环即可得到 $O(N)$ 时间、$O(N)$ 空间的整表。

欧拉定理：$\gcd (a,m)=1$ 时 $a^{\varphi (m)}\equiv 1 \bmod m$。互质条件下指数可直接对 $\varphi (m)$ 取模。例 $3^{100} \bmod 10$，$\varphi (10)=4$，降为 $3^{0}=1$。

不互质时不能直接取模：$2^{4} \bmod 8=0$，$\varphi (8)=4$，`2^{4%4}=1` 是错的。当 $b\ge \varphi (m)$ 时，可用扩展公式 `a^b≡a^{b%φ(m)+φ(m)} mod m`；当 $b<\varphi (m)$ 时保留 b。$m=1$ 直接输出 0。

若指数用十进制字符串表示，一边算 `b%φ`，一边用饱和变量 $\min (b,\varphi )$ 判断是否达到阈值，不能只保存余数。以下程序读 $\lvert a\rvert \le 10^{9}$、$1\le m\le 10^{9}$ 和非空非负指数字符串（可含前导零），输出余数。

## 正确性、复杂度与应用

互质部分利用群的周期，非互质部分在指数达到阈值后，各质数幂模数中的非互质因子已归零，再由 CRT 合并得到扩展公式。完整严密证明属于扩展选读，阈值条件是使用前提。

试除求 $\varphi$ 为 $O(\sqrt m)$，扫描 L 位指数 $O(L)$，快速幂 $O(\log m)$，空间 $O(L)$。筛 $\varphi$ 用于许多互质求和；$\varphi$ 是积性函数，仅在 $\gcd (a,b)=1$ 时 $\varphi (ab)=\varphi (a)\varphi (b)$。还有 $\sum _{d|n}\varphi (d)=n$，可按 $\gcd (k,n)$ 将 $1\ldots n$ 分类证明。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

long long phi_value(long long n)
{
    long long result = n;
    for (long long p = 2; p <= n / p; p++)
    {
        if (n % p == 0)
        {
            result = result / p * (p - 1);
            while (n % p == 0)
            {
                n /= p;
            }
        }
    }
    if (n > 1)
    {
        result = result / n * (n - 1);
    }
    return result;
}

long long power_mod(long long a, long long b, long long mod)
{
    a %= mod;
    if (a < 0)
    {
        a += mod;
    }
    long long result = 1 % mod;
    while (b > 0)
    {
        if (b & 1)
        {
            result = (__int128)result * a % mod;
        }
        a = (__int128)a * a % mod;
        b >>= 1;
    }
    return result;
}

int main()
{
    long long a, mod;
    string exponent;
    cin >> a >> mod >> exponent;
    if (mod == 1)
    {
        cout << 0 << '\n';
        return 0;
    }
    long long phi = phi_value(mod);
    long long remainder = 0;
    long long capped = 0;
    for (char ch : exponent)
    {
        int digit = ch - '0';
        remainder = (remainder * 10 + digit) % phi;
        capped = min(phi, capped * 10 + digit);
    }
    long long reduced = remainder;
    if (capped == phi)
    {
        reduced += phi;
    }
    cout << power_mod(a, reduced, mod) << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
2 8 0004
```

输出：

```text
0
```

## 补充实现

线性筛 $\varphi$ 的独立程序，输入 $1\le N\le 1000000$，逐行输出 $\varphi (1)\ldots \varphi (N)$。spf数组从进程零状态开始，单组输入；多测应清空。时间 $O(N)$、空间 $O(N)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000000 + 5;
int phi[MAXN], spf[MAXN];
vector<int> primes;

int main()
{
    int n;
    cin >> n;
    phi[1] = 1;
    for (int i = 2; i <= n; i++)
    {
        if (spf[i] == 0)
        {
            spf[i] = i;
            phi[i] = i - 1;
            primes.push_back(i);
        }
        for (int p : primes)
        {
            if (p > n / i)
            {
                break;
            }
            spf[i * p] = p;
            if (i % p == 0)
            {
                phi[i * p] = phi[i] * p;
                break;
            }
            phi[i * p] = phi[i] * (p - 1);
        }
    }
    for (int i = 1; i <= n; i++)
    {
        cout << phi[i] << '\n';
    }
}
```

教学样例输入：

```text
6
```

输出：

```text
1
1
2
2
4
2
```

## 扩展选读：不互质降幂为什么要达到阈值

设 $m>1$，$T=\varphi(m)$、$b\ge T$，令 $b'=b\bmod T+T$。证明 $a^b\equiv a^{b'}\pmod m$。把 m 分成互质的质数幂 $p^e$，分别讨论，再用 CRT 合并。

- 若 p 不整除 a，则 a 在模 $p^e$ 下可逆。欧拉定理的周期 $\varphi(p^e)=p^{e-1}(p-1)$ 整除 $\varphi(m)$。b−b' 是 T 的整数倍，所以两幂在这个质数幂下同余。
- 若 p 整除非零 a，设 a 含 p 的指数为 v≥1。当指数 c 满足 cv≥e 时，$a^c$ 被 $p^e$ 整除。因为 $T\ge\varphi(p^e)\ge e$，而 b、b' 都至少 T，两边都为 0。这里 $p^{e-1}(p-1)\ge e$ 可由最小的 p=2 检查：$2^{e-1}\ge e$（e≥1）。a=0 且 b≥T≥1 时两边也为 0。

所有质数幂下同余，所以模 m 同余。阈值 T 是统一的充分条件，未必最小；不要据此说 a 的幂从指数 0 就有周期 T。例 a=2,m=8：指数 1、2、3 分别为 2、4、0，开始几项还未归零。b=4 时必须还原为指数 4，而不是余数 0。

当 `b<T` 时保留原指数；b=0 的空乘积为 1，不能为了“不互质”无条件加 T。m=1 的答案直接为 0。程序的 capped 恰好区分这两段：例如指数字符串 0004、T=4 得 capped=4；0000 则为 0，前导零不改变阈值判断。

试除只读至当前剩余数的平方根，至多 $O(\sqrt m)$ 次；扫描 L 个数字每位只维护 capped 和余数，为 $O(L)$；还原指数小于 2T≤2m，快速幂为 $O(\log(m+1))$。保存输入字符串占 $O(L)$，其余迭代状态为 $O(1)$。
