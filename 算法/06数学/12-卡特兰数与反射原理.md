## 相同总数为什么不等于合法括号数

n 对括号一共有 $C(2n,n)$ 种排列，但合法要求每个前缀左括号不少于右括号。$n=2$ 时总共 6 种，只有 (()) 与 ()() 合法。将左括号看作高度 +1，右括号 −1，问题变为从 0 返回 0 且不跌到负高度的路径。

按第一个左括号对应的右括号划分，内侧有 i 对，外侧有 $n-1-i$ 对，两者独立，得到 $H_0=1$，$H_n=\sum_{i=0}^{n-1}H_iH_{n-1-i}$。$n=3$ 的三部分为 $1\times 2+1\times 1+2\times 1=5$。计数有序左右子树的二叉树、凸多边形三角剖分等也可转成同一递推。

## 从非法路径构造一个双射

对首次到达 −1 的前缀翻转所有步方向，原非法路径（n 次上升、n 次下降）转为 $n+1$ 次上升、$n-1$ 次下降的路径，可逆，因此非法数量 $C(2n,n-1)$。

$$
H_n=\binom{2n}{n}-\binom{2n}{n-1}=\frac{1}{n+1}\binom{2n}{n}.
$$

闭式包含除法，模数下先检查 $n+1$ 可逆；差值式加 Pascal 可用于任意正模数。下面递推程序不需要除法。

输入 $0\le n\le 2000$、$1\le \mathrm{mod}\le 10^{9}$，输出 Hn mod mod，`H[0]=1%mod`。时间 $O(n^{2})$、空间 $O(n)$。大 n 时改用差值组合数，素数模且 $2n<p$ 才能直接用阶乘表。

## 应用与边界

$H_0=1$ 表示空结构的唯一方案，不是 0。不要把任意含 n 个节点的无序树都算作 Hn：递推对应可区分左右且允许空子树的有序二叉树。

[洛谷 P1641](https://www.luogu.com.cn/problem/P1641) 有 n 个 1 和 m 个 0，$n\ge m$，要求所有前缀 1 不少于 0，是反射原理的应用题；$n=m$ 才退化为卡特兰数。一般答案 $C(n+m,m)-C(n+m,m-1)$，该题模数为 20100403，需按题目范围另配组合数实现。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 2000 + 5;
long long h[MAXN];

int main()
{
    int n;
    long long mod;
    cin >> n >> mod;
    h[0] = 1 % mod;
    for (int length = 1; length <= n; length++)
    {
        for (int inside = 0; inside < length; inside++)
        {
            h[length] = (h[length] + h[inside] * h[length - 1 - inside]) % mod;
        }
    }
    cout << h[n] << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
3 1000000007
```

输出：

```text
5
```
