## 模意义下如何除法

m>=2，ax≡1 mod m 时 x 是 a 的逆元，存在当且仅当 gcd(a,m)=1。例 3 mod 11 的逆元是 4；2 mod 6 不存在逆元。扩欧求 ax+my=1 并标准化 x 即可；素数 p 下非零 a 则有 a^{p−1}=1，因此逆元为 a^{p−2}。

费马方法需要已知 p 为素数；“题目用了常见模数”不能替代条件。扩欧只要互质即可，甚至合数模数 8 下 3 的逆元为 3。

## 批量递推的推导与边界

写 p=qi+r，模 p 有 r≡−qi。两边乘 i^{-1}r^{-1} 得 i^{-1}≡−q r^{-1}。所以 inv[1]=1，inv[i]=(p−p/i)×inv[p%i] mod p。要求 p 是素数且 1<=i<p，这样 r 非零且 r<i；i=p 时逆元不存在，递推到 inv[0] 是错误的。

p=7：inv[2]=(7−3)inv[1]=4，inv[3]=(7−2)inv[1]=5，inv[4]=(7−1)inv[3]=2。每项都乘回原数核对为 1。

阶乘逆元是**整个 i! 的逆元**，不是 inv[i]。先算 fac[0..N]，只用一次快速幂求 ifac[N]，再根据 ifac[i−1]=ifac[i]×i 倒推。需要 N<p，否则 fac[N]=0 无逆元。总预处理 O(N+log p)，查询 O(1)。顺便可得 inv[i]=ifac[i]fac[i−1]。

## 实现与复杂度

完整程序读 a m（|a|<=10^9，2<=m<=10^9），用扩欧输出最小非负逆元，不存在输出 −1。单次 O(log m)，递归空间 O(log m)。费马实现直接调用前章 power_mod(a,p−2,p)，不用复制另一套不处理边界的快速幂。

线性逆元的独立程序在下方补充；阶乘倒推程序见 [[10-组合数与Lucas定理]]；素数由调用方保证。多测重建数组。模数改变时旧预处理全部失效。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

long long extended_gcd(long long a, long long b, long long &x, long long &y)
{
    if (b == 0)
    {
        x = 1;
        y = 0;
        return a;
    }
    long long x1, y1;
    long long g = extended_gcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

int main()
{
    long long a, mod, x, y;
    cin >> a >> mod;
    a %= mod;
    if (a < 0)
    {
        a += mod;
    }
    long long g = extended_gcd(a, mod, x, y);
    if (g != 1)
    {
        cout << -1 << '\n';
    }
    else
    {
        x %= mod;
        if (x < 0)
        {
            x += mod;
        }
        cout << x << '\n';
    }
}
```

教学样例输入（不是平台官方样例）：

```text
3 11
```

输出：

```text
4
```

## 补充实现

这是独立的线性逆元程序，输入n,p（1<=n<=3000000，n<p<20000528，p保证素数），逐行输出inv[1..n]，与P3811相同输入输出。时间O(n)、空间O(n)。阶乘倒推完整实现见下一组合数章的build_factorials，勿混淆两类数组。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 3000000 + 5;
long long inverse[MAXN];

int main()
{
    int n;
    long long p;
    cin >> n >> p;
    inverse[1] = 1;
    for (int i = 2; i <= n; i++)
    {
        inverse[i] = (p - p / i) * inverse[p % i] % p;
    }
    for (int i = 1; i <= n; i++)
    {
        cout << inverse[i] << '\n';
    }
}
```

教学样例输入：

```text
3 7
```

输出：

```text
1
4
5
```
