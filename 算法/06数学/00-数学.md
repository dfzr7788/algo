## 算法选择与条件

| 需求 | 优先方法 | 必须核对 |
|---|---|---|
| 单个数分解 | 试除 / MR与Rho | 数值大小、多测总量、期望而非最坏保证 |
| 大量小值素数查询 | 筛法与SPF | 数组容量、实际内存、初始化 |
| 模除法 | 扩欧或费马逆元 | 分母互质，费马额外要求素数模 |
| 组合数 | Pascal / 阶乘 / Lucas | 模数素性、n是否小于模数 |
| 交叠条件计数 | 容斥 | 交集公式、条件数量的指数复杂度 |
| 恒定线性转移 | 矩阵幂 | 状态充分、乘法顺序与单位元 |
| 恰K步最优代价 | Min-Plus | 不得免费加0自环，代价上界 |
| 染色等价 | Burnside | 允许哪些对称、群大小是否可逆 |
| 几何关系 | 点积叉积 | 整数溢出、闭端点与退化情况 |
