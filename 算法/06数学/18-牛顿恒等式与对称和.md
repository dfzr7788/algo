## 避免枚举所有三元组

设 e_k 是选 k 个不同下标的数相乘再求和，e0=1；P_k=Σx_i^k 是幂和。暴力 e3 要 O(n³)，但 P1、P2、P3 可以一次扫描同时获得。牛顿恒等式连接两者：

$$
k e_k=\sum_{i=1}^k(-1)^{i-1}e_{k-i}P_i.
$$

特别地 e1=P1，e2=(P1²−P2)/2，e3=(e2P1−e1P2+P3)/3=(P1³−3P1P2+2P3)/6。e4=(e3P1−e2P2+e1P3−P4)/4。

例 x={1,2,3}：P1=6、P2=14、P3=36，e2=11，e3=(66−84+36)/3=6。下标不同是关键，x 值重复也允许分别选取。

在树上按分支大小 s_i 选三个人，每个分支最多一个，方案数就是 e3。原联系见 [[17-树上中位点与三元组计数]]。固定 k 的幂和扫描 O(nk)，恢复前 K 项 O(K²)；不能把任意 k 的求幂都笼统说成 O(n)。

## 无逆元时如何计算

模 2 或 3 下，除以 2、3 不合法。替代是处理一个数 x 后，对 j 从 K 倒到 1，执行 e[j]+=x×e[j−1]。新方案按是否选 x 分类，倒序确保每个 x 只用一次。这是 ∏(1+x_i t) 的系数动态规划，O(nK) 时间、O(K) 空间，无需除法。

程序输入 0<=n<=200000、0<=K<=100、1<=mod<=10^9，随后 n 个 |x_i|<=10^9，输出 e_K mod mod。n<K 时自然输出 0；K=0 输出 1%mod，负数需标准化。若在整数中用三阶闭式，立方和中间表达式可能溢出，至少按范围评估 __int128。

## 扩展选读：保留原母函数推导

令 F(t)=∏(1−x_i t)=Σ(-1)^k e_k t^k。形式幂级数中 F 的常数项为 1，因此可逆，不需要引入实数收敛条件。对数导数恒等式为

$$
\frac{F'(t)}{F(t)}=-\sum_i\frac{x_i}{1-x_it}=-\sum_{j\ge1}P_jt^{j-1}.
$$

乘回 F(t)，比较 t^{k−1} 系数：左边为 (-1)^k k e_k，右边为 −Σ_{i=1}^k(-1)^{k−i}e_{k−i}P_i，化简符号得到正文公式。x_i=0 时并不存在根 1/x_i，所以不应把 F 统一描述成“根全为 1/x_i 的多项式”。

## 完整 C++17 教学程序

```cpp
#include <bits/stdc++.h>
using namespace std;

long long e[100 + 5];

int main()
{
    int n, k;
    long long mod;
    cin >> n >> k >> mod;
    e[0] = 1 % mod;
    for (int i = 0; i < n; i++)
    {
        long long x;
        cin >> x;
        x %= mod;
        if (x < 0)
        {
            x += mod;
        }
        for (int j = k; j >= 1; j--)
        {
            e[j] = (e[j] + x * e[j - 1]) % mod;
        }
    }
    cout << e[k] << '\n';
}
```

教学样例输入（不是平台官方样例）：

```text
3 3 1000000007
1 2 3
```

输出：

```text
6
```
