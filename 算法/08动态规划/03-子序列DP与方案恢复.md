前置：[[02-线性DP与网格DP]]、[[07-二分]]。子序列可以跳过元素但不能改变顺序；子串、子段要求连续。

## 用途：保留顺序中的最优关系

最长严格上升子序列 LIS 处理一个序列中的递增选择；最长公共子序列 LCS 处理两个序列中的顺序匹配。枚举所有子序列需要指数时间，而“最后位置”或“两个前缀”足以合并大量选择。LIS 的 $O(n \log n)$ 优化有特定单调性质，不能直接替代任意序列 DP。

## LIS：从结尾状态到最小尾值

二次转移：`f[i]=1+max(f[j])`，条件为 $j<i$ 且 $a[j]<a[i]$；没有前驱时为 1。答案是 $\max f[i]$，并不一定是 $f[n]$。时间 $O(n^{2})$，空间 $O(n)$。

优化时定义 `tail[len]` 为已处理元素中，长度 len 的严格上升子序列的最小末尾。同长度的尾越小，未来可接的元素越多；其他历史可丢弃。tail 按长度严格递增，因此可找第一个 $\ge x$ 的位置替换为 x；若不存在就延长长度。

`3 1 2 2 4` 的 tail 依次为 `[3]→[1]→[1,2]→[1,2]→[1,2,4]`。第二个 2 只替换，不延长。求最长不下降子序列时改找第一个 $>x$（upper_bound）。tail 最终内容通常不是原数组的一条合法答案，例如 `2 3 1` 最终 tail 为 `[1,3]`，顺序在原数组中不成立。

完整教学程序：单组 n 和 n 个整数，`1<=n<=200000`，值使用 long long；$\mathrm{MAXN}=200005$，tail 为 1 下标，输出严格 LIS 长度。时间 $O(n \log n)$，空间 $O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 200000 + 5;
long long tail[MAXN];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int length = 0;
    for (int i = 1; i <= n; i++)
    {
        long long x;
        cin >> x;
        int pos = lower_bound(tail + 1, tail + length + 1, x) - tail;
        tail[pos] = x;
        length = max(length, pos);
    }
    cout << length << '\n';
}
```

教学输入（自设，非官方样例）：

```text
5
3 1 2 2 4
```

输出：

```text
3
```

若需恢复 LIS，另存每个长度当前尾的原位置 $pos[len]$，当前元素的前驱为修改前的 $pos[len-1]$，从最终 $pos[\mathrm{length}]$ 逆推；不能直接打印 tail。相等元素与多个最优方案的取舍需自行约定。

## LCS：二维前缀与回溯

`dp[i][j]` 为 s 的前 i 个字符与 t 的前 j 个字符的 LCS 长度，空前缀均为 0。若末字符不同，最优匹配至少舍弃一个末字符，取上方、左方最大值；相同时可以取左上+1。即便还有其他最优选择，这个匹配分支也能达到最优长度。

例如 `s="ab"`、`t="acb"`，表如下。行列分别表示前缀长度。

| s前缀 / t前缀 | 空 | a | ac | acb |
|---|---:|---:|---:|---:|
| 空 | 0 | 0 | 0 | 0 |
| a | 0 | 1 | 1 | 1 |
| ab | 0 | 1 | 1 | 2 |

从 $(2,3)$ 的 b 匹配到 $(1,2)$，此处不匹配向左到 $(1,1)$，收集 a，倒序即 ab。每次移动都保持当前 dp 最优值，匹配时才收字符。程序相等直接走对角；不等时上方优先，只保证任意一条 LCS，不保证字典序最小。

完整程序对应 [AtCoder DP F — LCS](https://atcoder.jp/contests/dp/tasks/dp_f)：单组两个非空字符串，长度均 $\le 3000$，输出任意 LCS（可能为空，此时输出空行）。dp 1 下标，字符串 0 下标，$\mathrm{MAXN}=3005$，int 存长度。时间 $O(nm)$，空间 $O(nm)$，固定数组约 36 MB。只要长度可滚动到 $O(m)$，但这里保留全表用于恢复。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 3000 + 5;
int dp[MAXN][MAXN];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    string t;
    cin >> s >> t;
    int n = s.size();
    int m = t.size();
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= m; j++)
        {
            if (s[i - 1] == t[j - 1])
            {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            }
            else
            {
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    string answer;
    int i = n;
    int j = m;
    while (i > 0 && j > 0)
    {
        if (s[i - 1] == t[j - 1])
        {
            answer += s[i - 1];
            i--;
            j--;
        }
        else if (dp[i - 1][j] >= dp[i][j - 1])
        {
            i--;
        }
        else
        {
            j--;
        }
    }
    reverse(answer.begin(), answer.end());
    cout << answer << '\n';
}
```

教学输入（自设，非官方样例）：

```text
ab
acb
```

输出：

```text
ab
```

## 变体与错误

最长公共子串必须连续，不匹配时设 0，答案在所有格子中取最大；不能照搬 LCS 的上左最大。编辑距离加入删除、插入、替换三类最后操作，空前缀初值分别为 i 与 j，这是独立的代价模型。统计不同 LCS 字符串数量也不能简单把等值分支相加，重复字符会导致重复计数。

练习：先独立写 $O(n^{2}) LIS$ 和只求长度的 LCS，再与本程序比较。平台与自编变式见 [[14-动态规划题单]]。

## ABC439E Kite

[官方题面](https://atcoder.jp/contests/abc439/tasks/abc439_e)

从 N 条连接两条平行线的线段中，选出最多条互不相交的线段；端点相接也算相交。N≤2×10⁵。

> [!tip]- 提示一
> 按下端点排序后，选中的上端点必须满足什么次序？

> [!tip]- 提示二
> 相同下端点的线段不能同选。怎样安排次关键字，让严格 LIS 自动排除它们？
>
> 复习：[[08动态规划/03-子序列DP与方案恢复]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码的 `per::operator<` 先按 a 递增，同 a 时按 b 递减。随后 `tails[len-1]` 维护长度为 len 的递增子序列的最小末尾，对每个 b 用 `lower_bound` 找到第一个不小于它的末尾并替换，找不到则延长。直接枚举两两连接的 DP 需 O(N²)，保留每个长度最有利的末尾后，每次只需二分。
>
> **正确性与适用条件。** 两个下端点严格递增时，线段不相交等价于上端点也严格递增。同 a 的 b 被降序排列，严格递增子序列至多选其中一个；`lower_bound` 又禁止两个相等 b 同时延长。相同长度下末尾越小，未来可接的元素越多，因此替换末尾不会损失最优答案。
>
> **手算与边界。** 线段 (1,3)、(1,2)、(2,4) 排序后 b=(3,2,4)，tails 依次为 (3)、(2)、(2,4)，答案 2；若同 a 时升序，会错误地把三条全选。
>
> **实际复杂度与实现。** 排序和二分总时间 O(N log N)，容器空间 O(N)。输出 tails 的长度；tails 本身不一定是一组真实选择。

## P8776 最长不下降子序列

[官方题面](https://www.luogu.com.cn/problem/P8776)

把连续K个数改成同一任意整数，使最长不下降子序列尽可能长，求其长度。

> [!tip]- 提示一
> 可令修改块K项全进入答案，连接左侧末值≤右侧首值的子序列。

> [!tip]- 提示二
> 前后缀LNDS配合二分，但修改块不能与右侧首项重叠。
>
> 复习：[[08动态规划/03-子序列DP与方案恢复]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码right倒序求rights[j]，表示以a[j]开头的LNDS长度；正序d维护已越过块左边界的前缀LNDS最小末尾。固定右侧首项a[j]，在d里二分可接≤a[j]的长度left，候选left+K+rights[j]；无右侧则len+K。
>
> **正确性与适用条件。** 合法分解应是修改块[i,i+K−1]、右侧起点j=i+K。将块全改为a[j]即可同时接上左、右子序列；任何最优方案按右侧首项归入候选，无右侧归入末尾候选。这解释有效模型，但不能作为原循环端点的正确性证明。
>
> **手算与边界。** 原循环从i=1,j=K开始，K+rights[j]把块内末项再算作右侧首项。N=2,K=1,A=(1,2)时首候选3，正确为2。修正方案是令循环初值i=1、j=K+1；每轮先查询当前前缀并计算left+K+rights[j]，再插入a[i]，随后i、j同增。循环结束仍比较len+K，覆盖修改块放在末尾的情形。不能靠min(ans,N)掩盖原先的分解错误。
>
> **实际复杂度与实现。** 目标时间O(N log N)、空间O(N)。K≥N直接输出N的分支成立；修改块在开头、结尾、包含重复值时均适用上述修正。这里说明了修正后的分解，个人源码仍保留原始端点错误。
