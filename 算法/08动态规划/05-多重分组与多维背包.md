前置：[[04-01背包与完全背包]]。本篇分别处理数量上限、组内互斥、多个资源，不把三者误当成同一种循环写法。

## 用途与朴素瓶颈

每类物品最多 c 件是多重背包；每组最多选一件是分组背包；同时受体积和重量限制是多维背包。直接枚举所有数量组合或组内选项会指数增长。它们都能按阶段合并历史，但每一层可选决策与状态维数不同。

## 难度与重要程度

| 算法或主题 | 难度 | 重要程度 | 理由 |
|---|---:|---:|---|
| 多重背包二进制拆分 | 5/10 | 8/10 | 把有界数量变为对数个01物品。 |
| 分组背包 | 5/10 | 8/10 | 组内选项必须共享同一旧层。 |
| 二维费用背包 | 5/10 | 7/10 | 资源维度直接决定状态规模。 |

评分为本学习路线的主观建议，尺度见 [[00-动态规划#评分尺度|评分尺度]]。

## 多重背包：二进制拆分

朴素转移枚举当前类型取 $k=0\ldots c$ 件，最坏 $O(W\sum c)$。把 c 拆为 `1,2,4,...,余数` 个件数组成的包，每包重量和价值均乘件数，再做 01 背包。$c=13$ 时拆为 1、2、4、6；前几个包可表示 $0\ldots7$，末包把可表示区间扩至 $0\ldots13$，没有超过上限。

拆包可以表示所有合法取件数，每个包最多一次，故对最大价值等价。但同一个件数可能有多种包表示，例如 $c=6$ 拆成 1、2、3，数量 3 有两种表示；不能直接用拆包计算原多重背包的方案数，否则重计。

完整自编程序：单组 n W，n 行 w v c，`1<=n<=100`、`0<=W<=100000`、`w>=1`、`0<=c<=10^9`、`|v|<=10^9`。先将 c 截至 W/w，避免无用大包。容量 0 下标，$\mathrm{MAXW}=100005$，价值 long long；允许不选，输出最大价值。每包调用 add_item，容量倒序。时间 $O(n+(W+1)\sum\log(c_{\text{有效}}+1))$，空间 $O(W+1)$。全部有效数量为 0 时仍需读取 n 类物品；W=0 也有一个容量状态。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXW = 100000 + 5;
long long dp[MAXW];
int capacity;

void add_item(int weight, long long value)
{
    for (int j = capacity; j >= weight; j--)
    {
        dp[j] = max(dp[j], dp[j - weight] + value);
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n >> capacity;
    for (int i = 1; i <= n; i++)
    {
        int weight;
        int count;
        long long value;
        cin >> weight >> value >> count;
        count = min(count, capacity / weight);
        int block = 1;
        while (count > 0)
        {
            int take = min(block, count);
            add_item(weight * take, value * take);
            count -= take;
            block *= 2;
        }
    }
    cout << dp[capacity] << '\n';
}
```

教学输入（自设，非官方样例）：

```text
1 10
3 5 2
```

输出：

```text
10
```

## 分组背包：组内不是多件01物品

`f[g][j]` 为前 g 组在容量 j 下的最优值。当前组不选或选某一件，所有候选必须取自 $f[g-1]$。若按物品外循环直接做 01 背包，会允许同组多件。

教学例：只有一组，两个选项 `(2,3)`、`(3,4)`，容量 5，只能选一件，答案 4；逐件 01 会错误地得到 7。下面显式复制上一组为 prev_group，避免把循环方向当成万能规则。

完整自编程序：单组 G W；每组先读 k，再读 k 行 w v。`G<=100`、`W<=10000`、每组 `1<=k<=100`、正重量、`|v|<=10^9`；$\mathrm{MAXW}=10005$，$\mathrm{MAXK}=105$。最多选一件，可以不选；输出最大价值。时间 $O(W\sum k)$，空间 $O(W+\max k)$。若每组必须选一件，next_group 不能复制旧层，需要初始化负无穷，只做选项转移。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXW = 10000 + 5;
const int MAXK = 100 + 5;
long long dp[MAXW];
long long prev_group[MAXW];
int weight[MAXK];
long long value[MAXK];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int groups;
    int capacity;
    cin >> groups >> capacity;
    for (int g = 1; g <= groups; g++)
    {
        int k;
        cin >> k;
        for (int i = 1; i <= k; i++)
        {
            cin >> weight[i] >> value[i];
        }
        for (int j = 0; j <= capacity; j++)
        {
            prev_group[j] = dp[j];
        }
        for (int j = 0; j <= capacity; j++)
        {
            for (int i = 1; i <= k; i++)
            {
                if (j >= weight[i])
                {
                    dp[j] = max(dp[j], prev_group[j - weight[i]] + value[i]);
                }
            }
        }
    }
    cout << dp[capacity] << '\n';
}
```

教学输入（自设，非官方样例）：

```text
1 5
2
2 3
3 4
```

输出：

```text
4
```

## 二维费用：两种资源都要保证旧层

物品消耗 a、b，资源容量 A、B。`dp[x][y]` 为两种消耗分别不超过 x、y 的最大收益。01 情况两维容量都倒序；这是用简单循环统一保障读旧层的写法。若某项资源消耗可以为 0，另一维的倒序仍很关键；两项都为 0 的物品在每个格子只更新一次，不能写成重复选取模型。

以下是局部片段，依赖已初始化为 0 的 `long long dp[A+1][B+1]`、当前物品 a,b,v 与容量 A,B，消耗非负，单件最多一次。实际数组按题目容量分配，需保证收益和在 long long 内。

```cpp
for (int x = A; x >= a; x--)
{
    for (int y = B; y >= b; y--)
    {
        dp[x][y] = max(dp[x][y], dp[x - a][y - b] + v);
    }
}
```

一个物品 $(a,b,v)=(1,2,5)$，容量 $(2,3)$，答案 5；增加第二件相同物品后仍不能选两件，因为第二资源不足。时间 $O(nAB)$，空间 $O(AB)$，每加一维都可能让规模不可承受。依赖背包（选子项必须选父项）需要树结构约束，不能用一般分组替代；树上合并见 [[07-树形DP与换根]]。
