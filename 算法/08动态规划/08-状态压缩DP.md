## 用途：未来需要知道哪些元素已经使用

分配、访问每个城市一次、少量元素分组时，单个计数不能代表集合。两个已用人数相同但人员不同的状态，剩余合法选择可能不同。用 n 位整数 mask 表示集合，第 j 位为 1 表示 j 已使用。

这没有消除指数：状态数为 $2^{n}$，只是把 $n!$ 级枚举合并到集合状态。$n=21$ 约两百万状态；$n=60$ 无法直接这样填表。移位还必须匹配类型，不能用 32 位的 1 去做大位数移位。

## 一一匹配计数：固定左侧顺序

有 n 个左侧对象与 n 个右侧对象，$a[i][j]$ 表示是否可匹配。要让每个对象恰好匹配一次，求合法完美匹配数量。

固定左侧按 $0\ldots n-1$ 顺序处理，`dp[mask]` 表示前 popcount(mask) 个左侧对象已经匹配给 mask 内右侧对象的方案数。下一左侧编号 $i=\mathrm{popcount}(\mathrm{mask})$，枚举未使用且兼容的 j，把 $dp[\mathrm{mask}]$ 加到 `dp[mask | (1<<j)]`。$dp[0]=1$，空匹配是一个方案；答案为全满集合。

$n=2$ 全兼容：$dp[00]=1$；先处理左 0 得 $dp[01]=1$、$dp[10]=1$；处理左 1，两条路径都到 $dp[11]$，得到 2。固定左侧顺序让每个完整匹配只有一条生成路径，避免把处理顺序再乘一次。

完整程序对应 [AtCoder DP O — Matching](https://atcoder.jp/contests/dp/tasks/dp_o)：单组 n 和 $n\times n$ 的 0/1 矩阵，`1<=n<=21`，矩阵 0 下标，$\mathrm{MAXN}=21$，`MAXS=1<<21`；long long 取模，输出数量。增加一个位一定使 mask 数值变大，数值正序是合法依赖顺序。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 21;
const int MAXS = 1 << MAXN;
const long long MOD = 1000000007;
int compatible[MAXN][MAXN];
long long dp[MAXS];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < n; j++)
        {
            cin >> compatible[i][j];
        }
    }
    int limit = 1 << n;
    dp[0] = 1;
    for (int mask = 0; mask < limit - 1; mask++)
    {
        int i = __builtin_popcount(static_cast<unsigned int>(mask));
        for (int j = 0; j < n; j++)
        {
            if ((mask & (1 << j)) == 0 && compatible[i][j] == 1)
            {
                int next_mask = mask | (1 << j);
                dp[next_mask] = (dp[next_mask] + dp[mask]) % MOD;
            }
        }
    }
    cout << dp[limit - 1] << '\n';
}
```

教学输入（自设，非官方样例）：

```text
2
1 1
1 1
```

输出：

```text
2
```

时间 $O(n2^{n})$，有效空间 $O(2^{n}+n^{2})$，当前 dp 固定分配约 16 MB。`__builtin_popcount` 是 GCC/Clang 扩展，模板采用这两类编译器的 C++17 环境。

## 为什么访问路径还需要终点

若求访问每个点恰好一次的最短路，未来费用依赖当前在哪个点，因此状态应为 $dp[\mathrm{mask}][\mathrm{last}]$，不是只保留 $dp[\mathrm{mask}]$。从 last 走到未访问 next 后更新新状态。固定起点的初始状态为该点单元素集合费用 0，其他正无穷。要回到起点则最后再加返回边；不要求成环则在终点中取 min。一般复杂度 $O(n^{2}2^{n})$，空间 $O(n2^{n})$。

## 子集划分与 $3^{n}$

若 $\mathrm{score}[sub]$ 表示一个组的得分，目标把集合 mask 分组取最大总分，可转移 `best[mask]=max(best[mask^sub]+score[sub])`。枚举非空 $sub\subseteq \mathrm{mask}$，$\mathrm{best}[0]=0$。最优化重复生成相同分组不改变 max，但计数会重复；可要求当前子组必须包含 mask 的最低位元素，使每个无序划分有唯一拆分顺序。

局部枚举片段，依赖非负 int mask、已准备的 score 和 best；必须按使剩余集合已完成的顺序填 best。

```cpp
for (int sub = mask; sub > 0; sub = (sub - 1) & mask)
{
    best[mask] = max(best[mask], best[mask ^ sub] + score[sub]);
}
```

每个元素在“子集里、mask 内但不在子集、mask 外”有三种情况，因此所有 mask 下枚举 sub 的总量是 $O(3^{n})$，不是 $O(2^{n})$。单独枚举一个 mask 的所有子集为 $O(2^{\operatorname{popcount}(\mathrm{mask})})$。

## 常见错误与练习

满集合不是 `1<<n`，而是 `(1<<n)-1`。零状态很可能有实际意义，不能跳过初始化。匹配数量和 [[10-二分图与匹配]] 的最大匹配大小是不同任务，后者的多项式算法不直接给所有完美匹配计数。练习见 [[14-动态规划题单]]。

## 完整子集划分：负得分与唯一拆分

自编输入 n 与对称的 n×n 得分矩阵，`0<=n<=16`、`|w[i][j]|<=10^6`。组的得分为其中所有 `i<j` 的 w[i][j] 之和，单人组为 0；所有人必须分进非空组，组无标号，输出最大总分。对角线忽略。

先计算 score[mask]。取最低位 i，rest=mask 去掉 i，则 score[mask]=score[rest]+i 与 rest 中所有人的得分。最优表 best[0]=0，其余先设 NEG，不能假设任意模型都允许空分组来跳过剩余元素。

划分 mask 时固定其最低位 fixed 所在的那个组 sub，要求 sub 含 fixed；剩余 mask^sub 的划分已求好。这样每个无序划分只按含最小元素的组拆一次。这里只求最大值，重复生成本也不改变 max，但唯一拆分为以后正确计数建立了明确顺序。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 16;
const int MAXS = 1 << MAXN;
const long long NEG = -4000000000000000000LL;
long long weight[MAXN][MAXN];
long long score[MAXS];
long long best[MAXS];

int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < n; j++)
        {
            cin >> weight[i][j];
        }
    }
    int limit = 1 << n;
    best[0] = 0;
    for (int mask = 1; mask < limit; mask++)
    {
        int bit = mask & -mask;
        int i = __builtin_ctz(static_cast<unsigned>(bit));
        int rest = mask ^ bit;
        score[mask] = score[rest];
        for (int j = i + 1; j < n; j++)
        {
            if ((rest >> j) & 1)
            {
                score[mask] += weight[i][j];
            }
        }
        best[mask] = NEG;
        for (int sub = mask; sub > 0; sub = (sub - 1) & mask)
        {
            if (sub & bit)
            {
                best[mask] = max(best[mask], score[sub] + best[mask ^ sub]);
            }
        }
    }
    cout << best[limit - 1] << '\n';
}
```

教学输入：

```text
2
0 -5
-5 0
```

输出：

```text
0
```

两人同组得 −5，分为两单人组得 0；若改成两人必须同组，答案才是 −5。score 已完成的 rest 与 best 的剩余 mask 都严格小于当前 mask，正序合法。总时间 O(n2^n+3^n)，有效空间 O(2^n+n²)，真实分数绝对值≤C(16,2)×10^6。n=0 对应空划分得 0。ctz 仅用于非零 bit，属于 GCC/Clang 扩展。

## 路径状态的手算与转移片段

从 0 固定出发，访问所有点后可选择是否回到 0。例三点有向代价 `0→1=2,0→2=5,1→2=1,2→1=4,1→0=3,2→0=2`。dp[111][2]=3，对应 0→1→2；dp[111][1]=9，对应 0→2→1。相同集合终点不同，返回费用也不同，成环最优为 min(3+2,9+3)=5。

以下局部转移依赖 `1<=n<=18`、`MAXS=1<<n`、`long long path_dp[MAXS][n]`、完整的非负代价矩阵 cost（每项≤10^9）；先全部设 INF=4×10^18，再令 path_dp[1][0]=0。标准数组实际维度可用固定上限替代，勿在标准 C++17 中声明运行时变长数组。

```cpp
for (int mask = 1; mask < (1 << n); mask++)
{
    for (int last = 0; last < n; last++)
    {
        if (path_dp[mask][last] == INF)
        {
            continue;
        }
        for (int next = 0; next < n; next++)
        {
            if ((mask & (1 << next)) == 0)
            {
                int next_mask = mask | (1 << next);
                path_dp[next_mask][next] = min(path_dp[next_mask][next],
                    path_dp[mask][last] + cost[last][next]);
            }
        }
    }
}
```

不成环在满集合各 last 中取最小，成环再加 cost[last][0]。n=1 成环约定无需移动、费用 0，单独处理，不凭对角线费用强制走自环。每个状态枚举 n 个下一点，时间 O(n²2^n)、空间 O(n2^n)；无边模型需额外检查边可达，不能对 INF 直接相加。

## 牛客136720E 小红的矩阵计数

[官方题面](https://ac.nowcoder.com/acm/contest/136720/E)

填2×N矩阵中的?，使每个2×2方块不全同，计数模998244353。N≤2×10⁵。

> [!tip]- 提示一
> 未来只需要知道最近一列的上下两位。

> [!tip]- 提示二
> 四种列状态只有00→00、11→11非法，再过滤与固定字符冲突的状态。
>
> 复习：[[08动态规划/08-状态压缩DP]]。

> [!example]- 详细题解
> **建模与源码主线。** dp[i][s]表示前i列填好、末列为s的方案数，上位×2+下位编码。首列四态各设1再按固定字符清零；后续00排除旧00，11排除旧11，01/10可接所有旧态。当前列转移结束再过滤固定字符，最后求四态和。
>
> **正确性与适用条件。** 新2×2方块只涉及最近两列，全同的充要条件恰为两个00或两个11。每个合法填法删去末列后有唯一前驱，转移既不漏计也不重复，过滤又精确保留固定输入位。
>
> **手算与边界。** 两列全?共有16种列对，只排除(00,00)、(11,11)，答案14；若输入两行均00，则唯一填法非法，答案0。
>
> **实际复杂度与实现。** 时间O(16N)=O(N)，源码保存4N表为O(N)空间；若滚动才是O(1)辅助空间。先以64位相加再取模，状态数小不表示方案数小。
