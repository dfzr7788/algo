## 用途：未来需要知道哪些元素已经使用

分配、访问每个城市一次、少量元素分组时，单个计数不能代表集合。两个已用人数相同但人员不同的状态，剩余合法选择可能不同。用 n 位整数 mask 表示集合，第 j 位为 1 表示 j 已使用。

这没有消除指数：状态数为 $2^{n}$，只是把 $n!$ 级枚举合并到集合状态。$n=21$ 约两百万状态；$n=60$ 无法直接这样填表。移位还必须匹配类型，不能用 32 位的 1 去做大位数移位。

## 一一匹配计数：固定左侧顺序

有 n 个左侧对象与 n 个右侧对象，$a[i][j]$ 表示是否可匹配。要让每个对象恰好匹配一次，求合法完美匹配数量。

固定左侧按 $0\ldots n-1$ 顺序处理，`dp[mask]` 表示前 popcount(mask) 个左侧对象已经匹配给 mask 内右侧对象的方案数。下一左侧编号 $i=\mathrm{popcount}(\mathrm{mask})$，枚举未使用且兼容的 j，把 $dp[\mathrm{mask}]$ 加到 `dp[mask | (1<<j)]`。$dp[0]=1$，空匹配是一个方案；答案为全满集合。

$n=2$ 全兼容：$dp[00]=1$；先处理左 0 得 $dp[01]=1$、$dp[10]=1$；处理左 1，两条路径都到 $dp[11]$，得到 2。固定左侧顺序让每个完整匹配只有一条生成路径，避免把处理顺序再乘一次。

完整程序对应 [AtCoder DP O — Matching](https://atcoder.jp/contests/dp/tasks/dp_o)：单组 n 和 $n\times n$ 的 0/1 矩阵，`1<=n<=21`，矩阵 0 下标，$\mathrm{MAXN}=21$，`MAXS=1<<21`；long long 取模，输出数量。增加一个位一定使 mask 数值变大，数值正序是合法依赖顺序。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 21;
const int MAXS = 1 << MAXN;
const long long MOD = 1000000007;
int compatible[MAXN][MAXN];
long long dp[MAXS];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < n; j++)
        {
            cin >> compatible[i][j];
        }
    }
    int limit = 1 << n;
    dp[0] = 1;
    for (int mask = 0; mask < limit - 1; mask++)
    {
        int i = __builtin_popcount(static_cast<unsigned int>(mask));
        for (int j = 0; j < n; j++)
        {
            if ((mask & (1 << j)) == 0 && compatible[i][j] == 1)
            {
                int next_mask = mask | (1 << j);
                dp[next_mask] = (dp[next_mask] + dp[mask]) % MOD;
            }
        }
    }
    cout << dp[limit - 1] << '\n';
}
```

教学输入（自设，非官方样例）：

```text
2
1 1
1 1
```

输出：

```text
2
```

时间 $O(n2^{n})$，有效空间 $O(2^{n}+n^{2})$，当前 dp 固定分配约 16 MB。`__builtin_popcount` 是 GCC/Clang 扩展，模板采用这两类编译器的 C++17 环境。

## 为什么访问路径还需要终点

若求访问每个点恰好一次的最短路，未来费用依赖当前在哪个点，因此状态应为 $dp[\mathrm{mask}][\mathrm{last}]$，不是只保留 $dp[\mathrm{mask}]$。从 last 走到未访问 next 后更新新状态。固定起点的初始状态为该点单元素集合费用 0，其他正无穷。要回到起点则最后再加返回边；不要求成环则在终点中取 min。一般复杂度 $O(n^{2}2^{n})$，空间 $O(n2^{n})$。

## 子集划分与 $3^{n}$

若 $\mathrm{score}[sub]$ 表示一个组的得分，目标把集合 mask 分组取最大总分，可转移 `best[mask]=max(best[mask^sub]+score[sub])`。枚举非空 $sub\subseteq \mathrm{mask}$，$\mathrm{best}[0]=0$。最优化重复生成相同分组不改变 max，但计数会重复；可要求当前子组必须包含 mask 的最低位元素，使每个无序划分有唯一拆分顺序。

局部枚举片段，依赖非负 int mask、已准备的 score 和 best；必须按使剩余集合已完成的顺序填 best。

```cpp
for (int sub = mask; sub > 0; sub = (sub - 1) & mask)
{
    best[mask] = max(best[mask], best[mask ^ sub] + score[sub]);
}
```

每个元素在“子集里、mask 内但不在子集、mask 外”有三种情况，因此所有 mask 下枚举 sub 的总量是 $O(3^{n})$，不是 $O(2^{n})$。单独枚举一个 mask 的所有子集为 $O(2^{\operatorname{popcount}(\mathrm{mask})})$。

## 常见错误与练习

满集合不是 `1<<n`，而是 `(1<<n)-1`。零状态很可能有实际意义，不能跳过初始化。匹配数量和 [[10-二分图与匹配]] 的最大匹配大小是不同任务，后者的多项式算法不直接给所有完美匹配计数。练习见 [[14-动态规划题单]]。
