## 用途：在巨大整数范围中按数字性质计数

要统计 [1,K] 内数位和满足条件、含指定数字、相邻位满足限制的整数。K 很大时逐个枚举不可行，但十进制位数可能只有几十到几万。逐位构造，把有相同“前缀性质”的数字合并，复杂度取决于位数与性质状态数量。

状态只能保留影响未来或最终判定的信息。数位和取模只需余数，不必保存整个数位和；数字集合需要 mask；相邻位限制需要上一位。若要求恰好某个数位和则可能不能只保留余数。多个性质组合会相乘扩大状态数。

## 上界限制 tight 与前导零 started

tight=1 表示当前前缀恰好等于 K 的前缀，此位最多放 K 当前数字；tight=0 表示已经更小，此位可放 0..9。新 tight 为 `tight && (digit==bound_digit)`。已经更小后不能重新变为相等。

统一补到 K 的长度，让短数也能按相同位数构造，每个整数恰有一个补零表示。对数位和，前导零不改变性质，因此不需要 started，最后减去整数 0 即可。对“出现多少种数字”“相邻位差”则通常要 started：尚未开始且放 0 的阶段不能把 0 记为真实数字；开始之后的 0 必须算真实数字。

## 基础模板：数位和能被D整除

`dp[remainder][tight]` 为已经处理当前长度前缀、数位和余数为 remainder、上界状态为 tight 的数量。初始 dp[0][1]=1。每一位枚举 digit，加到 `(remainder+digit)%D`。下一层必须清零。最终余数 0 的两种 tight 相加再减 1，去掉 0。

K=30、D=4，补零后的合法正数为 `04、08、13、17、22、26`。第一位若选 0、1、2 就已经小于 3，第二位自由；第一位选 3 就只能再选 0。30 的数位和为 3，不计入。这个例子同时展示短数、上界和零排除。

完整程序对应 [AtCoder DP S — Digit Sum](https://atcoder.jp/contests/dp/tasks/dp_s)：单组 K（十进制字符串）与 D，`1<=K<10^10000`、`1<=D<=100`；余数 0 下标，MAXD=105，MOD=10^9+7，long long。输出 [1,K] 内合法数数量取模。迭代避免万位递归，时间 O(10×位数×D)，DP 空间 O(D)，含输入字符串的总空间 O(D+位数)。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXD = 100 + 5;
const long long MOD = 1000000007;
long long dp[MAXD][2];
long long next_dp[MAXD][2];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string bound;
    int divisor;
    cin >> bound >> divisor;
    dp[0][1] = 1;
    for (char ch : bound)
    {
        for (int r = 0; r < divisor; r++)
        {
            for (int tight = 0; tight <= 1; tight++)
            {
                next_dp[r][tight] = 0;
            }
        }
        int bound_digit = ch - '0';
        for (int r = 0; r < divisor; r++)
        {
            for (int tight = 0; tight <= 1; tight++)
            {
                int upper = tight ? bound_digit : 9;
                for (int digit = 0; digit <= upper; digit++)
                {
                    int nr = (r + digit) % divisor;
                    int nt = tight && digit == bound_digit;
                    next_dp[nr][nt] = (next_dp[nr][nt] + dp[r][tight]) % MOD;
                }
            }
        }
        for (int r = 0; r < divisor; r++)
        {
            for (int tight = 0; tight <= 1; tight++)
            {
                dp[r][tight] = next_dp[r][tight];
            }
        }
    }
    cout << (dp[0][0] + dp[0][1] - 1 + MOD) % MOD << '\n';
}
```

教学输入（自设，非官方样例）：

```text
20
3
```

输出：

```text
6
```

每个合法补零数字对应一条唯一的逐位选择路径，tight 排除了超上界路径，余数更新准确记录数位和，层间加法统计互斥前缀。因此最终计数正确。

## 区间统计与缓存

定义 F(X) 为 [0,X] 或 [1,X] 的数量，先明确零的定义，再用 F(R)-F(L-1)。取模减法要加 MOD；L=0 时单独处理负上界。大整数不能转成 long long，L-1 需字符串减一并处理借位。

递归记忆化通常只缓存 tight=0 的状态，因为 tight=1 的可选上界与当前 K 有关；跨不同上界调用时不能复用绑定旧 K 的限制状态。还要缓存所有影响未来的信息，例如 started、last、mask。基础模板用分层迭代，不涉及跨调用缓存。

## Digit Circus扩展

原链接 [AtCoder ABC465 E — Digit Circus](https://atcoder.jp/contests/abc465/tasks/abc465_e) 已核对官方题面。原笔记显示名“模板”改为题名：它不是上面数位和模板的原题。范围为 `1<=N<10^500`，要求恰好满足下面三个条件中的一个，答案模 998244353：被 3 整除、真实十进制表示含 3、真实十进制表示恰好使用三种数字。

可用 `(position, remainder, mask, tight)`：remainder 为数值对 3 的余数，mask 是真实数字集合。mask=0 同时表示还没开始；尚未开始且 digit=0 时 mask 仍为 0，否则加入 digit 对应位。数值余数更新 `(remainder*10+digit)%3`，因为模 3 恰有 10≡1，也可写为加 digit。

末尾 mask=0 为整数 0，应排除。令 A=(remainder==0)，B=(mask含第3位)，C=(popcount(mask)==3)，必须 `int(A)+int(B)+int(C)==1`，不能用三个布尔量异或：异或会把三个条件全满足也计入。

例如 13 只满足含 3；1012 只满足三种数字；123 同时满足全部三个条件，必须排除。数字 3 的补零表示如 003，其 mask 只有数字 3，不能把前导 0 计入。普通 101 的中间 0 则必须计入。

分层 DP 状态 O(3×1024×2)，总时间 O(位数×3×1024×2×10)，可按当前有效状态跳过零值。这是原题的建模说明与练习方向，没有提供或提交该题的完整解答；基础程序的模数和状态均不能原样用于此题。练习与旧链接记录见 [[14-动态规划题单]]。
