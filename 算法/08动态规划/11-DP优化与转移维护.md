## 用途：保留状态，减少重复枚举

滚动数组减少内存，不一定减少时间；前缀和减少重复区间求和；单调队列维护滑动范围最值。它们通常不改变状态含义，而是更快取得转移需要的值。优化前必须确认窗口、版本和运算符合工具条件。

## 有界分配计数：从三层枚举到前缀和

有 n 个孩子，恰好分 K 颗糖，第 i 个可得 0..a[i]。`f[i][j]` 表示前 i 个恰好分 j 颗的方案数，f[0][0]=1。枚举本孩子拿 t 颗：

$$
f[i][j]=\sum_{t=0}^{\min(a[i],j)}f[i-1][j-t].
$$

求和是一段连续旧层区间 `[max(0,j-a[i]),j]`。设旧层前缀 P[j]，只需 `P[j]-P[j-a[i]-1]`，负下标视为 0。每层先生成完整旧层前缀，再写新层，避免把新层污染旧层。

两位孩子上限 1、2，K=3：第一层 `[1,1,0,0]`，前缀 `[1,2,2,2]`；第二层 j=0..3 分别为 1、2、2、1，答案为 1，即 `(1,2)`。这与二进制拆分计数不同，不会将同一分配重复生成。

完整程序对应 [AtCoder DP M — Candies](https://atcoder.jp/contests/dp/tasks/dp_m)：单组 n K、n 个上限，`1<=n<=100`、`0<=K<=100000`、`0<=a[i]<=K`。MAXK=100005，0 下标，long long，输出模 10^9+7 的方案数。时间 O(nK)，空间 O(K)。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXK = 100000 + 5;
const long long MOD = 1000000007;
long long dp[MAXK];
long long prefix[MAXK];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    int total;
    cin >> n >> total;
    dp[0] = 1;
    for (int i = 1; i <= n; i++)
    {
        int upper;
        cin >> upper;
        prefix[0] = dp[0];
        for (int j = 1; j <= total; j++)
        {
            prefix[j] = (prefix[j - 1] + dp[j]) % MOD;
        }
        for (int j = 0; j <= total; j++)
        {
            dp[j] = prefix[j];
            if (j - upper - 1 >= 0)
            {
                dp[j] = (dp[j] - prefix[j - upper - 1] + MOD) % MOD;
            }
        }
    }
    cout << dp[total] << '\n';
}
```

教学输入（自设，非官方样例）：

```text
2 3
1 2
```

输出：

```text
1
```

## 滑动前驱最值：单调队列

自编模型：从位置 0 出发到 n，每次前进 1..k，落在 i 获得 a[i]，必须到达 n，可有负收益。dp[0]=0，`dp[i]=a[i]+max(dp[j])`，j 在 `[max(0,i-k),i-1]`。朴素 O(nk)。

候选下标窗口不断右移。队列保存下标，dp 值从队首到队尾递减；先删除 j<i-k 的过期下标，查询队首后才加入 i，避免自己转移到自己。新 i 的 dp 若不小于队尾，旧队尾既更差又更早过期，可以永久删除。

k=2，收益 `5 -10 4`：初始队列 `[0]`；i=1 得 5，0 被支配，队列 `[1]`；i=2 得 -5，队列 `[1,2]`；i=3 得 9，先保留合法 1，再删除被 9 支配的 2、1，队列 `[3]`。答案 9，跳法 0→1→3。

完整自编程序：单组 n k 和 n 个收益，`1<=n<=200000`、`1<=k<=n`、`|a[i]|<=10^9`；MAXN=200005，下标 0..n，dp 用 long long，静态数组模拟队列闭区间 [head,tail]。输出到 n 的最大收益。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 200000 + 5;
long long dp[MAXN];
int candidate[MAXN];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    int k;
    cin >> n >> k;
    int head = 0;
    int tail = 0;
    candidate[0] = 0;
    for (int i = 1; i <= n; i++)
    {
        long long value;
        cin >> value;
        while (head <= tail && candidate[head] < i - k)
        {
            head++;
        }
        dp[i] = dp[candidate[head]] + value;
        while (head <= tail && dp[candidate[tail]] <= dp[i])
        {
            tail--;
        }
        candidate[++tail] = i;
    }
    cout << dp[n] << '\n';
}
```

教学输入（自设，非官方样例）：

```text
3 2
5 -10 4
```

输出：

```text
9
```

合法窗口始终含 i-1，k>=1，所以查询时队列非空。每个下标入队一次、最多出队一次，全部维护为 O(n)，空间 O(n)。这是总时间的摊还界，不是每轮 while 都 O(1)。可仅存窗口进一步节省空间，但需要循环队列管理。

## 优化选择表

| 转移形状 | 工具 | 需要的条件 |
|---|---|---|
| 仅上一层少数状态 | 滚动数组 | 读写版本与覆盖顺序正确 |
| 连续旧层区间求和 | 前缀和 | 可做减法，模减规范化 |
| 连续候选区间最值 | 单调队列 | 窗口端点随阶段单调移动，支配关系有效 |
| 值域前缀最大值 | 树状数组/线段树 | 需离散化并处理严格性，见已有数据结构模块 |
| 线性函数最小值 | 凸包/斜率优化 | 必须推导直线与查询条件，后续选学 |

## 扩展选读

后续选学：分治决策优化、Knuth 优化、斜率优化和状态压缩的子集变换。本模块未提供这些高阶机制的完整教程，不给已掌握式评分。分治优化要求该层最优决策对查询下标单调；Knuth 区间优化需要更强的两侧界 `opt[l][r-1]<=opt[l][r]<=opt[l+1][r]`，常通过合适的四边形不等式等充分条件证明。不能因为小数据最优分割点“看起来单调”就截断枚举。

斜率优化在斜率或查询横坐标无序时，普通双端队列方案可能失效；整数交叉乘法也可能溢出。先保留朴素解对拍，后续按具体题目补专题。练习见 [[14-动态规划题单]]。
