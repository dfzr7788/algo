## 用途：在资源限制下选择物品

物品重量 w、价值 v，容量 W；01 背包每件最多一次，完全背包每类可以无限次。比起枚举所有物品组合，按“已经考虑的物品”和“剩余容量”合并历史可得到 $O(nW)$。这是伪多项式时间：取决于数值 W，而非 W 的二进制位数。$W=10^{9}$ 时不能直接开数组。

## 01 背包：先理解二维，再压成一维

`f[i][j]` 为前 i 件物品、总重不超过 j 的最大价值。第 i 件不选：$f[i-1][j]$；选：$f[i-1][j-w]+v$，只有 $j\ge w$ 可选。前 0 件在任何容量都能取空集合，初值为 0。答案 $f[n][W]$。

只存 $dp[j]$ 时，从 W 到 w 倒序更新。更新 j 时，更小位置 $j-w$ 尚未处理本物品，仍是上一层；正序则可能读到刚选过本物品的值。只有一件 `(w=2,v=3)`、$W=4$：倒序给 $dp[4]=3$，正序会先得 $dp[2]=3$，再得 $dp[4]=6$，错误地取了两次。

完整程序与 [AtCoder DP D — Knapsack 1](https://atcoder.jp/contests/dp/tasks/dp_d) 同模型：单组 n W，随后 n 行重量价值。教学允许 `0<=W<=100000`、`1<=n<=100`、正重量、`|v|<=10^9`，允许不选。$\mathrm{MAXW}=100005$，容量 0 下标，long long，输出最大价值。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXW = 100000 + 5;
long long dp[MAXW];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    int capacity;
    cin >> n >> capacity;
    for (int i = 1; i <= n; i++)
    {
        int weight;
        long long value;
        cin >> weight >> value;
        for (int j = capacity; j >= weight; j--)
        {
            dp[j] = max(dp[j], dp[j - weight] + value);
        }
    }
    cout << dp[capacity] << '\n';
}
```

教学输入（自设，非官方样例）：

```text
2 5
2 3
3 4
```

输出：

```text
7
```

## 完全背包：当前物品可以继续选

二维式为 `f[i][j]=max(f[i-1][j],f[i][j-w]+v)`。右边第二项来自本层，因允许重复第 i 类。滚动后容量从 w 到 W 正序，读到的是已经允许本类物品的状态。

完整自编教学程序：接口与上例相同，但 n 行代表可无限取的物品类型；`n<=100`、`W<=100000`、`1<=w`、`|v|<=10^9`。要求重量严格正，否则零重量正收益会无界。允许空集合，答案不会为负。其他容量与类型约定同上。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXW = 100000 + 5;
long long dp[MAXW];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    int capacity;
    cin >> n >> capacity;
    for (int i = 1; i <= n; i++)
    {
        int weight;
        long long value;
        cin >> weight >> value;
        for (int j = weight; j <= capacity; j++)
        {
            dp[j] = max(dp[j], dp[j - weight] + value);
        }
    }
    cout << dp[capacity] << '\n';
}
```

教学输入（自设，非官方样例）：

```text
1 4
2 3
```

输出：

```text
6
```

两种算法都按最后一件的数量拆分，覆盖所有合法集合。时间 $O(nW)$，有效空间 $O(W)$；固定数组按 MAXW 分配。

## 恰好装满与计数不能照搬初始化

恰好重量 j 的最大价值：只有 $dp[0]=0$，其余负无穷。从不可达状态不转移，最终 $dp[W]$ 负无穷则无解。容量至多型全 0 初始化的含义是每个容量都允许空集合，不表示空集合重量是每个 j。

计数时 $dp[0]=1$，其他为 0。01 物品倒序计数；无限硬币的无序组合数通常物品在外、金额正序在内；有序序列数通常金额在外、枚举最后硬币在内。例如面值 1、2 凑 3：无序两种 `\{1,1,1\}`、`\{1,2\}`，有序三种 `111、12、21`。两者的被计数对象不同；重复面值若被视为相同类型要先去重。

恢复 01 背包选项时保留二维决策或不可变前驱记录；不要在一维滚动 dp 上随意串接可被覆盖的 parent。大容量、小价值之和的转换详见 [[12-从暴力到优化的完整题解]]。练习见 [[14-动态规划题单]]。
