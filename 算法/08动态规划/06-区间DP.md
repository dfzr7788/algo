## 用途：操作始终保持连续区间

相邻石堆合并、矩阵链括号化、区间两端取数，都需要知道左右边界。对于相邻合并，枚举每次先合哪对会出现大量重复中间局面；改看“最后一次把哪两段合起来”，子问题自然变成连续区间。

这与任意两堆可合并的合并果子不同：任意合并可用堆贪心，限定相邻时不能忽略顺序。环形区间也有额外边界，不能直接用线性终点答案。

## 相邻合并：状态与手算

`dp[l][r]` 表示把闭区间 l..r 合为一堆的最小总费用。单堆不需操作，$dp[i][i]=0$。最后一步把 l..k 与 $k+1\ldots r$ 合并，费用固定为 $sum(l,r)$，因此

$$
dp[l][r]=\min_{l\le k<r}\{dp[l][k]+dp[k+1][r]+sum(l,r)\}.
$$

按长度从小到大枚举，再枚举 l 和 k，保证两个严格更短的子区间已求出。

`10 20 30`：长度 1 都为 0；长度 2 的答案分别为 30、50；长度 3 比较 `0+50+60=110` 与 `30+0+60=90`，答案 90。前缀和 $O(1)$ 求区间总重，避免在每个分割点再求和。

完整程序与 [AtCoder DP N — Slimes](https://atcoder.jp/contests/dp/tasks/dp_n) 同模型。单组 n 与正整数大小；教学允许 `1<=n<=400`，每项 $\le 10^{9}$，$\mathrm{MAXN}=405$，1 下标闭区间；long long 与 $INF=4\times 10^{18}$。输出最小费用。上界可用 `(n-1)×总和` 粗估，当前范围远小于 INF。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 400 + 5;
const long long INF = 4000000000000000000LL;
long long prefix[MAXN];
long long dp[MAXN][MAXN];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++)
    {
        long long x;
        cin >> x;
        prefix[i] = prefix[i - 1] + x;
    }
    for (int length = 2; length <= n; length++)
    {
        for (int l = 1; l + length - 1 <= n; l++)
        {
            int r = l + length - 1;
            dp[l][r] = INF;
            for (int k = l; k < r; k++)
            {
                dp[l][r] = min(dp[l][r], dp[l][k] + dp[k + 1][r] + prefix[r] - prefix[l - 1]);
            }
        }
    }
    cout << dp[1][n] << '\n';
}
```

教学输入（自设，非官方样例）：

```text
3
10 20 30
```

输出：

```text
90
```

## 正确性与复杂度

最后一次操作必定合并两段相邻的完整连续子区间，分割点 k 穷尽所有可能。给定 k 后，两段可独立取最优，否则替换可降低整体费用。区间长度归纳即可证明。$O(n^{2})$ 状态、每个 $O(n)$ 分割，时间 $O(n^{3})$，空间 $O(n^{2})$。

## 两端取数：分差消去玩家维度

两人轮流从剩余区间取左或右端，均最大化自身最终得分。定义 $d[l][r]$ 为当前玩家分数减另一玩家分数的最优值，取左端后身份互换：候选 `a[l]-d[l+1][r]`；右端为 `a[r]-d[l][r-1]`。单点为 $a[l]$。最终 $d[1][n]$ 是先手分数减后手分数，不是先手总分。

`1 5 2`：单点 1、5、2；长度 2 分差 4、3；全段 $\max (1-3,2-4)=-2$。先手只能拿 3、后手拿 5。若需要先手分数，且总和 S，结果为 `(S+d[1][n])/2`。

下面是局部片段，依赖 1 下标 long long a、d，已令 $d[i][i]=a[i]$，$n\ge 1$，总分绝对值在 long long 范围内。

```cpp
for (int length = 2; length <= n; length++)
{
    for (int l = 1; l + length - 1 <= n; l++)
    {
        int r = l + length - 1;
        d[l][r] = max(a[l] - d[l + 1][r], a[r] - d[l][r - 1]);
    }
}
```

该模型每个状态两个选择，时间 $O(n^{2})$，空间 $O(n^{2})$。成立前提是得分和固定、双方最优、每回合规则对称，不能随意搬到有跳过回合或不对称收益的博弈。

## 变体与错误

- 环形相邻合并：复制数组至 2n，计算长度至多 n 的区间，在所有起点中取答案；是不同接口。
- 矩阵链：最后分割代价依赖矩阵维数，不能用区间元素和。
- 用正权并不自动获得分割点单调性；更快优化必须证明成本函数的特定性质，见 [[11-DP优化与转移维护#扩展选读|扩展选读]]。
- 不要把所有 dp 清零后直接取 min，多点区间初始必须是正无穷。

练习见 [[14-动态规划题单]]；手写 $n=1$、$n=2$、大权三个边界。
