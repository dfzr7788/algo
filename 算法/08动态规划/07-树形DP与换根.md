## 用途：局部约束沿树边连接

树上独立集、子树选点、所有节点到其他点的距离和，都可沿父子边聚合。因为树没有环，不同孩子子树之间只能通过父节点连接；给定父节点必要状态后，就能分别计算再合并。一般图上子分支可能重叠或有横边，这些公式不能直接使用。

## 独立集计数：选与不选

每个点涂白或黑，相邻不能都黑。`white[u]` 是 u 白时整个 u 子树的合法方案数；`black[u]` 是 u 黑时的方案数。叶子二者为 1，不是 0：固定自己的颜色后有一个空孩子方案。

对孩子 v：u 白时孩子可黑可白，乘 `(white[v]+black[v])`；u 黑时孩子必须白，乘 $\mathrm{white}[v]$。孩子子树相互独立用乘法，同一孩子的两种互斥状态用加法。根答案为二者之和。

三点链 1—2—3，根 1：节点 3 为 $(1,1)$，节点 2 为 $(2,1)$，节点 1 为 $(3,2)$，共 5。不是最大独立集大小；最大权独立集需将白状态改为孩子最优和、黑状态改为本点权加孩子白状态之和。

完整程序对应 [AtCoder DP P — Independent Set](https://atcoder.jp/contests/dp/tasks/dp_p)。单组 n 与 $n-1$ 条无向边，保证树，`1<=n<=100000`，点 1 下标，$\mathrm{MAXN}=100005$，long long 模乘，$MOD=10^{9}+7$。build_order 建父亲先于孩子的顺序；逆序计算，避免长链递归栈溢出。输出合法染色数取模。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 100000 + 5;
const long long MOD = 1000000007;
vector<int> graph[MAXN];
int parent_node[MAXN];
int order_node[MAXN];
long long white[MAXN];
long long black[MAXN];

void build_order()
{
    order_node[1] = 1;
    int count = 1;
    for (int i = 1; i <= count; i++)
    {
        int u = order_node[i];
        for (int v : graph[u])
        {
            if (v != parent_node[u])
            {
                parent_node[v] = u;
                order_node[++count] = v;
            }
        }
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = 1; i < n; i++)
    {
        int u;
        int v;
        cin >> u >> v;
        graph[u].push_back(v);
        graph[v].push_back(u);
    }
    build_order();
    for (int i = n; i >= 1; i--)
    {
        int u = order_node[i];
        white[u] = 1;
        black[u] = 1;
        for (int v : graph[u])
        {
            if (parent_node[v] == u)
            {
                white[u] = white[u] * ((white[v] + black[v]) % MOD) % MOD;
                black[u] = black[u] * white[v] % MOD;
            }
        }
    }
    cout << (white[1] + black[1]) % MOD << '\n';
}
```

教学输入（自设，非官方样例）：

```text
3
1 2
2 3
```

输出：

```text
5
```

每个父状态决定各孩子允许的状态集合，孩子间不交叉，乘积恰好生成所有合法方案。总共访问每条边常数次，时间 $O(n)$，空间 $O(n)$（包括邻接表）。数组与邻接表均需在多测时清理。

## 换根：所有点的距离和

对每个 u 求 `answer[u]=Σ dist(u,x)`。逐个源遍历要 $O(n^{2})$。先以 1 为根，求 $\mathrm{size}[u]$ 和 $\mathrm{answer}[1]$（所有深度之和），再从父 u 换到孩子 v：v 子树的 $\mathrm{size}[v]$ 个点距离各减少 1，其他 $n-\mathrm{size}[v]$ 个点距离各增加 1。

$$
answer[v]=answer[u]+n-2size[v].
$$

三点链答案为 3、2、3：由 1 到 2，$\mathrm{size}[2]=2$，差值 -1；由 2 到 3，$\mathrm{size}[3]=1$，差值 +1。这一步使用的是以原根 1 定义的子树大小，无需真的重建每个根的树。

完整自编程序：单组无权树，接口、容量与上例一致，输出按点编号排列的 n 个距离和。build_order 顺序计算父亲与深度，逆序聚合 size，再正序传播答案。最大和约 $n(n-1)/2$，long long。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 100000 + 5;
vector<int> graph[MAXN];
int parent_node[MAXN];
int order_node[MAXN];
int depth_node[MAXN];
int subtree_size[MAXN];
long long answer[MAXN];

void build_order()
{
    order_node[1] = 1;
    int count = 1;
    for (int i = 1; i <= count; i++)
    {
        int u = order_node[i];
        for (int v : graph[u])
        {
            if (v != parent_node[u])
            {
                parent_node[v] = u;
                depth_node[v] = depth_node[u] + 1;
                order_node[++count] = v;
            }
        }
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = 1; i < n; i++)
    {
        int u;
        int v;
        cin >> u >> v;
        graph[u].push_back(v);
        graph[v].push_back(u);
    }
    build_order();
    for (int i = n; i >= 1; i--)
    {
        int u = order_node[i];
        subtree_size[u]++;
        subtree_size[parent_node[u]] += subtree_size[u];
        answer[1] += depth_node[u];
    }
    for (int i = 2; i <= n; i++)
    {
        int u = order_node[i];
        answer[u] = answer[parent_node[u]] + n - 2LL * subtree_size[u];
    }
    for (int u = 1; u <= n; u++)
    {
        cout << answer[u] << (u == n ? '\n' : ' ');
    }
}
```

教学输入（自设，非官方样例）：

```text
3
1 2
2 3
```

输出：

```text
3 2 3
```

复杂度 $O(n)$ 时间与空间。$\mathrm{size}[0]$ 在程序中只作为根聚合的哨兵，不参与换根。带权边 e 时差值为 `(n-2size[v])×e`，需重新控制数值上界。

## 树上背包合并

若要求选 k 个点，仅保留选/不选不够。以“选点集合连通且必须含子树根”为例，$f[u][k]$ 表示 u 子树中选 k 点、包含 u 的最大权和，初始 $f[u][1]=w[u]$。合并孩子 v，枚举已处理孩子中的选点数 a 与从 v 子树选点数 b；$b=0$ 可不取该子树，$b>0$ 时必须使用包含 v 的 $f[v][b]$，保证连接。

合并的新表取 $\max (old[a]+f[v][b])$；以新旧表分离最容易理解，同层原地更新要证明不会重复使用孩子。不可达用负无穷，不能全 0。一个孩子中挑一个孙子却不挑孩子会破坏连通，不能放宽状态。

若每点最多 K 个状态，直接每条父子合并枚举 a,b 的安全上界 $O(nK^{2})$，空间 $O(nK)$。可把 a,b 限制在有效子树大小内，但更好的总界取决于模型，不能把所有树上背包都写成 $O(nK)$。这里为机制说明，未给独立完整模板。


## 完整树上背包：恰选 K 点，连通且包含根

自编模型：给一棵点权树，恰选 K 个点，所选点连通且包含点 1，最大化权和。负权不能跳过必要的连接点；这不同于任意选 K 点，也不同于先修课程森林的输入。

f[u][a] 表示 u 子树中恰选 a 个、连通且包含 u 的最优权和。开始只选 u：f[u][1]=w[u]。合并孩子 v 时 b=0 不选这个孩子子树；b>0 必须取包含 v 的 f[v][b]，这样通过边 u—v 接到已有集合。所有候选读旧表并写新表，防止同一个孩子重复使用。

例根权 5，两个叶子权 −2、4，K=2。初始根表只有 f[1][1]=5。合并 −2 后，表为 [5,3]；合并 4 后，f[1][1]=5、f[1][2]=max(3,5+4)=9。若 K=3 则必须选负点，答案 7，不能把“不可达”的状态清为 0 来逃避恰选约束。

完整单组输入 n K、n 个点权、n−1 条树边；`1<=K<=n<=150`、`|w[i]|<=10^9`，树连通，根固定为 1。输出最大权和。1 下标，二维容量 155，NEG=−4×10^18，真实权和绝对值≤1.5×10^11。先构造父节点顺序，再反序聚合，避免深链递归。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 150 + 5;
const long long NEG = -4000000000000000000LL;
vector<int> graph[MAXN];
int parent_node[MAXN];
int order_node[MAXN];
int subtree_size[MAXN];
long long weight[MAXN];
long long dp[MAXN][MAXN];
long long merged[MAXN];

int main()
{
    int n;
    int K;
    cin >> n >> K;
    for (int u = 1; u <= n; u++)
    {
        cin >> weight[u];
    }
    for (int i = 1; i < n; i++)
    {
        int u;
        int v;
        cin >> u >> v;
        graph[u].push_back(v);
        graph[v].push_back(u);
    }
    int count = 1;
    order_node[1] = 1;
    for (int i = 1; i <= count; i++)
    {
        int u = order_node[i];
        for (int v : graph[u])
        {
            if (v != parent_node[u])
            {
                parent_node[v] = u;
                order_node[++count] = v;
            }
        }
    }
    for (int index = n; index >= 1; index--)
    {
        int u = order_node[index];
        fill(dp[u], dp[u] + K + 1, NEG);
        dp[u][1] = weight[u];
        subtree_size[u] = 1;
        for (int v : graph[u])
        {
            if (parent_node[v] != u)
            {
                continue;
            }
            fill(merged, merged + K + 1, NEG);
            for (int a = 1; a <= min(K, subtree_size[u]); a++)
            {
                if (dp[u][a] == NEG)
                {
                    continue;
                }
                for (int b = 0; b <= min(K - a, subtree_size[v]); b++)
                {
                    long long child = b == 0 ? 0 : dp[v][b];
                    if (child != NEG)
                    {
                        merged[a + b] = max(merged[a + b], dp[u][a] + child);
                    }
                }
            }
            copy(merged, merged + K + 1, dp[u]);
            subtree_size[u] += subtree_size[v];
        }
    }
    cout << dp[1][K] << '\n';
}
```

教学输入：

```text
3 2
5 -2 4
1 2
1 3
```

输出：

```text
9
```

正确性按“已合并的孩子数”归纳：任意合法连通集合在孩子子树中的交集要么空，要么包含该孩子且连通；枚举 a,b 恰好覆盖这些互斥分解，孩子子树不重叠，取最大即可。每边一次合并，安全上界 O(nK²)，空间有效 O(nK+n)，静态数组按 MAXN 分配。限制有效子树大小减少实际计算量，本模板不宣称所有模型均达到更强 O(nK)。测试 K=1、K=n、全负、星形和长链。练习关联仍见题单的依赖选择模型，输入接口不能直接照搬。

## ABC447F Centipede Graph

[官方题面](https://atcoder.jp/contests/abc447/tasks/abc447_f)

树中求最长“蜈蚣”：骨架为k点路径，每个骨架点另接两片叶，求最大k；多测总N≤2×10⁵。

> [!tip]- 提示一
> 骨架内部点要留两条骨架边与两条叶边，端点只需一条骨架边。

> [!tip]- 提示二
> dp[u]记录可继续接到父亲的最优骨架链；最多合并两个孩子方向。
>
> 复习：[[08动态规划/07-树形DP与换根]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码度≥2允许答案1，度≥3让dp[u]=1，因为预留父边后仍有两条叶边。收集孩子dp的前两大max1/max2；度≥3可用u作端点接一条链更新答案，度≥4可接两条链更新答案，也可把1+max1作为向父继续的dp。
>
> **正确性与适用条件。** 在树中额外叶邻居不会与骨架其他部分重合，否则产生环；因此原树度数足以检验可用叶数。选一条向父链与选两条形成完整路径的条件不同，分别需度≥4；所有骨架路径可按其最高点分成零、一、两条孩子链，转移穷尽并取最优。
>
> **手算与边界。** 一个度为2的三点小树可选中心作k=1；两个相邻且度均为3的节点可组成k=2。度仅为3的点不能作为三点骨架中间点，因为两条骨架边只剩一条叶边。
>
> **实际复杂度与实现。** 每点每边处理常数次，O(N)时间与空间。源码DFS在长链上深度O(N)，多测需清空g、dp和ans；输出是骨架长度k，不是总节点数3k。
