## 问题与第一次尝试

有 n 件物品，每件只能取一次，容量 W，求最大价值。枚举选与不选是 O(2^n)，n=100 时不可行。按重量做 01 背包是 O(nW)，但如果 W 可到 10^9，空间与时间仍不可承受。

[AtCoder DP E — Knapsack 2](https://atcoder.jp/contests/dp/tasks/dp_e) 的官方范围为 n<=100、W<=10^9、单件正价值<=1000，价值和最多 100000。这提示用较小的价值维度替换重量维度。

## 难度与重要程度

| 算法或主题 | 难度 | 重要程度 | 理由 |
|---|---:|---:|---|
| 价值维度背包 | 5/10 | 8/10 | 交换被限制资源与被优化目标，利用更小总量。 |

评分为本学习路线的主观建议，尺度见 [[00-动态规划#评分尺度|评分尺度]]。

## 状态为什么改为最小重量

设 cost[s] 为恰好得到总价值 s 所需的最小重量。相同价值下，重量更小的前缀可以容纳至少同样多的后续物品，因此其他重量被支配。初始 cost[0]=0，其余正无穷。

物品重量 w、价值 v：不选保留 cost[s]；选更新 cost[s]=min(cost[s],cost[s-v]+w)。价值倒序仍保证每件最多一次。最终找最大的 s，使 cost[s]<=W。不是输出 cost[W]，因为下标已经不代表重量。

教学例 `(3,4)`、`(4,5)`、W=6：初始只可达 s=0；第一件后 s=4 成本 3；第二件后 s=5 成本 4、s=9 成本 7。最大可行 s=5，而价值 9 超容量。若把不可达 cost 全设 0，就会凭空认为所有价值都可用 0 重量取得。

## 完整程序与接口

单组输入 n W，随后 n 行重量价值。`1<=n<=100`、`1<=w<=10^9`、`1<=v<=1000`，MAXV=100005，下标为恰好价值 0..Σv。W 与 cost 用 long long；INF=4×10^18，跳过不可达来源。输出最大价值。接口与官方题一致，以下是自设教学样例。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXV = 100000 + 5;
const long long INF = 4000000000000000000LL;
long long cost[MAXV];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long capacity;
    cin >> n >> capacity;
    fill(cost, cost + MAXV, INF);
    cost[0] = 0;
    int total_value = 0;
    for (int i = 1; i <= n; i++)
    {
        long long weight;
        int value;
        cin >> weight >> value;
        total_value += value;
        for (int s = total_value; s >= value; s--)
        {
            if (cost[s - value] != INF)
            {
                cost[s] = min(cost[s], cost[s - value] + weight);
            }
        }
    }
    int answer = 0;
    for (int s = 0; s <= total_value; s++)
    {
        if (cost[s] <= capacity)
        {
            answer = s;
        }
    }
    cout << answer << '\n';
}
```

教学输入（自设，非官方样例）：

```text
2 6
3 4
4 5
```

输出：

```text
5
```

## 正确性与复杂度

前 i 件中恰好价值 s 的解按是否取第 i 件划分；已取时其余恰好 s-v，最小重量可替换而不影响价值。倒序保障前一层。最终扫描所有可行价值，最大者即原目标。

令 V=Σv，时间 O(nV)，有效空间 O(V)，固定程序分配 MAXV 个 long long。当前成本最多 100×10^9，远小于 INF；不能对任意数据都默认加法不会溢出。

## 对照与适用边界

| 数据规模 | 合适的起点 | 原因 |
|---|---|---|
| n很小，重量价值均大 | 暴力或折半搜索 | 状态按数值开数组代价太高 |
| W较小 | 重量维度01背包 | 直接在资源预算中优化收益 |
| 总价值V较小，W很大 | 价值维度背包 | 用较小值域记录最小成本 |
| n、W、V均大 | 重新分析结构 | 上面两种均不能保证可行 |

负价值、多个资源、计数任务改变了状态域或目标，不能只把数组大小换小。练习：用子集暴力对拍两种背包，加入全部超重、容量刚好等于某组合、大重量、重复物品。
