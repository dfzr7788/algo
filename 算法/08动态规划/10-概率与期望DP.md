## 用途：随机过程的分布与平均成本

求“出现多少次成功的概率”通常前向传播概率；求“从这个状态到终点平均还要多少步”通常写后向期望方程。枚举全部随机结果可能有 $2^{n}$ 种，合并相同成功次数或相同剩余局面可以大幅减小规模。

概率和方案数不同，不能在每条转移都加 1；期望也不能用“最大概率分支”代替所有分支加权。含自环的期望不一定是无环 DP，要先解去自环或解方程组。

## 硬币：恰好j次正面的概率

独立硬币第 i 枚正面概率 $p[i]$。`f[i][j]` 为前 i 枚恰好 j 次正面的概率，$f[0][0]=1$。最后一枚反面来自 $f[i-1][j]\times (1-p)$，正面来自 $f[i-1][j-1]\times p$，互斥相加。

两枚概率 0.5、0.25：第一层 `[0.5,0.5]`，第二层 `[0.375,0.5,0.125]`，和为 1。第二层至少一次正面的概率为 0.625，但正面严格多于反面只有 $j=2$，概率为 0.125。

完整程序与 [AtCoder DP I — Coins](https://atcoder.jp/contests/dp/tasks/dp_i) 同模型，单组 n 与 n 个概率，`1<=n<=2999`。教学允许偶数 n 及 0、1 概率，输出正面严格多于反面的概率。$\mathrm{MAXN}=3005$，次数 0 下标，double，固定输出 12 位小数。内层 j 倒序保证 $dp[j-1]$ 仍为旧层，$j=0$ 单独处理。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 3000 + 5;
double dp[MAXN];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    dp[0] = 1.0;
    for (int i = 1; i <= n; i++)
    {
        double p;
        cin >> p;
        for (int j = i; j >= 1; j--)
        {
            dp[j] = dp[j] * (1.0 - p) + dp[j - 1] * p;
        }
        dp[0] *= 1.0 - p;
    }
    double answer = 0.0;
    for (int j = n / 2 + 1; j <= n; j++)
    {
        answer += dp[j];
    }
    cout << fixed << setprecision(12) << answer << '\n';
}
```

教学输入（自设，非官方样例）：

```text
2
0.50 0.25
```

输出：

```text
0.125000000000
```

转移按最后一枚硬币的正反面拆分，独立性使联合概率可相乘，故正确。时间 $O(n^{2})$，空间 $O(n)$。浮点检查按误差比较，不比字符串相等；教学也应核对最终分布总和接近 1。

## 期望：集齐随机卡片

自编模型：有 n 种卡，每次独立均匀随机抽一张，求集齐所有种类所需抽取次数的期望。状态 i 为已经拥有 i 种；均匀性让具体卡种集合可合并，否则仅 i 不够。

终点 $E[n]=0$。当前再抽必花一次，概率 i/n 抽到旧种，仍留原状态；概率 $(n-i)/n$ 抽到新种：

$$
E[i]=1+\frac{i}{n}E[i]+\frac{n-i}{n}E[i+1].
$$

移项得到 `E[i]=n/(n-i)+E[i+1]`，按 i 递减求解。$n=2$ 时 $E[2]=0$，$E[1]=2$，$E[0]=3$：第一种只需一次，第二种平均两次。

完整自编教学程序：单组 `1<=n<=100000`，输出期望保留 10 位小数；$\mathrm{MAXN}=100005$，状态 $0\ldots n$，double。时间 $O(n)$，空间 $O(n)$，可进一步仅用一个累加变量。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 100000 + 5;
double expectation[MAXN];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = n - 1; i >= 0; i--)
    {
        expectation[i] = static_cast<double>(n) / (n - i) + expectation[i + 1];
    }
    cout << fixed << setprecision(10) << expectation[0] << '\n';
}
```

教学输入（自设，非官方样例）：

```text
2
```

输出：

```text
3.0000000000
```

## 自环与无穷期望

一般式 `E[s]=cost+Σ p(s,t)E[t]`，若唯一循环是本状态自环，且自环概率 $q<1$，可除以 1-q 消去。若 $q=1$ 且每次有正成本，则不能除零，终点不可达，期望为无穷。若不同状态互相成环，消去单状态自环不保证无环；可能需线性方程，先判断吸收和期望有限的条件。

不要用整数除法计算概率；不要把所有终点期望设 1，结束后剩余成本为 0。非均匀集卡需要记录具体已收集集合，可能与 [[08-状态压缩DP]] 结合。练习见 [[14-动态规划题单]]。
