## 常见错误与最小反例

| 错误想法 | 反例 | 应怎样修正 |
|---|---|---|
| 能行动就必胜 | 取 1..2，剩 3 | 要能走到对手 P 态才必胜 |
| 终局只有石子数 0 | 只可取 2 或 3，剩 1 | 判无合法动作，不能只判空堆 |
| 不同堆只看总数 | (1,1) 与 (2) | 保存完整堆结构或正确抽象值 |
| 单独都赢，组合也赢 | 两个大小 1 的 Nim 堆 | 子游戏合并需要 SG，不是逻辑或 |
| 任意取数集合都取模最大数+1 | {2,3}，剩 1 | 集合有缺口时先用 DP/SG |
| Nim 异或非零任意操作都赢 | (3,4,5) 将 3 变 2 | 必须实际构造到零异或 |
| SG 会沿动作严格减小 | {1,3,4} 中 2→1，SG 从 0→1 | mex 只排除自身、覆盖较小值 |
| 取最后者输也异或原堆数 | 单堆 (1) | 全 1 局面按奇偶单独处理 |
| 两堆联动仍分别当 Nim | 威佐夫 (1,1) | 同时取完可赢，不能错误拆分 |
| 斐波那契只记录剩余数量 | (8,r=7) 与 (8,r=8) | 中途必须保留行动上限 |
| 同规则“首步能取完”无影响 | Fibonacci 初始 n=2 | 能取完就直接赢，原必败结论失效 |
| 质因子只统计种类 | x=4 | 真因数 SG 为 {0,1}，SG(4)=2 |
| 计分游戏每步取较大端点 | (8,15,3,7) | 先取 7 可保证更高最终分差 |

## 证明中最容易漏掉的一半

提出某个必败集合后，必须同时证明“集合内部没有合法互相转移”和“集合外总能一步进入集合”，再结合有限性与终局。只列几个必败点、只证明零异或会变非零、只给一条获胜路线，都不完整。

在阶梯博弈里，零态走到的局面确实可由对手回应回零，但证明形式不是逐阶独立 SG；在斐波那契里，分解项不能作为彼此独立的真实堆。证明要跟真实动作对应。

## 数值和存储边界

- 巴什：算 m+1 前确认整数范围；反常公式只在 n≥1 使用。
- Nim：堆数非负；流式判定无需求和；构造检查目标严格小于当前值。
- SG：mex 标记每个状态重置；容量依据后继数，而不是凭样例值选。零取数或负取数会破坏递推依赖。
- 威佐夫：k=b−a 前先排序；精确模板 5k² 的上界限定 k≤10^9；平方根比较不用 mid*mid。
- Fibonacci：保留 1、2 起点；在加法之前检查上界；首步取数必须正且小于 n。
- 阶梯：物理阶号从 1 开始，0 阶不可操作；不能把数组下标和物理阶号混淆。
- 分差 DP：使用 long long；确认状态视角、短区间计算顺序和压缩遍历方向。

## 怎样做独立验证

小规模先枚举真实合法动作，保存完整局面，递归定义“存在到 P 的动作”，不用被验证的公式。Nim 与 SG 合并用两三堆小整数；威佐夫保存 (a,b) 并枚举两类动作；阶梯保存各阶数量；Fibonacci 保存 (n,r)。计分游戏直接枚举全部取端点路线，用初始先手 max、后手 min 评价最终分差。

生成规律后再扩大到边界：0/1、全空、全 1、同堆、交换 a/b、最大数组容量、多测清零。威佐夫特意检查 Fibonacci 分母附近的取整；构造输出验证合法性和后继性质，不仅核对文字。平台样例通过不等于已提交 AC。
