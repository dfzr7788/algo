本模块研究算法竞赛中的双人组合游戏：从规则建立状态，判断双方最优行动下的结果，并在需要时构造第一步。主线是有限、无随机、完全信息的游戏；概率博弈、纳什均衡和一般经济博弈不在本模块范围内。

## 先修知识与学习路线

先掌握 [[06-递归与分治]]、[[02-枚举与暴力]]、[[01-位运算与子集枚举]]；读 SG 前理解动态规划中“状态保存未来所需信息”的思想。会拓扑排序有助于把状态递推推广到 DAG。

第一轮学习 01 → 02 → 03 → 04，能够解释必胜态、构造 Nim 操作、计算单堆 SG 并合并。第二轮按需学习 05、06、07；08 介绍按得分评价的游戏，09 练习从规则推导公式。最后用 10 找反例、11 刷题、12 独立建模。

## 根据规则选方法

| 规则或需求 | 优先方法 | 必须核对 |
|---|---|---|
| 单堆，每次取 1 到 m | 巴什 | 上限固定，正常规则还是取最后者输 |
| 多堆，每次只动一堆、任意正数 | Nim | 不能跨堆，不能取 0 |
| 多个独立游戏，每次只动其中一个 | SG 异或 | 无偏、有限、正常规则、相互独立 |
| 两堆可同时减去相同数量 | 威佐夫 | 两堆联动，不能分别当 Nim 堆 |
| 下一步上限是上一步取数的两倍 | 斐波那契 | 首步不能取完；中途还需记录上限 |
| 石子从第 i 阶移到第 i−1 阶 | 阶梯博弈 | 一次只移动一个阶梯中的任意正数 |
| 最终比较分数 | 分差 DP | 目标是最优得分，不是无路可走判负 |
| 可回到旧状态、可能无限行走 | 另外分析环和平局 | 普通有限 DAG 递推不能直接套用 |

## 评分尺度与总览

评分为本项目竞赛学习路线的主观建议，均为 1–10。难度综合理解、实现、边界和基础证明；重要程度综合基础性、适用范围与后续依赖，不是官方难度或出题频率。高级选读证明不计进入门分数。

| 算法或主题 | 难度 | 重要程度 | 理由 |
|---|---:|---:|---|
| 必胜必败态与状态递推 | 3/10 | 10/10 | 所有后续模型的共同语言 |
| 巴什博弈 | 2/10 | 7/10 | 最容易练习必败集合证明 |
| 反常巴什 | 3/10 | 5/10 | 训练终局规则与边界 |
| Nim 判定与构造 | 4/10 | 10/10 | 异或策略是 SG 的基础 |
| 反常 Nim | 5/10 | 6/10 | 需要单独处理全 1 局面 |
| SG 函数与独立和 | 6/10 | 9/10 | 把复杂操作转为可合并数值 |
| 分裂游戏 SG 递推 | 6/10 | 6/10 | 一步产生多个独立子游戏 |
| 威佐夫博弈 | 5/10 | 5/10 | 规则专用，需处理取整精度 |
| 斐波那契博弈 | 6/10 | 4/10 | 动态上限与数论分解结合 |
| 阶梯博弈 | 5/10 | 6/10 | 用回应策略证明抽象模型 |
| 得分博弈与区间 DP | 5/10 | 8/10 | 学会双方最优下的视角变换 |
| 因数游戏 SG 优化 | 6/10 | 7/10 | 从可达值集合推导封闭公式 |
| 字符串删除博弈与终局构造 | 4/10 | 6/10 | 证明能一步终结，再线性判定有序端点 |

## 代码、练习与阅读约定

完整程序使用 C++17、四空格缩进、左花括号独占行、具名函数和明确容量。章节注明自己的输入输出；自编格式不能直接当平台提交格式。平台题仅核对题面，未实际提交，不声称 AC。

先讲“为什么需要”，再手算、看模板、检验正确性与边界；复杂证明放在扩展选读。只求单局胜负时布尔 DP 往往足够，合并子游戏时才需要 SG。有限样例中的周期只用于猜想，不能代替证明。
