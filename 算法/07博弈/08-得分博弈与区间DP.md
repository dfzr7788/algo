## 问题与为什么不能只记胜负

给定序列，每次从最左或最右取一个数加入自己得分，直到序列为空。双方都想让自己的总分减去对手总分最大。若只记“有没有合法动作”，除空区间外全能动，却无法回答最终分差；SG 也不能表示积分收益。

朴素枚举左右选择有指数级分支。每次剩余的一定是原序列的连续区间，相同区间的最优结果可以复用，把问题降为 O(n²) 个状态。

**难度 5/10，重要程度 8/10**：广泛用于双方最优决策，核心是统一状态视角。

## 从当前行动者视角定义分差

令 dp[l][r] 为剩余闭区间 l..r 中，当前行动者能保证的“自己分数−对手分数”。空区间为 0，单元素为 a[l]。

取左端后，下一步 dp[l+1][r] 从对手视角计算，必须减去它；取右端同理：

$$
dp[l][r]=\max\bigl(a_l-dp[l+1][r],\ a_r-dp[l][r-1]\bigr).
$$

虽然全程都取 max，已经体现对手最优，因为对手的最大优势被当前玩家减掉了。若把状态固定为“初始先手分差”，则要区分先后手 max/min，不能同时混用两种语义。

## 手算：10、100、10

单点分差分别为 10、100、10。区间 [1,2] 的最优分差 max(10−100,100−10)=90，[2,3] 同样为 90。全区间的两个选择都是 10−90=−80，最终先手败 80 分。双方都能合法取数，但先手没有办法避开中间 100 被后手拿走。

## 完整程序：二维区间 DP

对应 [AtCoder DP L — Deque](https://atcoder.jp/contests/dp/tasks/dp_l)。输入 n 和 n 个数，n≤3000、1≤a[i]≤10^9，输出初始先手总分−后手总分，可为负或 0。数组 1 下标，区间闭合；long long 保存最大约 3×10^12 的分差。二维静态数组约 69 MiB，平台题面内存限制允许；更小内存场景参考扩展选读。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 3000 + 5;
long long a[MAXN];
long long dp[MAXN][MAXN];

long long solve(int n)
{
    for (int i = 1; i <= n; i++)
    {
        dp[i][i] = a[i];
    }
    for (int len = 2; len <= n; len++)
    {
        for (int l = 1; l + len - 1 <= n; l++)
        {
            int r = l + len - 1;
            dp[l][r] = max(a[l] - dp[l + 1][r], a[r] - dp[l][r - 1]);
        }
    }
    return dp[1][n];
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
    }
    cout << solve(n) << '\n';
    return 0;
}
```

教学样例输入 `3`，第二行 `10 100 10`，输出 -80。时间 O(n²)，空间 O(n²)。程序通过按区间长度归纳保证计算时两段较短区间已求出。多测使用 n 对应区间重新计算即可，不能省略单点初始化。

## 应用、错误与练习

贪心取较大端点不可靠：(8,15,3,7) 中取 8 会让对手取 15，自己最佳只能取 7，分差为 −3；先取 7 则可保证分差 11。带负数的自编变式仍使用相同递推，但平台原题的数值是正数。

若只求最终先手分数，可设总和 S，则先手分数=(S+dp[1][n])/2。这个等式要求所有数最终都被取走、两人的收益确为这些数的和；中途可停止时不能直接使用。

练习见 [[11-博弈题单]] 的 DP L、D1。抽象游戏里双方若各有不同目标，或一个玩家只想让某阈值成立，需要重新定义效用和状态，不能默认零和。

## 扩展选读：一维压缩的方向

令 f[l] 保存上一长度的 dp[l][l+len−2]，初始 f[l]=a[l]。新长度 len 时，按 l 从小到大更新为 `max(a[l]−f[l+1],a[r]−f[l])`。此时 f[l+1] 尚未更新，f[l] 也还是旧值，正好对应两个短区间；倒序会读到被覆盖的新值。这个局部公式依赖外层 len、端点 r、1 下标数组与该遍历方向，不能脱离循环独立运行。空间可降到 O(n)，但如果要还原完整选取路径，还需要额外记录选择或重新计算。
