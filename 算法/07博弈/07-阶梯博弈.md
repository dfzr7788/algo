前置：[[03-尼姆博弈]]。阶梯博弈把一些看似联动的移动游戏转为 Nim 判胜，但需要专门的回应策略证明。

## 规则与用途

有 n 个阶梯，编号 1..n，第 i 阶有 a[i] 颗石子。每步选 i，将该阶任意正数颗石子移到 i−1；0 阶是移出区，不能再从中行动。所有石子最终移到 0 阶后，无法行动者输。

相邻阶数量一起改变，所以不能把每一阶直接当独立 Nim 堆。但每次势能 `Σ i·a[i]` 严格减少，游戏有限。若允许跳过多阶、向上移动或每次只移动一颗，都不是本篇模型。

**难度 5/10，重要程度 6/10**：练习通过配对回应证明抽象结论。

## 为什么只看奇数阶

结论：先手必胜当且仅当 `a[1] xor a[3] xor a[5] ... != 0`。从奇数阶移向偶数阶，在奇数阶集合中就是减少一堆，像一次 Nim 操作；从偶数阶移向奇数阶则可能增加某个被统计的堆，因此不能直接沿用“零异或操作后必非零”的 Nim 证明。

证明零异或态必败使用对手的回应策略：

1. 如果当前玩家从偶数阶 i 移 t 到 i−1，回应者立即把这 t 从奇数阶 i−1 移到 i−2。奇数阶数量恢复原值，异或仍为 0；i≥2，所以回应合法。
2. 如果当前玩家从奇数阶移 t，奇数阶异或由 0 变非零。回应者在奇数阶上执行普通 Nim 制胜操作，把奇数阶异或恢复为 0。这次移动一定合法。

回应不会让自己无动作可做，且势能严格下降，所以最终是回应者完成最后一次行动。非零态则先用奇数阶 Nim 操作交出零态，之后执行上述回应。这个证明说明胜负结论，未证明完整 SG 值等于奇数阶异或；不要把两者混为一谈。

## 手算

三阶 (1,2,1)，奇数阶异或 1 xor 1=0，先手必败。若先手从第 2 阶移 2 到第 1 阶，变 (3,0,1)，后手从第 1 阶移 2 到 0 阶，变 (1,0,1)，恢复零异或。

若先手从第 3 阶移 1 到第 2 阶，变 (1,3,0)，后手从第 1 阶移 1 到 0 阶，变 (0,3,0)，同样恢复零异或。零态也可能仍有偶数阶石子，不能把它当作终局。

## 完整程序：只判胜负

自编输入：n，随后 n 个非负整数 a[i]，1≤n≤200000、a[i]≤10^18，输出 First/Second。按物理阶号 1 下标判奇偶；流式扫描，不需数组。这里既不计算势能也不求总和，因此没有加法溢出问题。

```cpp
#include <iostream>
using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long sum = 0;
    for (int i = 1; i <= n; i++)
    {
        long long stones;
        cin >> stones;
        if (i % 2 == 1)
        {
            sum ^= stones;
        }
    }
    cout << (sum != 0 ? "First" : "Second") << '\n';
    return 0;
}
```

输入 `3`，第二行 `1 2 1`，输出 Second；输入 `2`，第二行 `0 1`，输出 Second：先手移到第 1 阶，后手移到 0 阶。输入 `1`，第二行 `7`，输出 First。时间 O(n)，额外空间 O(1)。

## 边界与练习

0 阶不计入输入，也不参与异或。若输入用 0 下标数组，物理第一阶仍应参与，不能机械筛选数组奇下标。全空初始为 Second。

练习见 [[11-博弈题单]] 的 T1。小规模暴力状态保存所有阶数量，而不能先用奇数阶结论作为暴力判定，否则对拍不独立。
