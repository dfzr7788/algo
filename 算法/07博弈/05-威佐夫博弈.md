前置：[[01-博弈基础与必胜必败态]]、[[03-尼姆博弈]]。威佐夫博弈（Wythoff Game）有两堆非负数量 a、b，每步从一堆取任意正数，或同时从两堆各取相同正数，无法行动者输。

## 难度与重要程度

| 算法或主题 | 难度 | 重要程度 | 理由 |
|---|---:|---:|---|
| 威佐夫博弈 | 5/10 | 5/10 | 掌握专用必败结构和数值边界，竞赛应用范围比 Nim、SG 窄。 |

## 为什么 Nim 结论失效

两堆 $(1,1)$ 的 Nim 异或为 0，但这里可以两堆同时取 1，直接赢。新动作让两堆互相影响，需要将 $(a,b)$ 当作一个完整状态。二维 DP 能在小范围观察必败点；范围达到 $10^{9}$ 时需要专用公式。

## 从必败点到黄金分割

统一 $a\le b$，前几个 P 态为 $(0,0)$、$(1,2)$、$(3,5)$、$(4,7)$、$(6,10)$、$(8,13)$。差值依次为 0、1、2、3、4、5。

可递推生成：从未使用的非负整数中选最小的 $a_{k}$，再令 $b_k=a_k+k$。$k=0$ 时 $(0,0)$ 的 0 出现两次；**两个正数序列覆盖每个正整数恰一次**，不能说包括 0 在内都仅出现一次。

它们的通项是：

$$
\phi=\frac{1+\sqrt5}{2},\qquad a_k=\lfloor k\phi\rfloor,\qquad b_k=a_k+k.
$$

正整数互补来自 Beatty 定理，见 [Rice University — Wythoff’s Game](https://math.rice.edu/~michael/teaching/2012Fall/Wythoff.pdf)。给定 $a\le b$，差值 $k=b-a$，当前必败当且仅当 $a=a_k$。公式适用于本节规定的两种动作，任意改规则都要重分析。

## 正确性要点和构造思路

不同 P 态没有相同正坐标，也没有相同差值：单堆取数不能连接两个 P 态，同时等量取数也不能。非 P 态必须证明能走到 P 态，不能只列几个点猜测。

若 $a>a_k$，两堆同时取 $a-a_k$ 到 ($a_{k}$,$b_{k}$)。若 $a<a_k$，$k>0$，用互补性找包含正数 a 的唯一 P 对；若 a 是较小项 $a_{j}$，则 $j<k$，配对较大项 $a+j<b$，可减大堆到它；若 a 是较大项 $b_{j}$，则可把 b 减到 $a_{j}$，排序后到 ($a_{j}$,$b_{j}$)。若 $a=0$、$b>0$，直接取完 b。

原例 $(4,7)$ 是 P 态；$(5,7)$ 差 2，对应 P 态 $(3,5)$，同时取 2 即可。不是每个 N 态都能靠“同差值同时取”解决，例如 $(1,3)$ 应从大堆取 1 到 $(1,2)$。本节完整程序只判胜；构造可在小范围枚举 P 对，在大范围用单调序列二分找包含 a 的配对。

## 为什么使用精确整数判定

直接计算 `(long long)(k*phi)` 会在 k*phi 非常接近整数时受到舍入影响；加 epsilon 也可能把正确的向下取整改成向上。这里针对 $a,b\le 10^{9}$ 使用整数平方根，无需任何浮点数。

令 $q=\operatorname{floor}(\operatorname{sqrt}(5k^{2}))$，则：

$$
\lfloor k\phi\rfloor=\left\lfloor\frac{k+q}{2}\right\rfloor.
$$

因为 $\operatorname{sqrt}(5k^{2})=q+\delta$，$0\le \delta <1$，整数 $k+q$ 无论奇偶，加 $\delta$ 都不会跨越下一个整数边界。$k\le 10^{9}$ 时 $5k^{2}\le 5\times 10^{18}$，long long 可容纳。二分比较 `mid <= value/mid` 避免 mid*mid 溢出。

## 完整程序：精确判胜

对应 [洛谷 P2252 — 威佐夫博弈 / 取石子游戏](https://www.luogu.com.cn/problem/P2252)。一行 a、b，非负且 $\le 10^{9}$；赢输出 1，输输出 0。题面列出 -1，但在有限、完全信息且无平局的本规则下结果总可确定，不需要输出 -1。没有数组。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

long long integer_sqrt(long long value)
{
    long long left = 0;
    long long right = 3000000000LL;
    while (left < right)
    {
        long long mid = left + (right - left + 1) / 2;
        if (mid <= value / mid)
        {
            left = mid;
        }
        else
        {
            right = mid - 1;
        }
    }
    return left;
}

bool first_wins(long long a, long long b)
{
    if (a > b)
    {
        swap(a, b);
    }
    long long k = b - a;
    long long root = integer_sqrt(5LL * k * k);
    long long losing_a = (k + root) / 2;
    return a != losing_a;
}

int main()
{
    long long a, b;
    cin >> a >> b;
    cout << (first_wins(a, b) ? 1 : 0) << '\n';
    return 0;
}
```

输入 `4 7` 输出 0；输入 `5 7` 输出 1；输入 `0 0` 输出 0；输入 `7 4` 同样输出 0。二分进行约 32 次，时间 $O(\log U)$，U 为平方根搜索上界，空间 $O(1)$。在当前固定整数范围内次数有固定上界；不要把这份二分模板写成通用 $O(1)$ 浮点实现。

## 边界与练习

mid 在循环内至少为 1，不会除零；$k=0$ 也能正确计算 $\mathrm{root}=0$。不能把范围无条件扩到 $10^{18}$，因为 $5k^{2}$ 会溢出；需要更宽整数或大整数方案。至少测试空堆、等堆、交换输入、大差值，以及 Fibonacci 分母附近的 P 态。

练习见 [[11-博弈题单]] 的 P2252 和 W1；小规模二维暴力必须同时枚举两种合法取法。
