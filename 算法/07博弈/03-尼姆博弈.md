前置：[[02-巴什博弈]]、[[01-位运算与子集枚举]]。尼姆博弈（Nim Game）有多堆石子，每次仅选一堆，取任意正数，可取光该堆；无法行动者输。

## 为什么总数和单堆胜负都不够

(1,1) 总数 2，先手取掉一堆，后手取掉另一堆，因此先手败；(2) 总数也是 2，却可一步取完。更进一步，两个单独必胜的子游戏放在一起可能必败，不能把每堆的 win 做逻辑或。

若直接枚举多堆状态，状态数可达各堆数量加一的乘积。Nim 的异或结论把判定降到一次扫描，并能构造合法首步。

**Nim 判定与构造：难度 4/10，重要程度 10/10**，是 SG 理论的基础。**反常 Nim：难度 5/10，重要程度 6/10**，要区分全 1 局面。

## 异或和与证明

设 S=a1 xor a2 xor ... xor an。S=0 为 P 态，S≠0 为 N 态（Bouton 定理）。

终局全为 0，异或和为 0。从 S=0 把一堆 a 改成更小的 b，新异或和是 `S xor a xor b = a xor b`，因为 a≠b，所以不为 0。

当 S≠0 时取其最高的 1 位，至少有一堆 a 在这一位为 1。令 b=a xor S：更高位不变，这一位从 1 变 0，因此 b<a，是合法取石子。新的异或和 `S xor a xor b=0`。这说明非零态一定能交出零态，结合有限性完成证明。

不要只说“每位偶数个 1”，还要证明从非零态存在一次合法操作。SG(n)=n 的单堆解释见下一篇。

## 手算：3、4、5

3=011，4=100，5=101，S=010=2。第一堆目标为 3 xor 2=1，所以取掉 2，变成 (1,4,5)，异或和为 0。对手改变任何一堆后都会破坏零异或，自己再恢复即可。

## 完整程序：构造第一步

对应 [洛谷 P1247 — 取火柴游戏](https://www.luogu.com.cn/problem/P1247)。一组输入：k 和 k 个堆数；k≤500000，堆数≤10^9，数组 1 下标。必败输出 `lose`；必胜第一行输出“取数 堆编号”，第二行输出操作后的所有堆。多解要求先最小化堆编号，再最小化取数。

从小到大找第一个 `(a[i] xor S)<a[i]` 即可。固定 i 时使异或变 0 的目标唯一，所以已满足题目排序要求。

```cpp
#include <iostream>
using namespace std;

const int MAXN = 500000 + 5;
long long a[MAXN];

int find_heap(int n, long long sum)
{
    for (int i = 1; i <= n; i++)
    {
        if ((a[i] ^ sum) < a[i])
        {
            return i;
        }
    }
    return 0;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long sum = 0;
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
        sum ^= a[i];
    }
    if (sum == 0)
    {
        cout << "lose\n";
        return 0;
    }
    int id = find_heap(n, sum);
    long long target = a[id] ^ sum;
    cout << a[id] - target << ' ' << id << '\n';
    a[id] = target;
    for (int i = 1; i <= n; i++)
    {
        if (i > 1)
        {
            cout << ' ';
        }
        cout << a[i];
    }
    cout << '\n';
    return 0;
}
```

教学样例输入 `3`，第二行 `3 4 5`；输出第一行 `2 1`，第二行 `1 4 5`。判定和构造总时间 O(n)，有效数组空间 O(n)。仅判定时不需保存数组，可流式 O(1) 额外空间；[洛谷 P2197 — Nim 游戏](https://www.luogu.com.cn/problem/P2197) 是多测，只输出 Yes/No，与这里格式不同。

## 反常 Nim：取最后一颗者输

先假设初始至少有一个非空堆。设 c 为大小恰为 1 的堆数，b 为大小≥2 的堆数，零堆忽略。

- b=0：共 c 次行动，奇数 c 时先手取到最后而输；偶数 c 时先手赢。
- b≥1：先手必胜当且仅当原始堆数异或和 S≠0。

这里第二条不能误用到全 1 状态。完整策略：b≥2 时选择普通 Nim 的零异或操作，操作后不可能只剩一个大堆且异或为 0，因此仍有至少两个大堆。b=1 时直接处理最后的大堆，使留给对手的 1 堆总数为奇数：若 c 奇数则取光大堆，若 c 偶数则把大堆降为 1。

正确性：b=1 必有 S≠0；上述操作进入全 1 的 P 态。b≥2 且 S=0 时，对手一次操作不能进入全 1，且必打破零异或；S≠0 时可构造上述 P 态。所以两类 P 态构成封闭的胜负递推。初始全空如何判定由题面决定，本节不把它混入“取最后者输”的口头描述。

## 应用与边界

异或是 `^`，不是加法，也不是逻辑异或；不能把负数当堆数。零堆合法且不影响异或；找首步一定要检查 target<a[i]，否则可能增加石子。允许跨堆同步操作时参见 [[05-威佐夫博弈]]，不能继续套 Nim。

练习路线：P2197 判胜 → P1247 构造 → [[11-博弈题单]] 的 N1 反常变式。构造答案应验证“只动一堆、严格减少、目标非负、新异或为 0”，而不是只比输出字符串。
