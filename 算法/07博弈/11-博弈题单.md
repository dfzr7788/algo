## 自编分层练习

下面均为自编题。沿用所指章节的自编输入格式，除非题目另行说明；不附未经核验的平台替代链接。

| 编号 | 题目 | 层次 | 要求与检查目标 |
|---|---|---|---|
| B1 | 连续取数与首步 | 入门 | 使用 02 的规则和格式，对 n=0、m、m+1、10^18 判胜并构造 |
| B2 | 取最后者输 | 变体 | 初始 n≥1，把 B1 改成反常规则，验证 n=1 与 m=1 |
| N1 | 反常多堆 | 变体 | 输入 n 和非负堆数，至少一堆非空，输出 First/Second；测全 1 与唯一大堆 |
| S1 | 多堆只能取 1、3、4 | 应用 | 使用 04 第一份程序格式，判定 (4,5,2)，再构造实际取数 |
| S2 | 不等分拆堆 | 变体 | 使用 04 第二份程序格式，枚举 n=1..20，与全局拆堆状态暴力对拍 |
| W1 | 威佐夫必胜操作 | 构造 | a,b≤100，输出一个合法操作后的 P 态；不得增加石子或取 0 |
| F1 | 动态上限首步 | 选学 | 使用 06 格式，输入 Fibonacci 数及其左右邻数，输出合法首步 |
| F2 | 动态上限中途 | 进阶 | 输入 n、r（1≤n≤100，1≤r≤200），每步上限改为上次取数两倍，判胜；用完整 (n,r) 暴力比较 |
| T1 | 逐阶移动 | 应用 | 使用 07 格式，加入只有偶数阶非空、全空、三阶小状态 |
| D1 | 有负数的取端点 | 变体 | 使用 08 格式，但 a[i] 可为负；验证始终必须取、不能跳过回合 |

建议把 S1 的操作构造和 W1 的配对寻找留到第二轮；初学第一轮重点是判断、状态正确性与反例。独立建模练习见 [[12-博弈综合练习]]。
