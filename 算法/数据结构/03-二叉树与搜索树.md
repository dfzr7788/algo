## 二叉树和搜索树有什么用

二叉树用于表示有左右顺序的层次关系，例如表达式的左右操作数、递归拆分的两个子问题。遍历的作用是把这种结构按指定顺序转成线性序列，而不是把节点按数值排序。

BST 则用于按键查找与插入：根的左边整棵子树保存较小键，右边整棵保存较大键，所以一次比较可以排除一整侧。如果只是需要高效有序容器，可以直接使用 set/map；普通 BST 主要用来理解结构，并不保证平衡。

遍历模板静态容量支持 n≤100000，但递归深链仍可能超出系统栈。BST 教学模板限定 n≤5000，避免把未平衡树当成大规模高效解法。数组中 left_child/right_child 存的是节点编号，不是元素值。

## 表示与遍历

数组 left[u]、right[u] 保存子节点编号，0 表示空。前序是根→左→右，中序是左→根→右，后序是左→右→根；层序用队列按层访问。树高描述最长根到叶路径，不等于节点总数。

## 完整程序：三种遍历

教学输入 n、根编号 root，接着 n 行对应节点 1..n 的左、右孩子，保证是一棵合法树。输出前、中、后序节点编号，各一行。n≥1，教学递归版适合较浅树，深链需显式栈。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int lch[N];
int rch[N];
int preorder[N];
int inorder[N];
int postorder[N];
int pre_count, in_count, post_count;

void dfs(int u)
{
    if (u == 0)
        return;
    preorder[pre_count++] = u;
    dfs(lch[u]);
    inorder[in_count++] = u;
    dfs(rch[u]);
    postorder[post_count++] = u;
}

void print_order(int order[], int n)
{
    for (int i = 0; i < n; i++)
    {
        if (i > 0)
            cout << ' ';
        cout << order[i];
    }
    cout << '\n';
}

int main()
{
    int n, root;
    cin >> n >> root;
    for (int u = 1; u <= n; u++)
        cin >> lch[u] >> rch[u];
    dfs(root);
    print_order(preorder, n);
    print_order(inorder, n);
    print_order(postorder, n);
}
```

每节点按自己的访问阶段加入三种结果，时间 O(n)，输出保存 O(n)，递归栈 O(h)。输入含环、共享孩子或断开的节点不是本模板承诺的合法树，不能直接套用。

## 完整程序：中序与后序重建先序

测试：[洛谷 P1030 — 求先序排列](https://www.luogu.com.cn/problem/P1030)。输入中序字符串、后序字符串，节点字符互不相同且序列合法，输出先序字符串。后序最后一个字符是根，中序根位置将左右子树分开。

```cpp
#include <bits/stdc++.h>
using namespace std;

string inorder;
string postorder;
int pos[256];

void build(int il, int ir, int pl, int pr)
{
    if (il >= ir)
        return;
    unsigned char root = postorder[pr - 1];
    int mid = pos[root];
    int left_size = mid - il;
    cout << (char)root;
    build(il, mid, pl, pl + left_size);
    build(mid + 1, ir, pl + left_size, pr - 1);
}

int main()
{
    cin >> inorder >> postorder;
    for (int i = 0; i < (int)inorder.size(); i++)
        pos[(unsigned char)inorder[i]] = i;
    build(0, inorder.size(), 0, postorder.size());
    cout << '\n';
}
```

区间是半开形式 `[il,ir)`、`[pl,pr)`。每次根与左右规模唯一决定，归纳得重建正确。预存中序位置后 O(n)，递归栈 O(h)。前序+中序也可唯一重建，前序+后序一般不行；重复标签还需额外信息。例如根只有左孩子或只有右孩子可产生相同前序、后序。

## 二叉搜索树（BST）

BST 可以把“从集合里找一个键”变为沿一条父子路径比较，而不用每次扫全部元素。例如根键为 5，寻找 3 就去左子树，寻找 8 就去右子树；这个排除成立，是因为整棵左/右子树都遵守顺序，而不是仅两个孩子大小合适。

约定每个不同键只存一个节点，重复键累加 count。左子树键小于根、右子树键大于根。查找时根据比较选择一边，插入在空位置；中序遍历输出有序键，按 count 可输出重复值。

删除有两个孩子的节点，可用后继（右子树最小键）替换，再删除后继位置；若维护频次，必须一并处理重复计数。初学者先完成查找与插入，再练习删除，不能仅将当前节点链接直接跳过而丢掉两个子树。

BST 不是堆：BST 保证左右整个子树顺序，堆只保证父子极值关系。标准 set/map 通常用平衡树，可用于稳定的有序查询，见 [[06-有序集合与映射]]。

## 练习与边界

### 完整程序：普通 BST 插入与频次查找

教学输入 n、q（0≤n≤5000），接着 n 个整数键，再输入 q 个待查键，输出每个键出现次数。重复值只增加 count。用静态数组分别保存键、左右孩子与次数，插入和查询都写成普通函数。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 5005;
long long key_value[N];
int left_child[N];
int right_child[N];
int count_value[N];
int root, used;

void insert_key(long long x)
{
    if (root == 0)
    {
        root = ++used;
        key_value[root] = x;
        count_value[root] = 1;
        return;
    }
    int u = root;
    while (true)
    {
        if (key_value[u] == x)
        {
            count_value[u]++;
            return;
        }
        int next_node;
        if (x < key_value[u])
            next_node = left_child[u];
        else
            next_node = right_child[u];
        if (next_node != 0)
        {
            u = next_node;
            continue;
        }
        int v = ++used;
        key_value[v] = x;
        count_value[v] = 1;
        if (x < key_value[u])
            left_child[u] = v;
        else
            right_child[u] = v;
        return;
    }
}

int find_count(long long x)
{
    int u = root;
    while (u != 0)
    {
        if (key_value[u] == x)
            return count_value[u];
        if (x < key_value[u])
            u = left_child[u];
        else
            u = right_child[u];
    }
    return 0;
}

int main()
{
    int n, q;
    cin >> n >> q;
    for (int i = 0; i < n; i++)
    {
        long long x;
        cin >> x;
        insert_key(x);
    }
    while (q--)
    {
        long long x;
        cin >> x;
        cout << find_count(x) << '\n';
    }
}
```

按照比较只排除不可能含目标的子树，插入在同样的查找路径空边位置，故维持 BST 不变量。n=0 时查询均为 0。单次 O(h)，大量有序键会导致总插入 O(n²)，仅作为原理练习，数据较大时优先标准有序容器。

测试单节点、仅左/仅右链、非满树、重复键。拓展 [洛谷 P1305 — 新二叉树](https://www.luogu.com.cn/problem/P1305) 使用字符节点与空孩子符号，输入不同，需调整读取。

## 扩展选读：树高与复杂度

遍历访问每个节点常数次，故 O(n)，并不是 O(log n)。BST 查找与插入为 O(h)，普通 BST 按升序插入会形成高度 n 的链，最坏 O(n) 单次操作，不能默认平衡。完整平衡树旋转及其证明属于后续专题；这里不把 O(log n) 当作普通 BST 的保证。
