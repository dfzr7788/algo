## 一、按要求排序的队伍

测试：[AtCoder ABC217 E — Sorting Queries](https://atcoder.jp/contests/abc217/tasks/abc217_e)。操作 1 x 追加队尾，2 移除并输出队首，3 将整个现有队伍升序排序。原题移除时保证非空。

每次排序全部元素再用数组删首项，可能反复 O(n log n) 与 O(n) 搬移。观察已经排序的前缀始终应先于排序后新追加的尾部；只有再次排序时，尾部才并入排序区。

维护小根堆 h 表示已排序部分，queue q 表示新加入的尾部。移除时先取 h 最小值，h 空才取 q 队首；排序时把 q 的元素转移进 h。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m;
    cin >> m;
    priority_queue<long long, vector<long long>, greater<long long>> sorted_part;
    queue<long long> waiting;
    while (m--)
    {
        int type;
        cin >> type;
        if (type == 1)
        {
            long long x;
            cin >> x;
            waiting.push(x);
        }
        else if (type == 2)
        {
            if (!sorted_part.empty())
            {
                cout << sorted_part.top() << '\n';
                sorted_part.pop();
            }
            else
            {
                cout << waiting.front() << '\n';
                waiting.pop();
            }
        }
        else
        {
            while (!waiting.empty())
            {
                sorted_part.push(waiting.front());
                waiting.pop();
            }
        }
    }
}
```

不变量：真实队伍由“堆元素升序排列”接上“q 的入队顺序”组成。追加、移除与排序均保持该表示；注意不能每次追加就进堆，否则没有排序操作时也会提前重排。

每个元素最多进入堆一次、弹出一次，总时间 O(m log m)，空间 O(m)。例：加入 3、1，排序，加入 0，依次取出得到 1、3、0。

## 二、树状数组统计逆序对

测试：[洛谷 P1908 — 逆序对](https://www.luogu.com.cn/problem/P1908)。输入 n 和数组，输出 i<j 且 a[i]>a[j] 的对数。朴素双层枚举 O(n²)。

从左到右扫描当前 x，已经出现的数有 i 个，减去≤x 的数量即为与当前构成逆序的数量。值域大时先 [[03-离散化]]，用排名作树状数组下标。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 500005;
long long a[N];
long long values[N];
int bit[N];
int value_count;

int prefix_count(int x)
{
    int result = 0;
    for (int i = x; i > 0; i -= i & (-i))
        result += bit[i];
    return result;
}

void add_count(int x)
{
    for (int i = x; i <= value_count; i += i & (-i))
        bit[i]++;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
        values[i] = a[i];
    }
    sort(values + 1, values + n + 1);
    value_count = unique(values + 1, values + n + 1) - values - 1;
    long long answer = 0;
    for (int i = 1; i <= n; i++)
    {
        int rank = lower_bound(values + 1, values + value_count + 1, a[i]) - values;
        answer += (i - 1) - prefix_count(rank);
        add_count(rank);
    }
    cout << answer << '\n';
}
```

每个逆序对在较晚下标扫描时恰好计一次，相等值被 prefix(rank) 包含并排除。查询后再加入当前值，避免把自己算进已出现数量。[3,1,2] 为 2，全相等为 0。总时间 O(n log n)，空间 O(n)，计数用长整数。
