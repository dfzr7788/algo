链表用 next（单向）或 prev、next（双向）描述相邻关系。它不支持数组那样的 O(1) 按位置访问；已知节点或前驱时才可能快速局部插入删除。

## 链表有什么用

当元素的先后顺序频繁变化，但操作已经给出要修改的节点身份时，链表能直接接好局部邻居，避免数组插入删除时搬移一整段。例如把编号 7 插到编号 3 后面、移除编号 4，而其余人的相对顺序不变。

数组的下标表示位置，链表的编号表示节点身份：编号 7 未必在队伍第 7 位。next[3]=7 表示 3 的后面是 7，而不是把元素放进数组第 7 个位置。单链表只记后继，双向链表还记前驱，因此已知当前节点删除时可以找到它的两侧。

本篇使用静态数组保存链接，不使用动态节点类。预留 N=100005，适用于 n≤100000；0 和 n+1 是两端哨兵，不能作为待删学生编号。

## 单链表与双向链表

| 操作 | 单链表 | 双向链表 |
|---|---|---|
| 已知前驱，插入/删其后继 | O(1) | O(1) |
| 仅知当前节点，删除它 | 通常需找到前驱 | O(1) |
| 按第 k 个位置查找 | O(n) | O(n) |
| 尾插 | 有尾指针可 O(1) | 有尾指针可 O(1) |

单链表头插先令新节点 next 指向旧头，再更新头。删除后继先保存待删节点，接好链接后释放；删除尾节点时同步更新尾指针。动态分配节点的生命周期必须管理，不能访问已释放节点。

竞赛中节点编号已知时可用数组模拟链接，不需实际指针。编号是节点身份，不等于它在队列中的位置。

## 完整程序：按编号安排队列

### 先手算一次插入和删除

当前顺序 [2,3,1]，把 4 插到 3 后面。先保存 right=nxt[3]=1，再依次让 nxt[3]=4、pre[4]=3、nxt[4]=1、pre[1]=4，就得到 [2,3,4,1]。先保存旧后继很重要，否则修改 nxt[3] 后再读取，会把原来位置 1 的信息丢掉。

删除 4 时，把 3 与 1 重新相连：nxt[3]=1、pre[1]=3，再标记 4 已删除。4 数组槽位里的旧前后链接可以还在，但它不再属于有效链表，重复删除必须先检查 alive。

测试：[洛谷 P1160 — 队列安排](https://www.luogu.com.cn/problem/P1160)。逐个把新编号插入某已有编号左或右，最后按编号删除，重复删除忽略。0 为头哨兵，n+1 为尾哨兵。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int pre[N];
int nxt[N];
bool alive[N];

void insert_after(int left, int x)
{
    int right = nxt[left];
    nxt[left] = x;
    pre[x] = left;
    nxt[x] = right;
    pre[right] = x;
}

void erase_node(int x)
{
    if (!alive[x])
        return;
    nxt[pre[x]] = nxt[x];
    pre[nxt[x]] = pre[x];
    alive[x] = false;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++)
        alive[i] = true;
    nxt[0] = 1;
    pre[1] = 0;
    nxt[1] = n + 1;
    pre[n + 1] = 1;
    for (int x = 2; x <= n; x++)
    {
        int k, p;
        cin >> k >> p;
        if (p == 1)
            insert_after(k, x);
        else
            insert_after(pre[k], x);
    }
    int m;
    cin >> m;
    while (m--)
    {
        int x;
        cin >> x;
        erase_node(x);
    }
    bool first = true;
    for (int x = nxt[0]; x != n + 1; x = nxt[x])
    {
        if (!first)
            cout << ' ';
        cout << x;
        first = false;
    }
    cout << '\n';
}
```

不变量：每对相邻有效节点 u、v 满足 nxt[u]=v 且 pre[v]=u。插入与删除同时维护两方向链接；重复删除用 alive 避免再次使用失效邻接。总时间 O(n+m)，存储 O(n)，n≥1。

## 边界与应用

测试插入最左/最右、删除头/尾、删除全部、重复删除。不要边遍历边删除后直接从已释放节点读取 next。std::list 提供双向链表，但按编号找迭代器仍需另存映射；数组模拟通常更直观。

链表适合频繁局部改顺序，普通随机访问与扫描优先数组或 vector。题单见 [[算法/数据结构/12-题单|数据结构题单]]。

## 扩展选读：复杂度的前提

局部更新只改变固定数量链接，故 O(1)；若首先需要按值或第 k 个位置寻找节点，整体操作仍可能 O(n)。有尾指针的尾插与每次遍历找尾的尾插复杂度不同，不要把局部更新界当作完整操作界。
