## A. 同一时刻的会议室

输入 n 和 n 个会议区间 `[l,r)`，$l<r$，端点为整数且允许负数，$n\le 200000$。输出同时进行的会议最大数量。

样例：区间 `[1,3)`、`[3,5)`、`[2,4)`，答案 2。边界：零个会议答案 0。说明同一时刻的开始和结束如何处理，不能把端点相接误算为重叠。

## B. 安排连续工作

输入 n、k 和 n 个非负耗时，$n\le 200000$，$1\le k\le n$，单项 $\le 10^{9}$。按原顺序分成恰好 k 个非空连续组，输出最大组耗时的最小可能值。

样例：[7,2,5,10,8]、$k=2$，答案 18。解释为什么“恰好 k”可以转为容易判断的条件，并给出存在负数时需要重新分析的原因。

## C. 禁用格上的摆放

输入 8 行棋盘，`.` 可放、`*` 禁用。放 8 个棋子，每行每列恰好一个，且任意两个不能处于同一对角线，输出方案数。

全空棋盘答案 92；全禁用答案 0。证明候选不重不漏，说明哪些状态必须恢复。

## D. 数量有限的选择

输入 n、x 与 n 个整数，$n\le 40$、$\lvert a[i]\rvert \le 10^{9}$、$\lvert x\rvert \le 10^{12}$。输出和等于 x 的下标子集数，允许空子集，重复值仍是不同元素。

样例：[1,1,-1]、$x=1$，答案 3。解释重复子集和如何影响计数，估算最大内存和答案范围。

## E. 一直走下去

输入 n、q 和每个位置唯一的下一位置，接着 q 个 $(x,k)$，位置为 1-based。$n,q\le 200000$，$0\le k\le 10^{18}$，输出每次走 k 步后的终点。

样例：下一位置 [2,3,1]，从 1 走 0 步到 1，走 5 步到 3。必须支持自环与环，说明预处理层数取决于什么。

## F. 输出一个合法排列

输入 n（$1\le n\le 10^{6}$），输出 $1\ldots n$ 的排列，所有相邻元素绝对差不能为 1；无解输出 `NO SOLUTION`。

先枚举小 n 发现规律，再证明无解分类和构造，不能只给几个成功例子。合法输出不要求与某个参考排列完全相同。

## G. 最长的一段

输入 n 和 n 个整数，$n\le 200000$、$\lvert a[i]\rvert \le 10^{9}$，输出最长无重复连续子数组长度。$n=0$ 时为 0。

样例：[1,2,1,3,2]，答案 3。不能改变原顺序；解释所用容器的时间保证是最坏、均摊还是期望。

## H. 限定长度的一段

输入 n、K、L 和整数数组，$1\le n\le 200000$、$1\le L\le n$、$\lvert a[i]\rvert \le 10^{9}$、$\lvert K\rvert \le 10^{14}$。统计长度至多 L 且和恰好为 K 的非空连续子数组数量。

样例：[1,-1,1]，$K=0$、$L=2$，答案 2。要求支持负数；指出限制长度给原模型增加了什么信息。

> [!tip]- H 提示一：基准解法
> 枚举左端点，最多向右延伸 L 个位置，逐项累加。时间 $O(nL)$。

> [!tip]- H 提示二：寻找关系
> 和为 K 可以转成两个前缀和的差。当前右端对应的合法左前缀下标还必须落在一个随扫描移动的范围内。

> [!tip]- H 提示三：完整方向
> 扫描前缀位置 r，只维护下标位于 `[max(0,r-L),r)` 的前缀和频次，查询 $pre[r]-K$。加入、删除各一次，在哈希分布良好、单次操作平均常数的条件下时间 $O(n)$，极端冲突下最坏可达 $O(n^2)$；空间 $O(n)$，也可只保存必要窗口信息。检查更新顺序，禁止空区间，重复前缀要计频次。见 [[15-问题转化与建模]]。

## I. 查询两个结果

输入 n、q，数组与 q 个阈值 x。n、$q\le 200000$，$\lvert a[i]\rvert$、$\lvert x\rvert \le 10^{9}$。对每个阈值按原输入顺序输出：数组中 $\le x$ 的元素数量，以及这些元素的总和。

样例：$a=[3,-1,2]$，查询 [2,-2,3]，依次输出 $(2,1)$、$(0,0)$、$(3,4)$。考虑重复阈值与负数。

> [!tip]- I 提示一：基准解法
> 每个查询独立扫描数组，统计数量与和，时间 $O(nq)$。

> [!tip]- I 提示二：复用工作
> 数组排序后，满足条件的元素是一个前缀。可以预处理前缀和再二分，也可以排序查询逐步加入元素。

> [!tip]- I 提示三：完整方向
> 在线版本排序数组并建前缀和，每次 upper_bound 找前缀长度。离线版本按阈值排序，同时维护指针与累计和，再按 id 输出。给出各自总复杂度，不要声称离线必然更快。见 [[14-预处理与离线思想]]。

## J. 恰好选这么多个

输入 n、k、T 和整数数组，$n\le 36$、$0\le k\le n$、$\lvert a[i]\rvert \le 10^{9}$、$\lvert T\rvert \le 10^{12}$。恰好选 k 个不同下标，使元素和 $\le T$，输出其中最大和；无可行子集输出 `IMPOSSIBLE`。$k=0$ 时只有空子集。

样例：[3,5,-2,4]，$k=2$、$T=5$，答案 3。重复数值仍是不同元素，不能把最大值初始化为 0 后忽略全负解。

> [!tip]- J 提示一：基准解法
> 枚举所有下标子集，检查大小和总和，时间 $O(n\cdot 2^{n})$。

> [!tip]- J 提示二：拆分状态
> 拆成两半，除了子集和，还要记录选择数量。左半选 c 个时，右半只能选 $k-c$ 个。

> [!tip]- J 提示三：完整方向
> 将右半子集和按数量分组并排序，对每个左状态，在对应组二分最后一个 $\le T-\mathrm{left}$ 的和。用独立 found 标记区分无解与负答案。时间 $O(n\cdot 2^{n/2})$ 量级，空间 $O(2^{n/2})$，若只求最大值可以去重，但计数版本不能照搬。见 [[12-搜索剪枝与折半搜索]]。

## A..G 的核对提示

> [!tip]- 完成后展开算法方向与核对点
> - A：端点事件排序。离开先于进入，或按时间分组；排序与扫描总 $O(n \log n)$。
> - B：二分最大组和，贪心求最少组数；非负条件下继续拆分可得到恰好 k。见 [[07-二分]]。
> - C：逐行回溯，列与两类对角线标记。见 [[12-搜索剪枝与折半搜索]]。
> - D：左右子集和合并计数，保留重复值。见 [[12-搜索剪枝与折半搜索]]。
> - E：静态函数复合倍增，按最大 k 决定层数。见 [[11-倍增思想]]。
> - F：分奇偶并检查连接处，小 n 独立处理。见 [[10-构造算法]]。
> - G：维护原数组窗口，频率冲突时收缩。见 [[05-双指针与滑动窗口]]。
