## 一、排序与分治：逆序对计数

### 题目与基准解法

输入 n 和 n 个整数，输出 $i<j$ 且 $a[i]>a[j]$ 的下标对数量。取 $n\le 200000$、$\lvert a[i]\rvert \le 10^{9}$。枚举所有 $i<j$，检查大小关系，时间 $O(n^{2})$，额外空间 $O(1)$，可作为小规模基准。

### 如何发现优化

计数依赖原下标，所以直接排序后丢弃原关系是不行的。把原下标区间分为左右两半，答案分成左内部、右内部、跨左右三类。两半分别排好序后，右边当前值若小于左边当前值，就同时小于所有剩余左值，可一次统计整个后缀。

### 手算、证明与实现

输入 [3,1,2]：左半 [3]，右半排为 $[1,2]$。取右边 1 时加 1，取 2 时再加 1，总计 2。递归计算内部贡献，合并计算跨区间贡献，三类不交且穷尽所有逆序对。

完整 C++17 程序和归纳证明见 [[06-递归与分治#完整例子：归并排序与逆序对]]。时间 $O(n \log n)$，辅助数组 $O(n)$，栈 $O(\log n)$。输出仍是原数组的逆序对数量，最终数组则会被排序。

### 易错点与验证

全相等不能算逆序；降序输入答案 $n(n-1)/2$；用 `long long` 保存数量。测试 []、[1]、$[1,1]$、[3,2,1]，再与双层枚举对拍。两边长度不相等时也要正确合并。

## 二、双指针：正整数数组中和为目标的区间数

### 题目与暴力

输入 n、x 和 n 个正整数，统计非空连续子数组和恰为 x 的数量。$n\le 200000$，$1\le x$、$a[i]\le 10^{9}$。这是和恰好为目标的教学模型。拓展测试：[AtCoder ABC130 D — Enough Array](https://atcoder.jp/contests/abc130/tasks/abc130_d)，原题统计和至少为 K 的区间，须改变计数规则。

暴力枚举左端点，再逐步右移并累加区间和，时间 $O(n^{2})$，不需要每个区间重新求和。

### 关键性质与证明

由于所有值严格为正，右移右端点使和严格增大，右移左端点使和严格减小。对固定右端点，最多存在一个和等于 x 的左端点。

扫描每个 r，加入 $a[r]$ 后在和 $>x$ 时删除左端元素。被删除的左端点对于当前及未来右端点都不可能再得到 x，所以排除安全。收缩后若和 $=x$，恰好找到一个新区间。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
long long a[N];
int main()
{
    int n;
    long long target;
    cin >> n >> target;
    for (int i = 0; i < n; i++)
        cin >> a[i];
    int l = 0;
    long long current = 0, answer = 0;
    for (int r = 0; r < n; r++)
    {
        current += a[r];
        while (l <= r && current > target)
            current -= a[l++];
        if (l <= r && current == target)
            answer++;
    }
    cout << answer << '\n';
}
```

两指针各移动至多 n 次，时间 $O(n)$，数组空间 $O(n)$。本范围总和 $\le 2\times 10^{14}$，`long long` 足够。

### 手算与适用边界

[1,2,1,2]、$x=3$：合法区间为 $[0,1]$、$[1,2]$、$[2,3]$，答案 3。全大于 x 时为 0。含零时，同一右端点可能有多个合法左端点，例如 $[0,1]$、$x=1$ 有两个；含负数则删除可能不安全。扩展题可用前缀和频次哈希，不能照搬此程序。

## 三、二分：机器最早完成目标数量

### 题目与暴力

n 台机器从时间 0 同时开始，第 i 台每 $a[i]$ 时间生产一个产品，求至少生产 goal 个产品的最早整数时刻。$n\ge 1$、$\mathrm{goal}\ge 1$、$a[i]\ge 1$。这是教学模型。二分判定拓展：[洛谷 P2440 — 木材加工](https://www.luogu.com.cn/problem/P2440)，原题求最大可切长度，判定方向及输入输出均与本例不同。以下要求 $\min (a)\cdot \mathrm{goal}\le 10^{18}$。

枚举时刻并在每个时刻计算产量，需要 $O(n\cdot \text{答案})$，大答案不可行。我们不需要逐个知道产量，只要判断某时刻是否已足够。

### 单调性、边界与实现

t 时的产量为 $\sum \lfloor t/a[i]\rfloor$，随 t 不减。可行判定为假→真。下界 0，上界 min(a)·goal，因为最快机器独自产出即可保证足够。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
long long a[N], goal;
int n;
bool check(long long time)
{
    long long made = 0;
    for (int i = 0; i < n; i++)
    {
        long long add = time / a[i];
        if (add >= goal - made)
            return true;
        made += add;
    }
    return false;
}
int main()
{
    cin >> n >> goal;
    for (int i = 0; i < n; i++)
        cin >> a[i];
    long long lo = 0, hi = *min_element(a, a + n) * goal;
    while (lo < hi)
    {
        long long mid = lo + (hi - lo) / 2;
        if (check(mid))
            hi = mid;
        else
            lo = mid + 1;
    }
    cout << lo << '\n';
}
```

不变量：最早可行时刻始终位于 $[lo,hi]$，hi 可行；比较 mid 后只排除不含答案的一侧。终止得到最早时刻。单次判定 $O(n)$，总 $O(n \log U)$，U 为初始上界，存储 $O(n)$。

### 手算与边界

$a=[2,3]$、$\mathrm{goal}=5$，$t=5$ 产量为 3，$t=6$ 产量为 5，答案 6。检查单机器、同耗时、目标 1、最大乘积。饱和累计只防止产量求和溢出，上界乘法仍必须满足前提。

## 四、搜索：统计网格连通区域

### 题目与错误暴力

输入 $n\times m$ 网格，`.` 可走、`#` 为墙，四方向相邻，输出可走区域数；$n,m\ge 1$。这是连通块计数教学模型。拓展测试：[洛谷 P1162 — 填涂颜色](https://www.luogu.com.cn/problem/P1162)，需从边界搜索外部区域，再填充内部，输出为矩阵而非区域数量。

一个粗糙办法是对每个可走格独立搜索可达区域，再对结果去重。每次可访问 $O(nm)$ 格，总时间可能 $O((nm)^{2})$，还需定义区域表示以去重。

### 消除重复工作

第一次搜索完整访问一个连通区域，之后其中的格子不必再启动搜索。外层扫描只在未访问可走格启动，计数增加一次。由连通性，启动不会漏掉该区域；由永久访问标记，同一区域不会重复计数。

完整显式栈程序见 [[08-搜索#完整例子二：网格连通块]]，每个格子入栈一次、检查四邻居，时间与存储 $O(nm)$。与排列枚举不同，遍历结束不能撤销 visited。

### 手算与边界

网格 `..# / #.# / ##.` 有两个区域。全墙为 0，全空为 1；仅对角接触不连通。长走廊可导致递归过深，显式栈避免系统栈限制。若改为八方向邻接，程序和证明中的邻接定义都要同步修改。

## 五、贪心：最多不相交区间

### 题目与暴力

输入 n 个半开区间 `[l,r)`，$l<r$，端点相接允许，输出能选择的最大数量。同模型测试：[洛谷 P1803 — 凌乱的 yyy / 线段覆盖](https://www.luogu.com.cn/problem/P1803)，输入输出与此处的区间选择程序一致。

暴力枚举 $2^{n}$ 个子集，排序选中的区间后检查相邻是否冲突，最坏 $O(2^{n}\cdot n \log n)$。这能验证小规模结果，但不能处理大 n。

### 从失败策略到交换论证

开始最早会被长区间阻挡；最短优先可能选到跨越两个相容区间的中间区间。真正有用的性质是：结束越早，留给后续的空间至少一样大。

取任意最优方案，将其第一个区间替换为全局结束最早的区间，后续仍能接上，数量不减。因此存在包含该选择的最优方案，剩余问题同型，逐步选择即可。

完整程序见 [[09-贪心#五、 完整模型：最多不相交区间]]。排序 $O(n \log n)$，扫描 $O(n)$，数组 $O(n)$。`[0,10)`、`[1,2)`、`[2,3)`、`[3,4)` 的答案为 3。

### 变式与边界

闭区间相接若算冲突，需要严格大于；若改为带收益区间，数量最优不等于收益最优，需要新算法。验证空集合、负端点、同结束时刻、相接区间，使用子集枚举作为基准。
