## 递归与分治的区别

递归是函数调用自身的实现方式。分治是把问题拆成规模更小的子问题，分别求解，再合并结果的思想。分治常用递归实现，但不是所有递归都是分治：排列回溯是在枚举选择，朴素斐波那契递归还会重复求解同一状态。

写递归前明确：参数表示什么？函数完成后保证什么？终止条件是什么？哪一个量严格缩小？调用后是否需要恢复共享状态？

## 完整例子：归并排序与逆序对

逆序对是满足 $i<j$ 且 $a[i]>a[j]$ 的下标对。输入 n 和数组，输出逆序对数量。重复值不算逆序。

测试链接：[洛谷 P1908 — 逆序对](https://www.luogu.com.cn/problem/P1908)。输入输出对应本例，原题 n 最大为 500000。

`solve(l,r)` 使用半开区间 `[l,r)`，返回区间内部逆序对数量，并将这个区间排好序。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 500005;
long long a[N], temporary[N];
long long solve(int l, int r)
{
    if (r - l <= 1)
    {
        return 0;
    }
    int mid = l + (r - l) / 2;
    long long answer = solve(l, mid) + solve(mid, r);
    int i = l, j = mid, k = l;
    while (i < mid && j < r)
    {
        if (a[i] <= a[j])
        {
            temporary[k++] = a[i++];
        }
        else
        {
            answer += mid - i;
            temporary[k++] = a[j++];
        }
    }
    while (i < mid)
    {
        temporary[k++] = a[i++];
    }
    while (j < r)
    {
        temporary[k++] = a[j++];
    }
    for (int p = l; p < r; p++)
    {
        a[p] = temporary[p];
    }
    return answer;
}
int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
    }
    cout << solve(0, n) << '\n';
}
```

## 正确性证明

区间长度 $\le 1$ 时没有逆序对。假设左右递归均正确，则所有逆序对分为左内部、右内部、跨左右三类，互不重叠。

合并时，如果 $a[i]>a[j]$，左侧已经排序，因此 $a[i\ldots m)$ 都大于 $a[j]$，一次增加 $m-i$；如果 $a[i]\le a[j]$，$a[i]$ 不会与剩余右侧元素形成逆序，可以直接取走。每个跨区间逆序对恰好被统计一次。合并又恢复了父问题要求的有序性，归纳得出结果正确。

例如 [3,1,2] 有 $(3,1)$、$(3,2)$ 两个逆序对。全相等时答案为 0；严格降序时为 $n(n-1)/2$，所以计数使用 `long long`。

## 复杂度与边界

递归关系 $T(n)=2T(n/2)+O(n)$，每层总合并成本 $O(n)$，共有 $O(\log n)$ 层，因此时间 $O(n \log n)$。辅助数组 $O(n)$，递归栈 $O(\log n)$。

- 中点和递归区间要一致，不要混用闭区间与半开区间。
- `<=` 保证相等元素不计逆序，也让合并保持稳定。
- 本模板会修改数组；要保留原数组时先复制。
- 不要每次递归复制整个原数组，避免额外成本。

## 记忆化为何不同

例如 $F(n)=F(n-1)+F(n-2)$，朴素递归反复求相同的 F(k)。记忆化保存每个 k 的结果，可将该递推降为 $O(n)$ 时间；若状态数量本身为指数级，缓存后仍可能指数复杂度。状态必须足以唯一决定结果，详见 [[08-搜索]]。
