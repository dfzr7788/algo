## 适用条件

二分寻找单调判定的分界；三分利用目标函数先降后升（求最小值）或先升后降（求最大值）的单峰结构。不能仅凭图像像一个谷就使用，必须证明搜索区间内满足条件。

实数三分求最小值，取 $m1<m2$：若 $f(m1)>f(m2)$，可排除 m1 左侧；若 $f(m1)<f(m2)$，可排除 m2 右侧。凸函数可以出现最小值平台，两个值相等时保留 $[m1,m2]$ 仍包含最小点。对更宽泛的非严格单峰定义，非最优水平平台可能使相等比较无法排除，应额外分析，不宜直接套用凸函数规则。

## 完整例子：平方距离和最小

给 n 个实数 $a[i]$，选择实数 x，使 $\sum (x-a[i])^{2}$ 最小，输出 x 及目标值。$n\ge 1$，$\lvert a[i]\rvert \le 10^{6}$。

该函数二阶导为 $2n>0$，严格凸；最小点在 [min a,max a]，因为区间外往区间方向移动会同时减小所有距离。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
long double a[N];
int n;
long double evaluate(long double x)
{
    long double result = 0;
    for (int i = 0; i < n; i++)
    {
        long double difference = x - a[i];
        result += difference * difference;
    }
    return result;
}
int main()
{
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
    }
    long double l = *min_element(a, a + n), r = *max_element(a, a + n);
    for (int it = 0; it < 150; it++)
    {
        long double m1 = l + (r - l) / 3, m2 = r - (r - l) / 3;
        long double v1 = evaluate(m1), v2 = evaluate(m2);
        if (v1 > v2)
        {
            l = m1;
        }
        else if (v1 < v2)
            r = m2;
        else
        {
            l = m1;
            r = m2;
        }
    }
    long double x = (l + r) / 2;
    cout << fixed << setprecision(10) << x << ' ' << evaluate(x) << '\n';
}
```

150 次迭代是该例的实践选择，精度仍受浮点表示和目标值比较误差影响；不能推断到任意规模。每轮两次 $O(n)$ 求值，时间 $O(n\cdot I)$，存储 $O(n)$。此题可直接由导数推出 x 为平均数，用 $O(n)$ 精确表达最优位置；三分只是演示，当有更简单公式时应优先使用公式。

## 整数优化

离散凸序列中，差分 $f(x+1)-f(x)$ 单调，可以二分第一个差分非负的位置。若用整数三分，区间缩到少量候选后逐个枚举，避免 $m1=m2$ 导致不前进。

例如 x 在整数 $[0,4]$，$f(x)=(x-2)^{2}$，最小点是 2；若目标是一般多峰函数，丢掉一段可能遗漏更优峰。评估一次 f 的复杂度、上下界、浮点误差都必须计入。

## 整数凸差分二分：包含平台与端点

设整数域 [L,R] 上 $\Delta(x)=f(x+1)-f(x)$ 对 x 单调不减。在 [L,R−1] 找第一个 Δ≥0：它左边函数严格下降，右边不再下降，所以该位置是最左最小点。若没有非负差分，答案为 R；若 L 已非负，答案为 L。平台 Δ=0 时要返回平台起点，不能要求差分严格为正。

例 f 在 x=0..5 的值为 [9,4,1,1,1,4]，差分 [−5,−3,0,0,3]。第一次测试 x=2 为真，把右界收至 2；再测试 x=1 为假，收左界到 2，返回 2；2、3、4 都最优，但返回最左者。

局部函数依赖具名 `long long value_at(long long x)`。要求 L≤R、R−L 可放入 long long，求值结果可放入 long long；求值差先转 `__int128` 避免两个安全值相减溢出。当前搜索不会在 R 求 Δ，所以也不会访问 R+1。

```cpp
long long leftmost_convex_min(long long L, long long R)
{
    while (L < R)
    {
        long long mid = L + (R - L) / 2;
        __int128 difference = (__int128)value_at(mid + 1) - value_at(mid);
        if (difference >= 0)
        {
            R = mid;
        }
        else
        {
            L = mid + 1;
        }
    }
    return L;
}
```

若一次求值成本 C，整体 O(C·(1+log(R−L+1)))，额外 O(1)（不含求值内部空间）。单点区间直接返回。离散凸是这里的条件；一般非严格单峰可能在非最优高度有平台，不能仅凭“先下降后上升”的模糊描述使用这套差分判定。
