## 目标与思考流程

构造题通常要求输出任意合法方案，可能同时限制长度或操作次数。先找必要条件判断哪些输入不可能，再找统一构造，最后证明每条约束和输出规模都满足。必要条件不自动是充分条件，必须由成功构造补上充分性证明。

常见切入点：奇偶分组、对称配对、分块、先固定一部分、从目标倒推、维护逐步完成的前缀。验证方案时检查约束，不要求与样例方案完全相同。

## 完整例子一：相邻差不为 1 的排列

给定 n，输出 $1\ldots n$ 的排列，使所有相邻数绝对差不为 1。无解输出 `NO SOLUTION`。这是教学例题。拓展测试：[CF 1352G — Special Permutation](https://codeforces.com/problemset/problem/1352/G)，原题还要求相邻差不超过 4，不能直接提交本例构造。

暴力枚举 $n!$ 个排列再检查，最多 $O(n\cdot n!)$。观察同奇偶的数差至少为 2，考虑先输出偶数，再输出奇数。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    int n;
    cin >> n;
    if (n == 2 || n == 3)
    {
        cout << "NO SOLUTION\n";
        return 0;
    }
    bool first = true;
    for (int parity : {0, 1})
        for (int x = parity == 0 ? 2 : 1; x <= n; x += 2)
        {
            if (!first)
                cout << ' ';
            cout << x;
            first = false;
        }
    cout << '\n';
}
```

证明：$n=1$ 时直接合法。$n=2$ 无合法相邻对；$n=3$ 中元素 2 与 1、3 均不能相邻，无论放哪里都无法构成排列。$n\ge 4$ 时，各组内部相邻差为 2；两组交界是“最大偶数、1”，差至少为 3。每个元素恰好出现一次，所以方案合法且覆盖所有可行情形。时间 $O(n)$，本实现直接输出，额外空间 $O(1)$。

错误构造：先奇数升序、再偶数升序，$n=4$ 输出 [1,3,2,4]，交界差为 1。分组正确不代表连接处正确。

## 完整例子二：$1\ldots n$ 等和分组

把 $1\ldots n$ 分成两个集合，要求和相等。$n\ge 1$，输出 `NO` 或 `YES` 和两组大小及元素。这是教学例题。入门可行性练习：[CF 4A — Watermelon](https://codeforces.com/problemset/problem/4/A)，要求拆成两个正偶数，练习必要与充分条件，题意与本例不同。

必要条件：总和 $n(n+1)/2$ 是偶数，等价于 n mod 4 为 0 或 3。下面用分块证明条件也充分。

- $n \bmod 4=0$：每四个连续数 $x,x+1,x+2,x+3$，把 x 与 $x+3$ 放第一组，其余放第二组，两组块内和相等。
- $n \bmod 4=3$：先把 $\{1,2\}$ 与 ${3}$ 分给两组，再对 $4\ldots n$ 做四元素分块。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 1000005;
int group_a[N], group_b[N], count_a, count_b;
void print_group(int group[], int count)
{
    cout << count << '\n';
    for (int i = 0; i < count; i++)
        cout << group[i] << ' ';
    cout << '\n';
}
int main()
{
    int n;
    cin >> n;
    if (n % 4 != 0 && n % 4 != 3)
    {
        cout << "NO\n";
        return 0;
    }
    int start = 1;
    if (n % 4 == 3)
    {
        group_a[count_a++] = 1;
        group_a[count_a++] = 2;
        group_b[count_b++] = 3;
        start = 4;
    }
    for (int x = start; x <= n; x += 4)
    {
        group_a[count_a++] = x;
        group_a[count_a++] = x + 3;
        group_b[count_b++] = x + 1;
        group_b[count_b++] = x + 2;
    }
    cout << "YES\n";
    print_group(group_a, count_a);
    print_group(group_b, count_b);
}
```

初始块两组和相等，每次增加等和块；所有数恰好分配一次，最终两组等和。时间与存储 $O(n)$。计算总和时要用 `1LL*n*(n+1)/2`，并确认范围；本实现仅靠模 4 判断，避免了总和计算。

## 操作序列构造：把排列排好

允许任意交换两个位置，目标得到 [1,2,...,n]。维护每个值的位置 pos；从左到右，对位置 i，把值 $i+1$ 所在位置与 i 交换，然后更新两个值的 pos。

不变量：处理 i 前，位置 `[0,i)` 已经正确。需要的值不可能在已正确前缀中，故交换不会破坏前缀。每轮固定一个新位置，至多 $n-1$ 次交换，维护 pos 可达 $O(n)$ 时间。若只允许相邻交换，这个操作和次数界不成立。

## 完整实现：输出排序交换操作

测试链接：[AtCoder ABC350 C — Sort](https://atcoder.jp/contests/abc350/tasks/abc350_c)。输入 n 和 $1\ldots n$ 的一个排列，输出操作数量，再输出每次交换的两个 1-based 位置。原题允许至多 n 次任意位置交换；下面构造至多 $n-1$ 次。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
int a[N], pos[N], op_left[N], op_right[N], operation_count;
int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
        pos[a[i]] = i;
    }
    for (int i = 0; i < n; i++)
    {
        if (a[i] == i + 1)
            continue;
        int j = pos[i + 1], other = a[i];
        swap(a[i], a[j]);
        pos[i + 1] = i;
        pos[other] = j;
        op_left[operation_count] = i + 1;
        op_right[operation_count] = j + 1;
        operation_count++;
    }
    cout << operation_count << '\n';
    for (int i = 0; i < operation_count; i++)
        cout << op_left[i] << ' ' << op_right[i] << '\n';
}
```

每次维护 a 与 pos 的互逆关系，修好新位置后不会影响已正确前缀；前 $n-1$ 个位置正确后，最后一个自动正确。时间 $O(n)$，存储 $O(n)$。例如 [3,1,2] 可先交换 1、2，再交换 2、3。

验证时复制原排列，依次执行输出操作，检查位置合法、操作数 $\le n$、最终为升序。不要要求它与参考程序的操作序列逐行相同；已排序时输出 0 即合法。

## 练习与自查

检查无解是否有证明、所有元素是否恰好用一次、分块边界和连接处、最大输出规模、操作是否符合权限。练习见 [[20-题单|题单]]；不要用样例字符串是否相同作为构造题的判定标准。
