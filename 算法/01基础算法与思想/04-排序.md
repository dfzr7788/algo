## 排序解决什么问题

排序把无序关系转为有序关系，使相同元素相邻、极值位于端点、候选范围可以缩小。常用于去重、配对、区间贪心、二分查找和离散化。排序可能改变原下标或原相邻关系，需要在建模时确认这种改变是否允许。

## 基础用法与比较器

```cpp
// a 为 long long 数组，n 为元素个数；片段使用 <algorithm>、<functional>、<utility>。
sort(a, a + n);
sort(a, a + n, greater<long long>());
// items 的 first 对应 x，second 对应 y；不封装自定义类。
pair<long long, long long> items[200005];
sort(items, items + n,
    [](const pair<long long, long long> &a, const pair<long long, long long> &b)
    {
        if (a.first != b.first)
        {
            return a.first < b.first;
        }
        return a.second > b.second;
    });
```

`cmp(a,b)` 的含义是“a 应排在 b 前面”。比较器必须满足严格弱序：不能让元素小于自身；先后关系和等价关系需要具有传递性。使用 `<=`、随机规则或会变化的外部状态都会破坏要求。

- 比较乘积时先提升类型，且确认 `long long` 足够；更大范围可用 GCC 的 `__int128`。
- 不要通过 `a-b<0` 比较整数，减法可能溢出。
- 浮点比较直接加入 epsilon 可能破坏传递性，不宜随意作为排序规则。
- `sort` 不保证相等元素保留原顺序；有此需求用 `stable_sort`，或加入原下标作为次关键字。

## 完整例子：数有多少个不同的整数

输入 n 和 n 个整数，输出不同值的数量。允许 $n=0$。

测试链接：[洛谷 P1059 — 明明的随机数](https://www.luogu.com.cn/problem/P1059)。原题除了数量，还要求输出升序去重序列；本例程序需要补充第二行输出。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
long long a[N];
int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
    }
    sort(a, a + n);
    int count = unique(a, a + n) - a;
    cout << count << '\n';
}
```

正确性：排序后每个值的所有出现组成一个连续段；unique 将每段压为一个代表，返回逻辑末尾。本静态数组模板用末尾减起始位置得到有效个数，后面的槽位不再参与查询。vector 版本才需要配合 erase 改变容器大小。时间 $O(n \log n)$；数组存储 $O(n)$，排序本身的额外空间依赖实现。

## 常见排序算法的取舍

| 算法 | 时间 | 特点 |
|---|---|---|
| 插入排序 | 最坏 $O(n^{2})$，已排序时 $O(n)$ | 可稳定，适合理解局部插入 |
| 归并排序 | $O(n \log n)$| 可稳定，常需 $O(n)$ 辅助空间；可统计逆序对 |
| 朴素快速排序 | 平均 $O(n \log n)$，最坏 $O(n^{2})$ | 划分枢轴，通常不稳定 |
| 堆排序 | $O(n \log n)$ | 可原地实现，通常不稳定 |
| 计数排序 | $O(n+U)$| 键在有限整数值域内，空间 $O(U)$ |

竞赛中普通排序优先使用 C++17 的 `std::sort`，其比较次数为 $O(n \log n)$；手写归并排序用于需要合并统计的场景，见 [[06-递归与分治]]。

## 排序为什么能帮助优化

- 两数之和：排序后，和过小则增大左值，过大则减小右值。
- 最多不相交区间：按结束时间建立贪心顺序，见 [[09-贪心]]。
- 值域很大但只有 n 个不同位置：排序去重后 [[03-离散化]]。
- 找值的范围：排序后使用 [[07-二分]]，重复查询的总复杂度为 $O(n \log n+q \log n)$。

## 插入排序：把一个新值插入已排前缀

局部函数依赖 long long 数组 a、有效长度 n≥0。每轮开始 a[0..i) 有序，把 a[i] 暂存，右移所有比它大的数，再放入空位。不交换相等元素，因此稳定。

```cpp
void insertion_sort(long long a[], int n)
{
    for (int i = 1; i < n; i++)
    {
        long long value = a[i];
        int j = i;
        while (j > 0 && a[j - 1] > value)
        {
            a[j] = a[j - 1];
            j--;
        }
        a[j] = value;
    }
}
```

[3,1,2]：先把 1 插到 [3] 前面，得 [1,3,2]；再右移 3、把 2 放中间，得 [1,2,3]。插入后前缀仍有序且元素多重集不变，按 i 归纳得到整体排序正确。已排序时每轮只比较一次，为 O(n)；逆序时移动 1+2+…+(n−1) 项，为 O(n²)；额外 O(1)。用 `>=` 移动会破坏相等键的原顺序。

## 计数排序：值域规模也是成本

键值为 0..U 的整数时，用频次数组计数，再按键升序输出，避免逐对比较。例 [2,0,2,1] 得 count=[1,1,2]，展开为 [0,1,2,2]。这是纯键的排序；含姓名等附带信息时不能只展开键，否则会丢掉原记录。

局部纯键函数：依赖 `<algorithm>`，数组 a 容纳 n 项、frequency 容纳 U+1 项，0≤a[i]≤U。计数必须先清零，多组不能沿用上次频次。

```cpp
void counting_sort(int a[], int n, int U, int frequency[])
{
    fill(frequency, frequency + U + 1, 0);
    for (int i = 0; i < n; i++)
    {
        frequency[a[i]]++;
    }
    int position = 0;
    for (int key = 0; key <= U; key++)
    {
        for (int count = 0; count < frequency[key]; count++)
        {
            a[position++] = key;
        }
    }
}
```

输出频次总数恰为 n，且各键数量保持、输出顺序非降，得到正确排序。时间 O(n+U+1)，额外空间 O(U+1)。n 很小但 U=10^9 时，值域初始化和内存都不可接受；考虑比较排序或离散化。

稳定记录排序可先令 end[key] 为频次前缀和，从右到左扫描记录，将记录放到 `output[--end[key]]`。例两条键 2 的记录 A、B（A 先出现），先处理 B 放该键最后位置，再处理 A 放前面，保留 A、B 顺序；从左到右使用递减尾指针则会反转。需要额外 O(n+U) 空间，不能把仅排序键的常数搬移空间套到稳定记录实现上。

## 普通快排与堆排序的学习定位

普通快排的机制是选 pivot，把小于、等于、大于它的元素分开，再处理两侧。例 [3,1,3,2] 以 3 为 pivot，可分为 [1,2]、[3,3]、空；等值段无需递归。一次线性划分，若两侧平衡，递推 2T(n/2)+O(n)=O(n log n)；若持续分出 0 与 n−1，递推 T(n−1)+O(n)=O(n²)。随机枢轴的期望界依赖抽样，不能给固定枢轴最坏对数保证。

当前主线要求熟练使用 std::sort、比较器和计数排序；普通快排手写划分属于后续选学，评分只描述学习成本。归并的实现与递归层证明见 [[06-递归与分治]]；堆的插入、删顶、线性建堆和原地堆排序空间区分见 [[04-堆与优先级队列#扩展选读：建堆与堆排序]]。不要为了记住排序名称，把 O(n log n) 当作所有手写实现的无条件最坏界。
