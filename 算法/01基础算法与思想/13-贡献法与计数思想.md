## 从枚举对象到枚举贡献

当答案是很多对象的某种量之和，可以换一个求和顺序：先固定元素或局部关系，统计它出现多少次，再累加贡献。这是对同一批项重新分组，不会自动解决最大值、最小值等非加法目标。

推导时明确三个问题：被统计的对象是什么？每个对象拆成哪些项？每项在哪些对象中出现？最后检查是否漏计、重计以及数值范围。

## 完整例子一：所有连续子数组的元素和之和

输入 n 和 n 个整数，输出所有非空连续子数组的元素和之和。教学范围为 $n\le 100000$、$\lvert a[i]\rvert \le 10000$，结果可用 `long long`。允许 $n=0$。

直接枚举区间再逐项累加需要 $O(n^{3})$；固定左端点并增量累加区间和，可降到 $O(n^{2})$。进一步固定第 i 个元素（0-based）：左端点有 $i+1$ 种选择，右端点有 $n-i$ 种选择，它出现在 $(i+1)(n-i)$ 个子数组中。

$$
答案=\sum_{i=0}^{n-1} a_i(i+1)(n-i).
$$

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    int n;
    cin >> n;
    long long ans = 0;
    for (int i = 0; i < n; ++i)
    {
        long long x;
        cin >> x;
        ans += x * (i + 1LL) * (n - i);
    }
    cout << ans << '\n';
}
```

正确性：一个区间的和是其中每个元素的贡献之和；交换“区间”和“元素”的求和顺序后，每个原始项恰好计入一次。负数贡献同样成立，不需要单调性。

例如 [1,2,3]，三项贡献为 3、8、9，答案 20。时间 $O(n)$，额外空间 $O(1)$。本范围答案绝对值不超过 $10000\cdot n(n+1)(n+2)/6$，约 $1.67\times 10^{18}$；若扩大范围，必须重新检查乘积与总和，不能仅因使用 `long long` 就认为安全。

## 完整例子二：移除一个元素后的相等数对

测试链接：[AtCoder ABC159 D — Banned K](https://atcoder.jp/contests/abc159/tasks/abc159_d)。输入 n 和数组，$1\le a[i]\le n$；对每个位置分别移除该元素，输出剩余元素中值相等的无序下标对数量。每次移除独立，不能永久修改频率。

值 v 出现 $c[v]$ 次，贡献 c[v](c[v]-1)/2 对。先求总数 total，移除一个值 v 的元素只会删除与它组成的 $c[v]-1$ 对，因此答案为 $\mathrm{total}-(c[v]-1)$。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
int a[N], count_value[N];
int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
        count_value[a[i]]++;
    }
    long long total = 0;
    for (int i = 1; i <= n; i++)
    {
        long long count = count_value[i];
        total += count * (count - 1) / 2;
    }
    for (int i = 0; i < n; i++)
        cout << total - (count_value[a[i]] - 1) << '\n';
}
```

被移除的每一对恰好含当前元素和另一个同值元素，数量为 $c[v]-1$，其余对均保留。$n\le 200000$ 时总对数约 $2\times 10^{10}$，必须使用长整数。时间与存储 $O(n)$。样例 [1,1,2,1,2] 输出 2、2、3、2、3。

## 计数对象与去重

| 模型 | 区分什么 | 常见错误 |
|---|---|---|
| 无序下标对 | 只计 $i<j$，相同数值可来自不同位置 | 把有序对数直接当答案 |
| 值序列排列 | 相同值交换可能产生同一序列 | 每个下标排列都输出一次 |
| 下标子集 | 每个元素的位置都是身份 | 相同子集和去重后丢失方案数 |
| 多个贡献项 | 一个对象可合法贡献多项 | 看见“多次出现”就错误除以 2 |

例如 [1,1,1] 有三个相等无序下标对，而不是一个不同数值对。是否重复必须依据题目计数对象决定。

## 分组贡献与进一步衔接

有些问题先把元素按颜色、余数或奇偶位置分组，再维护数量、下标和、数值和等统计量。展开乘积后，找哪些量可预先累计。
