## 核心思想

枚举所有可能的候选，检查是否合法，再统计或更新最优值。先回答三个问题：枚举对象是什么？为什么不遗漏？同一个解会不会被重复计数？暴力既可能直接通过，也可以作为优化算法的正确性基准。

## 常见枚举对象

| 对象 | 枚举方式 | 候选数量 |
|---|---|---|
| 不同下标的无序数对 | i<j | n(n-1)/2 |
| 非空连续子数组 | 0≤l≤r<n | n(n+1)/2 |
| 子集 | 每个元素选或不选 | 2^n |
| n 个不同元素的排列 | 逐位置选择未使用元素 | n! |

候选数量还要乘以检查或输出一个候选的成本。枚举所有区间再逐项求和为 O(n³)；增量累加或 [[01-前缀和#一维前缀和|一维前缀和]] 可降到 O(n²)。

## 完整例子：分成两组，使重量差最小

输入 n 和 n 个非负整数，输出两组总重量差的最小值。允许空组，n≤20，权重总和保证在 `long long` 范围内。

拓展测试：[洛谷 P2392 — 考前临时抱佛脚](https://www.luogu.com.cn/problem/P2392)。每科分别分成两组，求较大组耗时的最小值，再累加四科；需调整输入与目标值，不能直接提交本例。

把每个下标的一位作为“是否放入第一组”。其余元素放入第二组，两组差为 |total-2·sum|。

```cpp
#include <bits/stdc++.h>
using namespace std;
long long a[25];
int main()
{
    int n;
    cin >> n;
    long long total = 0;
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
        total += a[i];
    }
    long long best = total;
    for (unsigned mask = 0; mask < (1u << n); mask++)
    {
        long long sum = 0;
        for (int i = 0; i < n; i++)
            if (mask & (1u << i))
                sum += a[i];
        best = min(best, llabs(sum - (total - sum)));
    }
    cout << best << '\n';
}
```

正确性：每一种第一组都对应唯一位掩码，因此覆盖所有划分。交换两组会重复得到同一个无序划分，但这里只求最小值，不影响结果；如果统计方案数就必须处理这种重复。时间 O(n·2^n)，额外空间 O(n)。

## 排列枚举

```cpp
// a 是可比较元素的数组，n 为有效长度；从最小排列开始。
sort(a, a + n);
do
{
    // 检查或输出 a
} while (next_permutation(a, a + n));
```

如果值有重复，以上按字典序枚举不同的值序列；它不会区分数值相同但下标不同的元素。需要区分个体时枚举下标。回溯实现见 [[08-搜索]]。

## 如何优化暴力

1. 消去一个变量：已知 a+b+c=S，枚举 a、b 后直接计算 c。
2. 保存重复计算：区间和用前缀和，出现次数用频率表。
3. 排序后排除候选：两数之和用 [[05-双指针与滑动窗口]]。
4. 排除不可能完成的分支：见 [[08-搜索]] 的安全剪枝。
5. 拆分指数空间：折半枚举两组子集和，再排序、二分或双指针合并。通常需要 O(n·2^(n/2)) 级时间和 O(2^(n/2)) 空间，具体取决于生成与合并方式。

## 边界与反例

- 下标相同能否选两次？无序数对通常要求 i<j。
- 求连续区间还是任意子序列？两者的候选空间不同。
- 空集是否合法？初始答案能否为 0？
- `1u<<n` 不能用于任意大的 n；上面的模板明确限制 n≤20。
- 求最大值且可能全负时，不能盲目把答案初始化为 0。
