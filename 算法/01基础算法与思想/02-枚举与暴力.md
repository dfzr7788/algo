评分是本项目的学习建议；尺度见 [[00-基础算法与思想#评分尺度|评分尺度]]。

## 核心思想

枚举所有可能的候选，检查是否合法，再统计或更新最优值。先回答三个问题：枚举对象是什么？为什么不遗漏？同一个解会不会被重复计数？暴力既可能直接通过，也可以作为优化算法的正确性基准。

## 常见枚举对象

| 对象 | 枚举方式 | 候选数量 |
|---|---|---|
| 不同下标的无序数对 | $i<j$|$n(n-1)/2$ |
| 非空连续子数组 | $0\le l\le r<n$|$n(n+1)/2$ |
| 子集 | 每个元素选或不选 | $2^{n}$ |
| n 个不同元素的排列 | 逐位置选择未使用元素 | $n!$ |

候选数量还要乘以检查或输出一个候选的成本。枚举所有区间再逐项求和为 $O(n^{3})$；增量累加或 [[01-前缀和#一维前缀和|一维前缀和]] 可降到 $O(n^{2})$。

## 完整例子：分成两组，使重量差最小

输入 n 和 n 个非负整数，输出两组总重量差的最小值。允许空组，$n\le 20$，权重总和保证在 `long long` 范围内。

拓展测试：[洛谷 P2392 — 考前临时抱佛脚](https://www.luogu.com.cn/problem/P2392)。每科分别分成两组，求较大组耗时的最小值，再累加四科；需调整输入与目标值，不能直接提交本例。

把每个下标的一位作为“是否放入第一组”。其余元素放入第二组，两组差为 $\lvert \mathrm{total}-2\cdot sum\rvert$。

```cpp
#include <bits/stdc++.h>
using namespace std;
long long a[25];
int main()
{
    int n;
    cin >> n;
    long long total = 0;
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
        total += a[i];
    }
    long long best = total;
    for (unsigned mask = 0; mask < (1u << n); mask++)
    {
        long long sum = 0;
        for (int i = 0; i < n; i++)
            if (mask & (1u << i))
            {
                sum += a[i];
            }
        best = min(best, llabs(sum - (total - sum)));
    }
    cout << best << '\n';
}
```

正确性：每一种第一组都对应唯一位掩码，因此覆盖所有划分。交换两组会重复得到同一个无序划分，但这里只求最小值，不影响结果；如果统计方案数就必须处理这种重复。时间 $O(n\cdot 2^{n})$，额外空间 $O(n)$。

## 排列枚举

```cpp
// a 是可比较元素的数组，n 为有效长度；从最小排列开始。
sort(a, a + n);
do
{
    // 检查或输出 a
} while (next_permutation(a, a + n));
```

如果值有重复，以上按字典序枚举不同的值序列；它不会区分数值相同但下标不同的元素。需要区分个体时枚举下标。回溯实现见 [[08-搜索]]。

## 如何优化暴力

1. 消去一个变量：已知 $a+b+c=S$，枚举 a、b 后直接计算 c。
2. 保存重复计算：区间和用前缀和，出现次数用频率表。
3. 排序后排除候选：两数之和用 [[05-双指针与滑动窗口]]。
4. 排除不可能完成的分支：见 [[08-搜索]] 的安全剪枝。
5. 拆分指数空间：折半枚举两组子集和，再排序、二分或双指针合并。通常需要 $O(n\cdot 2^{n/2})$ 级时间和 $O(2^{n/2})$ 空间，具体取决于生成与合并方式。

## 边界与反例

- 下标相同能否选两次？无序数对通常要求 $i<j$。
- 求连续区间还是任意子序列？两者的候选空间不同。
- 空集是否合法？初始答案能否为 0？
- `1u<<n` 不能用于任意大的 n；上面的模板明确限制 $n\le 20$。
- 求最大值且可能全负时，不能盲目把答案初始化为 0。

## AtCoder ABC480E — Product-Bounded Arithmetic Sequences

[官方题面](https://atcoder.jp/contests/abc480/tasks/abc480_e)。统计长度至少 3、首项为正整数、公差为正整数、所有项的乘积不超过 $N$ 的等差数列，$1\le N\le10^{18}$。不同长度分别计数，答案保证不超过 $10^{18}$。

> [!tip]- 提示一：三个参数不应同样枚举
> 一个数列由首项 $a$、公差 $d$ 和长度确定。长度为 3 时可行公差可能很多，但固定 $a$ 后乘积随 $d$ 严格递增，可以直接二分公差的最大可行值。

> [!tip]- 提示二：长数列有更强的乘积限制
> 把长度恰好为 3 与长度至少为 4 分开。后者必须先满足 $a(a+d)(a+2d)(a+3d)\le N$，再依次追加下一项；某次乘积超限后，同一首项和公差的更长数列都不可能合法。

> [!example]- 详细题解
> **分类的必要性。** 用户代码把两类长度分别统计到 `ans`。若对所有合法三项数列逐个枚举公差，会遇到很大的候选集合；若统一枚举长度并二分，也没有利用短序列与长序列的数量差异。现有实现只对三项情形批量计数，对四项及以上逐个延长。
>
> **第一部分：长度恰为 3。** 外层从 $a=1$ 递增。最小公差为 1，若 $a(a+1)(a+2)>N$，当前以及更大首项全部无解，可以结束。令 `m=N/a`，判定条件改为 $(a+d)(a+2d)\le m$。因为两边都是整数，除法取整不改变等价性。二分得到最大公差 `best`，合法公差恰为 $1,\ldots,best$，直接累加 `best`；没有合法公差则为 0。
>
> **二分上界为何够用。** 对正整数 $a,d$，三项乘积大于 $2d^2$，所以合法 $d<\sqrt{N/2}<10^9$。源码在 $[1,10^9]$ 搜索不会遗漏；中间乘积用 `__int128`，必须在第一次乘法前转换。
>
> **第二部分：长度至少为 4。** 若最小四项乘积 $a(a+1)(a+2)(a+3)>N$ 就停止首项循环。对每个首项从 $d=1$ 开始枚举，`prod` 初始化为四项乘积；首次超过 $N$ 时，由公差单调性停止。每个合法四项数列先令答案加 1，再设 `nxt=a+4*d`。只要 `prod<=N/nxt` 就乘上下一项、再计一个更长数列，并把 `nxt` 增加 $d$。除法比较保证不会先乘出一个不必要的大整数。
>
> **手算。** 取 $N=24$。三项部分：$a=1$ 时合法公差为 1、2，分别得到 $(1,2,3)$ 与 $(1,3,5)$；$a=2$ 时只有 $(2,3,4)$，$a=3$ 起最小乘积已超限。四项部分只有 $(1,2,3,4)$，乘积 24；追加 5 会超限。两部分合计 4。$N=120$ 时应得到 18。
>
> **正确性。** 两个分支按长度划分且互不重叠。三项分支对每个首项一次性统计全部合法公差；长序列分支枚举唯一的 $(a,d)$，依次计入它的每个合法长度。正公差与正首项保证增加公差、增加长度都不能把已经超限的乘积降回可行范围，所有停止条件均安全。
>
> **复杂度与实现边界。** 三项分支最多枚举 $O(N^{1/3})$ 个首项，每个二分 $O(\log U)$，$U=10^9$。设合法四项参数对数为 $M$，每对最长延伸 $O(\log N)$ 次，总时间可写为 $O(N^{1/3}\log U+M\log N+N^{1/4})$，额外空间 $O(1)$。第二部分实际枚举了公差，不能误写成只枚举首项的复杂度。$N<6$ 时两个循环均不计数；$N=6$ 时只有 $(1,2,3)$；公差 0 和长度 2 都不应计入。累计答案用 `long long`，乘积用 `__int128`。

### 扩展选读：四项参数对的数量界

对于合法四项数列，$a^4<N$ 且 $6ad^3<a(a+d)(a+2d)(a+3d)\le N$。因此 $a<N^{1/4}$，固定 $a$ 的公差数量为 $O((N/a)^{1/3})$。对首项求和得 $M=O(N^{1/2})$，可推出上述实现的保守上界 $O(N^{1/3}\log U+N^{1/2}\log N)$。这是枚举上界，不能用官方另一种算法的复杂度替代。
