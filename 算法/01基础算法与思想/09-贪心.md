## 一、 贪心的核心原理

贪心算法每一步按既定规则选择，并缩小剩余问题。成立的关键是证明这种选择保留至少一个全局最优解；“当前看起来最好”本身不足以保证正确，也不是逐步逼近的近似保证。

一个问题要能用贪心求解，必须满足两个数学性质：

1. **贪心选择性质（Greedy Choice Property）：** 我们可以保证，每一步所做的局部最优选择，最终必定能推导出全局最优解。这意味着我们不需要像动态规划（DP）那样回溯或比较多个分支。
    
2. **最优子结构（Optimal Substructure）：** 原问题的最优解包含其子问题的最优解。

**贪心与DP的区别：** 动态规划会穷尽所有可能的状态转移并选最优，而贪心是“一条路走到黑”，一旦做出选择就不可更改（除非使用反悔贪心）。

## 二、 经典使用场景

在竞赛中，纯贪心通常出现在以下几类标准模型中：

- **区间问题（Interval Problems）：**
    
    - **区间调度/最多不相交区间：** 按照**右端点从小到大**排序，依次选择不冲突的区间。
        
    - **区间选点：** 同样按右端点排序，在区间的最后一点放标记，能覆盖最多后续区间。
        
    - **区间覆盖：** 按照**左端点从小到大**排序，每次选择能覆盖当前起点且右端点最远的区间。
        
- **图论中的贪心：**
    
    - **Dijkstra 算法：** 在非负边权前提下，每次选择当前暂定距离最小且尚未确定距离的节点。
        
    - **Kruskal：** 按边权排序，选择连接不同连通块的边。**Prim：** 每次选择当前生成树与外部顶点之间的最小权边。两者的候选集合不同，不能直接混用规则。
        
- **树上问题：** 部分覆盖问题可以从叶子向上决策，但必须结合约束证明；一般树上优化可能需要树形 DP，不能仅凭“叶子先处理”判断可贪心。
    
- **哈夫曼编码（Huffman Coding）：** 每次合并权值最小的两个节点。

## 三、 常用技巧与思维切入点

解决贪心问题时，寻找贪心策略的常用技巧：

1. **排序（Sorting）：** 贪心最形影不离的工具。绝大多数贪心问题都需要先对数据进行某个维度的排序（如按权值、按结束时间、按比率 $v_i/w_i$ 等），将无序转化为有序，从而暴露出贪心选择的方向。
    
2. **极端化思考（Extremum Thinking）：** 思考“最少、最大、最后、最前”的元素应该怎么处理。往往边界上的元素其最优决策是唯一确定的。
    
3. **优先队列 / 堆（Priority Queue）：** 动态维护当前的最大/最小值。当贪心策略需要不断从一个动态集合中取最值时（如合并果子），`std::priority_queue` 是标准配置。
    
4. **双指针（Two Pointers）：** 对于配对类问题（如乘船问题、两数之和），通常排序后使用头尾指针，最大的和最小的进行贪心匹配。

## 四、 进阶技巧（竞赛高频）

在 Codeforces (Div.2 C/D 及以上) 或 ICPC 中，简单的贪心往往无法直接奏效，以下进阶技巧是破题的关键。

### 1. 反悔贪心（Regret Greedy / 反悔自动机）

**核心思想：** 传统的贪心不能回头，但反悔贪心允许我们先“盲目”地做出局部最优选择，并在后续发现这个选择阻碍了更好的结果时，通过数据结构（通常是优先队列）**撤销之前的选择，替换为当前的更优解**。

- **典型场景：** 带截止时间的任务调度、最多能买多少件商品等。
    
- **套路：** 维护一个大根堆/小根堆记录“已选决策的代价”。遍历后续元素时，如果发现当前元素比堆顶记录的最差历史决策更优，就把历史决策从堆中弹出（反悔），将当前元素加入堆中。
    
- **例题模型：** 有 $N$ 项任务，每项任务有耗时 $t_i$ 和截止时间 $d_i$。按截止时间 $d_i$ 从小到大遍历。如果当前时间够，直接加入堆并累加时间；如果时间不够但当前任务耗时 $t_i$ 小于堆顶（已选任务中最耗时的），则弹出堆顶，加入当前任务。
### 2. 邻项交换法（Exchange Argument）

**核心思想：** 用于推导出复杂的、非直观的排序规则，并顺带证明贪心的正确性。

- **操作步骤：**
    
    1. 假设存在一个最优解序列，其中相邻的两个元素为 $A$ 和 $B$（$A$ 在 $B$ 前面）。
        
    2. 写出不交换 $A, B$ 时的代价函数 $f(A, B)$，和交换 $A, B$ 后的代价函数 $f(B, A)$。
        
    3. 令 $f(A, B) < f(B, A)$（假设不交换更优），化简这个不等式。
        
    4. 化简后得到的不等式关系，直接作为 `std::sort` 中的 `cmp` 比较函数。
        
- **经典例题：** 洛谷 P1080 [NOIP2012 提高组] 国王游戏。每个大臣有左右手数字 $a_i, b_i$，推导后发现按 $a_i \times b_i$ 从小到大排序即为最优策略。

### 3. 二分答案 + 贪心验证（Binary Search on Answer）

**核心思想：** 当直接求最优解很难，但验证一个解是否可行相对容易时（特别是题目带有“最大值最小化”或“最小值最大化”字眼）。

- **操作步骤：** 先二分最终的答案 $X$。在 `check(X)` 函数中，问题转化为一个判定性问题：“在限制条件 $X$ 下，能否完成任务？” 此时往往可以通过非常暴力的贪心策略来验证。

### 4. 拟阵理论（Matroid Theory）与带权贪心

这是贪心算法的理论天花板。如果一个问题可以被抽象为带权拟阵（Weighted Matroid）上的独立集问题，那么必定可以用贪心求解。

- **特征：** 满足“遗传性”（独立集的子集仍是独立集）和“交换性”（小的独立集总能从大的独立集中借一个元素来扩展）。
    
- **实战意义：** 图中的森林、域上线性无关向量组构成典型拟阵。例如，在非负权重向量中选择总权重最大的线性无关子集，可按权重降序尝试插入线性基。“整个集合异或和非零”不等价于线性无关，不能用作线性拟阵的独立条件。一般的带耗时任务调度也不能不经证明就认定为拟阵。本节作为进阶阅读，基础阶段先掌握交换论证。

## 五、 完整模型：最多不相交区间

输入 n 个半开区间 `[l,r)`，$l<r$，相邻区间可以端点相接，输出最多能选多少个两两不相交区间。

测试链接：[洛谷 P1803 — 凌乱的 yyy / 线段覆盖](https://www.luogu.com.cn/problem/P1803)。输入输出可对应本程序。

错误策略：开始最早的优先，会在 `[0,10)`、`[1,2)`、`[2,3)`、`[3,4)` 中只选一个。最短优先也可能失败：`[0,3)`、`[3,6)`、`[2,4)`，选最短的 `[2,4)` 只能选一个。

正确策略：结束最早的优先。某个最优解的第一段若不是全局结束最早区间，可将它替换为结束最早区间，后续区间仍合法，数量不减。因此存在包含贪心第一段的最优解，对剩余区间重复论证。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 1000005;
pair<long long, long long> intervals[N];
int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        cin >> intervals[i].first >> intervals[i].second;
    }
    sort(intervals, intervals + n,
        [](const pair<long long, long long> &a, const pair<long long, long long> &b)
        {
            return a.second < b.second;
        });
    bool selected = false;
    long long last = 0;
    int answer = 0;
    for (int i = 0; i < n; i++)
    {
        long long l = intervals[i].first, r = intervals[i].second;
        if (!selected || l >= last)
        {
            answer++;
            last = r;
            selected = true;
        }
    }
    cout << answer << '\n';
}
```

时间 $O(n \log n)$，数组空间 $O(n)$。用 selected 处理尚未选择的情况，避免错误地假设坐标非负。如果区间是闭区间且相接算重叠，判断应为 `l>last`。带权区间最大收益不能直接用此策略，通常需要 DP。

## 六、 完整模型：最优合并

输入 n 个非负重量，每次合并两堆，代价为两堆重量之和，求合并为一堆的最小总代价。允许任意两堆合并，总代价保证在 `long long` 范围内。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    int n;
    cin >> n;
    priority_queue<long long, vector<long long>, greater<long long>> q;
    for (int i = 0; i < n; ++i)
    {
        long long x;
        cin >> x;
        q.push(x);
    }
    long long ans = 0;
    while (q.size() > 1)
    {
        long long x = q.top();
        q.pop();
        long long y = q.top();
        q.pop();
        ans += x + y;
        q.push(x + y);
    }
    cout << ans << '\n';
}
```

证明：合并过程对应一棵二叉树，总代价等于各叶子重量乘其深度之和。最深的一对兄弟叶子可通过交换放入两个最小重量，交换不会增加总代价；因此存在最优树让两个最小重量为兄弟。将它们收缩成一片重量为两者之和的叶子，得到同类子问题，递归证明策略正确。

例如 [1,2,3]，先合并 1、2 的代价为 $3+6=9$，先合并 2、3 为 $5+6=11$。时间 $O(n \log n)$，空间 $O(n)$。$n\le 1$ 代价为 0。如果只允许相邻两堆合并，此证明不成立，通常需要区间 DP。

## 七、 完整模型：截止时间内完成最多任务

每个任务有正耗时 t 和非负截止时间 d；从时间 0 开始，单机执行、不可中断，所有任务同时可选，收益相同。选择并安排最多任务，使每个任务都在其截止时间之前或恰好完成。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
pair<long long, long long> jobs[N];
int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        cin >> jobs[i].second >> jobs[i].first;
    }
    sort(jobs, jobs + n);
    priority_queue<long long> chosen;
    long long total = 0;
    for (int i = 0; i < n; i++)
    {
        long long deadline = jobs[i].first, duration = jobs[i].second;
        total += duration;
        chosen.push(duration);
        if (total > deadline)
        {
            total -= chosen.top();
            chosen.pop();
        }
    }
    cout << chosen.size() << '\n';
}
```

证明要点：可行集合总能按截止时间排序执行。算法处理一个截止时间前缀时，先加入新任务；若超时，在加入后的集合中删除最长任务，得到同样数量下耗时最小的一次删除。历史任务的完成时间因删除只会提前，若删的是新任务则恢复旧方案，因而保持可行。

数量最优性可用更强的归纳性质证明：对于每个已处理前缀，所保留集合大小为最大可行数量；对每个不超过该大小的 q，所保留集合中最短的 q 个任务总耗时不大于任意可行 q 任务集合。加入任务时，候选 q 集合要么不含新任务，要么由旧 $q-1$ 集合加新任务构成；最短 q 个任务取两种候选的较小耗时，保持性质。若加入后超时，候选全部任务的数量无法达到，删去最长项保留的更小 q 的最小耗时性质不变，因此数量最优。

每步只需删一次：删除的最大耗时至少为新任务耗时，删后总时间不超过加入前总时间。假设耗时总和不溢出。时间 $O(n \log n)$，空间 $O(n)$。若任务收益不同，不能按此规则直接求最大收益。

## AtCoder ABC480C — Self-Stopping Shower

[官方题面](https://atcoder.jp/contests/abc480/tasks/abc480_c)。每次按按钮都会从当前时刻起供水 $K$ 秒，另有 $N$ 次免费的按压，时刻为 $A_i$。求使整个 $[0,T]$ 连续供水所需的最少额外按压次数。$N\le 2\times10^5$，$K,T\le10^9$，允许 $A_i=0$、重复时刻和 $A_i>T$；供水端点相接合法。

> [!tip]- 提示一：只关心下一次免费事件
> 逐秒模拟无法适应大时间范围。将免费时刻排序，维护当前已经连续覆盖到的最右时刻 `cur`。

> [!tip]- 提示二：缺口能批量补齐
> 若下一次免费按压在 $a>cur$，每次付费最多再延长 $K$，至少需要 $\lceil(a-cur)/K\rceil$ 次。到达免费事件后，能否把之前的付费安排都归结为同一个后续状态？

> [!example]- 详细题解
> **状态与初始化。** 用户代码先排序，`cnt` 是已付费次数，`cur` 是持续供水的右端点。若最早免费事件不在 0，必须在 0 付费一次，因此初始化为 `cnt=1, cur=K`；否则保留 `cnt=0, cur=0`，交由时刻 0 的免费事件开始供水。
>
> **从逐次按压到批量计数。** 依序处理 $a=A_i$。当 $a\le cur$ 时无需付费，免费按压使右端点变为 $\max(cur,a+K)$。当 $a>cur$ 时，缺口长度为 $a-cur$，代码增加 $(a-cur+K-1)/K$ 次，再令 `cur=a+K`。这等价于每到供水结束时才补按；最后一次付费到达的右端点严格小于 $a+K$，所以免费的这一次一定能接管后续覆盖。
>
> **为什么最优。** 在相邻免费事件之间没有其他免费机会，每次付费最多增加 $K$ 的覆盖长度，因而上述向上取整是下界。在已有供水结束时按压即可达到此下界。把任何提前付费的按压延后到供水将结束时，不会破坏连续性，并且后续右端点不会更早；因此不需要为了未来提前多付费。免费事件后的最优状态由它的时刻决定，逐段最优可以衔接。
>
> **手算。** $K=4,T=20,A=(6,7,12)$。起点付费一次得到 `cur=4,cnt=1`；到 6 前补一次，免费事件后 `cur=10,cnt=2`；时刻 7 免费续至 11；到 12 前再补一次，免费续至 16；最后补一次到 20，答案 4。
>
> **停止与边界。** `cur>=T` 时已经完成；$a>T$ 时剩余免费事件均无用。遍历结束后若 `cur<T`，再补 $\lceil(T-cur)/K\rceil$ 次。$a=cur$ 可以直接免费衔接，不能按缺口处理；重复免费时刻不会增加费用。$A_1>T$ 时，起点那一次和尾部补齐合计为 $\lceil T/K\rceil$。
>
> **复杂度。** 排序 $O(N\log N)$，扫描 $O(N)$；事件数组占 $O(N)$ 空间，原代码静态容量为 200005。时间与次数计算使用 `long long`。

## CF2269C — K Is Important

[官方题面](https://codeforces.com/contest/2269/problem/C)。当前数组长度为 $m\ge k$ 时，必须删除从左数第 $k$ 个或从右数第 $k$ 个元素，并获得该元素的值；剩余元素保持相对顺序。求最终最大得分。$1\le k\le n\le10^5$，$1\le a_i\le10^9$，所有测试的 $n$ 之和不超过 $10^5$。与 Div. 1 的 CF2268A 同题。

> [!tip]- 提示一：先找哪些位置一定会被删除
> 当 $n\ge2k-1$ 时，初始中间区间 $[k,n-k+1]$ 的左右两端就是两个可删位置。在这段删空之前，外侧元素会成为可删位置吗？

> [!tip]- 提示二：后续决策按对称位置配对
> 中间段处理完后，从内向外考察 $(a_i,a_{n-i+1})$。证明每一对必须且只能删去一个，而且选择哪一侧不会改变下一对的两个候选。$n<2k-1$ 时，先判断中间有哪些元素永远删不到。

> [!example]- 详细题解
> **暴力与结构。** 直接枚举左右两种删除选择有指数级分支，使用数组删除还会反复移动元素。源码只累加答案：先加入所有 $k\le i\le n-k+1$ 的 `a[i]`，再令 `l=min(k-1,n-k+1)`，把前 `l` 对对称位置的较大值累加到 `ans`。`l` 表示配对数量，不是动态数组的左端点。
>
> **中间段非空时必删。** 若 $n\ge2k-1$，中间段两侧各有 $k-1$ 个元素。只要中间段还非空，两种操作都只能删除其中的左端或右端，外侧这两段不动。因此整个中间段必定被删完，其贡献固定为 $\sum_{i=k}^{n-k+1}a_i$。之后数组只剩两侧各 $k-1$ 个元素，开始处理 $k-1$ 对。
>
> **中间段为空时的保护区域。** 若 $n<2k-1$，令 $l=n-k+1$。原位置 $[l+1,n-l]=[n-k+2,k-1]$ 到任一边的排名都小于 $k$，删除其他元素只会让排名更小，故它们永远不能被选中。剩下两侧各 $l$ 个元素形成配对。$n=2k-2$ 时该保护区域为空，也适用同一分析。
>
> **每对独立选择的严格依据。** 按 $i=l,l-1,\ldots,1$ 处理。轮到第 $i$ 对时，两侧尚未处理的元素各有 $i$ 个，中间已有 $k-1-i$ 个保留元素，总长是 $k-1+i$。从左数第 $k$ 个恰为右侧未处理段的第一个元素 $a_{n-i+1}$；从右数第 $k$ 个恰为左侧未处理段的最后一个元素 $a_i$。删去其中任意一个，另一个进入中间保留区域，于是相同结构在 $i-1$ 时继续成立。最后恰好剩下 $k-1$ 个元素，过程结束。
>
> **最优性。** 每一对只能贡献其中一个值，得分至多为该对的最大值；上述结构保证每对选较大值都能实际执行，且不改变下一对候选。因此所有局部上界可以同时达到，得到
>
> $$\mathrm{ans}=\sum_{i=k}^{n-k+1}a_i+\sum_{i=1}^{\min(k-1,n-k+1)}\max(a_i,a_{n-i+1}),$$
>
> 其中上下界倒置的第一段和按 0 处理。源码从外向内累加配对值只是求和顺序，真实删除顺序应从内向外，二者不要混淆。
>
> **手算。** $n=6,k=3,a=(1,4,8,2,6,3)$，先删原位置 3、4，得分 $8+2=10$，剩 $(1,4,6,3)$。内层对 $(4,6)$ 选 6，剩 $(1,4,3)$；外层对 $(1,3)$ 选 3，最终得分 $10+6+3=19$。当 $n=4,k=4,a=(3,4,1,2)$ 时，只能在两端 3 和 2 中选一个，中间的 4 无法选中，答案 3。
>
> **复杂度与边界。** 读入、中央累加和配对扫描均为 $O(n)$，`vector<int> a(n+1)` 占 $O(n)$ 空间。$k=1$ 时全部求和、没有配对；$k=n$ 时只取两端最大值；$n=2k-1$ 时中间唯一元素只计一次。总分可达 $10^{14}$，`ans` 必须使用 `long long`。删除次数固定为 $n-k+1$，不能把题目误解成选任意这么多个最大元素。

## CF2149D A and B

[官方题面](https://codeforces.com/contest/2149/problem/D)

相邻交换只含a、b的字符串，使所有a或所有b连续，求最少交换次数；未被聚拢的字符可分在两侧。

> [!tip]- 提示一
> 固定待聚拢字符的位置pos[i]，最终会连续占据k+i。

> [!tip]- 提示二
> 把距离写成Σ|(pos[i]−i)−k|，思考绝对值和的最优中心。
>
> 复习：[[01基础算法与思想/09-贪心]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码分别收集posa、posb，减去各自序号得到pa、pb，排序后各取中位数计算位移和ca、cb，再取min。相邻交换保持同种字符的相对顺序，所以无需枚举匹配顺序；位置减序号把连续块起点k变成所有元素共享的目标。
>
> **正确性与适用条件。** 一次有效交换只能让一个待聚拢字符移动一格，顺序匹配的总位移给出下界；按次序把字符移到目标块能达到此下界。绝对距离和在中位数处最小，因此无须枚举所有起点。
>
> **手算与边界。** ababa中a位置(0,2,4)变为(0,1,2)，成本2；b位置(1,3)变为(1,2)，成本1，答案1。此时a可以仍在两侧，不能误解为最后仅有两个字符段。
>
> **实际复杂度与实现。** 源码对本已非降序的pa、pb又排序，实际时间O(N log N)，空间O(N)，去掉冗余排序才是线性。累加用long long；某字符缺失时不能无条件读空向量中位数。

## P4653 CEOI 2017 Sure Bet

[官方题面](https://www.luogu.com.cn/problem/P4653)

两类灯泡各N个，任取每个付1，最终只亮某一类，最大化亮起权值和减总成本的最坏值。

> [!tip]- 提示一
> 固定两类选择数后，各自取最大的若干个；输入行配对不约束选择。

> [!tip]- 提示二
> 设两类前缀和S、T，评价min(S,T)−i−j，每次扩展较小和的一侧。
>
> 复习：[[01基础算法与思想/09-贪心]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码将a、b独立降序排序，i=j=0。S<T就增加i，否则增加j；某侧用尽则只能增加另一侧。每步更新ans=max(ans,min(S,T)−i−j)，初始0允许一个也不选。
>
> **正确性与适用条件。** 当S<T时，固定i继续增大j不会提高瓶颈min(S,T)，只增加成本，因此这类组合不优于当前组合，可直接前进i；另一侧对称。两指针把未经过的组合都交给一个瓶颈相同、费用更低的已检查组合支配，故不遗漏最优。
>
> **手算与边界。** N=1,a=3,b=4，两侧都选得min(3,4)−2=1，优于只选一侧或全不选。不能把每行两灯强行绑定购买。
>
> **实际复杂度与实现。** 时间O(N log N)，空间O(N)。double累计，输出四位小数；判断真实最坏收益，不先取整，也不按平均权值替代总收益。

## ABC443D Pawn Line

[官方题面](https://atcoder.jp/contests/abc443/tasks/abc443_d)

每列棋子行号R[i]只能减小，要求相邻行号差至多1，求最少总上移步数。

> [!tip]- 提示一
> 对每个位置尽可能保留较大的最终行号，避免多移动。

> [!tip]- 提示二
> 任一位置j会给i施加上界R[j]+|i−j|，分别从左右传播。
>
> 复习：[[01基础算法与思想/09-贪心]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码保存原r1，正向令r[i]=min(r[i],r[i−1]+1)，反向令r[i]=min(r[i],r[i+1]+1)，最后累加r1−r。两遍取最小实现所有位置施加的距离上界，不必反复模拟逐格上移。
>
> **正确性与适用条件。** 任何合法结果h都满足h[i]≤R[j]+|i−j|，故不能超过这些上界的最小值。两遍扫描得到该下包络，它自身相邻差至多1且不超过R，因此可行并逐点最大，总代价最小。
>
> **手算与边界。** R=(4,1,4)，正向得(4,1,2)，反向得(2,1,2)，移动数2+0+2=4。只扫一遍会遗漏右侧低点对左侧的约束。
>
> **实际复杂度与实现。** 每测试O(N)时间、O(N)空间；多测重建向量。答案最高为平方量级，应long long；最终行号仍≥1，因为所有原值≥1。

## ABC474E One-Time Coupon

[官方题面](https://atcoder.jp/contests/abc474/tasks/abc474_e)

每类商品需至少买一次，可原价A购入并得一券，或用一券按B购买，允许重复买商品，初始无券，求最低总价。

> [!tip]- 提示一
> 固定有K类商品用券，优先选择节省A−B最多的K类。

> [!tip]- 提示二
> 原价买下其余N−K类得到券，不足的2K−N张券可通过最便宜原价商品补充。
>
> 复习：[[01基础算法与思想/09-贪心]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码suma=ΣA，mi=min A，c=A−B降序。枚举K，cur为前K大节省量，成本suma−cur+max(0,2K−N)·mi，与全原价基线比较。补券购买可以是重复商品，不违反“至少一次”。
>
> **正确性与适用条件。** 固定用券覆盖K个必需种类，剩余N−K次原价最多直接提供这么多券，不足部分每张至少花mi再原价购买；此下界可先完成所有原价及补券购买，再用券购买K类达到。多余的用券重复购买不产券且正成本，删去不影响可行性，故这种分类已覆盖最优结构。
>
> **手算与边界。** 两类价格(10,1),(100,2)，K=1选第二类节省98，成本12；K=2需另买两次最便宜原价来供券，成本1+2+20=23。只按最大折扣盲目全用券会更贵。
>
> **实际复杂度与实现。** 排序O(N log N)，扫描O(N)，空间O(N)。累计和、补券数乘mi需long long；K=0基线不可遗漏，所有B<A保证节省为正但仍不表示每类都该用券。

## CF2200D Portal

[官方题面](https://codeforces.com/contest/2200/problem/D)

排列中两个可移动传送门允许把邻接元素移到另一门侧，反复操作后求字典序最小排列。

> [!tip]- 提示一
> 门内元素的循环相对次序不变，门外元素的线性相对次序不变。

> [!tip]- 提示二
> 门内循环转到最小值开头，再决定整段插在门外序列何处。
>
> 复习：[[01基础算法与思想/09-贪心]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码win由原[x,y)段旋转到其最小值开头，ca是其余两端拼接。扫描ca，遇第一个大于win[0]的元素前插入整段win；若没有则放末尾。操作可把门内头移尾来旋转，也可移动边界让外侧元素绕过整段，从而实现这些插入位置。
>
> **正确性与适用条件。** 每次操作要么旋转门内序列，要么让一个门外元素从整块的一侧绕到另一侧；门内元素始终是相同长度的连续块，门外线性次序不变。这些旋转与块插入位置也都可达。排列无重复，块首项取其最小值最优；插入点前的外侧项若较小，先保留它字典序更优，遇到首个较大项则应立即插块。后续比较无须继续，因为首个不同元素已决定全局次序。
>
> **手算与边界。** 原p=(1,3,5,2,4)，x=1,y=3，win=(3,5)，ca=(1,2,4)，在4前插入得(1,2,3,5,4)。把门内任意排序会错误地允许改变其循环次序。
>
> **实际复杂度与实现。** 时间O(N)，空间O(N)。x、y是元素间边界，代码[x,y)为门内，不能当1下标闭区间。应以门内连续块插入的可达结构证明，不能把此操作误作任意稳定归并。

## CF2254C2 Marenol

[官方题面](https://codeforces.com/contest/2254/problem/C2)

二进制串允许001↔100、110↔011，求a变b的最少操作数，不可达输出−1。

> [!tip]- 提示一
> 操作恰是交换距离2的不同端点，中间位可任意，因此奇偶位置互不混合。

> [!tip]- 提示二
> 在两个压缩子序列中按顺序匹配1的位置，计算最小相邻交换次数。
>
> 复习：[[01基础算法与思想/09-贪心]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码分别收集0下标偶位、奇位的1位置，存i/2作为压缩坐标，得到aeven1、aodd1、beven1、bodd1。若任一组1的数量不同就−1，否则对同组第k个1累计位置差绝对值。一次原操作恰对应某组中一次相邻01交换，另一组不受影响。
>
> **正确性与适用条件。** 奇偶组1数是不变量，也是二进制相邻交换的全部可达条件。最优匹配不交叉：交叉配对可交换目标而不增距离。每步让一个1移一格，顺序匹配总距离是下界，也可通过相邻交换达到，两组最优之和即总最优。
>
> **手算与边界。** a=001,b=100，两个1均在偶下标组，压缩位置1→0，答案1；a=010,b=100的1从奇组到偶组，数量不符，无解。
>
> **实际复杂度与实现。** 时间O(N)，空间O(N)，答案可达平方量级，使用long long。原坐标差要除2，源码通过预先存i/2处理，不能直接累计原位移。
