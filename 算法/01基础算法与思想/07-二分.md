## 一、 二分的核心原理：二段性

很多人误以为二分的前提是“单调性”，但更准确的本质是“二段性”。

对于某个定义域内的所有变量 $x$，如果存在一个判定函数 $P(x)$，使得 $x$ 在某一个分界点的一侧全都满足 $P(x) = \text{true}$，在另一侧全都满足 $P(x) = \text{false}$，那么我们就可以通过二分法找到这个分界点。

判定函数本身需要是单调布尔序列（全假后全真，或全真后全假）；原始数值函数不一定整体单调，但必须证明目标判定具有这种分界结构。

### 基础防死循环模板（整数二分）

整数二分的难点在于边界处理，稍有不慎就会陷入死循环（例如 `l = r - 1` 时无限循环）。算法竞赛中最通用的是以下两套模板，分别用于寻找“左边界”和“右边界”。

**模板 1：寻找满足条件的“最左”位置**（例如：第一个 $\ge x$ 的数）

```cpp
int l = min_val, r = max_val;
while (l < r)
{
    int mid = l + (r - l) / 2; // 向下取整
    if (check(mid))
    {
        r = mid; // 答案在 mid 或 mid 左侧
    }
    else
    {
        l = mid + 1; // mid 不满足条件，答案一定在 mid 右侧
    }
}
// 前提：初始区间内存在满足条件的位置；否则须额外判断无解。
// 结束时 l == r，check(l) 为真时才是答案。
```

**模板 2：寻找满足条件的“最右”位置**（例如：最后一个 $\le x$ 的数）

```cpp
int l = min_val, r = max_val;
while (l < r)
{
    int mid = l + (r - l + 1) / 2; // 注意这里加了 1，向上取整
    if (check(mid))
    {
        l = mid; // 答案在 mid 或 mid 右侧
    }
    else
    {
        r = mid - 1; // mid 不满足条件，答案一定在 mid 左侧
    }
}
```

> **口诀记忆**：`l = mid` 时，`mid` 计算必须加 $1$（向上取整），否则会死循环；`r = mid` 时不用加 $1$。

## 二、 二分答案（Binary Search on Answer）

这是算法竞赛中最常用的二分技巧。如果一个最优化问题很难直接求解，但验证一个给定的答案却很容易，我们就可以“猜”答案，并用二分来调整猜测的范围。

**适用场景标志词**：

- **最大值最小化**（Minimize the maximum）：例如“将数组分成 $K$ 段，求使得和最大的一段的和尽可能小”。
    
- **最小值最大化**（Maximize the minimum）：例如“在坐标轴上选 $K$ 个点，使得相邻两点之间的最小距离尽可能大”。
    
- **求第 $K$ 大 / 第 $K$ 小**：例如在矩阵或多维结构中找第 $K$ 极值。

**核心逻辑**：

把求 $x$ 变成判断 `check(x)`。如果 $x$ 满足条件，那么小于（或大于）$x$ 的值也必定满足条件，从而构成二段性。

**经典例题：“进击的奶牛” (Aggressive Cows)**

- **题意**：有 $N$ 个牛棚位于直线上，将 $C$ 头牛放入牛棚，求让相邻两头牛的“最小距离”尽可能“大”。
    
- **转化**：二分这个“最小距离” $D$。写一个 `check(D)`，判断在距离至少为 $D$ 的情况下，能否放下 $C$ 头牛。
    
- **贪心 Check**：从左到右遍历牛棚，如果当前牛棚与上一头牛的距离 $\ge D$，就放一头牛。如果最后放下的牛的数量 $\ge C$，则 `check(D)` 为真。

## 三、 二分区间（查找范围）

在实际问题中，我们需要在数组中找一段满足特定条件的区间 $[L, R]$，这通常通过两次二分来分别确定左右端点。

### 1. 手写二分查找区间

例如，在一个有序数组中查找元素 $X$ 出现的起始位置和结束位置：

1. 用 **模板1** 查找第一个 $\ge X$ 的位置，得到左端点 $L$。
    
2. 用 **模板2** 查找最后一个 $\le X$ 的位置，得到右端点 $R$。
    
    如果数组中不存在 $X$，则最后得到的 $L$ 处的值将不等于 $X$。
    

### 2. STL 函数的妙用 (C++ 专属技巧)

算法竞赛中，强烈建议熟练使用 STL 自带的二分函数，代码短且不易出错：

- `std::lower_bound(begin, end, val)`：返回**第一个** $\ge val$ 的元素的迭代器。
    
- `std::upper_bound(begin, end, val)`：返回**第一个** $> val$ 的元素的迭代器。

**求区间技巧**：如果要求有序序列中等于 $X$ 的元素区间 $[L, R]$：

```cpp
auto l_it = std::lower_bound(a, a + n, X);
auto r_it = std::upper_bound(a, a + n, X);
// 元素的个数就是 r_it - l_it
```

_注意：对于 `std::set` 和 `std::map`，必须使用它们自身的成员函数（例如 `s.lower_bound(x)`），若使用全局 `std::lower_bound` 会退化为 $O(N)$ 复杂度。_

## 四、 浮点数二分与精度技巧

当问题的答案是实数时，我们需要进行浮点数二分。相比整数二分，浮点数二分没有 `l = mid + 1` 的烦恼，只需要直接替换边界即可。

**常规写法（基于 epsilon）**：

```cpp
double l = 0, r = 1e9;
while (r - l > 1e-6)
{ // eps 根据题目要求的精度决定，一般比要求多 2 位
    double mid = (l + r) / 2;
    if (check(mid))
        r = mid;
    else
        l = mid;
}
```

**竞赛防坑技巧（固定迭代次数法）**：

由于浮点数精度在极端情况下可能导致 `r - l > eps` 永远成立（陷入死循环，引发 TLE），竞赛中经常使用**固定循环次数**的方法代替 `eps` 判定。

```cpp
double l = 0, r = 1e9;
for (int i = 0; i < 100; ++i)
{ // 迭代次数按区间大小与误差要求选择；精度仍受 double 限制
    double mid = (l + r) / 2.0;
    if (check(mid))
        r = mid;
    else
        l = mid;
}
```

## 五、 进阶阅读（基础掌握后再学习）

在更高级的比赛（如 Codeforces Div.1 / Div.2 后期题，ICPC）中，二分通常作为外层框架，内层嵌套其他算法：

1. **三分法 (Ternary Search)**
    
    - **场景**：当目标函数不是单调的，而是**单峰/单谷**的（例如开口向上或向下的抛物线），我们需要求极值。
        
    - **做法**：每次取区间的两个三等分点 $m1, m2$。如果求最大值且 $f(m1) < f(m2)$，说明左侧区间 $[l, m1]$ 不包含峰值，可以直接舍弃该段（$l = m1$）；反之亦然。
        
2. **0/1 分数规划 (0/1 Fractional Programming)**
    
    - **场景**：给定物品的价值 $v_i$ 和成本 $c_i$，选出若干物品，最大化 $\frac{\sum v_i}{\sum c_i}$。
        
    - **转化**：二分答案 $mid$，问题转化为判断是否存在 $\frac{\sum v_i}{\sum c_i} \ge mid$。
        
    - 变形式子：$\sum v_i - mid \times \sum c_i \ge 0$。每次 `check(mid)` 时，将每件物品的权值视为 $v_i - mid \times c_i$，然后根据题意（贪心、背包、网络流等）求最大权值和是否 $\ge 0$。
        
3. **整体二分 (Parallel Binary Search)**
    
    - **场景**：有多个独立的查询，每个查询都可以用二分答案解决，但单独为每个查询二分会 TLE。
        
    - **做法**：批量处理查询的判定，复用操作或数据结构。递归划分答案域的整体二分与分轮并行二分是相关但不同的组织方式，具体实现和复杂度取决于问题、事件处理与数据结构，不能套用统一的复杂度公式。

## 六、 有无解都安全的半开区间查找

以下函数返回第一个 ≥x 的下标；不存在时返回 n。a 必须升序，下标使用 `[l,r)`。

```cpp
int first_ge(const long long a[], int n, long long x)
{
    int l = 0, r = n;
    while (l < r)
    {
        int m = l + (r - l) / 2;
        if (a[m] >= x)
            r = m;
        else
            l = m + 1;
    }
    return l;
}
```

不变量：下标 <l 的值全都 <x，下标 ≥r 的值全都 ≥x。初始两部分为空，每次比较保持性质且缩小区间；最终 l=r 是唯一分界。时间 O(log n)，额外空间 O(1)。函数片段接收数组、长度 n 与查询值，不需要容器类。

| 输入 | 查找值 | 返回下标 |
|---|---|---|
| [] | 3 | 0（即 n） |
| [2,2,5] | 2 | 0 |
| [2,2,5] | 3 | 2 |
| [2,2,5] | 6 | 3（即 n） |

判断元素存在必须先检查 `p<n`，再访问 `a[p]`。原来的两个闭区间模板分别要求假→真、真→假，且区间内有可行位置；不能在全不满足时直接把终点视为可行答案。

## 七、 完整例子：最小化最大分段和

输入 n、k 和 n 个非负整数，将数组分成至多 k 个非空连续段，最小化最大段和。要求 n≥1、k≥1，数组总和不超过 `long long`。如果要求恰好 k 段且 k≤n，非负条件下可以继续拆段而不增加最大段和，所以最优值相同。

测试链接：[洛谷 P1182 — 数列分段 Section II](https://www.luogu.com.cn/problem/P1182)。原题要求恰好 M 段，满足上述可拆分条件，输入输出可对应本程序。

下界是最大元素，上界是总和。判定 `check(limit)`：每段和≤limit 时，最少需要几段？从左到右尽量延长当前段，超过限制才另起一段。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
long long a[N];
int n, k;
bool check(long long limit)
{
    int parts = 1;
    long long current = 0;
    for (int i = 0; i < n; i++)
    {
        if (a[i] > limit)
            return false;
        if (current > limit - a[i])
        {
            parts++;
            current = a[i];
        }
        else
            current += a[i];
    }
    return parts <= k;
}
int main()
{
    cin >> n >> k;
    long long lo = 0, hi = 0;
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
        lo = max(lo, a[i]);
        hi += a[i];
    }
    while (lo < hi)
    {
        long long mid = lo + (hi - lo) / 2;
        if (check(mid))
            hi = mid;
        else
            lo = mid + 1;
    }
    cout << lo << '\n';
}
```

判定正确性：对固定限制，贪心第一段覆盖的前缀不短于任何可行第一段；归纳可得相同段数时贪心覆盖得至少一样远，因此所需段数最少。非负性保证缩短一段不会增加其和。

单调性：若限制 L 可行，所有更大限制也可沿用同一分段。因此判定假→真，上界一定可行，二分得到最小可行限制。

单次判定 O(n)，整体 O(n·log(初始区间长度+1))，数组空间 O(n)。例如 [7,2,5,10,8]、k=2，答案为 18。
