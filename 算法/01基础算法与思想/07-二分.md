## 一、 二分的核心原理：二段性

很多人误以为二分的前提是“单调性”，但更准确的本质是“二段性”。

对于某个定义域内的所有变量 $x$，如果存在一个判定函数 $P(x)$，使得 $x$ 在某一个分界点的一侧全都满足 $P(x) = \text{true}$，在另一侧全都满足 $P(x) = \text{false}$，那么我们就可以通过二分法找到这个分界点。

判定函数本身需要是单调布尔序列（全假后全真，或全真后全假）；原始数值函数不一定整体单调，但必须证明目标判定具有这种分界结构。

### 基础防死循环模板（整数二分）

整数二分的难点在于边界处理，稍有不慎就会陷入死循环（例如 `l = r - 1` 时无限循环）。算法竞赛中最通用的是以下两套模板，分别用于寻找“左边界”和“右边界”。

**模板 1：寻找满足条件的“最左”位置**（例如：第一个 $\ge x$ 的数）

```cpp
int l = min_val, r = max_val;
while (l < r)
{
    int mid = l + (r - l) / 2; // 向下取整
    if (check(mid))
    {
        r = mid; // 答案在 mid 或 mid 左侧
    }
    else
    {
        l = mid + 1; // mid 不满足条件，答案一定在 mid 右侧
    }
}
// 前提：初始区间内存在满足条件的位置；否则须额外判断无解。
// 结束时 l == r，check(l) 为真时才是答案。
```

**模板 2：寻找满足条件的“最右”位置**（例如：最后一个 $\le x$ 的数）

```cpp
int l = min_val, r = max_val;
while (l < r)
{
    int mid = l + (r - l + 1) / 2; // 注意这里加了 1，向上取整
    if (check(mid))
    {
        l = mid; // 答案在 mid 或 mid 右侧
    }
    else
    {
        r = mid - 1; // mid 不满足条件，答案一定在 mid 左侧
    }
}
```

> **口诀记忆**：`l = mid` 时，`mid` 计算必须加 $1$（向上取整），否则会死循环；`r = mid` 时不用加 $1$。

## 二、 二分答案（Binary Search on Answer）

这是算法竞赛中最常用的二分技巧。如果一个最优化问题很难直接求解，但验证一个给定的答案却很容易，我们就可以“猜”答案，并用二分来调整猜测的范围。

**适用场景标志词**：

- **最大值最小化**（Minimize the maximum）：例如“将数组分成 $K$ 段，求使得和最大的一段的和尽可能小”。
    
- **最小值最大化**（Maximize the minimum）：例如“在坐标轴上选 $K$ 个点，使得相邻两点之间的最小距离尽可能大”。
    
- **求第 $K$ 大 / 第 $K$ 小**：例如在矩阵或多维结构中找第 $K$ 极值。

**核心逻辑**：

把求 $x$ 变成判断 `check(x)`。如果 $x$ 满足条件，那么小于（或大于）$x$ 的值也必定满足条件，从而构成二段性。

**经典例题：“进击的奶牛” (Aggressive Cows)**

- **题意**：有 $N$ 个牛棚位于直线上，将 $C$ 头牛放入牛棚，求让相邻两头牛的“最小距离”尽可能“大”。
    
- **转化**：二分这个“最小距离” $D$。写一个 `check(D)`，判断在距离至少为 $D$ 的情况下，能否放下 $C$ 头牛。
    
- **贪心 Check**：从左到右遍历牛棚，如果当前牛棚与上一头牛的距离 $\ge D$，就放一头牛。如果最后放下的牛的数量 $\ge C$，则 `check(D)` 为真。

## 三、 二分区间（查找范围）

在实际问题中，我们需要在数组中找一段满足特定条件的区间 $[L, R]$，这通常通过两次二分来分别确定左右端点。

### 1. 手写二分查找区间

例如，在一个有序数组中查找元素 $X$ 出现的起始位置和结束位置：

1. 用 **模板1** 查找第一个 $\ge X$ 的位置，得到左端点 $L$。
    
2. 用 **模板2** 查找最后一个 $\le X$ 的位置，得到右端点 $R$。
    
    如果数组中不存在 $X$，则最后得到的 $L$ 处的值将不等于 $X$。
    

### 2. STL 函数的妙用 (C++ 专属技巧)

算法竞赛中，强烈建议熟练使用 STL 自带的二分函数，代码短且不易出错：

- `std::lower_bound(begin, end, val)`：返回**第一个** $\ge val$ 的元素的迭代器。
    
- `std::upper_bound(begin, end, val)`：返回**第一个** $> val$ 的元素的迭代器。

**求区间技巧**：如果要求有序序列中等于 $X$ 的元素区间 $[L, R]$：

```cpp
auto l_it = std::lower_bound(a, a + n, X);
auto r_it = std::upper_bound(a, a + n, X);
// 元素的个数就是 r_it - l_it
```

_注意：对于 `std::set` 和 `std::map`，必须使用它们自身的成员函数（例如 `s.lower_bound(x)`），若使用全局 `std::lower_bound` 会退化为 $O(N)$ 复杂度。_

## 四、 浮点数二分与精度技巧

当问题的答案是实数时，我们需要进行浮点数二分。相比整数二分，浮点数二分没有 `l = mid + 1` 的烦恼，只需要直接替换边界即可。

**常规写法（基于 epsilon）**：

```cpp
double l = 0, r = 1e9;
while (r - l > 1e-6)
{ // eps 根据题目要求的精度决定，一般比要求多 2 位
    double mid = (l + r) / 2;
    if (check(mid))
    {
        r = mid;
    }
    else
    {
        l = mid;
    }
}
```

**竞赛防坑技巧（固定迭代次数法）**：

由于浮点数精度在极端情况下可能导致 `r - l > eps` 永远成立（陷入死循环，引发 TLE），竞赛中经常使用**固定循环次数**的方法代替 `eps` 判定。

```cpp
double l = 0, r = 1e9;
for (int i = 0; i < 100; ++i)
{ // 迭代次数按区间大小与误差要求选择；精度仍受 double 限制
    double mid = (l + r) / 2.0;
    if (check(mid))
    {
        r = mid;
    }
    else
    {
        l = mid;
    }
}
```

## 五、 进阶阅读（基础掌握后再学习）

在更高级的比赛（如 Codeforces Div.1 / Div.2 后期题，ICPC）中，二分通常作为外层框架，内层嵌套其他算法：

1. **三分法 (Ternary Search)**
    
    - **场景**：当目标函数不是单调的，而是**单峰/单谷**的（例如开口向上或向下的抛物线），我们需要求极值。
        
    - **做法**：每次取区间的两个三等分点 $m1, m2$。如果求最大值且 $f(m1) < f(m2)$，说明左侧区间 $[l, m1]$ 不包含峰值，可以直接舍弃该段（$l = m1$）；反之亦然。
        
2. **0/1 分数规划 $(0/1 \mathrm{Fractional} \mathrm{Programming})$**
    
    - **场景**：给定物品的价值 $v_i$ 和成本 $c_i$，选出若干物品，最大化 $\frac{\sum v_i}{\sum c_i}$。
        
    - **转化**：二分答案 $mid$，问题转化为判断是否存在 $\frac{\sum v_i}{\sum c_i} \ge mid$。
        
    - **前提**：每个合法候选非空且总成本严格为正，例如恰选 $1\le k\le n$ 件且所有 $c_i>0$。负分母会改变不等号方向，零分母没有该比值；若允许空集，空集权值和 0 会使所有 mid 被误判可行。

    - 变形式子：$\sum v_i - mid \times \sum c_i \ge 0$。每次 `check(mid)` 时，将每件物品的权值视为 $v_i - mid \times c_i$，然后根据题意（贪心、背包、网络流等）求最大权值和是否 $\ge 0$。
        
3. **整体二分 (Parallel Binary Search)**
    
    - **场景**：有多个独立的查询，每个查询都可以用二分答案解决，但单独为每个查询二分会 TLE。
        
    - **做法**：批量处理查询的判定，复用操作或数据结构。递归划分答案域的整体二分与分轮并行二分是相关但不同的组织方式，具体实现和复杂度取决于问题、事件处理与数据结构，不能套用统一的复杂度公式。

## 六、 有无解都安全的半开区间查找

以下函数返回第一个 $\ge x$ 的下标；不存在时返回 n。a 必须升序，下标使用 `[l,r)`。

```cpp
int first_ge(const long long a[], int n, long long x)
{
    int l = 0, r = n;
    while (l < r)
    {
        int m = l + (r - l) / 2;
        if (a[m] >= x)
        {
            r = m;
        }
        else
        {
            l = m + 1;
        }
    }
    return l;
}
```

不变量：下标 $<l$ 的值全都 $<x$，下标 $\ge r$ 的值全都 $\ge x$。初始两部分为空，每次比较保持性质且缩小区间；最终 $l=r$ 是唯一分界。时间 $O(\log n)$，额外空间 $O(1)$。函数片段接收数组、长度 n 与查询值，不需要容器类。

| 输入 | 查找值 | 返回下标 |
|---|---|---|
| [] | 3 | 0（即 n） |
| [2,2,5] | 2 | 0 |
| [2,2,5] | 3 | 2 |
| [2,2,5] | 6 | 3（即 n） |

判断元素存在必须先检查 `p<n`，再访问 `a[p]`。原来的两个闭区间模板分别要求假→真、真→假，且区间内有可行位置；不能在全不满足时直接把终点视为可行答案。

## 七、 完整例子：最小化最大分段和

输入 n、k 和 n 个非负整数，将数组分成至多 k 个非空连续段，最小化最大段和。要求 $n\ge 1$、$k\ge 1$，数组总和不超过 `long long`。如果要求恰好 k 段且 $k\le n$，非负条件下可以继续拆段而不增加最大段和，所以最优值相同。

测试链接：[洛谷 P1182 — 数列分段 Section II](https://www.luogu.com.cn/problem/P1182)。原题要求恰好 M 段，满足上述可拆分条件，输入输出可对应本程序。

下界是最大元素，上界是总和。判定 `check(limit)`：每段和 $\le \mathrm{limit}$ 时，最少需要几段？从左到右尽量延长当前段，超过限制才另起一段。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
long long a[N];
int n, k;
bool check(long long limit)
{
    int parts = 1;
    long long current = 0;
    for (int i = 0; i < n; i++)
    {
        if (a[i] > limit)
        {
            return false;
        }
        if (current > limit - a[i])
        {
            parts++;
            current = a[i];
        }
        else
        {
            current += a[i];
        }
    }
    return parts <= k;
}
int main()
{
    cin >> n >> k;
    long long lo = 0, hi = 0;
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
        lo = max(lo, a[i]);
        hi += a[i];
    }
    while (lo < hi)
    {
        long long mid = lo + (hi - lo) / 2;
        if (check(mid))
        {
            hi = mid;
        }
        else
        {
            lo = mid + 1;
        }
    }
    cout << lo << '\n';
}
```

判定正确性：对固定限制，贪心第一段覆盖的前缀不短于任何可行第一段；归纳可得相同段数时贪心覆盖得至少一样远，因此所需段数最少。非负性保证缩短一段不会增加其和。

单调性：若限制 L 可行，所有更大限制也可沿用同一分段。因此判定假→真，上界一定可行，二分得到最小可行限制。

单次判定 $O(n)$，整体 $O(n\cdot \log(\text{初始区间长度}+1))$，数组空间 $O(n)$。例如 [7,2,5,10,8]、$k=2$，答案为 18。

## 分数规划的一个完整判定模型

先把“可选若干件”具体化为：恰选 k 件，所有成本正，最大化总价值/总成本。对于固定 x，给每件权 $v_i-xc_i$；从大到小取 k 个的和≥0，当且仅当有合法比值≥x。恰选 k 件排除了空集，各总成本正保证乘分母不变号。

例 `(v,c)=(6,2),(3,1),(4,2)`，k=2。x=3 时新权为 0、0、−2，前两项和 0，可行；x=3.1 时为 −0.2、−0.1、−2.2，最大的两项也为负，不可行。任一方案可行的 x 是从小到大的真→假序列，所以可二分最大可行值。上下界可取各单件比值的最小、最大，因为总比值是按成本加权的单件比值平均。

判定的局部片段，依赖 `1<=k<=n<=200000`、正成本数组 c、价值数组 v、long double 权数组 transformed；使用 `<algorithm>`。要求数值尺度和比较误差适合题意，不将浮点边界视作精确有理数比较。

```cpp
bool feasible_ratio(long double x, int n, int k)
{
    for (int i = 0; i < n; i++)
    {
        transformed[i] = v[i] - x * c[i];
    }
    sort(transformed, transformed + n, greater<long double>());
    long double sum = 0;
    for (int i = 0; i < k; i++)
    {
        sum += transformed[i];
    }
    return sum >= 0;
}
```

单次 O(n log n)，I 次二分总 O(I n log n)，空间 O(n)，计算比值与误差也需考虑。仅一个 (1,1)、k=1，x=2 时新权 −1，所以正确返回 false。

整体二分/并行二分目前是方法提要，尚无独立教程；两种组织方式不混为一个模板。先掌握本篇单个判定和 [[14-预处理与离线思想]]，需要批量判定时再选学。相应评分表示预计学习难度，不表示正文已给完整机制。

## ABC440D Forbidden List 2

[官方题面](https://atcoder.jp/contests/abc440/tasks/abc440_d)

给N个互异禁用整数，每次查询大于等于X且不在表内的第Y小整数；N,Q≤3×10⁵，X,Y≤10⁹。

> [!tip]- 提示一
> 排序后，任一禁用值前的可用数可直接由数轴长度减禁用个数计算。

> [!tip]- 提示二
> 先定位首个≥X的禁用值idx，再二分最后一个“其前可用数仍不足Y”的禁用下标。
>
> 复习：[[01基础算法与思想/07-二分]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码lower_bound求idx。禁用值a[mid]之前可用数为cnt=a[mid]−X−(mid−idx)，cnt随mid非降。若cnt<Y就令bestk=mid并向右，否则向左；最后从a[bestk]再走Y−cnt个整数。若X已在全部禁用值右侧，或首个禁用值前已有Y个数，直接输出X+Y−1。
>
> **正确性与适用条件。** 相邻禁用值间的可用数量非负，所以二分谓词单调。bestk是答案之前最后一处禁用障碍，下一个禁用值之前已有足够剩余空位，故偏移不会撞到另一个禁用值；特判保证bestk存在。
>
> **手算与边界。** 禁用(3,5)，X=2,Y=3，可用序列2,4,6，idx=0；a=5前可用2个，故最后从5走1得到6。Y=1则答案2，走首间隙特判。
>
> **实际复杂度与实现。** 排序O(N log N)，每查询O(log N)，空间O(N)。源码X+Y−1不超过1999999999，符合int；涉及a差值、最终答案及通用扩展仍用long long更清晰。

## ABC463D Maximize Gap

[官方题面](https://atcoder.jp/contests/abc463/tasks/abc463_d)

选K个两两不相交的闭区间，使最近两区间的距离最大，无法选够则−1。N≤2×10⁵。

> [!tip]- 提示一
> 固定间距d后，希望已选最后一个区间尽早结束。

> [!tip]- 提示二
> 按右端排序贪心取能接上的区间，再二分d；闭区间端点相接算相交。
>
> 复习：[[01基础算法与思想/07-二分]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码右端递增排序，check顺扫区间，与上个所选区间严格不相交且距离≥mid时接上，计数够K为真。排序保证新右端不更早，实际只需考察新区间左端>nowr且差值≥mid；原代码的反向分支不会新增候选。二分最大可行mid，找不到保留−1。
>
> **正确性与适用条件。** 任一可行选择的下一段若不是当前可用中右端最早者，换成最早者不会减少后续可用空间，故可归纳使贪心至少选同样多区间。间距增大只会减少可接区间，满足二分单调性。
>
> **手算与边界。** [0,1]、[2,3]、[5,6]选2个，最佳第一与第三距离4。若只有[0,1]、[1,2]，闭端点重合导致无解，即使试d=0也不能选够。
>
> **实际复杂度与实现。** 时间O(N log N+N log C)，C≤10⁹，空间O(N)。源码从−1试二分但仍保留严格不相交判断；不能为了让负阈值可行而允许相交。
