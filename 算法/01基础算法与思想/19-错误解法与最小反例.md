配套：[[17-正确性证明与反例]]。这里保存规模很小、便于手算的反例；“最小”需明确按哪个维度衡量，以下不声称每个例子都是所有输入中的唯一最小反例。

| 错误规则 | 小反例 | 正确结果与错误原因 |
|---|---|---|
| 同步更新直接覆盖旧数组 | 环异或 [1,0,0]，1 轮 | 应为 [1,1,0]，原地依次改成 [1,1,1] |
| 会议相接也算重叠 | `[0,1)`、`[1,2)` | 最大并发为 1；半开区间先离开再进入 |
| 奇数升序再偶数升序即可构造 | n=4，输出 [1,3,2,4] | 交界 3 与 2 差为 1 |
| 和超过目标就收缩，允许负数 | [4,-3]，求和≤2最长区间 | 整段长度 2，过早删除 4 会漏解 |
| 和等于目标每个右端只计一次，允许零 | [0,1]，目标 1 | [1] 与 [0,1] 两段都满足，答案 2 |
| 子集和去重后再统计下标方案 | [1,1]，目标 1 | 两个下标子集，答案 2 |
| 当前子集和超过目标就剪掉，允许负数 | [3,-2]，目标 1 | 先选 3 后再选 -2 是合法解 |
| 区间开始最早优先 | `[0,4)`、`[1,2)`、`[2,3)` | 最优数量 2，选长区间只得 1 |
| 区间最短优先 | `[0,3)`、`[3,6)`、`[2,4)` | 最优数量 2，中间短区间阻挡两边 |
| 不同边权图用普通 BFS 首次发现距离 | s→t 为 10，s→u 为 1，u→t 为 1 | 最短代价 2，首次一条边到达不等于最小代价 |
| 倍增层数只按 n 决定 | n=3，1→2→3→1，从 1 走 8 步 | 终点 3；若仅存位 0、1，会忽略 8 并错误留在 1 |
| 闭区间二分收敛即表示有解 | [2,4]，查第一个≥5 | 不存在；必须返回哨兵或验证最终位置 |
| 比较器用 a≤b | 两个相等元素 [1,1] | cmp(1,1) 为真，破坏严格弱序，排序行为不受正确性保证 |

## 如何把失败输入缩小

1. 保存原输入与两种算法输出，保证能稳定复现。
2. 删除不相关的元素、边或行列，保留失败条件。
3. 缩小数值和区间端点，但保持原题约束。
4. 去掉多余查询，只留触发错误的一次。
5. 写清哪个不变量或适用前提被破坏，再修正算法或代码。

不要为了简化反例，加入原题禁止的负数或空输入，然后声称原算法在该题错误。那只能说明它不能推广到新的约束。

## 调试顺序

1. 将样例手算成状态序列，先检查输入、下标、更新顺序和输出格式。
2. 检查不变量，例如 pos 是否始终与排列互逆、窗口频率是否对应当前区间。
3. 查看溢出和越界：乘法先提升类型，访问前检查下标，递归栈计入空间。
4. 再检查算法前提：负数是否破坏窗口，查询是否真的可离线，剪枝上界是否安全。
5. 算法较复杂时，用独立暴力小规模对拍。暴力不能复用被怀疑的关键假设。

构造题比较合法性而非输出文本，浮点题按原题误差规则比较，集合输出只有在顺序无关时才排序后比较。程序崩溃、超时也应记录为失败，不能当作“没有差异”。

## 对拍例题：含负数的区间和计数

输入 n、K 和整数数组，输出非空连续子数组和为 K 的数量。这里使用前缀频次，支持负数与零。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    int n;
    long long K;
    cin >> n >> K;
    unordered_map<long long, long long> freq;
    freq[0] = 1;
    long long pre = 0, ans = 0;
    for (int i = 0; i < n; ++i)
    {
        long long x;
        cin >> x;
        pre += x;
        auto it = freq.find(pre - K);
        if (it != freq.end())
            ans += it->second;
        ++freq[pre];
    }
    cout << ans << '\n';
}
```

先查询再插入保证左端点在当前右端点之前；`freq[0]=1` 允许从第一个元素开始的区间。假设前缀和、pre-K 和答案不溢出，期望时间 O(n)，空间 O(n)；哈希不保证最坏线性。

## 可复现的对拍脚本

把上述程序编译为可执行文件，例如 `solution.exe`，将以下脚本保存为 `stress.py`，使用 `python stress.py solution.exe`。脚本仅用 Python 标准库，固定随机种子；暴力逐个枚举区间，不使用前缀频次。

```python
import pathlib, random, subprocess, sys

exe=str(pathlib.Path(sys.argv[1]).resolve())
rng=random.Random(20261012)

def encode(a,k):
    return f"{len(a)} {k}\n"+" ".join(map(str,a))+"\n"

def brute(a,k):
    ans=0
    for l in range(len(a)):
        total=0
        for r in range(l,len(a)):
            total+=a[r]
            ans+=total==k
    return ans

cases=[([],0),([0],0),([0,0],0),([4,-3],1),([1,1,1],2)]
cases += [([rng.randint(-5,5) for _ in range(rng.randint(0,12))],
           rng.randint(-10,10)) for _ in range(500)]
for case_id,(a,k) in enumerate(cases):
    data=encode(a,k)
    try:
        result=subprocess.run([exe],input=data,text=True,capture_output=True,
                              timeout=2,check=True)
        actual=int(result.stdout.strip())
        expected=brute(a,k)
        if actual!=expected:
            raise ValueError(f"expected={expected}, actual={actual}")
    except (subprocess.SubprocessError,ValueError) as error:
        pathlib.Path("failed.in").write_text(data,encoding="utf-8")
        print(f"failed case {case_id}: {error}")
        print(data)
        raise SystemExit(1)
print(f"passed {len(cases)} cases")
```

固定种子和保存 `failed.in` 使失败可复现。若实际题目不允许空数组，生成器应移除空输入；不能用非法输入指控解法错误。随机通过不是证明，也不能替代最大规模的时间与内存分析。

失败后按前文删除元素、缩小数值，每次重新运行并确认仍失败。先处理第一个可复现错误，再重新生成测试，不要只修改输出掩盖差异。
