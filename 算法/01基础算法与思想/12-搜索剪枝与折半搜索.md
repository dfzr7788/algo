## 难度与重要程度

| 算法或学习主题 | 难度 | 重要程度 |
|---|---:|---:|
| 可行性与去重剪枝 | 5/10 | 8/10 |
| 上界/下界最优性剪枝 | 7/10 | 7/10 |
| 折半搜索 | 6/10 | 7/10 |

评分是本项目的学习建议；尺度见 [[00-基础算法与思想#评分尺度|评分尺度]]。

**静态容量：** 折半子集和两张静态表每张容量约 $2^{20}$，支持 $n\le 40$；背包数组支持 $n\le 25$。 增大输入范围前需调整容量并检查内存；多组数据需重置有效状态。

## 剪枝分类

| 方法 | 为什么可以丢弃 | 注意事项 |
|---|---|---|
| 可行性剪枝 | 当前分支无法完成合法解 | 例如可用元素不足、皇后冲突 |
| 最优性剪枝 | 该分支最乐观的结果也不优于当前答案 | 下界/上界必须方向正确 |
| 去重剪枝 | 不同选择实际上产生同一目标方案 | 数值相同不代表下标方案相同 |
| 优化搜索顺序 | 更早找到好解，加强后续界限 | 本身不能保证减少最坏复杂度 |

最小化问题用下界 LB，若 $LB\ge \mathrm{best}$，可跳过“求更好值”的分支；如果还要统计所有最优方案，等号处不能直接删。背包不能把普通贪心结果当作一定成立的最优上界，必须推导界限。

## 完整例子一：带禁用格的八皇后

本例是带禁用格的教学变式。测试链接：[洛谷 P1219 — 八皇后](https://www.luogu.com.cn/problem/P1219)，原题输入 n、没有禁用格，需输出前三个方案及总数，不能直接提交本例程序。输入 8 行棋盘，`.` 可放、`*` 不可放，输出八皇后方案数。禁用格不会阻挡攻击。

暴力在 64 个格子里选 8 个后再验证，候选很多。利用每行必须恰好一个皇后，先逐行选列；再用列与两种对角线标记提前排除冲突。

```cpp
#include <bits/stdc++.h>
using namespace std;
string board[8];
bool col[8]{}, diag1[15]{}, diag2[15]{};
int ans = 0;
void dfs(int row)
{
    if (row == 8)
    {
        ++ans;
        return;
    }
    for (int c = 0; c < 8; ++c)
    {
        int d1 = row - c + 7, d2 = row + c;
        if (board[row][c] == '*' || col[c] || diag1[d1] || diag2[d2])
            continue;
        col[c] = diag1[d1] = diag2[d2] = true;
        dfs(row + 1);
        col[c] = diag1[d1] = diag2[d2] = false;
    }
}
int main()
{
    for (auto &s : board)
        cin >> s;
    dfs(0);
    cout << ans << '\n';
}
```

正确性：每个合法方案每行恰好一个皇后，因而对应唯一的一条列选择路径。行差列差相同的格子共享 row-col，另一方向共享 $row+col$；发生冲突的前缀无法被后续补救，因此剪枝安全。撤销标记保证兄弟分支互不干扰。

若推广到 n 皇后，列标记使完整候选至多 $n!$，每个搜索节点扫描 n 列，可以用 $O(n\cdot n!)$ 作保守上界；对角线剪枝会减少实际访问量，但不能因此声称多项式复杂度。标记与递归栈 $O(n)$，棋盘 $O(n^{2})$。本例固定 $n=8$，全空棋盘答案为 92。

## 去重的适用对象

对于排序后的重复值排列，如果按值序列去重，可以在同一层跳过“与前一个相等且前一个未使用”的值；前一个已在当前路径中使用时不能跳过，否则不能放入第二个相同值。

对子集按下标计数，相同数值的不同元素是不同选择。此时去重会改变答案。例如 $[1,1]$ 中和为 1 的子集有两个。

## 完整例子二：折半子集和计数

输入 n、目标 x 与数组，统计和为 x 的下标子集数。$n\le 40$；允许负数与零，所有子集和及 x 与子集和之差保证在 `long long` 范围内。包括空子集。拓展测试：[AtCoder ABC184 F — Programming Contest](https://atcoder.jp/contests/abc184/tasks/abc184_f)。原题求不超过 T 的最大子集和，需要将合并计数改为二分最优补数；本例是计数模型。

全枚举 $O(n\cdot 2^{n})$ 不适合 $n\approx 40$。拆成两半，分别生成子集和：任意原子集都能唯一拆成左子集与右子集，所需条件为 $\mathrm{left}+\mathrm{right}=x$。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int S = (1 << 20) + 5;
long long a[45], left_sum[S], right_sum[S];
void generate_sums(int l, int r, long long sums[], int &count)
{
    count = 1;
    sums[0] = 0;
    for (int j = l; j < r; j++)
    {
        int previous_count = count;
        for (int i = 0; i < previous_count; i++)
            sums[count++] = sums[i] + a[j];
    }
}
int main()
{
    int n;
    long long target;
    cin >> n >> target;
    for (int i = 0; i < n; i++)
        cin >> a[i];
    int left_count, right_count, middle = n / 2;
    generate_sums(0, middle, left_sum, left_count);
    generate_sums(middle, n, right_sum, right_count);
    sort(right_sum, right_sum + right_count);
    long long answer = 0;
    for (int i = 0; i < left_count; i++)
    {
        auto range = equal_range(right_sum, right_sum + right_count, target - left_sum[i]);
        answer += range.second - range.first;
    }
    cout << answer << '\n';
}
```

生成时，把旧的子集和保留，再给每个旧子集加上新元素，分别对应不选/选；即使数值相同也保留重复项。`equal_range` 返回补数出现次数，每个左右子集对恰好计一次。

设两半规模为 a、b，生成 $O(2^{a}+2^{b})$，右侧排序 $O(b\cdot 2^{b})$，每个左和二分 $O(b)$，总计 $O(2^{a}\cdot b+2^{b}\cdot b)$，平衡划分后为 $O(n\cdot 2^{n/2})$；空间 $O(2^{a}+2^{b})$。生成用了增量法，不需要为每个掩码再遍历所有元素。方案数最多 $2^{40}$，要用长整数。

## 完整例子三：最优性剪枝求小规模 0/1 背包

输入 n、容量 W，接着 n 行重量 w、价值 v，每件至多选一次，输出最大价值。教学范围 $n\le 25$、$0\le W\le 10^{6}$、$1\le w\le 10^{6}$、$0\le v\le 10^{6}$。只求最优值，不统计最优方案。

基准是枚举所有子集。为了安全排除分支，按价值/重量比降序排序，假想剩余物品允许取一部分：先装完整物品，最后装一部分。分数背包的最优值不小于 0/1 背包最优值，向上取整后仍是安全上界。若“当前价值+上界 $\le$ 已知 best”，分支无法改善答案。

```cpp
#include <bits/stdc++.h>
using namespace std;
long long weight[30], value[30], best;
int order_id[30], n;
long long upper(int i, long long cap)
{
    long long result = 0;
    for (; i < n; i++)
    {
        int id = order_id[i];
        if (weight[id] <= cap)
        {
            cap -= weight[id];
            result += value[id];
        }
        else
        {
            result += (value[id] * cap + weight[id] - 1) / weight[id];
            break;
        }
    }
    return result;
}
void dfs(int i, long long cap, long long current)
{
    best = max(best, current);
    if (i == n || current + upper(i, cap) <= best)
        return;
    int id = order_id[i];
    if (weight[id] <= cap)
        dfs(i + 1, cap - weight[id], current + value[id]);
    dfs(i + 1, cap, current);
}
int main()
{
    long long W;
    cin >> n >> W;
    for (int i = 0; i < n; i++)
    {
        cin >> weight[i] >> value[i];
        order_id[i] = i;
    }
    sort(order_id, order_id + n,
        [](int x, int y)
        {
            return value[x] * weight[y] > value[y] * weight[x];
        });
    dfs(0, W, 0);
    cout << best << '\n';
}
```

正确性：未剪枝的选/不选分支覆盖所有子集，超重的选分支不可行；分数松弛扩大可行集合，故上界不会低估该分支的最大收益。密度降序的分数填充可以由交换论证证明最优：若先取低密度而仍有高密度未取，交换相同重量不会降低价值。本范围交叉乘积与分数乘积均 $\le 10^{12}$，避免浮点向下误差导致误剪。

例如物品 $(2,3)$、$(3,4)$、$(4,5)$，$W=5$，答案 7。容量为 0、全超重、价值全为 0 都输出 0。时间最坏仍为 $O(n\cdot 2^{n})$，空间 $O(n)$，不是多项式保证。

拓展测试：[洛谷 P1048 — 采药](https://www.luogu.com.cn/problem/P1048)。原题输入顺序、规模与本教学程序不同，通常应使用背包 DP；用它练习对比建模和复杂度，不把本小规模搜索直接当作大规模解法。如果统计所有最优方案，等号剪枝会删掉同值方案，必须重新设计。

## 边界与反例

- $[1,1]$、$x=1$，答案 2；把子集和去重会错误得到 1。
- $[0,0]$、$x=0$，含空子集答案 4；若题目要求非空，应在 $x=0$ 时减去唯一空子集。
- [-2,3]、$x=1$，答案 1；含负数时不能用“当前和超过目标”剪枝。
- $n=0$ 时只存在空子集；本模板能处理，原题不提供这种输入。
- 空间仍是指数级，应按每半的规模估算内存，不能只看时间改善。
