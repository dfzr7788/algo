## 深度优先搜索 (DFS) 与回溯

DFS 的原理是“不撞南墙不回头”，利用系统调用栈向深处探索状态树，遇到边界或非法状态时进行回溯。

- **框架伪代码**：下面含中文占位操作，不是可编译 C++。图遍历不撤销永久访问标记，方案回溯才撤销路径标记。

```text
void dfs(int u)
{
    if (达到目标状态)
    {
        记录答案;
        return;
    }
    for (遍历 u 的所有分支 v)
    {
        if (未访问 v 且状态合法)
        {
            标记 v;
            dfs(v);
            撤销标记(回溯);
        }
    }
}
```

- **进阶优化**：**剪枝**提前排除无法完成或不可能改善答案的分支，但最坏情况仍可能指数级；**记忆化搜索**缓存重复状态，时间约为状态数乘每状态转移成本。状态数若仍为指数级，缓存后也不会自动变成多项式复杂度。
    

## 广度优先搜索 (BFS) 与层序扩展

BFS 的原理是“由近及远”，利用队列按层级（步数）逐层扩展状态，首次到达目标状态时即为无权图的最短路径。

- **框架伪代码**：下面含中文占位操作，不是可编译 C++。图遍历不撤销永久访问标记，方案回溯才撤销路径标记。

```text
void bfs(int start)
{
    queue<int> q;
    q.push(start);
    标记 start;
    while (!q.empty())
    {
        int u = q.front();
        q.pop();
        for (遍历 u 的相邻节点 v)
        {
            if (未访问 v)
            {
                标记 v;
                记录距离;
                q.push(v);
            }
        }
    }
}
```

- **进阶优化**：**0-1 BFS** 针对边权仅为 $0$ 和 $1$ 的图，使用双端队列（`deque`）将 $0$ 边压入队首、$1$ 边压入队尾；**双向 BFS** 从起点和终点同时扩展，按完整层寻找连接，在分支近似均匀的状态树中可能减少访问量；任意图最坏仍为 $O(V+E)$。停止条件与完整模板见 [[04-双向BFS与A星]]。

## 算法的正确性与复杂度证明

- **完备性证明**：对有限图，从起点出发并正确标记，DFS 和 BFS 能遍历所有可达顶点。非连通图要枚举未访问顶点并启动新遍历。方案枚举需要另一种证明，且不能随意以顶点 visited 排除不同路径。
    
- **BFS 最优性证明**：基于数学反证法。假设 BFS 首次访问目标节点 $T$ 的路径长度 $d$ 不是最短路，则必存在更短路径 $d' < d$。但 BFS 按层严格单调递增扩展（$1, 2, \dots$），路径长度为 $d'$ 的节点必然在遍历到 $d$ 层之前出队并完成扩展，故首次到达必定是最短路径。
    
- **时间复杂度**：每个顶点和边只处理常数次的邻接表图遍历为 $O(V + E)$，邻接矩阵遍历通常为 $O(V^{2})$。回溯的成本由搜索树规模和每节点操作决定，例如输出全部排列需 $O(n\cdot n!)$。
    

## 进阶高阶搜索体系

下面为方法提要。折半搜索完整讲解见 [[12-搜索剪枝与折半搜索]]，A* 与双向 BFS 主讲见 [[04-双向BFS与A星]]，0-1 BFS 主讲见 [[06-Dijkstra与非负权最短路]]。IDDFS、IDA* 仍为后续选学，评分不代表这里已有完整模板。基础剪枝失效时，先重新审视状态与模型，不保证引入启发式就变快。

- **折半搜索 (Meet in the Middle)**：将 $O(2^N)$ 的搜索空间拆半，分别生成两半候选，再合并。增量生成子集和可用 $O(2^{N/2})$；若比较排序后双指针或二分，整体通常为 $O(N\cdot2^{N/2})$。哈希合并的期望界还依赖哈希模型，详见 [[12-搜索剪枝与折半搜索]]。
    
- **迭代加深搜索 (IDDFS)**：限制 DFS 的最大深度进行搜索，结合了 DFS 省空间和 BFS 求最短路的优点。
    
- **A\* 算法**：用优先队列与估价函数 $f(n) = g(n) + h(n)$ 扩展状态。最优性需要合适的启发函数和重复状态处理规则；不能用任意估价代替 BFS 就保证最短路。
    
- **IDA\* 算法**：迭代提高 $f=g+h$ 的阈值，用深度优先方式搜索；在满足条件时可以求最优解，性能取决于启发函数和状态空间，不存在对所有谜题都最好的保证。

## 状态设计与访问标记

状态必须包含决定后续合法选择的全部信息。例如带钥匙迷宫不能只记坐标，还要记钥匙集合；两个坐标相同但钥匙不同的状态不能合并。

| 用途 | 标记表示什么 | 返回时撤销？ |
|---|---|---|
| 图的遍历、连通块 | 已经处理过的顶点 | 不撤销 |
| 排列、简单路径枚举 | 当前选择路径中已使用 | 通常撤销 |
| 记忆化 | 完整状态的结果已经计算 | 保留缓存 |

前面的 DFS 伪代码是回溯框架。图遍历若照搬撤销，会重复搜索，甚至指数级展开。

## 完整例子一：排列回溯

输入 n（$1\le n\le 9$），按字典序输出 $1\ldots n$ 的所有排列。

测试链接：[洛谷 P1706 — 全排列问题](https://www.luogu.com.cn/problem/P1706)。原题要求每个数字保留 5 个场宽，提交时需将空格输出改为场宽输出。

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, path_value[15], depth;
bool used[15];
void dfs()
{
    if (depth == n)
    {
        for (int i = 0; i < n; i++)
        {
            cout << path_value[i] << (i + 1 == n ? '\n' : ' ');
        }
        return;
    }
    for (int x = 1; x <= n; x++)
    {
        if (used[x])
        {
            continue;
        }
        used[x] = true;
        path_value[depth++] = x;
        dfs();
        depth--;
        used[x] = false;
    }
}
int main()
{
    cin >> n;
    dfs();
}
```

每个位置尝试所有尚未使用的值，所有排列都对应唯一选择路径；选完后恢复状态，让兄弟分支互不干扰。含输出时间 $O(n\cdot n!)$，额外空间 $O(n)$。值有重复时需要另外去重，不能直接把数值作为 used 下标。

## 完整例子二：网格连通块

输入 n、m 和网格，`.` 可走、`#` 为墙，四方向相邻，输出可走区域数量。用显式栈避免大网格递归过深。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 1005;
char grid[N][N];
int dx[4] = {1, -1, 0, 0}, dy[4] = {0, 0, 1, -1};
int main()
{
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++)
    {
        cin >> grid[i];
    }
    int answer = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
        {
            if (grid[i][j] != '.')
            {
                continue;
            }
            answer++;
            stack<pair<int, int>> st;
            st.push({i, j});
            grid[i][j] = '#';
            while (!st.empty())
            {
                int x = st.top().first, y = st.top().second;
                st.pop();
                for (int d = 0; d < 4; d++)
                {
                    int u = x + dx[d], v = y + dy[d];
                    if (u < 0 || u >= n || v < 0 || v >= m || grid[u][v] != '.')
                    {
                        continue;
                    }
                    grid[u][v] = '#';
                    st.push({u, v});
                }
            }
        }
    cout << answer << '\n';
}
```

入栈时标记且不恢复，每个格子最多入栈一次。一次启动访问一个完整连通块，外层每次新启动都对应一个新区域。时间 $O(nm)$，网格与栈空间 $O(nm)$。模板会修改网格，若需保留原图使用独立 visited。

## 完整例子三：迷宫最短路与路径还原

输入 n、m 和网格，`A` 为唯一起点，`B` 为唯一终点，`.` 可走、`#` 为墙；每一步代价为 1。输出最短步数与一条由 D/U/R/L 构成的路径，无解输出 `IMPOSSIBLE`。

拓展测试：[AtCoder ABC007 C — 幅優先探索](https://atcoder.jp/contests/abc007/tasks/abc007_3)。原题单独输入起终点坐标，网格无 A/B，只输出距离；需调整读取和输出。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 1005;
char grid[N][N];
int dist[N][N], from_direction[N][N];
int dx[4] = {1, -1, 0, 0}, dy[4] = {0, 0, 1, -1};
string direction = "DURL";
int main()
{
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++)
    {
        cin >> grid[i];
    }
    pair<int, int> start = {-1, -1}, target = {-1, -1};
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
        {
            dist[i][j] = -1;
            from_direction[i][j] = -1;
            if (grid[i][j] == 'A')
            {
                start = {i, j};
            }
            if (grid[i][j] == 'B')
            {
                target = {i, j};
            }
        }
    if (start.first < 0 || target.first < 0)
    {
        cout << "IMPOSSIBLE\n";
        return 0;
    }
    queue<pair<int, int>> q;
    q.push(start);
    dist[start.first][start.second] = 0;
    while (!q.empty())
    {
        int x = q.front().first, y = q.front().second;
        q.pop();
        for (int d = 0; d < 4; d++)
        {
            int u = x + dx[d], v = y + dy[d];
            if (u < 0 || u >= n || v < 0 || v >= m || grid[u][v] == '#' || dist[u][v] != -1)
            {
                continue;
            }
            dist[u][v] = dist[x][y] + 1;
            from_direction[u][v] = d;
            q.push({u, v});
        }
    }
    int x = target.first, y = target.second;
    if (dist[x][y] == -1)
    {
        cout << "IMPOSSIBLE\n";
        return 0;
    }
    string path;
    while (make_pair(x, y) != start)
    {
        int d = from_direction[x][y];
        path += direction[d];
        x -= dx[d];
        y -= dy[d];
    }
    reverse(path.begin(), path.end());
    cout << dist[target.first][target.second] << '\n' << path << '\n';
}
```

按队列层序访问，第一次发现状态就是最短距离；前驱保存这次发现的来源。时间 $O(nm)$，空间 $O(nm)$。这个输出格式是教学约定，提交具体题目时需按题目修改格式。

## 安全剪枝与记忆化

- 可行性剪枝：选 k 个元素时，剩余元素不够补足 k 就返回。
- 最优性剪枝：最小化非负代价时，当前代价已不小于已知最优，可停止；若后续能产生负代价则不能直接这样剪。
- 排序优先尝试有希望的分支能更早获得好答案，但不等于可直接删除其他分支。
- 记忆化键要包含完整状态。排列中的“当前深度”不能单独作为键，因为使用过的元素影响后续选择。
- 含环状态转移不能只用“递归+缓存答案”解决，需额外处理环和求值顺序。

普通 BFS 不能处理任意不同边权；0-1 BFS 需要按距离松弛，不能照搬首次入队永久 visited 的规则。迭代加深的最短步数性质适用于等步长状态搜索，折半搜索的合并成本也必须计入。练习见 [[20-题单|题单]]。

完整推导见 [[18-从暴力到优化的完整题解#四、搜索：统计网格连通区域]]。八皇后剪枝和带重复值的子集计数详见 [[12-搜索剪枝与折半搜索]]。
