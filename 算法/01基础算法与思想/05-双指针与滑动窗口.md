## 核心思想与适用条件

维护两个位置，利用有序性或窗口性质，让指针沿一个方向移动，排除不可能的候选。关键是证明排除安全，而不只是代码中出现了两个指针。

| 类型 | 常见模型 | 关键性质 |
|---|---|---|
| 相向指针 | 有序数组两数之和 | 移动端点时和有确定变化方向 |
| 同向指针 | 合并有序序列、去重 | 已处理前缀无需重新访问 |
| 滑动窗口 | 最长无重复子数组 | 冲突可通过不断收缩左端消除 |
| 快慢指针 | 链表中点、判环 | 需要分析步速及相遇关系 |

## 完整例子一：两数之和，输出原下标

输入 n、目标值 target 和数组。找不同下标的两个数，输出 1-based 下标；无解输出 `IMPOSSIBLE`。假定两数相加在 `long long` 范围内。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
pair<long long, int> a[N];
int main()
{
    int n;
    long long target;
    cin >> n >> target;
    for (int i = 0; i < n; i++)
    {
        cin >> a[i].first;
        a[i].second = i + 1;
    }
    sort(a, a + n);
    int l = 0, r = n - 1;
    while (l < r)
    {
        long long sum = a[l].first + a[r].first;
        if (sum == target)
        {
            cout << a[l].second << ' ' << a[r].second << '\n';
            return 0;
        }
        if (sum < target)
        {
            l++;
        }
        else
        {
            r--;
        }
    }
    cout << "IMPOSSIBLE\n";
}
```

正确性：若 $a[l]+a[r]<\mathrm{target}$，那么固定 l，和它配对的其余候选都不大于 $a[r]$，不可能得到 target，所以可以排除 l。和过大时同理排除 r。`l<r` 保证不重复用一个元素。排序 $O(n \log n)$，扫描 $O(n)$，数组空间 $O(n)$。

## 完整例子二：最长无重复连续子数组

输入 n 和整数数组，输出最长无重复连续子数组的长度。数组不能排序，因为连续性依赖原顺序。

测试链接：[牛客 NC41 — 最长无重复子数组](https://www.nowcoder.com/practice/b56799ebfd684fb394bd315e89324fb4)。原题使用 `Solution::maxLength` 函数接口，需将本例扫描逻辑移入函数并返回 best。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
long long a[N];
int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
    }
    unordered_map<long long, int> freq;
    int l = 0, best = 0;
    for (int r = 0; r < n; r++)
    {
        freq[a[r]]++;
        while (freq[a[r]] > 1)
        {
            freq[a[l++]]--;
        }
        best = max(best, r - l + 1);
    }
    cout << best << '\n';
}
```

循环不变量：处理每个 r 后，$[l,r]$ 无重复，且 l 是当前 r 的最早合法左端点。旧窗口无重复，新增 $a[r]$ 后只可能这个值冲突；移除至旧的相同元素离开后，窗口恢复合法。所有以 r 结尾的合法窗口都不比该窗口长，逐个 r 取最大值即为答案。

两个指针各推进至多 n 次。在哈希分布使单次操作平均为 $O(1)$ 的条件下，总时间 $O(n)$，空间 $O(n)$；默认整数哈希是确定的，不能对任意输入承诺期望线性，极端冲突下最坏可达 $O(n^2)$。若改用 `map`，有确定的 $O(n \log n)$ 时间界。

## 非负数组的区间和窗口

当所有 $a[i]\ge 0$ 时，右移 r 不会减小窗口和，右移 l 不会增大窗口和。因此“和 $\le S$ 的最长区间”可以在和过大时收缩。$S\ge 0$ 时，每个 r 收缩后更新长度即可。

**反例：含负数时不能照搬。** $a=[4,-3]$、$S=2$。看到 4 就删除它，会漏掉总和为 1、长度为 2 的整个区间。需要考虑 [[01-前缀和#一维前缀和|一维前缀和]]、哈希或其他结构。

即使数组非负，统计“和恰好为 S”的区间数也不能每个 r 只加 1：零元素可能产生多个合法左端点。必须单独推导计数规则。

## 边界与练习

相向指针检查 $n<2$、重复值、无解；窗口检查空数组、全部相同、全部不同和零元素。解释 $O(n)$ 时统计指针总移动次数。练习见 [[20-题单|题单]]。

完整推导：[[18-从暴力到优化的完整题解#二、双指针：正整数数组中和为目标的区间数]]。对比 $O(n^{2})$ 区间枚举与 $O(n)$ 扫描，重点检查正整数前提。

## 快慢指针：中点、判环与入口

链表不能按数组下标直接访问第 n/2 项。慢指针每次走一步，快指针每次走两步，可在一次顺序行走中找到中点；当快指针到尾部，慢指针约走过一半。偶数长度需要先约定前一个还是后一个中点：slow、fast 同从头出发，循环条件 `fast!=0 && next_node[fast]!=0` 得后一个中点。本方法要求每个节点最多一个后继；多分支图不能直接套用。

若链表有环，快指针不会到尾。进入环后，两指针的相对位置每轮增加 1（模环长 λ），至多 λ 轮相遇。设头到环入口 μ 步、入口到相遇点 δ 步，慢指针相遇时共走 t 步；快指针走 2t 步，所以 t 是 λ 的倍数，同时 t=μ+δ（模 λ）。于是 μ 步恰好抵消 δ。让一个指针回头、另一个留在相遇点，两者各走一步，会在入口相遇；头侧第一次进入环前不可能与环内节点相同。

例 `1→2→3→4→5→3`，μ=2、λ=3。判环阶段 `(slow,fast)` 依次为 (2,3)、(3,5)、(4,4)。回头后 (1,4)→(2,5)→(3,3)，入口为 3。自环 μ=0、λ=1 也成立。

完整自编程序：输入 `n head`，随后 n 个后继编号；`0<=n<=200000`，编号 1..n，0 表示空，所有后继与 head 合法。输出头可达链的环入口编号，无环输出 0。不要求所有输入节点都能由头到达。单组数据，数组容量 200005。

```cpp
#include <iostream>
using namespace std;
const int MAXN = 200000 + 5;
int next_node[MAXN];

int cycle_entry(int head)
{
    int slow = head;
    int fast = head;
    while (fast != 0 && next_node[fast] != 0)
    {
        slow = next_node[slow];
        fast = next_node[next_node[fast]];
        if (slow == fast)
        {
            int from_head = head;
            while (from_head != slow)
            {
                from_head = next_node[from_head];
                slow = next_node[slow];
            }
            return slow;
        }
    }
    return 0;
}

int main()
{
    int n;
    int head;
    cin >> n >> head;
    for (int i = 1; i <= n; i++)
    {
        cin >> next_node[i];
    }
    cout << cycle_entry(head) << '\n';
}
```

教学输入：

```text
5 1
2 3 4 5 3
```

输出：

```text
3
```

无环中点的局部函数，依赖上述 next_node，输入链保证无环；空头返回 0。

```cpp
int second_middle(int head)
{
    int slow = head;
    int fast = head;
    while (fast != 0 && next_node[fast] != 0)
    {
        slow = next_node[slow];
        fast = next_node[next_node[fast]];
    }
    return slow;
}
```

判环及入口时间 O(μ+λ)，无环 O(可达节点数)，额外指针空间 O(1)。本教学程序用数组保存输入，所以总存储 O(n)，不能把额外 O(1) 说成整个程序不存链表。检查空链、单点、头部环、自环、入口在中间和偶数长度中点。

## CF2148E Split

[官方题面](https://codeforces.com/contest/2148/problem/E)

把整个数组分入K个相同多重集，指定子数组必须全放第一个，统计可行的非空子数组数。N≤2×10⁵。

> [!tip]- 提示一
> 先判断每个值的总频数是否被K整除。

> [!tip]- 提示二
> 区间里每个值最多出现总频数/K次；用双指针维护逐值容量。
>
> 复习：[[01基础算法与思想/05-双指针与滑动窗口]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码先cnt统计全局，任一非零频数不整除K立即答0，否则limit[v]=cnt[v]/K。扫描r增加wincnt[a[r]]，只要该值超限就移动l并删去经过元素，最后加r−l+1。新入一个值以前窗口合法，所以只需检查这个值的超限。
>
> **正确性与适用条件。** 全局可均分的前提下，每值在第一个多重集容量固定，区间频数不超容量便可用区间外元素补齐全部集合，条件充要。合法窗口任一后缀仍合法，故每个r恰有r−l+1个合法左端点，计数不重不漏。
>
> **手算与边界。** a=(1,2,1,2),K=2，每值容量1；合法区间为四个单点和三个相邻异值对，共7。若a=(1,1,1),K=2，全局已不能均分，答案0。
>
> **实际复杂度与实现。** 每测试O(N)时间、O(N)空间，两指针各移动至多N次。答案需long long，且多测cnt、limit、wincnt都需清空当前值域。

## 牛客136720D 小红的数字染色

[官方题面](https://ac.nowcoder.com/acm/contest/136720/D)

正整数数组选一段连续子数组，使所选与未选元素和的乘积最大，最后模998244353；N≤2×10⁵，a[i]≤10⁹。

> [!tip]- 提示一
> 总和S固定，s(S−s)随|S−2s|减小而增大。

> [!tip]- 提示二
> 正数让窗口和随右端增加、随左端删除单调，寻找跨越S/2的相邻候选。
>
> 复习：[[01基础算法与思想/05-双指针与滑动窗口]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码sum为总和，sonsum为[l,r)窗口和。若sonsum>S/2或r到末尾就删左项，否则加右项；每次操作后比较|sum−2sonsum|，更小时记录ans1、ans2。最后只对两因子分别取模后相乘，不直接保存可能溢出的乘积。
>
> **正确性与适用条件。** 固定左端时窗口和随右端严格增大，离S/2最近只会在第一次越过阈值前后；当和超半数时继续扩右只会更差，应移动左端。双指针的路径经过每个阈值附近必要候选，跳过的窗口都在同一侧离阈值更远，因此不损失最优。
>
> **手算与边界。** a=(3,1,4,1,5)，S=14，窗口和8与6距离半数同为1，乘积均48。若先对和取模再比较大小，会破坏最大化真实乘积的次序。
>
> **实际复杂度与实现。** O(N)时间、O(N)空间。总和≤2×10¹⁴，差值可用64位，但真实乘积可达10²⁸，不可直接long long相乘；源码比较距离再对因子取模，规避此问题。正数前提不能放宽为含负数。
