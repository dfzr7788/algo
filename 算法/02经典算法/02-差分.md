差分记录变化边界，适合批量区间或矩形加法后统一恢复。先学习一维两端点，再推广到二维四角更新。

## 一维差分

前置：[[01-前缀和#一维前缀和|一维前缀和]]。本篇是批量区间加法，最后统一还原；不支持每次修改后立即 $O(1)$ 查询整段统计。

### 定义与两次边界更新

设 $a[0]=0$，$d[i]=a[i]-a[i-1]$。前缀累加 d 恢复 a。给闭区间 $[l,r]$ 加 c，只需 `d[l]+=c`、`d[r+1]-=c`。

第一个更新让 l 及以后都增加 c，第二个让 $r+1$ 及以后抵消，目标区间外净变化为 0。多个加法可以叠加，所以可统一记账、一次还原。

### 完整程序：批量加法后的数组

输入 n、q、原数组，再输入 q 行 l、r、c，输出最终数组。$n\ge 1$，允许 c 为负，数值与中间差在 `long long` 范围内。分配 $n+2$，保留 $r=n$ 时的取消位置。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 5000005;
long long d[N];
void range_add(int l, int r, long long value)
{
    d[l] += value;
    d[r + 1] -= value;
}
int main()
{
    int n, q;
    cin >> n >> q;
    long long previous = 0;
    for (int i = 1; i <= n; i++)
    {
        long long x;
        cin >> x;
        d[i] = x - previous;
        previous = x;
    }
    while (q--)
    {
        int l, r;
        long long value;
        cin >> l >> r >> value;
        range_add(l, r, value);
    }
    long long current = 0;
    for (int i = 1; i <= n; i++)
    {
        current += d[i];
        if (i > 1)
        {
            cout << ' ';
        }
        cout << current;
    }
    cout << '\n';
}
```

[1,2,3,4,5] 对 $[2,4]$ 加 10，结果 [1,12,13,14,5]。构建 $O(n)$，每次记账 $O(1)$，最终还原 $O(n)$，总 $O(n+q)$，存储 $O(n)$。如果每次修改都完整还原，整体仍可能 $O(nq)$。

### 什么时候不能直接使用

- 区间赋值、取最大值不是相同的可叠加加法，不能照搬两个端点更新。
- 修改与查询交错，可考虑对差分维护 [[08-树状数组|树状数组]]，或使用 [[09-线段树|线段树]]。
- 左闭右开区间 `[l,r)` 在 $d[r]$ 取消；不能和本篇闭区间公式混用。
- 覆盖次数：初始全 0，每个区间加 1，再恢复后统计。

拓展测试：[洛谷 P2367 — 语文成绩](https://www.luogu.com.cn/problem/P2367)，原题只输出最终最低分，需把数组输出改为维护最小值；大规模输入要注意内存和读取速度。两层差分应用见 [[09-从暴力到优化的完整题解]]。

## 二维差分

前置：[[01-前缀和#二维前缀和|二维前缀和]]、[[02-差分#一维差分|一维差分]]。适用场景是批量矩形加法，最后输出或统计矩阵。

### 四个角的符号

给闭矩形 $(x1,y1)\ldots (x2,y2)$ 加 c：

```text
d[x1][y1]       += c
d[x2+1][y1]     -= c
d[x1][y2+1]     -= c
d[x2+1][y2+1]   += c
```

二维前缀累加时，起点加 c 覆盖右下区域，两个减号消去多余行列，右下角加号补回双重扣除。对任意格子计算净系数即可证明矩形内部为 1，外部为 0。

### 完整程序：地毯覆盖次数

测试：[洛谷 P3397 — 地毯](https://www.luogu.com.cn/problem/P3397)。输入 n、q，再输入 q 个闭矩形角坐标，初始 $n\times n$ 全零，每次覆盖加 1，输出覆盖次数。一般非零矩阵初始化见下一节。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 1005;
long long d[N][N];
void rectangle_add(int x1, int y1, int x2, int y2)
{
    d[x1][y1]++;
    d[x2 + 1][y1]--;
    d[x1][y2 + 1]--;
    d[x2 + 1][y2 + 1]++;
}
int main()
{
    int n, q;
    cin >> n >> q;
    while (q--)
    {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        rectangle_add(x1, y1, x2, y2);
    }
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= n; j++)
        {
            d[i][j] += d[i - 1][j] + d[i][j - 1] - d[i - 1][j - 1];
            if (j > 1)
            {
                cout << ' ';
            }
            cout << d[i][j];
        }
        cout << '\n';
    }
}
```

两块覆盖 $(1,1)\ldots (2,2)$ 与 $(2,2)\ldots (3,3)$，中心格为 2，四个边角各按所在矩形计数。时间 $O(n^{2}+q)$，存储 $O(n^{2})$，输出本身需要 $O(n^{2})$。

### 非零矩阵与常见边界

已有矩阵 a 时，初始化 $d[i][j]=a[i][j]-a[i-1][j]-a[i][j-1]+a[i-1][j-1]$，0 行列设为 0；之后四角更新，最后恢复。也可对每格执行单格加法初始化，但不要在完整初始化后又把 a 加一遍。

$n+2$、$m+2$ 的边界空间用于 $x2=n$、$y2=m$ 的取消点。矩形输入是闭区间；若半开，取消坐标不再加 1。推广到任意矩形加 c 时使用长整数并检查溢出。

注意：恢复时修改了 d，不能继续把这个已恢复的矩阵当原始差分表随意追加更新。在线矩形修改与查询需要其他结构。
