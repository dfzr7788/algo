差分记录变化边界，适合批量区间或矩形加法后统一恢复。先学习一维两端点，再推广到二维四角更新。

## 一维差分

前置：[[01-前缀和#一维前缀和|一维前缀和]]。本篇是批量区间加法，最后统一还原；不支持每次修改后立即 $O(1)$ 查询整段统计。

### 定义与两次边界更新

设 $a[0]=0$，$d[i]=a[i]-a[i-1]$。前缀累加 d 恢复 a。给闭区间 $[l,r]$ 加 c，只需 `d[l]+=c`、`d[r+1]-=c`。

第一个更新让 l 及以后都增加 c，第二个让 $r+1$ 及以后抵消，目标区间外净变化为 0。多个加法可以叠加，所以可统一记账、一次还原。

### 完整程序：批量加法后的数组

输入 n、q、原数组，再输入 q 行 l、r、c，输出最终数组。$n\ge 1$，允许 c 为负，数值与中间差在 `long long` 范围内。分配 $n+2$，保留 $r=n$ 时的取消位置。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 5000005;
long long d[N];
void range_add(int l, int r, long long value)
{
    d[l] += value;
    d[r + 1] -= value;
}
int main()
{
    int n, q;
    cin >> n >> q;
    long long previous = 0;
    for (int i = 1; i <= n; i++)
    {
        long long x;
        cin >> x;
        d[i] = x - previous;
        previous = x;
    }
    while (q--)
    {
        int l, r;
        long long value;
        cin >> l >> r >> value;
        range_add(l, r, value);
    }
    long long current = 0;
    for (int i = 1; i <= n; i++)
    {
        current += d[i];
        if (i > 1)
        {
            cout << ' ';
        }
        cout << current;
    }
    cout << '\n';
}
```

[1,2,3,4,5] 对 $[2,4]$ 加 10，结果 [1,12,13,14,5]。构建 $O(n)$，每次记账 $O(1)$，最终还原 $O(n)$，总 $O(n+q)$，存储 $O(n)$。如果每次修改都完整还原，整体仍可能 $O(nq)$。

### 什么时候不能直接使用

- 区间赋值、取最大值不是相同的可叠加加法，不能照搬两个端点更新。
- 修改与查询交错，可考虑对差分维护 [[08-树状数组|树状数组]]，或使用 [[09-线段树|线段树]]。
- 左闭右开区间 `[l,r)` 在 $d[r]$ 取消；不能和本篇闭区间公式混用。
- 覆盖次数：初始全 0，每个区间加 1，再恢复后统计。

拓展测试：[洛谷 P2367 — 语文成绩](https://www.luogu.com.cn/problem/P2367)，原题只输出最终最低分，需把数组输出改为维护最小值；大规模输入要注意内存和读取速度。两层差分应用见 [[09-从暴力到优化的完整题解]]。

## 二维差分

前置：[[01-前缀和#二维前缀和|二维前缀和]]、[[02-差分#一维差分|一维差分]]。适用场景是批量矩形加法，最后输出或统计矩阵。

### 四个角的符号

给闭矩形 $(x1,y1)\ldots (x2,y2)$ 加 c：

```text
d[x1][y1]       += c
d[x2+1][y1]     -= c
d[x1][y2+1]     -= c
d[x2+1][y2+1]   += c
```

二维前缀累加时，起点加 c 覆盖右下区域，两个减号消去多余行列，右下角加号补回双重扣除。对任意格子计算净系数即可证明矩形内部为 1，外部为 0。

### 完整程序：地毯覆盖次数

测试：[洛谷 P3397 — 地毯](https://www.luogu.com.cn/problem/P3397)。输入 n、q，再输入 q 个闭矩形角坐标，初始 $n\times n$ 全零，每次覆盖加 1，输出覆盖次数。一般非零矩阵初始化见下一节。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 1005;
long long d[N][N];
void rectangle_add(int x1, int y1, int x2, int y2)
{
    d[x1][y1]++;
    d[x2 + 1][y1]--;
    d[x1][y2 + 1]--;
    d[x2 + 1][y2 + 1]++;
}
int main()
{
    int n, q;
    cin >> n >> q;
    while (q--)
    {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        rectangle_add(x1, y1, x2, y2);
    }
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= n; j++)
        {
            d[i][j] += d[i - 1][j] + d[i][j - 1] - d[i - 1][j - 1];
            if (j > 1)
            {
                cout << ' ';
            }
            cout << d[i][j];
        }
        cout << '\n';
    }
}
```

两块覆盖 $(1,1)\ldots (2,2)$ 与 $(2,2)\ldots (3,3)$，中心格为 2，四个边角各按所在矩形计数。时间 $O(n^{2}+q)$，存储 $O(n^{2})$，输出本身需要 $O(n^{2})$。

### 非零矩阵与常见边界

已有矩阵 a 时，初始化 $d[i][j]=a[i][j]-a[i-1][j]-a[i][j-1]+a[i-1][j-1]$，0 行列设为 0；之后四角更新，最后恢复。也可对每格执行单格加法初始化，但不要在完整初始化后又把 a 加一遍。

$n+2$、$m+2$ 的边界空间用于 $x2=n$、$y2=m$ 的取消点。矩形输入是闭区间；若半开，取消坐标不再加 1。推广到任意矩形加 c 时使用长整数并检查溢出。

注意：恢复时修改了 d，不能继续把这个已恢复的矩阵当原始差分表随意追加更新。在线矩形修改与查询需要其他结构。

## CF2195D Absolute Cinema

[官方题面](https://codeforces.com/contest/2195/problem/D)

已知F(x)=Σa[i]·|i−x|在x=1..N的值，恢复可含负数的序列a，N≥2，输入保证合法。

> [!tip]- 提示一
> 绝对值函数的斜率只在对应下标改变。

> [!tip]- 提示二
> 内部用二阶差分，端点另用F(1)+F(N)求总和。
>
> 复习：[[02经典算法/02-差分]]。

> [!example]- 详细题解
> **建模与源码主线。** 完成版本令Sn=(f[1]+f[n])/(n−1)，因为每项到两个端点的距离和都是n−1。内部a[i]=(f[i+1]−2f[i]+f[i−1])/2；边界由f[2]−f[1]=2a[1]−Sn得到a[1]，另一端a[n]=(Sn−f[n]+f[n−1])/2。另一份只读入的版本是草稿。
>
> **正确性与适用条件。** 固定系数a[i]的绝对值函数在i处斜率从−a[i]变为+a[i]，二阶差分仅留下2a[i]，其余项抵消。端点一次差分及总和补齐两个边界未知数，故恢复唯一，系数为负也成立。
>
> **手算与边界。** a=(2,−1,3)产生f=(5,5,3)，Sn=4，中间(3−10+5)/2=−1，两端分别恢复2、3。负系数下f未必凸，不能依赖凸性。
>
> **实际复杂度与实现。** 时间O(N)，源码两个向量占O(N)。用long long保留差分的负值；N=2时内部循环为空，边界式仍有效。合法输入保证整除，无需把非整除情况误作四舍五入。

## CF2259E Treasure Map Destruction

[官方题面](https://codeforces.com/contest/2259/problem/E)

至少一座岛有宝藏，给出部分位置到最近宝藏的距离，未知为−1，构造任意分布或判无解。N≤2×10⁵。

> [!tip]- 提示一
> 给定距离d的位置i禁止更近处放宝藏。

> [!tip]- 提示二
> 把所有未禁止位置都放宝藏，再验证全部已知距离。
>
> 复习：[[02经典算法/02-差分]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码对a[i]>0在[i−a[i]+1,i+a[i]−1]做差分禁用并裁边，恢复后覆盖数为0的位置全置1。若没有候选则无解。左右各扫一次得到最近1的距离dis，逐项检查a[i]≠−1时dis[i]=a[i]。a[i]=0靠最后验证保证本岛有宝藏。
>
> **正确性与适用条件。** 任意合法集合只能由未禁用位置组成。全集中不存在比已知距离更近的宝藏；若某个子集能在恰好该距离提供宝藏，全集也包含它，所以最近距离恰相等。故全集验证失败意味着任何子集都不可能成功。
>
> **手算与边界。** b=(−1,1,−1,1,−1)，只禁位置2、4，在1、3、5全放宝藏即可；b=(−1,0,2)中第三位置无论如何都距位置2的宝藏至多1，故无解。
>
> **实际复杂度与实现。** 时间和空间均O(N)。−1仅为未知，不能参与禁区；必须检查至少一个1。题目要求任意合法解，没有额外最大化目标。

## P5026 Lycanthropy

[官方题面](https://www.luogu.com.cn/problem/P5026)

每个体积v、位置x的入水事件产生两侧正波与中央负波，叠加后输出1..M水位；N,M≤10⁶，v≤10000。

> [!tip]- 提示一
> 分段折线可拆为斜率固定的等差数列更新。

> [!tip]- 提示二
> [l,r]加首项s、公差d、末项e，在二阶差分上只改四个点。
>
> 复习：[[02经典算法/02-差分]]。

> [!example]- 详细题解
> **建模与源码主线。** setting在l、l+1、r+1、r+2分别加s、d−s、−d−e、e；fall将波形拆成四段，斜率依次+1、−1、+1、−1。offset=30001平移可能为负的坐标，两次前缀后输出offset+1起M项。每个事件只做常数次端点修改。
>
> **正确性与适用条件。** 第一次前缀得到一阶差分：l跳s，内部保持d，r+1抵消末项e；第二次前缀恢复目标等差段且区间外归零。四段不重叠且完整覆盖波形，线性叠加保证独立记账正确。
>
> **手算与边界。** v=1的非零贡献只有x−2加1、x减1、x+2加1，其余为0，适合核对分段边界。湖外部分也先在平移缓冲区记完整，再只输出湖内。
>
> **实际复杂度与实现。** 时间O(N+M+offset)，空间为固定约10⁶缓冲区。原arr使用int有溢出风险：10⁶个同位置v=10000事件可形成−10¹⁰水位，端点及恢复均应使用64位；此次保留原源码并记录修正方向。
