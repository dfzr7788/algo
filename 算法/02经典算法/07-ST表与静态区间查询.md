前置：[[11-倍增思想]]。ST 表预处理长度为 2 的幂的区间信息，适合静态数组大量查询。

## 难度与重要程度

| 算法或学习主题 | 难度 | 重要程度 |
|---|---:|---:|
| ST表静态最值查询 | 5/10 | 8/10 |

评分是本项目的学习建议；尺度见 [[00-经典算法#评分尺度|评分尺度]]。

**静态容量：** $st[18][100005]$ 支持 $n\le 100000$；查询数量不占额外查询数组。 增大输入范围前需调整容量并检查内存；多组数据需重置有效状态。

## 转移与重叠查询

$st[k][i]$ 保存从 i 开始、长度 $2^{k}$ 的最大值，转移为左右两半最大值。查询长度 len，取 $k=\lfloor\log_2\mathrm{len}\rfloor$，用首尾两个长度 $2^{k}$ 的区间覆盖整个目标。

两个区间可以重叠。max 满足结合律且重复值不改变结果，即幂等性，所以重复覆盖安全。min、gcd、按位 AND/OR 同理；sum、XOR 不能用同一个重叠公式。一般结合律并不足以支持这套 $O(1)$ 查询。

## 完整程序：静态区间最大值

测试：[洛谷 P3865 — ST 表与 RMQ](https://www.luogu.com.cn/problem/P3865?lang=en)。输入 n、q、数组，再输入 q 个 1-based 闭区间 l、r，输出最大值；$n\ge 1$。本程序输入输出对应原题，原题查询量可达 2000000，需关注读取输出的实际耗时，不能仅凭复杂度就保证时限内通过。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 100005;
const int LOG = 18;
long long st[LOG][N];
int lg[N];
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    for (int i = 2; i <= n; i++)
        lg[i] = lg[i / 2] + 1;
    for (int i = 0; i < n; i++)
        cin >> st[0][i];
    for (int k = 1; k <= lg[n]; k++)
        for (int i = 0; i + (1 << k) <= n; i++)
            st[k][i] = max(st[k - 1][i], st[k - 1][i + (1 << (k - 1))]);
    while (q--)
    {
        int l, r;
        cin >> l >> r;
        l--;
        r--;
        int k = lg[r - l + 1];
        cout << max(st[k][l], st[k][r - (1 << k) + 1]) << '\n';
    }
}
```

预处理 $O(n \log n)$，每次查询 $O(1)$，存储 $O(n \log n)$。用整型 log 数组避免浮点对数取整误差。单点、长度刚过 2 的幂、全负数组都需检查。

数组修改后多个表项失效，不支持直接 $O(1)$ 更新。动态区间查询见 [[09-线段树|线段树]]；更通用的静态结合律查询有其他实现，但不在本入门模板范围内。
