## 完整程序：0-based 排名

测试：[AtCoder ABC036 C — 座圧](https://atcoder.jp/contests/abc036/tasks/abc036_c)。输入 n 和 n 个整数，按原顺序逐行输出排序去重后的排名，从 0 开始。支持负数和重复值。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
long long a[N], values[N];
int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
        values[i] = a[i];
    }
    sort(values, values + n);
    int count = unique(values, values + n) - values;
    for (int i = 0; i < n; i++)
        cout << lower_bound(values, values + count, a[i]) - values << '\n';
}
```

[1000000000,20,500,20,-999] 映射为 [3,1,2,1,0]。排序 $O(n \log n)$，每个映射 $O(\log n)$，整体 $O(n \log n)$，存储 $O(n)$。相同键必须得到相同排名。

## unique 与查询点

`unique` 将不同值依次写到前面，返回逻辑末尾；后面的值状态不应依赖，不能说它们一定仍是重复元素。本静态模板用 count 保存逻辑长度；若使用 vector，配合 erase 才改变容器大小。

只收集实际存储的键时，查询边界未必存在：找 $[l,r]$ 中的元素，应使用 lower_bound(l) 和 upper_bound(r)，形成排名半开区间 `[L,R)`。不能把不存在的查询点误认成精确排名；如果算法需要所有更新端点，先全部收集后统一压缩。

## 排名与真实长度

原坐标 [1,100,101] 的相邻长度为 99、1，不是 1、1。区间并长度、矩形面积必须保留 values，用 $\mathrm{values}[i+1]-\mathrm{values}[i]$ 表示压缩后的第 i 段真实长度。

连续半开区间 `[l,r)` 可以直接压缩端点；整数闭区间 $[l,r]$ 若要统计格点，可转换成 `[l,r+1)`，但要先检查 $r+1$ 溢出。是否需要补相邻坐标取决于模型，不能不加分析就统一插入 $x\pm 1$。

## 静态与动态

树状数组通常采用 1-based 排名，需在结果上加 1；普通数组和本模板为 0-based。顺序映射可用 map 收集并遍历赋排名，但插入新键可能改变全部旧排名，不能直接当作动态有序排名系统。

哈希表可以将任意键映射为独立编号，但遍历顺序不代表大小顺序。不能用 unordered_map 的编号替代有序离散化。map 与 vector 的实际性能取决于数据和实现，不作固定倍数速度保证。
