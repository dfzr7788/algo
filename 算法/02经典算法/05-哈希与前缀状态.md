## 频率统计

前置：[[02-枚举与暴力]]。这里的哈希指按键保存状态与频次；字符串哈希另见 [[03-字符串哈希|字符串哈希]]，不要混淆。

### 按值域选择容器

| 数据 | 方法 | 成本 |
|---|---|---|
| 小整数值域 $[0,U]$| 数组频次 | 单次 $O(1)$，空间 $O(U)$ |
| 静态稀疏键，需顺序 | [[03-离散化]] 后数组 | 预处理 $O(n \log n)$ |
| 任意可比较键 | map | 单次 $O(\log n)$，有序 |
| 可哈希键，只需查找 | unordered_map | 平均 $O(1)$；最坏 $O(n)$，取决于哈希分布 |

频率保存数量，set 只保存存在性。重复值来自不同下标时，不应使用集合代替频率。

### 完整例子：和为 K 的无序下标对

输入 n、K 和数组，统计 $i<j$ 且 $a[i]+a[j]=K$ 的数量。支持负数、重复值；假设 $K-x$ 不溢出，n 的规模使答案可用长整数。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long K;
    cin >> n >> K;
    unordered_map<long long, long long> count;
    long long ans = 0;
    for (int i = 0; i < n; ++i)
    {
        long long x;
        cin >> x;
        auto it = count.find(K - x);
        if (it != count.end())
        {
            ans += it->second;
        }
        ++count[x];
    }
    cout << ans << '\n';
}
```

扫描到 j 时，容器仅含 j 之前的元素，每个合法对恰好在较晚位置被计一次，因此不重不漏。先查询再加入可避免一个元素与自己配对。[1,1,1]、$K=2$ 的答案为 3。

在哈希分布使单次操作平均为常数的分析条件下，总时间为 $O(n)$；固定默认哈希没有自动引入随机性，不能据此保证任意输入上的期望线性，最坏可达 $O(n^2)$。空间 $O(n)$；改用 map 后为 $O(n \log n)$。`count[key]` 会插入不存在的键，纯查询优先 find。reserve 可以减少扩容，但不能保证没有冲突或改善最坏复杂度。

### 边界与练习

检查 $K=2x$、全相同、负数、无解、单元素。构造两个含相同值但数量不同的输入，说明为什么 set 丢失信息。

拓展：[洛谷 P1102 — A-B 数对](https://www.luogu.com.cn/problem/P1102) 的目标是差而非和，需重新推导补数和计数方向。[[13-贡献法与计数思想]] 的相等数对移除问题也依赖频率，但目标不同。

## 前缀状态匹配

前置：[[01-前缀和#一维前缀和|一维前缀和]]、[[05-哈希与前缀状态#频率统计|频率统计]]。

### 区间性质转为两个前缀的关系

$pre[0]=0$。区间 `[l,r)` 和为 K 等价于 $pre[l]=pre[r]-K$。扫描当前前缀时，统计此前补数出现次数。这个等式不依赖正数，所以支持负数和零。

### 完整程序：区间和恰好为 K

测试：[AtCoder ABC233 D — Count Interval](https://atcoder.jp/contests/abc233/tasks/abc233_d)。输入 n、K 和数组，输出非空连续区间数量；假设前缀、中间差及答案均不溢出。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long K;
    cin >> n >> K;
    unordered_map<long long, long long> freq;
    freq[0] = 1;
    long long pre = 0, ans = 0;
    for (int i = 0; i < n; ++i)
    {
        long long x;
        cin >> x;
        pre += x;
        auto it = freq.find(pre - K);
        if (it != freq.end())
        {
            ans += it->second;
        }
        ++freq[pre];
    }
    cout << ans << '\n';
}
```

频率只包含当前前缀之前的位置，每一对前缀对应唯一非空区间，每个区间在右端扫描时计一次。初始空前缀允许从第一个元素开始；先插入再查询会在 $K=0$ 时误计空区间。

[1,-1,1]、$K=0$，答案 2。全零长度 n 的答案 $n(n+1)/2$，不可把重复前缀去重。在上述哈希分布条件下平均时间 $O(n)$，最坏 $O(n^2)$，存储 $O(n)$；改 map 可获得 $O(n \log n)$ 的确定上界。

### 三种常见前缀状态

- 和可被 m 整除：两个前缀余数相同；要求 $m>0$，先令 `rem=pre%m`，仅在 `rem<0` 时执行 `rem+=m`。不要无条件写 `(pre%m+m)%m`：m 接近 `LLONG_MAX` 时，中间的正余数加 m 可能溢出。例如 `pre=LLONG_MAX-1,m=LLONG_MAX` 已有合法正余数，无需加 m。前缀累加本身也必须不溢出；只关心余数且输入很大时，应使用足够宽的类型进行每次模加。
- 区间异或为 K：此前状态补数为 prefixXor XOR K，而不是相减。
- 0/1 数量相等：把 0 映射为 -1，1 为 +1，寻找前缀和相同的位置。

求数量保存频次；求最长长度保存状态最早出现的位置。两种容器信息不同，不能每次覆盖最早位置。限定长度时需删除过期左前缀，见 [[21-综合练习]] 的 H 题。

## CF2275C Unrequited Love

[官方题面](https://codeforces.com/contest/2275/problem/C)

三和弦取位置i,i+2,i+4，得分a[i]+a[i+2]−a[i+4]；统计得分相同且不共用位置的无序和弦对。

> [!tip]- 提示一
> 先按得分计数，空间区间重叠不代表所用键一定重叠。

> [!tip]- 提示二
> 对起点i，真正冲突的未来起点只有i+2、i+4，暂时排除后查询。
>
> 复习：[[02经典算法/05-哈希与前缀状态]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码map先统计全部和弦分数。顺扫i时永久移除当前和弦，使表中只剩更晚起点；再临时移除i+2、i+4（存在时），加map[当前分数]到ans，最后恢复两项。相邻奇偶起点即使覆盖范围交叉，也没有共同键。
>
> **正确性与适用条件。** 两三元位置集相交的起点差只能为0、±2、±4。当前已从表中去掉，较早起点也都永久去掉，再排除+2/+4就恰剩全部不相交未来候选。每个无序对仅在较早起点计一次。
>
> **手算与边界。** N=7且全0，起点1、2、3得分均0。1与3共享3、5，只有(1,2)、(2,3)有效，总2；不能简单取C(3,2)。
>
> **实际复杂度与实现。** 哈希期望O(N)时间，最坏可能退化，空间O(N)。分数允许负，ans用long long；临时扣除的两项必须恢复，当前项则不能恢复。
