前缀和将重复的区间统计转为预处理。先学习一维，再通过容斥推广到二维。两部分均使用 1-based 闭区间输入。

## 一维前缀和

前置：[[01-复杂度分析与数据范围]]。本篇用 1-based 闭区间查询，$pre[0]=0$；原数组在查询期间不变。

### 原理与适用条件

$pre[i]$ 保存前 i 个元素之和，因此区间 $[l,r]$ 的和等于 $pre[r]-pre[l-1]$。扣掉前 $l-1$ 项后，每个区间元素恰好留下一次。构建 $O(n)$，单次查询 $O(1)$，q 次查询总 $O(n+q)$，存储 $O(n)$。

前缀和支持负数；它不依赖单调性。若数组频繁修改，直接维护所有后续前缀可能 $O(n)$，应转向 [[08-树状数组|树状数组]] 或 [[09-线段树|线段树]]。

### 完整程序：静态区间求和

测试：[洛谷 P8218 — 求区间和](https://www.luogu.com.cn/problem/P8218)。输入 n、n 个数、查询数 q，再输入 q 个 l、r，输出各区间和。程序支持负数，假设所有中间和与差都在 `long long` 范围内。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 100005;
long long pre[N];
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++)
    {
        long long x;
        cin >> x;
        pre[i] = pre[i - 1] + x;
    }
    int q;
    cin >> q;
    while (q--)
    {
        int l, r;
        cin >> l >> r;
        cout << pre[r] - pre[l - 1] << '\n';
    }
}
```

[1,2,3,4,5] 的前缀为 [0,1,3,6,10,15]，查询 $[2,4]$ 得 $10-1=9$。检查单点、整段、$l=1$、负数与零。不要把公式写为 $pre[r]-pre[l]$，那会漏掉第 l 项。

### 还能维护哪些前缀信息

- 个数：把满足条件的元素映射为 1，其余为 0，再求前缀和。
- 异或：区间异或为 $\oplus[r] \oplus \oplus[l-1]$，因为相同项异或抵消。
- 不能直接用两个前缀最值相减得到区间最值；max/min 无此逆运算，见 [[07-ST表与静态区间查询]]。
- 区间和计数：把 $pre[r]-pre[l]$ 变为匹配补数，见 [[05-哈希与前缀状态#前缀状态匹配|前缀状态匹配]]。

前缀与差分的互逆关系见 [[02-差分#一维差分|一维差分]]，题单见 [[11-题单|经典算法题单]]。

## 二维前缀和

前置：[[01-前缀和#一维前缀和|一维前缀和]]。本篇使用 1-based 矩阵，查询两个角确定的闭矩形，行列均包含端点。

### 定义、构建与容斥

$S[i][j]$ 表示左上角 $(1,1)$ 到 $(i,j)$ 的矩形和，0 行和 0 列为 0。

$$
S_{i,j}=S_{i-1,j}+S_{i,j-1}-S_{i-1,j-1}+a_{i,j}.
$$

上方和左侧区域共同覆盖左上部分两次，因此减一次，再加当前格子。

$$
Q=S_{x_2,y_2}-S_{x_1-1,y_2}-S_{x_2,y_1-1}+S_{x_1-1,y_1-1}.
$$

减去上方与左方时，交叉区被减了两次，最后加回来。可以对格子逐一判断系数：目标区域为 1，其余为 0。

### 完整程序：子矩阵查询

教学输入 n、m、q，接着 $n\times m$ 个整数，再输入 q 个 x1、y1、x2、y2。输出每个矩形和。要求角坐标合法、有序，所有中间结果在 `long long` 范围内。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 2005;
long long s[N][N];
int main()
{
    int n, m, q;
    cin >> n >> m >> q;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
        {
            long long x;
            cin >> x;
            s[i][j] = s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1] + x;
        }
    while (q--)
    {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        cout << s[x2][y2] - s[x1 - 1][y2] - s[x2][y1 - 1] + s[x1 - 1][y1 - 1] << '\n';
    }
}
```

矩阵 `1 2 3 / 4 5 6 / 7 8 9`，查询 $(2,2)\ldots (3,3)$ 得 28。构建 $O(nm)$，查询 $O(1)$，总 $O(nm+q)$，存储 $O(nm)$。$2000\times 2000$ 的长整型表仅元素约占 32 MB，还需容器开销。

### 边界与拓展

检查单格、单行、单列、整张矩阵、负数及触及第一行列的查询。矩阵很大但非零点少时，不能盲目建立稠密二维表；压缩后的两个维度乘积也可能过大。

拓展：[洛谷 P1719 — 最大加权矩形](https://www.luogu.com.cn/problem/P1719)。原题求最优矩形而非给定矩形查询；枚举四个边界配合前缀是 $O(n^{4})$，可固定上下边界、按列累加再用 [[06-最大子段和]] 降至 $O(n^{3})$。程序输入输出不能直接照搬。

## AtCoder ABC480D — Concatenation of Prefixes

[官方题面](https://atcoder.jp/contests/abc480/tasks/abc480_d)。把 $A$ 的长度为 $1,2,\ldots,N$ 的前缀依次拼成 $B$，回答 $B$ 中闭区间 $[L,R]$ 的元素和。$N,Q\le10^5$，$|A_i|\le10^8$，下标从 1 开始；$B$ 长度达到 $N(N+1)/2$，不能显式构造。

> [!tip]- 提示一：整块的和是什么
> 第 $i$ 块就是 $A_1,\ldots,A_i$，块长为 $i$，块和为原数组的第 $i$ 个前缀和。再对块和做一次前缀和，就能批量统计完整块。

> [!tip]- 提示二：先定位端点，再扣除多余部分
> 第 $k$ 块占据 $\frac{k(k-1)}2+1$ 到 $\frac{k(k+1)}2$。二分的位置由块长决定，与数组值的正负无关。先纳入左右端点所在的全部块，再扣左侧前缀与右侧后缀。

> [!example]- 详细题解
> **预处理。** 用户代码用 `sum[i]` 表示 $S_i=\sum_{j=1}^{i}A_j$，用 `summ[i]` 表示 $P_i=\sum_{j=1}^{i}S_j$，全局数组使 $S_0=P_0=0$。原数组的前缀和恰好是拼接序列的块和，所以第二层前缀和统计的是完整块。
>
> **定位函数的严格条件。** `f(x)` 返回满足 $k(k-1)/2<x$ 的最大 $k$，也就是第 $x$ 个元素所在块。块起点随 $k$ 增大，满足条件的候选形成前缀，因此可以二分。代码搜索 $[0,10^5]$；上界覆盖官方的所有块。这里是严格小于，若 $x=k(k+1)/2$，它仍属于第 $k$ 块。
>
> **还原源码公式。** 设 $p=f(L),q=f(R)$，源码中的 `x1=p-1, x2=q`。先取 $P_q-P_{p-1}$，覆盖第 $p$ 到第 $q$ 块。左端点在块内的位置为 $u=L-p(p-1)/2$，需扣 $S_{u-1}$；右端点的块内位置为 $v=R-q(q-1)/2$，需扣第 $q$ 块的尾部 $S_q-S_v$。于是答案为
>
> $$P_q-P_{p-1}-S_{u-1}-S_q+S_v.$$
>
> 把 $p=x1+1,q=x2$ 代入，正是代码的 `ans` 表达式。即使左右端点在同一块，扣去的两段也不相交，公式仍然成立。
>
> **手算。** $A=(1,10,100,1000)$，则 $S=(0,1,11,111,1111)$，$P=(0,1,12,123,1234)$。查询 $[3,6]$ 时，$p=2,q=3,u=2,v=3$，答案为 $123-1-1-111+111=121$。查询 $[8,8]$ 时同在第 4 块、第 2 位，答案为 $1111-1-1111+11=10$。
>
> **正确性与复杂度。** 每个位置唯一属于一个块，整块求和后恰好去掉查询外的两个端部，因此没有遗漏或重计。预处理 $O(N)$，每次两个二分，按源码固定搜索上界 $U=10^5$ 分析，总时间为 $O(N+Q\log U)$；有效存储为 $O(N)$，原数组各分配 100005 个长整数。
>
> **整数与边界。** 二分的是下标，不要求 $A_i$ 非负。所有块的和的绝对值不超过 $10^8N(N+1)/2\le5.00005\times10^{17}$，`long long` 足够；三角数乘法也必须先使用长整数。检查 $L=1$、$R=N(N+1)/2$、整块、跨块及同块单点；$u=1$ 时读取的是有效哨兵 $S_0$。

## ABC438D Tail of Snake

[官方题面](https://atcoder.jp/contests/abc438/tasks/abc438_d)

将三行评分按1≤x<y<N切为非空三段，最大化第一段A、第二段B、第三段C之和，N≤3×10⁵。

> [!tip]- 提示一
> 用三套前缀和表达总分，把只与x有关的部分分离。

> [!tip]- 提示二
> 固定y后，扫描维护x<y的最大SA[x]−SB[x]。
>
> 复习：[[02经典算法/01-前缀和]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码构造sa、sb、sc，把得分化为(sa[x]−sb[x])+sb[y]+sc[N]−sc[y]。y从2到N−1，先将x=y−1的差值并入md，再计算当前cur并更新maxvalue，避免枚举全部O(N²)切点对。
>
> **正确性与适用条件。** 进入某次计算时md恰为1≤x<y中差值的最大值；从前一轮只新增合法x=y−1，归纳维持不变量。其他项固定，因此当前cur就是第二切点为y时的最优解，全部y取最大穷尽所有分法。
>
> **手算与边界。** N=3时只有x=1,y=2，答案A1+B2+C3；循环恰做一次。一般不能让md从0开始，因为所有SA[x]−SB[x]都可能为负。
>
> **实际复杂度与实现。** 时间O(N)，源码保存六个向量为O(N)空间。总分可达3×10¹¹，前缀、md及答案均需long long；更新md必须在使用当前y之前，但不能加入x=y。

## CF2275E Repentance Is Already on the Way

[官方题面](https://codeforces.com/contest/2275/problem/E)

两排各N栋建筑，旧路连接同列异排及相邻列异排，同公司边长2、不同公司1，从a1出发恰访每点一次，求最长路。

> [!tip]- 提示一
> 只考虑旧路，按列奇偶交换两排行可看成标准梯形图。

> [!tip]- 提示二
> 从角点出发的哈密顿路径可按“已完成逐列段”的终点枚举，剩余段绕到最右端再折返。
>
> 复习：[[02经典算法/01-前缀和]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码weight相等返回2，否则1。fixsum初始为全部相邻列两条交叉边加最右列竖边，表示前缀长度0的路线。把前缀长度从i−1推到i时，去掉weight(a[i−1],b[i])，加入weight(a[i−1],b[i−1])，其余边保持。逐个i更新最大值，不必重建路线。
>
> **正确性与适用条件。** 在梯形图里，若先沿每列竖边完成一个前缀，剩余两轨必须先沿一轨到最右端，跨末列后沿另一轨返回，否则会封死未访问点。反过来，考察第一个没立即跨竖边的列，后续即被迫如此绕行，所以这些前缀长度穷尽角点出发的可行结构。每个候选含2N−1边，增量替换不重计。
>
> **手算与边界。** N=2，两种结构都用第2列竖边及b1−a2边，区别仅a1−b2与a1−b1。源码一次替换就可比较两条路线；N=1直接取a1−b1的长度。
>
> **实际复杂度与实现。** 时间O(N)，数组空间O(N)，累计长度用long long。新建主干路不属于可用旧路；这里是最长恰访一次路线，不能用普通最短路或允许重复点的最长游走解释。
