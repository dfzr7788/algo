## 一、两层差分：操作也被区间调用

测试：[CF 295A — Greg and Array](https://codeforces.com/problemset/problem/295/A)。数组有 n 项，m 个区间加法操作；k 次调用各指定操作下标区间 $[x,y]$，执行其中每个操作一次，最后输出数组。

朴素遍历每次调用的所有操作，再逐个更新数组位置，最坏 $O(kmn)$。重复工作有两层：同一操作被调用多次，同一数组区间被多次加值。

第一层对操作下标差分，求每个操作的执行次数 $\mathrm{times}[i]$。第二层把该操作的增量乘 $\mathrm{times}[i]$，在数组下标上做差分。两个“区间”位于不同的坐标域，数组差分长度 $n+2$，次数差分长度 $m+2$。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 100005;
long long a[N], times[N], delta[N], value[N];
int left_end[N], right_end[N];
int main()
{
    int n, m, k;
    cin >> n >> m >> k;
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
    }
    for (int i = 1; i <= m; i++)
    {
        cin >> left_end[i] >> right_end[i] >> value[i];
    }
    while (k--)
    {
        int x, y;
        cin >> x >> y;
        times[x]++;
        times[y + 1]--;
    }
    for (int i = 1; i <= m; i++)
    {
        times[i] += times[i - 1];
        long long change = times[i] * value[i];
        delta[left_end[i]] += change;
        delta[right_end[i] + 1] -= change;
    }
    for (int i = 1; i <= n; i++)
    {
        delta[i] += delta[i - 1];
        if (i > 1)
        {
            cout << ' ';
        }
        cout << a[i] + delta[i];
    }
    cout << '\n';
}
```

证明：第一次前缀恢复后，$\mathrm{times}[i]$ 等于包含操作 i 的调用区间数；加法可叠加，所以重复操作等价于一次加 $\mathrm{times}[i]\cdot d[i]$。第二次恢复得到每个数组位置的所有增量，再加原值。原题范围下结果量级可达 $10^{15}$，使用长整数。

例：$a=[1,2,3]$，操作为 (1,2,+1)、(1,3,+2)、(2,3,+4)，调用 $[1,2]$、$[1,3]$、$[2,3]$，执行次数 [2,3,2]，输出 [9,18,17]。

时间 $O(n+m+k)$，空间 $O(n+m)$。验证 $m\ne n$、重复调用、单点操作、整段操作；不能把操作下标误当数组下标。

## 二、矩阵降维：最大加权矩形

测试：[洛谷 P1719 — 最大加权矩形](https://www.luogu.com.cn/problem/P1719)。输入 n 和 $n\times n$ 的整数矩阵，输出非空矩形最大元素和。

四个边界有 $O(n^{4})$ 种组合，逐格求和最坏 $O(n^{6})$；二维前缀将单次求和降到 $O(1)$，整体仍 $O(n^{4})$。进一步固定上、下边界，把这几行每列之和形成一维数组，矩形的左右边界就是这数组中的连续子段。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 125;
long long a[N][N], col[N];
int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
        {
            cin >> a[i][j];
        }
    long long best = LLONG_MIN;
    for (int top = 0; top < n; top++)
    {
        fill(col, col + n, 0);
        for (int bottom = top; bottom < n; bottom++)
        {
            for (int j = 0; j < n; j++)
            {
                col[j] += a[bottom][j];
            }
            long long ending = col[0];
            best = max(best, ending);
            for (int j = 1; j < n; j++)
            {
                ending = max(col[j], ending + col[j]);
                best = max(best, ending);
            }
        }
    }
    cout << best << '\n';
}
```

每个矩形有唯一上下边界，且对固定上下边界有唯一列区间；两者相互对应且和相同，因此取所有一维最大子段的最大值就是全局最优。时间 $O(n^{3})$，矩阵空间 $O(n^{2})$，额外列数组 $O(n)$。$n\ge 1$，所有中间和须不溢出。

例：矩阵 `-1 2 / 3 -4` 最大值为 3。全负时选择最大的单格，不能返回 0；上下边界改变时 col 的清零和增量更新顺序不能混淆。

## 三、CF2276C Subarrays：延迟加入前缀余数

[官方题面](https://codeforces.com/contest/2276/problem/C)。给正整数数组，统计元素和能被 k 整除、长度严格大于 k 的子数组。$1\le k<n\le2\times10^5$，$a_i\le10^9$，所有测试的 n 之和不超过 $2\times10^5$。

前置：[[01-前缀和]]、[[05-哈希与前缀状态]]。层次：应用。训练重点是把长度限制转成前缀状态的入表时机；本题并不需要额外的数论算法。

> [!tip]- 提示一：先消去区间求和
> 定义 $P_0=0$、$P_r=(a_1+\cdots+a_r)\bmod k$。区间 $[l,r]$ 满足整除条件，等价于 $P_{l-1}=P_r$。但长度限制还要求 $l-1\le r-k-1$，不能查询全部历史前缀。

> [!tip]- 提示二：查询与入表的先后顺序
> 当前源码先把 $P_0$ 放入 map，再从第 k+1 个元素开始扫描。每轮查询前，map 只含 $P_0$ 到 $P_{r-k-1}$；查询后才把 $P_{r-k}$ 加入，供下一轮使用。若把这次加入提前，会错误地计入长度恰好为 k 的区间。

> [!example]- 详细题解：按 sum1、sum2 与 map 的扫描顺序
> **1. 从二次枚举转到前缀匹配。**
>
> 暴力枚举两个端点有 $O(n^2)$ 个区间，即使预处理前缀和，也没有减少候选数量。两个前缀余数相同，就能一次汇总一批合法左端点：固定右端点 r，只需知道足够早的前缀中，有多少个等于 $P_r$。
>
> 代码读入时先令每个 a 元素对 k 取模，之后维护的也是前缀余数。原数组为正数，不涉及负余数归一化；预先取模不改变任何区间和是否能被 k 整除。
>
> **2. 两个滚动前缀各自表示什么？**
>
> 源码数组是 0 下标。进入主循环前，sum1=0，sum2 已累加 a[0] 到 a[k-1]，所以分别代表 $P_0$、$P_k$；map[0]=1 代表空前缀的一次出现。
>
> 主循环 i 从 k 开始。先更新 sum1 与 sum2 后，sum1 等于 $P_{i-k+1}$，sum2 等于 $P_{i+1}$。此时右端点按 1 下标计为 r=i+1，而查询前 map 恰好包含 $P_0,\ldots,P_{i-k}$，也就是所有下标不超过 r-k-1 的合法前缀。ans 加 map[sum2]，正好统计以 r 结尾、长度严格大于 k 的区间。
>
> 随后 map[sum1]++，把下一个前缀加入。它本轮对应长度恰为 k，不能参与本轮统计；到下一轮右端点前进一步后，长度才变成 k+1。这一顺序保持了不变量。每个区间只在自己的右端点被计数，因此没有遗漏或重复。
>
> **3. 手算 a=(2,1,3,1,4)、k=2。**
>
> 前缀余数是 $(P_0,\ldots,P_5)=(0,0,1,0,1,1)$。初始化 sum2=$P_2$=1，map 中只有 $P_0$=0。
>
> r=3 时，sum1=$P_1$=0，sum2=$P_3$=0，查询得到 1，计入区间 [1,3]；之后再加入 $P_1$。r=4 时查询 $P_4$=1，尚无可用的同余前缀，贡献 0，再加入 $P_2$=1。r=5 时查询 $P_5$=1，匹配 $P_2$，计入 [3,5]，最终答案为 2。
>
> **4. 实际复杂度与边界。**
>
> unordered_map 的操作按平均常数开销分析，整体期望时间 $O(n)$；哈希冲突极端时最坏可退化到 $O(n^2)$。读入数组占 $O(n)$，键都在 0 到 k-1，map 至多 $O(k)$ 个键，整体空间 $O(n+k)$。查询使用 operator[]，缺失的键也会插入一个零频次条目；它不改变计数不变量。选读对照：由于余数值域已知，可用长度为 k 的频次数组得到确定性的线性时间。
>
> k<n 保证初始累加 k 项不越界。k=1 时所有元素余数均为 0，答案应为 $n(n-1)/2$，只排除长度 1；k=n-1 时只可能统计整段。sum1、sum2 每次相加小于 2k，int 足够；答案可超过 32 位，源码使用 ll。每组测试的数组、map 和累计变量均在 solve 内重新建立。

| 静态区间和 | $O(nq)$|$O(n+q)$ | 可逆前缀统计 |
