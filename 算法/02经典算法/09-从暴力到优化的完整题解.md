## 一、两层差分：操作也被区间调用

测试：[CF 295A — Greg and Array](https://codeforces.com/problemset/problem/295/A)。数组有 n 项，m 个区间加法操作；k 次调用各指定操作下标区间 [x,y]，执行其中每个操作一次，最后输出数组。

朴素遍历每次调用的所有操作，再逐个更新数组位置，最坏 O(kmn)。重复工作有两层：同一操作被调用多次，同一数组区间被多次加值。

第一层对操作下标差分，求每个操作的执行次数 times[i]。第二层把该操作的增量乘 times[i]，在数组下标上做差分。两个“区间”位于不同的坐标域，数组差分长度 n+2，次数差分长度 m+2。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 100005;
long long a[N], times[N], delta[N], value[N];
int left_end[N], right_end[N];
int main()
{
    int n, m, k;
    cin >> n >> m >> k;
    for (int i = 1; i <= n; i++)
        cin >> a[i];
    for (int i = 1; i <= m; i++)
        cin >> left_end[i] >> right_end[i] >> value[i];
    while (k--)
    {
        int x, y;
        cin >> x >> y;
        times[x]++;
        times[y + 1]--;
    }
    for (int i = 1; i <= m; i++)
    {
        times[i] += times[i - 1];
        long long change = times[i] * value[i];
        delta[left_end[i]] += change;
        delta[right_end[i] + 1] -= change;
    }
    for (int i = 1; i <= n; i++)
    {
        delta[i] += delta[i - 1];
        if (i > 1)
            cout << ' ';
        cout << a[i] + delta[i];
    }
    cout << '\n';
}
```

证明：第一次前缀恢复后，times[i] 等于包含操作 i 的调用区间数；加法可叠加，所以重复操作等价于一次加 times[i]·d[i]。第二次恢复得到每个数组位置的所有增量，再加原值。原题范围下结果量级可达 10^15，使用长整数。

例：a=[1,2,3]，操作为 (1,2,+1)、(1,3,+2)、(2,3,+4)，调用 [1,2]、[1,3]、[2,3]，执行次数 [2,3,2]，输出 [9,18,17]。

时间 O(n+m+k)，空间 O(n+m)。验证 m≠n、重复调用、单点操作、整段操作；不能把操作下标误当数组下标。

## 二、矩阵降维：最大加权矩形

测试：[洛谷 P1719 — 最大加权矩形](https://www.luogu.com.cn/problem/P1719)。输入 n 和 n×n 的整数矩阵，输出非空矩形最大元素和。

四个边界有 O(n⁴) 种组合，逐格求和最坏 O(n⁶)；二维前缀将单次求和降到 O(1)，整体仍 O(n⁴)。进一步固定上、下边界，把这几行每列之和形成一维数组，矩形的左右边界就是这数组中的连续子段。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 125;
long long a[N][N], col[N];
int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            cin >> a[i][j];
    long long best = LLONG_MIN;
    for (int top = 0; top < n; top++)
    {
        fill(col, col + n, 0);
        for (int bottom = top; bottom < n; bottom++)
        {
            for (int j = 0; j < n; j++)
                col[j] += a[bottom][j];
            long long ending = col[0];
            best = max(best, ending);
            for (int j = 1; j < n; j++)
            {
                ending = max(col[j], ending + col[j]);
                best = max(best, ending);
            }
        }
    }
    cout << best << '\n';
}
```

每个矩形有唯一上下边界，且对固定上下边界有唯一列区间；两者相互对应且和相同，因此取所有一维最大子段的最大值就是全局最优。时间 O(n³)，矩阵空间 O(n²)，额外列数组 O(n)。n≥1，所有中间和须不溢出。

例：矩阵 `-1 2 / 3 -4` 最大值为 3。全负时选择最大的单格，不能返回 0；上下边界改变时 col 的清零和增量更新顺序不能混淆。

## 其他模板的暴力到优化路线

| 模型 | 基准 | 优化 | 关键性质 |
|---|---|---|---|
| 静态区间和 | O(nq) | O(n+q) | 可逆前缀统计 |
| 批量矩形更新 | 最坏 O(qnm) | O(nm+q) | 四角变化可叠加 |
| 巨大坐标并集 | 按全部坐标扫描 | O(n log n) | 排序后不必访问空白跨度 |
| 含负数的区间和计数 | O(n²) | 期望 O(n) | 两个前缀状态匹配 |
| 静态最值查询 | O(nq) | O(n log n+q) | 结合律与幂等性 |
