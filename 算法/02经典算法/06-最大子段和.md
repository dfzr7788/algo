## 从 $O(n^{2})$ 到线性递推

枚举左端点再累加右端点需要 $O(n^{2})$。令 end 表示以当前位置结尾的最大非空子段和，新的最优段只有两种：单独当前值 x，或接在前一个最优结尾段之后。因此 $end=\max (x,end+x)$，全局 best 取所有 end 最大值。

## 完整程序

测试：[洛谷 P1115 — 最大子段和](https://www.luogu.com.cn/problem/P1115)。输入 $n\ge 1$ 和 n 个整数，输出最大非空连续段和。所有计算保证在长整数范围内。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long x;
    cin >> x;
    long long ending = x, best = x;
    for (int i = 1; i < n; ++i)
    {
        cin >> x;
        ending = max(x, ending + x);
        best = max(best, ending);
    }
    cout << best << '\n';
}
```

以结尾位置归纳，两种情况穷尽所有非空段，保留最大的前段即可，因此递推正确。[-3,-1,-2] 答案 -1，不能初始化 $\mathrm{best}=0$，否则隐含允许空段。时间 $O(n)$，额外空间 $O(1)$。

## 前缀最小值形式

令 $pre[0]=0$、$pre[r]=a[1]+\cdots+a[r]$。固定右端 r，任意非空段都唯一写成 $[j+1,r]$，其中 $0\le j<r$，段和为 $pre[r]-pre[j]$。因此

$$
ending(r)=pre[r]-\min_{0\le j<r}pre[j].
$$

维护 `min_prefix=0`，按 r 从 1 到 n 扫描：先用当前前缀减旧的 min_prefix 更新答案，再把当前前缀加入最小值候选。若先更新 min_prefix，便会允许 j=r，误把空区间的和 0 算入；单元素 −3 就会错误返回 0。数学上该式与前面的结尾递推求的是同一个量，两者均为线性时间。

手算数组 `[2,-5,4,3]`：

| r | 当前前缀 | 查询前的最小前缀 | 以 r 结尾的最大和 | 全局最大和 |
|---:|---:|---:|---:|---:|
| 1 | 2 | 0 | 2 | 2 |
| 2 | −3 | 0 | −3 | 2 |
| 3 | 1 | −3 | 4 | 4 |
| 4 | 4 | −3 | 7 | 7 |

若需返回端点，同时保存最小前缀的位置 j；每次产生更优答案时记录 `[j+1,r]`。只在前缀严格更小时更新 j，会保留并列最小前缀的最早位置；改为小于等于则保留最新位置，适合倾向较短区间。全局答案并列时仍需另外按题意比较端点或长度，不能只靠更新 j 决定全部规则。此变体额外要求所有前缀及相减均在所用整数类型内。

限制长度后，合法左前缀范围变化，不能继续维护全历史最小值；可能需要单调队列。矩阵最大子矩形可固定上下边界后压成一维列和，见 [[09-从暴力到优化的完整题解]]。这也是向动态规划过渡的简单模型。
