## 从 O(n²) 到线性递推

枚举左端点再累加右端点需要 O(n²)。令 end 表示以当前位置结尾的最大非空子段和，新的最优段只有两种：单独当前值 x，或接在前一个最优结尾段之后。因此 end=max(x,end+x)，全局 best 取所有 end 最大值。

## 完整程序

测试：[洛谷 P1115 — 最大子段和](https://www.luogu.com.cn/problem/P1115)。输入 n≥1 和 n 个整数，输出最大非空连续段和。所有计算保证在长整数范围内。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long x;
    cin >> x;
    long long ending = x, best = x;
    for (int i = 1; i < n; ++i)
    {
        cin >> x;
        ending = max(x, ending + x);
        best = max(best, ending);
    }
    cout << best << '\n';
}
```

以结尾位置归纳，两种情况穷尽所有非空段，保留最大的前段即可，因此递推正确。[-3,-1,-2] 答案 -1，不能初始化 best=0，否则隐含允许空段。时间 O(n)，额外空间 O(1)。

## 前缀最小值形式

对当前 pre[r]，最大段和为 pre[r]-此前最小前缀。先查询再更新最小前缀，保证非空。若需返回端点，还要保存最小前缀位置；多个答案并列时明确选择最早、最短或任意一个。

限制长度后，合法左前缀范围变化，不能继续维护全历史最小值；可能需要单调队列。矩阵最大子矩形可固定上下边界后压成一维列和，见 [[09-从暴力到优化的完整题解]]。这也是向动态规划过渡的简单模型。
