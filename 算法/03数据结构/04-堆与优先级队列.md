## 堆有什么用

当集合不断加入和删除元素，而每次只需要取当前最小或最大值时，堆比反复排序更适合。例如不断合并重量最小的两堆、挑选当前最早截止任务，或者维护图搜索中暂定距离最小的候选。

堆顶保证是极值，但整个数组并没有排好序。它用父子大小关系保证极值一路处于顶部；插入和删顶时只修复一条路径。要寻找任意键、前驱后继或完整排序结果，需要另外的结构。

正文完整模板采用 1-based 静态小根堆数组，$N=1000005$，最多保存 1000000 个元素。标准 priority_queue 声明作为补充，便于实际做题时选择。

## 数组结构与操作

例如小根堆数组 [1,4,3] 加入 2：把 2 放到第 4 个位置，父亲是位置 2 的 4，交换后得到 [1,2,3,4]；再与根 1 比较，无需继续上浮。删除最小值 1 时，用末尾 4 覆盖根、缩短长度，暂时成为 [4,2,3]；选较小孩子 2 交换，得到 [2,4,3]。它满足堆性质，但不是完整升序数组。

本模板使用 1-based 数组，父亲为 i/2，孩子为 2i、$2i+1$；不要套入 0-based 公式。插入放末尾并上浮；删除堆顶用末尾覆盖并下沉，每次选择更优的孩子。取堆顶 $O(1)$，插入和删除堆顶 $O(\log n)$，空间 $O(n)$。

STL 默认 priority_queue 是大根堆；小根堆用 `greater<T>`。top 只读，pop 不返回值。空堆不能查询或弹出，普通堆不直接支持任意元素删除或快速按键搜索。

## 完整程序：小根堆

测试：[洛谷 P3378 — 堆](https://www.luogu.com.cn/problem/P3378)。1 x 加入，2 输出最小值，3 删除一个最小值；查询、删除的输入应保证非空。本例防御性地忽略空操作，不把这种行为当作原题输出要求。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1000005;
long long heap_value[N];
int heap_size;

void push_min(long long x)
{
    int u = ++heap_size;
    heap_value[u] = x;
    while (u > 1)
    {
        int parent = u / 2;
        if (heap_value[parent] <= heap_value[u])
        {
            break;
        }
        swap(heap_value[parent], heap_value[u]);
        u = parent;
    }
}

void pop_min()
{
    if (heap_size == 0)
    {
        return;
    }
    heap_value[1] = heap_value[heap_size--];
    int u = 1;
    while (u * 2 <= heap_size)
    {
        int child = u * 2;
        if (child + 1 <= heap_size && heap_value[child + 1] < heap_value[child])
        {
            child++;
        }
        if (heap_value[u] <= heap_value[child])
        {
            break;
        }
        swap(heap_value[u], heap_value[child]);
        u = child;
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    while (q--)
    {
        int op;
        cin >> op;
        if (op == 1)
        {
            long long x;
            cin >> x;
            push_min(x);
        }
        else if (op == 2 && heap_size > 0)
            cout << heap_value[1] << '\n';
        else if (op == 3)
            pop_min();
    }
}
```

## 标准库写法与自定义比较

```cpp
// 使用 <queue>、<vector>、<functional>；只展示标准库声明。
std::priority_queue<long long> max_heap;
std::priority_queue<long long, std::vector<long long>, std::greater<long long>> min_heap;
```

自定义比较器 `cmp(a,b)` 为真意味着 a 的优先级低于 b；要让较小 deadline 优先可比较 `a.deadline>b.deadline`。相等时按题意补充次关键字，使用严格比较；不要通过可能溢出的相减判断顺序。

应用：最优合并、动态取极值、Dijkstra 的候选距离。堆只是维护工具，选择规则正确性仍要另证，见 [[09-贪心]]。失效候选可用额外版本/状态标记并在取出时跳过，不能仅修改堆外变量就认为已有堆自动重新排序。

## 扩展选读：建堆与堆排序

单条上浮/下沉路径高度 $O(\log n)$。从最后一个非叶节点倒序下沉建堆，许多节点只移动少数层：高度至少 k 的节点数量约 $n/2^{k}$，总调整量上界为 $O(n\cdot \sum k/2^{k})=O(n)$，不是 n 次插入的 $O(n \log n)$。

原地堆排序可使用 $O(1)$ 额外空间；用 priority_queue 保存全部元素再逐个弹出则容器本身占 $O(n)$，不要混淆两个实现的空间界。

## ABC458D Chalkboard Median

[官方题面](https://atcoder.jp/contests/abc458/tasks/abc458_d)

初始一个数X，每次新增两个整数，输出所有数的中位数；Q≤2×10⁵。

> [!tip]- 提示一
> 把中位数单独保存，较小半与较大半分别放两个堆。

> [!tip]- 提示二
> 每次两数按X分入两侧，侧数相差2时移动原中位数并换出一个堆顶。
>
> 复习：[[03数据结构/04-堆与优先级队列]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码pq是较小半的大根堆，qq是较大半的小根堆，x保存当前中位数。新数>x放qq，否则放pq；若pq更多，先把旧x入qq，再取pq顶为新x；反向对称。每次处理完两个数后两侧大小重新相等。
>
> **正确性与适用条件。** 插入前全部pq元素≤x≤全部qq元素。一次新增两数造成的大小差只能是0或2，一次交换中位数即可恢复等大，并保持两侧有序关系。因此x正是2i+1个数中第i+1小，不必整体排序。
>
> **手算与边界。** 初始x=5，新增1、2都进pq，旧5进qq，取pq顶2为新中位数，两侧为1和5；再增2、9时两侧各增1，中位数仍2。相等元素可统一放左侧。
>
> **实际复杂度与实现。** 总时间O(Q log Q)，空间O(Q)。不要在每次插入一个数后就套用本实现的等大约定，它是按两个新数为一轮设计的。
