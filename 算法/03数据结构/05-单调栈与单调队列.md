## 单调栈：右侧第一个更大元素

### 单调栈有什么用

它适合回答每个位置的“右边第一个更大/更小的位置”这类问题。逐个向右搜索可能 $O(n^{2})$；单调栈把还没找到答案的下标集中保存，新元素到来时一次解决一批旧位置。

这里的“单调”不是原数组有序，而是栈里的候选值按规则保持顺序。栈中保留的是等待解答的位置；弹出意味着该位置已经找到了答案，而不是原数据被删除。

对 [3,1,2,4]：读到 2 时，只解决值 1 的位置（答案为下标 3）；读到 4 时，解决值 2 和值 3 的位置（答案均为下标 4）。最后答案为 [4,3,4,0]。

静态模板 $N=3000005$，对应原题 $n\le 3000000$。stk 保存原数组下标，answer 保存答案下标，两者都不能误存成元素值。

测试：[洛谷 P5788 — 单调栈](https://www.luogu.com.cn/problem/P5788)。输入 n 和数组，输出每个位置右侧第一个严格更大元素的 1-based 下标，无则 0。

从左到右维护尚未找到答案的下标，值非递增。新值 x 若严格大于栈顶值，栈顶答案就是当前下标：之前扫描过的右侧元素均没能使它出栈，因此当前是第一个。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 3000005;
int a[N];
int stk[N];
int answer[N];
int top_index;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
    }
    for (int i = 1; i <= n; i++)
    {
        while (top_index > 0 && a[stk[top_index]] < a[i])
        {
            answer[stk[top_index]] = i;
            top_index--;
        }
        stk[++top_index] = i;
    }
    for (int i = 1; i <= n; i++)
    {
        if (i > 1)
        {
            cout << ' ';
        }
        cout << answer[i];
    }
    cout << '\n';
}
```

[2,2,3] 输出 [3,3,0]。严格更大用 `<` 出栈；若目标改为更大或相等，要改条件并重新检查重复值。柱状图、区间最值贡献涉及左右边界及相等元素的归属，不宜未经推导直接套用。

## 单调队列：固定窗口最值

### 单调队列有什么用

窗口每次向右移动一个位置，需要反复求其中最大或最小值。例如最近 k 次测量的最高值。每个窗口逐项扫描需要 $O(nk)$，单调队列只保留未来还有机会成为答案的候选。

队首可以因“离开窗口”而失效，队尾可以因“被更晚、更优的新元素支配”而失效，两者原因不同。下标递增保证能从队首检查过期；候选值单调保证最值位于队首。

例如 [9,1,2]、$k=2$，最大值先是 9。处理第三个元素时，位置 1 已不在窗口 $[2,3]$，必须先移除它，否则会继续错误输出 9；正确结果是 2。

本模板用静态 que 保存有效半开范围 `[head,tail)`，头部出队只增加 head，尾部删除只减少 tail；每次扫描最多 n 次入队，容量 $N=1000005$ 足够。求最小、最大各调用一次普通函数，重新设置头尾。

测试：[洛谷 P1886 — 滑动窗口](https://www.luogu.com.cn/problem/P1886)。输入 n、k（$1\le k\le n$）和数组，输出每个窗口最小值、最大值，各一行。

用数组模拟下标递增、候选值单调的双端队列。先移除窗口左侧过期下标，再删除队尾被新值支配的候选；当前队首就是最值。新元素更优且更晚过期，旧候选在未来窗口里都不再有优势。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1000005;
long long a[N];
int que[N];
int n, k;

void print_windows(bool minimum)
{
    int head = 0;
    int tail = 0;
    bool first = true;
    for (int i = 1; i <= n; i++)
    {
        while (head < tail && que[head] <= i - k)
        {
            head++;
        }
        while (head < tail)
        {
            int last = que[tail - 1];
            bool worse;
            if (minimum)
            {
                worse = a[last] >= a[i];
            }
            else
            {
                worse = a[last] <= a[i];
            }
            if (!worse)
            {
                break;
            }
            tail--;
        }
        que[tail++] = i;
        if (i >= k)
        {
            if (!first)
            {
                cout << ' ';
            }
            cout << a[que[head]];
            first = false;
        }
    }
    cout << '\n';
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> k;
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
    }
    print_windows(true);
    print_windows(false);
}
```

相等时本程序保留更新的下标，以更晚过期；如果要求最早最值下标，比较条件应调整。$k=1$ 输出原数组，$k=n$ 每行仅一个值。

## 选择与边界

“最近更大/更小位置”通常考虑栈，“移动范围内最值”考虑队列。并非所有窗口统计都能用单调队列，众数或中位数需要其他结构。测试升序、降序、全相同、重复极值过期与负数。

## 扩展选读：为什么总时间 $O(n)$

两种程序中每个下标入容器一次、离开最多一次，所有 while 的弹出次数合计 $\le n$，故总时间 $O(n)$。一次处理可弹出很多元素，并非单次最坏 $O(1)$，这里是整个扫描的摊还界。单调栈需要 $O(n)$ 候选空间，窗口里有效候选最多 k 个；本程序用容量按 n 预留的静态队列和原数组，因此实际分配空间按 N 计算，量级 $O(n)$，不保存整行输出数组。

## P1950 长方形

[官方题面](https://www.luogu.com.cn/problem/P1950)

网格中.可用、*障碍，统计完全可用的非空轴对齐矩形数。

> [!tip]- 提示一
> 固定下边界，用各列连续空格高度h，把矩形数转成所有列区间最小值之和。

> [!tip]- 提示二
> dp[j]是右端在j的区间最小值和，利用左侧最近严格更低高度p递推。
>
> 复习：[[03数据结构/05-单调栈与单调队列]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码逐行更新h，障碍归零。递增栈弹出高度≥h[j]者；若无更低前驱，dp[j]=(j+1)h[j]，否则dp[j]=dp[p]+(j−p)h[j]，将全部dp[j]加入total。暴力枚举左端需要平方时间，栈把贡献分为两类批量处理。
>
> **正确性与适用条件。** 左端在p+1..j时，区间最小值都是h[j]，贡献(j−p)h[j]；左端≤p时，中间高度均≥h[j]>h[p]，最小值与截到p时相同，贡献dp[p]。两类不交且穷尽，每个矩形由下边界、右边界及高度唯一确定。
>
> **手算与边界。** 一行柱高(2,1,2)，dp=(2,2,4)，该行贡献8；末列的三个区间最小值为2、1、1。相等高度弹栈可保持前驱严格更低。
>
> **实际复杂度与实现。** 每行各下标入出栈一次，总O(NM)。源码存完整字符矩阵，空间O(NM+M)，不能只算O(M)栈。total和高度乘宽需long long。

## CF2227E It All Went Sideways

[官方题面](https://codeforces.com/contest/2227/problem/E)

若干竖直方块列随后受向右重力，每块按高度向右滑；此前可从任一列删顶块至多一次，最大化最终移动过的方块数。

> [!tip]- 提示一
> 某列底部连续不动的高度由它及右侧全部列的最小高度决定。

> [!tip]- 提示二
> 删去后缀最低列的顶块才能降低某些后缀最小值；左边最近严格更低列界定影响范围。
>
> 复习：[[03数据结构/05-单调栈与单调队列]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码r[i]=min(a[i..N−1])，不删时移动数base=Σ(a[i]−r[i])。单调栈求左侧最近严格更低位置p[i]，遇≥a[i]弹栈。只有a[i]=r[i]才可能获益，此时删顶块新增移动数i−p[i]−1，取maxgain加base。
>
> **正确性与适用条件。** 高度h的方块不动当且仅当右侧每列都有同高度方块，故不动高度恰为后缀最小。若删i的顶块但a[i]>r[i]，后缀最小不变且还少一个原本会移动的块，无益。若a[i]=r[i]，从p[i]+1到i的后缀最小都降1，少不动块i−p[i]个，但总块数也少1，净增i−p[i]−1。
>
> **手算与边界。** a=(1,2,3,2,1)，r全1，base=4；删末列顶块，p=−1，净增4，答案8。严格更低前驱保证与当前等高的列也在受影响范围内。
>
> **实际复杂度与实现。** 时间O(N)，空间O(N)，base与答案用long long。允许不删，maxgain从0开始；不能把“移动块数”误作移动距离之和。
