## 有序集合与映射有什么用

如果需要维护一个不断变化的有序集合，并询问“第一个不小于 x 的数”“x 的前驱”“某个键是否存在”，堆不够，因为堆只保证顶端极值。有序容器可以沿键顺序查找边界。

set 适合不同键集合，multiset 适合保留重复元素，map 则给每个不同键附带值，比如出现次数或额外属性。本篇保留标准库容器；它们提供动态有序维护，简单静态数组加插入搬移不能保持相同的对数操作界，因此不自行封装类。

## 关键接口

例如 multiset 中有 [10,20,20,30]，lower_bound(20) 找到第一个 20，upper_bound(20) 找到 30。要问 $\le 20$ 的第二大，可以从 upper_bound(20) 向前走两次，得到另一个 20。重复元素各占一个位置，不能用 set 去重后再回答这类问题。

成员 lower_bound(x) 找第一个 $\ge x$，upper_bound(x) 找第一个 $>x$。返回 end 时不能解引用，begin 时不能直接向前减。set/map 应使用成员查找，通用 lower_bound 对非随机访问迭代器可能花 $O(n)$ 次移动。

multiset.erase(x) 删除所有等于 x 的项；仅删一个时先 find，再 erase(iterator)。$map[x]$ 会在键不存在时插入默认值，纯查询用 find，避免意外修改状态。

## 完整程序：带重复值的有序查询

测试：[AtCoder ABC241 D — Sequence Query](https://atcoder.jp/contests/abc241/tasks/abc241_d)。操作 1 x 加入；2 x k 输出 $\le x$ 的第 k 大，3 x k 输出 $\ge x$ 的第 k 小，不足输出 -1。原题 $k\le 5$，故可以查到边界后移动少量迭代器。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    multiset<long long> values;
    while (q--)
    {
        int type;
        long long x;
        cin >> type >> x;
        if (type == 1)
        {
            values.insert(x);
            continue;
        }
        int k;
        cin >> k;
        long long answer = -1;
        if (type == 2)
        {
            auto it = values.upper_bound(x);
            bool valid = true;
            while (k--)
            {
                if (it == values.begin())
                {
                    valid = false;
                    break;
                }
                it--;
            }
            if (valid)
            {
                answer = *it;
            }
        }
        else
        {
            auto it = values.lower_bound(x);
            for (int j = 1; j < k && it != values.end(); j++)
            {
                it++;
            }
            if (it != values.end())
            {
                answer = *it;
            }
        }
        cout << answer << '\n';
    }
}
```

边界查找 $O(\log n)$，移动 $O(k)$，每次 $O(\log n+k)$，空间 $O(n)$。大量第 k 小且 k 很大时，不可用 advance 或 distance 假装 $O(\log n)$，可考虑离散化+权值树状数组或顺序统计树。

## 扩展选读：平衡与迭代器

标准有序容器提供对数级查找与插入保证，普通 BST 则可能退化。遍历所有元素仍需 $O(n)$，删除一个迭代器后该迭代器失效；不要认为删除后还能用它继续 ++。具体容器修改的迭代器失效规则需按容器区别，vector 扩容与树容器插入不能混为一谈。

## P1904 天际线

[官方题面](https://www.luogu.com.cn/problem/P1904)

输入多栋建筑(L,H,R)直到文件结束，输出城市轮廓高度发生变化的横坐标与高度。

> [!tip]- 提示一
> 当前天际线就是仍覆盖扫描位置的建筑最大高度。

> [!tip]- 提示二
> 把入场记为−H、退场记为+H；同坐标排序顺序可避免输出瞬时假拐点。
>
> 复习：[[03数据结构/06-有序集合与映射]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码将(L,−H)、(R,+H)排序，multiset heigh初放0。负事件插入高度，正事件只删除find定位的一份；每步cur取最大值，与pre不同才输出。相同x先处理更高的入场，再较低入场，再从低到高退场，确保不因处理顺序临时露出更低高度。
>
> **正确性与适用条件。** 扫描事件间活动建筑不变，高度必恒为其最大值，只可能在端点变化。入场高者先到，退场低者先走，使同x处理过程不会在最终高度之外产生额外折线；多重集保留相同高度不同建筑，删除一份不会误删其他覆盖。
>
> **手算与边界。** 建筑(1,3,3)、(3,3,5)在x=3首尾相接，处理插入后删除仍最高3，无需输出(3,0)与(3,3)；整条轮廓为(1,3),(5,0)。
>
> **实际复杂度与实现。** N建筑总O(N log N)时间、O(N)空间。输入无首个N，必须读到EOF；erase(value)会删掉全部同高建筑，源码使用erase(iterator)正确。
