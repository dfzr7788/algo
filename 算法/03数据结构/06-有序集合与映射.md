## 有序集合与映射有什么用

如果需要维护一个不断变化的有序集合，并询问“第一个不小于 x 的数”“x 的前驱”“某个键是否存在”，堆不够，因为堆只保证顶端极值。有序容器可以沿键顺序查找边界。

set 适合不同键集合，multiset 适合保留重复元素，map 则给每个不同键附带值，比如出现次数或额外属性。本篇保留标准库容器；它们提供动态有序维护，简单静态数组加插入搬移不能保持相同的对数操作界，因此不自行封装类。

## 关键接口

例如 multiset 中有 [10,20,20,30]，lower_bound(20) 找到第一个 20，upper_bound(20) 找到 30。要问≤20 的第二大，可以从 upper_bound(20) 向前走两次，得到另一个 20。重复元素各占一个位置，不能用 set 去重后再回答这类问题。

成员 lower_bound(x) 找第一个≥x，upper_bound(x) 找第一个>x。返回 end 时不能解引用，begin 时不能直接向前减。set/map 应使用成员查找，通用 lower_bound 对非随机访问迭代器可能花 O(n) 次移动。

multiset.erase(x) 删除所有等于 x 的项；仅删一个时先 find，再 erase(iterator)。map[x] 会在键不存在时插入默认值，纯查询用 find，避免意外修改状态。

## 完整程序：带重复值的有序查询

测试：[AtCoder ABC241 D — Sequence Query](https://atcoder.jp/contests/abc241/tasks/abc241_d)。操作 1 x 加入；2 x k 输出≤x 的第 k 大，3 x k 输出≥x 的第 k 小，不足输出 -1。原题 k≤5，故可以查到边界后移动少量迭代器。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    multiset<long long> values;
    while (q--)
    {
        int type;
        long long x;
        cin >> type >> x;
        if (type == 1)
        {
            values.insert(x);
            continue;
        }
        int k;
        cin >> k;
        long long answer = -1;
        if (type == 2)
        {
            auto it = values.upper_bound(x);
            bool valid = true;
            while (k--)
            {
                if (it == values.begin())
                {
                    valid = false;
                    break;
                }
                it--;
            }
            if (valid)
                answer = *it;
        }
        else
        {
            auto it = values.lower_bound(x);
            for (int j = 1; j < k && it != values.end(); j++)
                it++;
            if (it != values.end())
                answer = *it;
        }
        cout << answer << '\n';
    }
}
```

边界查找 O(log n)，移动 O(k)，每次 O(log n+k)，空间 O(n)。大量第 k 小且 k 很大时，不可用 advance 或 distance 假装 O(log n)，可考虑离散化+权值树状数组或顺序统计树。

## 扩展选读：平衡与迭代器

标准有序容器提供对数级查找与插入保证，普通 BST 则可能退化。遍历所有元素仍需 O(n)，删除一个迭代器后该迭代器失效；不要认为删除后还能用它继续 ++。具体容器修改的迭代器失效规则需按容器区别，vector 扩容与树容器插入不能混为一谈。
