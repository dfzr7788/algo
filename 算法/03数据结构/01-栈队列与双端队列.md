## 栈

### 栈有什么用

栈适合“最后发生的事先处理”。例如匹配右括号时应先匹配最近的左括号，撤销编辑时先撤销最近一次操作，DFS 回到上一步时恢复最近保存的状态。它不负责找最小值，也不允许直接删除中间位置。

静态模板中 top_index 表示元素个数，也是最后一个有效位置；push 先增加它再写入，pop 只减少它，query 读取 stk[top_index]。删除不需要把数组清零，因为栈顶之外的旧值已不属于有效栈。

后进先出（LIFO），push 压入、top 读取、pop 移除，适合括号匹配、撤销、DFS 与表达式处理。pop 不返回值，读取前要先检查 empty。

数组模拟可用 vector 尾部作为栈顶，push_back 与 pop_back；追加均摊 O(1)，访问顶 O(1)。不要用 erase(begin()) 实现出栈，那会整体搬移。

测试：[洛谷 B3614 — 栈](https://www.luogu.com.cn/problem/B3614)。原题多组输入，值可能达到 unsigned long long 范围；下面用静态数组与栈顶下标实现，容量 N=1000005，单组操作数不超过 1000000。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1000005;
unsigned long long stk[N];
int top_index;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--)
    {
        int q;
        cin >> q;
        top_index = 0;
        while (q--)
        {
            string op;
            cin >> op;
            if (op == "push")
            {
                unsigned long long x;
                cin >> x;
                stk[++top_index] = x;
            }
            else if (op == "pop")
            {
                if (top_index > 0)
                    top_index--;
                else
                    cout << "Empty\n";
            }
            else if (op == "query")
            {
                if (top_index > 0)
                    cout << stk[top_index] << '\n';
                else
                    cout << "Anguei!\n";
            }
            else if (op == "size")
                cout << top_index << '\n';
        }
    }
}
```

## 队列

### 队列有什么用

队列适合“先来的事先处理”。例如 BFS 先处理较早发现、较近的状态，服务队伍按到达顺序处理。加入尾部与移除头部使旧元素的先后顺序保持不变。

本静态模板有效元素位于 `[head_index,tail_index)`，push 写入 tail_index 后增加尾指针，pop 增加头指针。head_index==tail_index 就是空，大小为两者之差；出队不需移动后面的元素。N=10005 适用于 B3616 最多 10000 次操作。

先进先出（FIFO），尾部入队、头部出队，适合 BFS、任务缓冲。queue 的 front 是队首，back 是队尾；top 是栈或堆接口，不能混用。

测试：[洛谷 B3616 — 队列](https://www.luogu.com.cn/problem/B3616)。输入操作数量，1 x 入队、2 出队、3 查询、4 大小，空操作按题目输出错误字符串。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 10005;
int que[N];
int head_index = 0;
int tail_index = 0;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    while (q--)
    {
        int op;
        cin >> op;
        if (op == 1)
        {
            int x;
            cin >> x;
            que[tail_index++] = x;
        }
        else if (op == 2)
        {
            if (head_index < tail_index)
                head_index++;
            else
                cout << "ERR_CANNOT_POP\n";
        }
        else if (op == 3)
        {
            if (head_index < tail_index)
                cout << que[head_index] << '\n';
            else
                cout << "ERR_CANNOT_QUERY\n";
        }
        else if (op == 4)
            cout << tail_index - head_index << '\n';
    }
}
```

数组队列以 head、tail 指向有效半开范围 `[head,tail)`；一次性处理最多 q 次入队时开 q 空间即可，不必每次出队搬移元素。固定容量循环队列可用 size 区分空与满，取模要求容量>0。

## 双端队列

### 双端队列有什么用

如果两端都可能加入或删除，单纯 stack/queue 接口不够。双端队列可以把更紧急的状态放在前面、普通状态放后面，也可同时移除过期队首与较差队尾。0-1 BFS 与单调队列会用到它，但仅换成 deque 不能自动保证这些算法正确。

deque 支持 push_front、push_back、pop_front、pop_back、front、back。两端操作可用于维护窗口候选，见 [[05-单调栈与单调队列]]。它也支持下标访问，但不是连续存储的 vector，不要假定其元素构成一块连续内存。

```cpp
// 使用 <deque>；这段只演示接口。
std::deque<int> d;
d.push_back(2);
d.push_front(1);
if (!d.empty())
{
    d.pop_front();
}
```

## 扩展选读：递归栈与方案数

递归把参数、局部状态、返回位置等保存在调用栈中。改为显式栈时，复杂递归还需保存“当前执行阶段”，并非只压入顶点即可保持相同行为。长链递归有系统栈深度限制，显式容器也仍需 O(深度) 存储。

固定入栈顺序、只允许合法入栈与出栈时，出栈序列数量对应卡特兰数，衔接 [[12-卡特兰数与反射原理]]；这不是任意排列数量 n!。摊还分析：vector 偶尔扩容搬移 O(n)，连续追加的总搬移量在通常几何扩容策略下为 O(n)，因此单次追加均摊常数时间。
