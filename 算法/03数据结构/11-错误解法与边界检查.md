## 反例记录

| 错误做法                   | 小例子           | 为什么错              |
| ---------------------- | ------------- | ----------------- |
| 空容器直接 top/front        | 删空后再次 query   | 接口前提不满足           |
| 链表仅改 next              | 在两节点中间插入      | 反向链接不同步           |
| 重复删除仍接旧邻居              | 同一编号删两次       | 已失效邻接破坏当前链        |
| 前序+后序唯一重建              | A 根只有一个 B 孩子  | B 可以在左或右          |
| BST 总是对数查找             | 依次插入 1、2、3    | 普通树退化为链           |
| 堆外改优先级后直接 top          | 改某元素 deadline | 堆的结构未重新维护         |
| 单调栈把相等当严格更大            | $[2,2]$         | 两者都应无更大答案         |
| 窗口候选不删过期               | [9,1,2]，$k=2$   | 第二窗口最大值为 2，不是 9   |
| multiset.erase(x) 只删一个 | 有两个 5         | 按键删除会删全部 5        |
| 并查集直接连普通节点             | 合并时改中间节点父亲    | 可能拆走原集合的一部分       |
| BIT 用 0 下标更新           | $add(0,1)$     |$\mathrm{lowbit}(0)=0$，循环不前进 |
| lazy 只改 tag，不改 sum     | 整段加后立即整段查     | 父统计遗漏了修改          |
| 下放后不清父标记               | 后续局部访问        | 同一增量被重复下放         |

## 对拍基准

- 栈/队列/堆：普通列表模拟；堆最值每次直接 min 查找。
- 链表：Python 列表按编号插入删除，检查全部顺序。
- 树遍历与重建：随机生成合法小树，核对三种序列，深链另查栈限制。
- 单调结构：每个位置向右暴力找答案，每个窗口直接求 min/max。
- 并查集：保存无向边并 BFS 判断连通，避免暴力也复用 DSU。
- BIT/线段树：直接修改数组并逐项求和，测试整段与边角更新交错。

所有输入需合法，固定种子保存失败。构造与重建先核对合法性，再核对需要的输出；不凭随机通过替代证明。方法见 [[19-错误解法与最小反例]]。
