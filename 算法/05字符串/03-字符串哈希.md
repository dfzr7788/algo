## 把长比较换成短指纹

若一个长串有 q 次“两个子串是否相同”的询问，逐字符比较最坏 O(nq)。先用多项式计算每个前缀的指纹，再通过前缀差取任意子串，每次只比较固定数量整数。

**指纹不唯一。** 相同字符串必有相同指纹，不同字符串也可能相同，即碰撞。原笔记的“映射为唯一整数”不成立；双模降低通常输入上的误判风险，固定基数与模数不能提供对任意输入无碰撞保证。需要确定性单模式匹配时直接用 KMP。

哈希表如 unordered_map 是按键存储的数据结构；这里的多项式哈希是把字符串映射为数字的函数，两者用途不要混淆。

## 递推与权值对齐

使用正字符编码 c，基数 B，模数 M。H[i] 表示前 i 个字符（H[0]=0），P[i]=B^i mod M。

$$
H[i]=(H[i-1]B+c_i)\bmod M.
$$

闭区间、1 下标的子串哈希为

$$
hash(l,r)=\bigl(H[r]-H[l-1]P[r-l+1]\bigr)\bmod M.
$$

用 `abcde` 取 `de`：H[5] 中 abc 的贡献是 H[3]·B²，直接 H[5]−H[3] 没有对齐位权。取整串 l=1 时减去 H[0]=0，边界不用特判。比较不同长度串时先检查长度，去重键也带长度。

## 手算一个允许碰撞的例子

为便于手算，设 B=10、a=1,b=2,c=3、M=101。`abc` 原值 123，H[3]=22；取 `bc` 时算 `(22−1×100) mod 101=23`，与独立计算 2×10+3 一致。**负数取模需要归一化**。若再出现另一个值与 123 相差 101，模哈希仍相同，这正说明取模不是可逆编码。

主模板以字节转 unsigned char 再加 1，避免 signed char 的负值及字符编码 0；B=499、两个模数约 10^9，乘法最大约 10^18，long long 可以容纳。换更大基数、模数后要重新估计乘积。

## 完整模板一：静态子串比较

输入非空、无空白字符串 s，长度<=10^6；再输入 q<=200000，q 行 `l1 r1 l2 r2`，均为 **1 下标闭区间**且合法，输出 Yes/No。这是哈希指纹判断，可能碰撞；字符串修改后原前缀数组失效。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000000 + 5;
const long long BASE = 499;
const long long MOD[2] = {1000000007, 1000000009};
long long prefix_hash[2][MAXN], power_base[2][MAXN];

void build_hash(const string &s)
{
    for (int k = 0; k < 2; k++)
    {
        prefix_hash[k][0] = 0;
        power_base[k][0] = 1;
        for (int i = 1; i <= (int)s.size(); i++)
        {
            int code = (unsigned char)s[i - 1] + 1;
            prefix_hash[k][i] = (prefix_hash[k][i - 1] * BASE + code) % MOD[k];
            power_base[k][i] = power_base[k][i - 1] * BASE % MOD[k];
        }
    }
}

long long get_hash(int k, int l, int r)
{
    long long removed = prefix_hash[k][l - 1] * power_base[k][r - l + 1] % MOD[k];
    return (prefix_hash[k][r] - removed + MOD[k]) % MOD[k];
}

bool equal_substrings(int l1, int r1, int l2, int r2)
{
    if (r1 - l1 != r2 - l2)
    {
        return false;
    }
    for (int k = 0; k < 2; k++)
    {
        if (get_hash(k, l1, r1) != get_hash(k, l2, r2))
        {
            return false;
        }
    }
    return true;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    int q;
    cin >> s >> q;
    build_hash(s);
    while (q--)
    {
        int l1, r1, l2, r2;
        cin >> l1 >> r1 >> l2 >> r2;
        cout << (equal_substrings(l1, r1, l2, r2) ? "Yes" : "No") << '\n';
    }
}
```

教学样例输入（自编）：

```text
ababa 4
1 3 3 5
1 2 2 3
1 1 3 3
1 2 1 3
```

输出：

```text
Yes
No
Yes
No
```

## 完整模板二：不同字符串数量

输入 n<=10000 个非空无空白字符串，长度每个<=1500，区分大小写。取 `(长度,模1指纹,模2指纹)` 排序去重，接口对应原链接 [洛谷 P3370 — 字符串哈希](https://www.luogu.com.cn/problem/P3370)。原单 64 位哈希思路改为双模主模板；即使双模也不能声称数学上完全正确，需要确定性去重时存原串排序或使用保存原键的集合。

```cpp
#include <bits/stdc++.h>
using namespace std;

const long long BASE = 499;
const long long MOD1 = 1000000007;
const long long MOD2 = 1000000009;

tuple<int, long long, long long> fingerprint(const string &s)
{
    long long h1 = 0;
    long long h2 = 0;
    for (unsigned char c : s)
    {
        int code = c + 1;
        h1 = (h1 * BASE + code) % MOD1;
        h2 = (h2 * BASE + code) % MOD2;
    }
    return {(int)s.size(), h1, h2};
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<tuple<int, long long, long long>> keys;
    for (int i = 0; i < n; i++)
    {
        string s;
        cin >> s;
        keys.push_back(fingerprint(s));
    }
    sort(keys.begin(), keys.end());
    keys.erase(unique(keys.begin(), keys.end()), keys.end());
    cout << keys.size() << '\n';
}
```

教学样例输入（自编）：

```text
5
abc
ABC
abc
123
ab
```

输出：

```text
4
```

设总字符数 L，去重模板时间 O(L+n log n)，键空间 O(n)，逐词读入最大单词空间 O(maxlen)。子串模板预处理 O(n)、每询问 O(1)，总 O(n+q) 时间，辅助空间 O(n)，静态数组实际分配约 32 MB（每元素 8 字节时）。

## 原有 64 位自然溢出思路

unsigned long long 通常为 64 位，下面用 uint64_t 明确宽度。无符号乘加减按模 2^64 运算，是定义良好的行为；signed long long 溢出没有同等保证。原基数 499 和前缀差思想保留，但不能把“自然溢出省去 %”当作不发生碰撞的依据。

以下是局部片段，依赖 n<=10^6、合法 1 下标区间；每次建新串重置 H[0]、P[0]。不与上面双模函数混用。

```cpp
const int N64 = 1000000 + 5;
uint64_t h64[N64], p64[N64];

void build_hash64(const string &s)
{
    h64[0] = 0;
    p64[0] = 1;
    for (int i = 1; i <= (int)s.size(); i++)
    {
        h64[i] = h64[i - 1] * 499 + (unsigned char)s[i - 1] + 1;
        p64[i] = p64[i - 1] * 499;
    }
}

uint64_t get_hash64(int l, int r)
{
    return h64[r] - h64[l - 1] * p64[r - l + 1];
}
```

原字符映射把数字、大写、小写分别映射到 1..62，也可以使用；本篇统一 byte+1，支持同一字节字符集。若想用哈希替代原 strStr，先算非空模式指纹，再扫所有等长窗口；找到第一个相同指纹只表示候选，碰撞仍可能误报。逐候选逐字复核可消除误报，却可能回到 O(nm)，不能同时声称无条件线性和绝对无碰撞。

## 扩展选读：概率假设

固定参数没有随机实验，不应直接给碰撞概率 `1/M` 或双模 `1/(M1M2)`。随机基数的分析需说明取样范围、模数性质、字符串长度、是否独立，以及多次比较的联合风险；实际固定种子的随机检查只能检查实现，不能证明未来输入不碰撞。
