## 题解一：重复信息可不可以截断

给非空串 s，问两个不同目标：①找最小 d，使所有 $i\ge d$ 都满足 $s[i]=s[i-d]$，允许最后一段不完整；②找最短块，使 s 是该块完整重复若干次。

对 `ababa`，第一问周期是 2，重复 ab 后截断最后一个 b；第二问不能完整重复 ab，最短完整块就是 ababa，长 5。`ababab` 两问都为 2。不能把周期与可整除重复块混用。

### 暴力瓶颈与 border 转换

枚举 $d=1\ldots n$，再逐字符检验，总 $O(n^{2})$。对某个 d，周期条件等价于 $s[d\ldots n-1]=s[0\ldots n-d-1]$，即存在长度 $n-d$ 的 border。最小 d 对应最长 border，直接 $d=n-pi[n-1]$，由 KMP 预处理线性获得。

完整重复还要求 `n%d=0`。若最短周期不能整除 n，为何不能有更长但整除 n 的重复块？若存在完整重复块 $e<n$ 且 $d<e$，则 $e\le n/2$；d、e 两周期在这段长度上会导出 $\gcd (d,e)$ 的周期（周期引理），最小性强迫 d|e，进而 d|n，矛盾。基础练习先记住并用小例子验证该结论；较严格的周期引理属于选读，不用一行“不能整除”冒充证明。

### 完整教学程序

输入非空、无空白字符串，长度 $\le 10^{6}$；输出 `最短允许截断周期 最短完整重复块长度`，单组。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000000 + 5;
int pi[MAXN];

void build_prefix(const string &s)
{
    pi[0] = 0;
    for (int i = 1; i < (int)s.size(); i++)
    {
        int j = pi[i - 1];
        while (j > 0 && s[i] != s[j])
        {
            j = pi[j - 1];
        }
        if (s[i] == s[j])
        {
            ++j;
        }
        pi[i] = j;
    }
}

int main()
{
    string s;
    cin >> s;
    int n = s.size();
    build_prefix(s);
    int shortest_period = n - pi[n - 1];
    int complete_block = (n % shortest_period == 0 ? shortest_period : n);
    cout << shortest_period << ' ' << complete_block << '\n';
}
```

教学样例输入（自编）：

```text
ababa
```

输出：

```text
2 5
```

时间 $O(n)$，辅助空间 $O(n)$。[洛谷 P4391 — Radio Transmission](https://www.luogu.com.cn/problem/P4391) 要从重复广播的片段求最短原信息长度，允许末尾不完整；官方输入另有 L，输出只有第一问 d。不能加上 `n%d=0` 的限制，也不能把本程序两个数字直接当其输出。

## 题解二：保留原笔记的差分序列前缀应用

原 Trie 笔记只有 countConsistentKeys 的接口，没有题面与可核验来源。本篇明确成**自编教学模型**，不声称是某平台原题：有若干非空整数序列 A，对每次查询 B，数有多少个 A 满足 $\lvert B\rvert \le \lvert A\rvert$ 且存在常数 k，让所有 $B[i]=A[i]+k$（仅比较 A 的同长前缀）。

### 暴力与不变量

逐个 A 检查 B 每个元素之差是否相同，需要反复扫描词库。等价地，对于 $i\ge 1$ 检查 `B[i]−B[i−1]=A[i]−A[i−1]`。只要所有相邻差相同，取 $k=B[0]-A[0]$ 并逐项相加即可得到同一偏移；反向也明显成立。

因此“整体平移相同”转成“差分序列前缀相同”，再交给 Trie 前缀计数。原例 `[3,6,50,10]` 的相邻差为 `[3,44,−40]`，序列化为 `3#44#-40#`，字符集数字 $0\ldots9$、负号、分隔符共 12 种。

### 分隔符不是装饰

差分 `[1,23]` 与 `[12,3]` 不分隔都会变成 123，错误相同；即使单个差只比较前缀，1 也会错误匹配 10。每个差后加 `#`，得到 `1#23#` 与 `12#3#`，查询 `1#` 不会匹配 `10#`。符号与数字顺序保留，0 按 to_string 写成 `0#`，避免其他编码形式。

长度 1 的 B 没有相邻差，编码为空串；它是所有非空 A 编码的前缀。查询返回根 $\mathrm{pass}=n$，正好对应任意 A 首元素都能平移到 $B[0]$，不能误判为没有条件所以答案为 0。

### 完整教学程序

输入 `n q`；随后 n 个 A，再 q 个 B，每个序列以 `length` 和 length 个整数给出，长度 $\ge 1$，$n,q\le 200000$。所有输入元素绝对值 $\le 10^{12}$，差用 long long 相减，避免原 `vector<int>` 版本的减法溢出。**所有插入 A 的差分编码总字符数 $\le 200000$**，查询编码总长 $\le 200000$；容量按编码字符而非原元素个数确定。单组输入，输出每个 B 的匹配数量。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXNODE = 200000 + 5;
int child[MAXNODE][12], pass_count[MAXNODE], nodes;

int code_of(char c)
{
    if (c == '#')
    {
        return 10;
    }
    if (c == '-')
    {
        return 11;
    }
    return c - '0';
}

string read_difference_key()
{
    int length;
    cin >> length;
    long long previous;
    cin >> previous;
    string key;
    for (int i = 1; i < length; i++)
    {
        long long current;
        cin >> current;
        key += to_string(current - previous);
        key.push_back('#');
        previous = current;
    }
    return key;
}

void insert_key(const string &key)
{
    int u = 0;
    ++pass_count[u];
    for (char c : key)
    {
        int k = code_of(c);
        if (child[u][k] == 0)
        {
            child[u][k] = ++nodes;
        }
        u = child[u][k];
        ++pass_count[u];
    }
}

int count_prefix(const string &key)
{
    int u = 0;
    for (char c : key)
    {
        int k = code_of(c);
        if (child[u][k] == 0)
        {
            return 0;
        }
        u = child[u][k];
    }
    return pass_count[u];
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    for (int i = 0; i < n; i++)
    {
        insert_key(read_difference_key());
    }
    while (q--)
    {
        cout << count_prefix(read_difference_key()) << '\n';
    }
}
```

教学样例输入（自编）：

```text
3 4
4 3 6 50 10
3 10 13 16
2 1 4
2 0 3
3 7 10 54
1 8
2 0 30
```

输出：

```text
3
1
3
0
```

## 正确性与复杂度

先证明原整数模型与差分前缀等价；带分隔符与符号的十进制编码唯一并保持差分项边界；Trie 逐字符前缀查询于是准确计数。重复 A 各算一次，长度比查询短的 A 不能沿完整查询编码走到末尾，符合长度限制。

设原输入元素总数 E、插入编码字符总数 S、查询编码总数 Q，时间 $O(E+S+Q)$，字符集 12 固定；空间 $O(S)$，固定数组约 11 MB。单元素序列编码长度 0，但仍需读取首元素，E 不可忽略；不能只写 $O(S+Q)$ 就遗漏大量空编码序列的处理。
