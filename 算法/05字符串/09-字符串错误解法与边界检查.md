返回：[[00-字符串]]。用最小反例检查状态含义和边界，不对这页混合评分。

## 从反例定位错误

| 错误 | 反例或边界 | 修正 |
|---|---|---|
| 子序列当子串 | abcde 中的 ace | 匹配与回文子串要求连续 |
| substr 第二参数写右端点 | abcdef 的闭区间 [2,4] | 应 substr(2,3) 得 cde；错误的 substr(2,4) 得 cdef，第二参数是长度 |
| cin 读取包含空格的串 | 一行 a b | 只会读到 a，整行用 getline |
| 数字后直接 getline | 输入 3 换行 abc | 残留换行让第一次得到空行，先消费数字行余部 |
| m 比 n 大仍访问 text[start+j] | 文本 a，模式 abc | 合法起点要求 start+m<=n |
| 空模式规则没说明 | 文本 abc，模式空 | 先约定答案；暴力 n+1 个边界，KMP/AC 主模板禁空模式 |
| pi 与 −1 next 混用 | ABABAC | pi[i] 看到 i，fallback[j] 只看到 j−1，不能用同一失配公式 |
| 匹配成功 j 不回退 | ABABA 中 ABA | j=m 后下步越界；退 pi[m−1] 才能继续且发现重叠 |
| 匹配成功 j 归零 | AAA 中 AA | 漏掉位置 2 的重叠出现 |
| 把周期一律要求整除 | ababa | 截断周期 2，完整重复块 5，题意决定限制 |
| hash 相同等于原串必相同 | 指纹范围有限，字符串无限 | 可能碰撞；需要保证时用确定性方法 |
| 前缀哈希直接相减 | abcde 取 de | 先乘 B² 对齐再减 |
| 不比较区间长度 | 长度不同的子串 | 比较键含长度，不能仅靠指纹判断 |
| signed 溢出当自然取模 | 大量乘基数 | signed 溢出非同等保证，用 uint64_t 或安全模乘 |
| Trie 路径存在就算完整词 | 只插 apple，查 app | end[app]=0，pass>0，只是前缀 |
| Trie 存重复词用 bool 计数 | app 插两次 | end/pass 是次数，除非题意明确去重 |
| 每次新图只令 nodes=0 | 两组先 apple 后 b | 旧孩子仍在，先清旧有效节点和计数 |
| 对字母、数字统一 c−a | 查询 A、1 | 负列号或非法列号，字符集映射必须对应 |
| 差分不加分隔符 | [1,23] 与 [12,3] | 数字边界丢失，每个差后加 # |
| 先 int 减法再转 long long | 10^12 和 −10^12 | 读取及相减都用足够类型 |
| 回文只枚举字符中心 | abba | 偶数回文需要缝隙中心 |
| 把长度当半径 | aba 的虚拟串中心 | 本篇 radius=4，原长度=3，right 为独占边界 |
| 镜像半径不取 min | 镜像超过已有 right | 未知字符不能直接继承，需边界截断后再比 |
| 原串 # 与真实哨兵不区分 | 字符集可含 # | 虚拟分隔符或重新证明表示；不能读未校验字符集 |
| Z 的第 0 项约定混用 | 模式 aba | 本篇 z[0]=3，另一约定为 0，会改变统计输出 |
| 扩展 KMP 复用文本 extended | 文本区间等于模式前缀 | 复用的是模式 z[i−left] |
| AC 只统计当前状态 | he 和 she，文本 she | he 在失败链上同样出现，需反序汇总 |
| AC 重复词合成一个输出 | a、aa、aa，文本 aaa | 三个编号分别输出 3、2、2 |
| AC 建完继续按 Trie 插入 | go 已补失败转移 | go 不全是真孩子，必须先全部插入再建 |
| AC 汇总两次不清 visits | 第二段文本再次传播 | 原汇总值再向祖先加，重复计数 |

## 验证模型

- KMP：逐个合法起点比较，pi 每项枚举真前缀长度；验证无匹配、m=1、m>n、重叠。
- 哈希：小串全部闭区间与真实 substr 比较，核对相同片段取到同样指纹；去重用原串 set。测试通过不证明无碰撞。
- Trie：原词列表计 exact 与 startswith 次数；两个连续测试词库验证清理。
- 回文：枚举所有子串、用反转相等判断，与中心扩展和 Manacher 对比，包括空串、#、空格、全同字符、奇偶。
- Z / 扩展：每起点从 0 逐字比较真实 LCP，不用另一个区间复用算法当唯一验证模型。
- AC：每个模式独立枚举位置，重复模式各按编号比较；长 a 链用来检查失败树计数。
- 周期：枚举 d、逐项比较；完整重复块独立枚举整除 n 的长度。
- 差分编码：直接验证每个候选前缀的元素偏移是否为同一常数，不只与另一种序列化实现互比。

## 提交前

核对输入是否包含空格与空串、输出下标 0/1、区间闭合方式、是否按词编号计重复、是否计重叠、模板容量按字符数还是节点数；不要把平台输出与自编额外数组输出混用。多测要清所有状态，碰撞与容量限制要写在对应算法正文。
