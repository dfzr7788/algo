## 字符串问题先问什么

字符串是有顺序的字符序列。常见问题包括：某段是否相同、一个词出现在哪里、哪些词具有同一前缀、是否左右对称。先明确字符集、长度、空串、大小写和是否包含空格，再判断需要确定性答案还是可以接受哈希指纹判断。

这里的 C++ string 保存字节。英文字符可直接比较；$UTF-8$ 中文通常一个字占多个字节，s.size() 不是中文字符数，不能把本模块的字节下标当中文字符位置。所有竞赛模板的字符集由各篇注明。

## 前缀、后缀、子串与子序列

以 `abcde` 为例，`abc` 是前缀，`cde` 是后缀，`bcd` 是连续子串，`ace` 是子序列但不是子串。完整串和空串也是前缀、后缀；**真前缀、真后缀**排除完整串，空串长度为 0。KMP 的 border 是既为真前缀又为真后缀的串，不是两个任意位置子串的公共前后段。

string 本体使用 0 下标，闭区间 $s[l\ldots r]$ 长 $r-l+1$；半开区间 `[l,r)` 长 $r-l$。`substr(pos,len)` 的第二项是长度，不是右端点。对 `abcde`，$\mathrm{substr}(1,3)$ 得 bcd；读懂模板中位置还是长度的含义，比背公式更重要。

## C++ 常见操作与成本

| 操作 | 作用 | 需要注意的成本或条件 |
|---|---|---|
| `cin >> s` | 读一个非空白串 | 遇空白停止，不能读空串或包含空格的一行 |
| $\mathrm{getline}(cin,s)$ | 读一行，可能为空 | 前面用 cin 读数字后，要消费残留换行 |
| $s[i]$| 访问字符 | i 必须是有效字符下标；不要靠 $s[\mathrm{size}()]$ 当普通字符 |
| $s.\mathrm{substr}(pos,len)$| 复制子串 |$O(\text{复制长度})$，循环中反复复制可能变慢 |
| `s==t`、$s<t$| 相等、字典序比较 | 最坏扫描公共前缀长度，不是普遍 $O(1)$ |
| s.find(t) | 标准库搜索 | 未找到是 string::npos，算法保证不要自行当作线性 KMP |
| s.push_back(c) | 追加字符 | 常用实现按容量增长摊还处理，避免反复头插 |

如需混合数字与整行，使用 `cin.ignore(numeric_limits<streamsize>::max(),'\n')` 消费数字行余部，再 getline；若要保留行首空格，不要用 `getline(cin >> ws,s)`，ws 会吃掉空白。模板若使用 cin 读词，就明示不支持空词。

## 暴力匹配：枚举起点再逐字比较

给文本 text 和模式 pattern，尝试每个合法起点 start，比较 $\mathrm{text}[\mathrm{start}+j]$ 与 $\mathrm{pattern}[j]$；只要不相等，就换下一个起点。模式更长时没有合法起点。文本 `aaaa`，模式 `aa`，起点 0、1、2 都能成功；**重叠出现也必须计入**，不是每成功一次就跳过 m 个字符。

### 完整教学程序

输入两行，第一行为文本、第二行为模式；可含空格，可为空，两行长度各不超过 2000。输出出现次数，再输出全部 0 下标位置；无出现时第二行为空。这里约定空模式在 $n+1$ 个边界处出现，方便完整定义暴力函数；后续 KMP、AC 教学输入要求模式非空，不自动套用同一空模式规则。

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> find_all(const string &text, const string &pattern)
{
    int n = text.size();
    int m = pattern.size();
    vector<int> positions;
    for (int start = 0; start + m <= n; start++)
    {
        int matched = 0;
        while (matched < m && text[start + matched] == pattern[matched])
        {
            ++matched;
        }
        if (matched == m)
        {
            positions.push_back(start);
        }
    }
    return positions;
}

int main()
{
    string text, pattern;
    getline(cin, text);
    getline(cin, pattern);
    vector<int> positions = find_all(text, pattern);
    cout << positions.size() << '\n';
    for (int i = 0; i < (int)positions.size(); i++)
    {
        cout << positions[i] << (i + 1 == (int)positions.size() ? '\n' : ' ');
    }
    if (positions.empty())
    {
        cout << '\n';
    }
}
```

教学样例输入（自编）：

```text
aaaa
aa
```

输出：

```text
3
0 1 2
```

## 正确性与复杂度

全部合法位置都被枚举，每个位置只有全部 m 个字符相同才加入，因此不漏且不误报。$m>0$ 时最坏 $O(nm)$ 时间；空模式输出 $n+1$ 个位置，$O(n)$。位置数组最坏 $O(n)$，不计输出存储时匹配辅助空间 $O(1)$，输入 string 空间 $O(n+m)$。

例如 `aaaa…a` 中找 `aaaa…ab`，每次都到最后才失败，重复比较大量已相同字符；KMP 和 Z 函数就是保留这些已知相同信息。长度很小则直接暴力，易写、无碰撞，适合对拍，不需要为了“高级”强行换算法。
