## 核心思想与适用条件

维护两个位置，利用有序性或窗口性质，让指针沿一个方向移动，排除不可能的候选。关键是证明排除安全，而不只是代码中出现了两个指针。

| 类型 | 常见模型 | 关键性质 |
|---|---|---|
| 相向指针 | 有序数组两数之和 | 移动端点时和有确定变化方向 |
| 同向指针 | 合并有序序列、去重 | 已处理前缀无需重新访问 |
| 滑动窗口 | 最长无重复子数组 | 冲突可通过不断收缩左端消除 |
| 快慢指针 | 链表中点、判环 | 需要分析步速及相遇关系 |

## 完整例子一：两数之和，输出原下标

输入 n、目标值 target 和数组。找不同下标的两个数，输出 1-based 下标；无解输出 `IMPOSSIBLE`。假定两数相加在 `long long` 范围内。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
pair<long long, int> a[N];
int main()
{
    int n;
    long long target;
    cin >> n >> target;
    for (int i = 0; i < n; i++)
    {
        cin >> a[i].first;
        a[i].second = i + 1;
    }
    sort(a, a + n);
    int l = 0, r = n - 1;
    while (l < r)
    {
        long long sum = a[l].first + a[r].first;
        if (sum == target)
        {
            cout << a[l].second << ' ' << a[r].second << '\n';
            return 0;
        }
        if (sum < target)
            l++;
        else
            r--;
    }
    cout << "IMPOSSIBLE\n";
}
```

正确性：若 a[l]+a[r]<target，那么固定 l，和它配对的其余候选都不大于 a[r]，不可能得到 target，所以可以排除 l。和过大时同理排除 r。`l<r` 保证不重复用一个元素。排序 O(n log n)，扫描 O(n)，数组空间 O(n)。

## 完整例子二：最长无重复连续子数组

输入 n 和整数数组，输出最长无重复连续子数组的长度。数组不能排序，因为连续性依赖原顺序。

测试链接：[牛客 NC41 — 最长无重复子数组](https://www.nowcoder.com/practice/b56799ebfd684fb394bd315e89324fb4)。原题使用 `Solution::maxLength` 函数接口，需将本例扫描逻辑移入函数并返回 best。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
long long a[N];
int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
        cin >> a[i];
    unordered_map<long long, int> freq;
    int l = 0, best = 0;
    for (int r = 0; r < n; r++)
    {
        freq[a[r]]++;
        while (freq[a[r]] > 1)
            freq[a[l++]]--;
        best = max(best, r - l + 1);
    }
    cout << best << '\n';
}
```

循环不变量：处理每个 r 后，[l,r] 无重复，且 l 是当前 r 的最早合法左端点。旧窗口无重复，新增 a[r] 后只可能这个值冲突；移除至旧的相同元素离开后，窗口恢复合法。所有以 r 结尾的合法窗口都不比该窗口长，逐个 r 取最大值即为答案。

两个指针各推进至多 n 次，哈希表操作期望 O(1)，所以期望时间 O(n)，空间 O(n)。若改用 `map`，有确定的 O(n log n) 时间界。

## 非负数组的区间和窗口

当所有 a[i]≥0 时，右移 r 不会减小窗口和，右移 l 不会增大窗口和。因此“和≤S 的最长区间”可以在和过大时收缩。S≥0 时，每个 r 收缩后更新长度即可。

**反例：含负数时不能照搬。** a=[4,-3]、S=2。看到 4 就删除它，会漏掉总和为 1、长度为 2 的整个区间。需要考虑 [[01-前缀和#一维前缀和|一维前缀和]]、哈希或其他结构。

即使数组非负，统计“和恰好为 S”的区间数也不能每个 r 只加 1：零元素可能产生多个合法左端点。必须单独推导计数规则。

## 边界与练习

相向指针检查 n<2、重复值、无解；窗口检查空数组、全部相同、全部不同和零元素。解释 O(n) 时统计指针总移动次数。练习见 [[算法/基础算法与思想/20-题单|题单]]。
