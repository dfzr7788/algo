## 排序后维护当前覆盖段

按左端点排序。若下一段左端点≤当前右端点，则并集没有空隙，把右端点更新为两者最大值；否则结算旧段并开启新段。

半开区间 `[1,3)` 与 `[3,5)` 没有共同点，但并集等于 `[1,5)`，所以求最少段并集时可合并相接段。闭区间、整数格点以及“严格重叠数量”等任务应分别明确语义。

## 完整程序：覆盖总长度

测试：[洛谷 P1496 — 火烧赤壁](https://www.luogu.com.cn/problem/P1496)，原题为半开区间长度。输入 n 和 n 个 l、r，l<r，输出并集长度。原题坐标范围在 32 位整数内；用长整数保证端点差安全。本程序也支持 n=0。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
pair<long long, long long> intervals[N];
int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
        cin >> intervals[i].first >> intervals[i].second;
    sort(intervals, intervals + n);
    long long total = 0, l = 0, r = 0;
    bool active = false;
    for (int i = 0; i < n; i++)
    {
        long long x = intervals[i].first, y = intervals[i].second;
        if (!active)
        {
            l = x;
            r = y;
            active = true;
        }
        else if (x <= r)
            r = max(r, y);
        else
        {
            total += r - l;
            l = x;
            r = y;
        }
    }
    if (active)
        total += r - l;
    cout << total << '\n';
}
```

不变量：已结算段互不重叠，当前段表示尚未结算的连续覆盖。排序后若出现 x>r，后续左端点也>r，不可能再连接旧段，因此可安全结算。时间 O(n log n)，存储 O(n)。

`[1,4)`、`[2,3)`、`[4,6)` 合并为 `[1,6)`，长度 5。嵌套区间必须用 max 更新，不能把右端点缩回；最后一段不能漏结算。

拓展：[AtCoder ABC256 D — Union of Interval](https://atcoder.jp/contests/abc256/tasks/abc256_d) 要输出合并后的各段，不是总长度，需调整结算时输出。求整数闭区间点数时，每段长度应为 r-l+1；不要把它混入连续长度公式。
