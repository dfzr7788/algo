## 常见反例

| 错误做法 | 小输入 | 正确结论 |
|---|---|---|
| pre[r]-pre[l] 求闭区间和 | a=[5]，查询 [1,1] | 应为 5，错误写法得到 0 |
| 差分只加起点，不取消 | 全零，给 [1,1] 加 2，n=2 | 应为 [2,0]，不能为 [2,2] |
| 四角更新右下也减 | n=2，给 (1,1) 单格加 1 | (2,2) 应为 0，交叉区需加回 |
| 把排名差当长度 | 原坐标 1、100 | 长度 99，而不是 1 |
| 合并时直接覆盖右端点 | `[1,10)`、`[2,3)` | 不能把覆盖右端缩为 3 |
| 用 set 代替下标频次 | [1,1,1]，和为 2 的对数 | 答案为 3 |
| 插入当前前缀再查询 | [0]，K=0 | 非空区间只有 1 个 |
| 最大子段允许隐含空段 | [-2,-1] | 非空答案 -1，不能为 0 |
| ST 重叠统计和 | [1,2,3]，查整段 | 两个长度 2 的段会重复计入 2 |
| 分块末块统一按 B 长度加 | n=5，B=2，最后块加 3 | 最后块仅有 1 个元素，块和增 3 |

## 模板检查表

- 输入区间是闭还是半开，下标是 0-based 还是 1-based？
- 空前缀是否初始化？n+1、m+1 的取消点是否有空间？
- 预处理期间数组是否静态？恢复后的差分表是否又被当作未恢复的差分？
- 数值、计数、乘积、累计量的最大值是多少？中间减法也可能溢出。
- 求数量、最大值、最长长度分别需要频次、值或最早位置，保存的信息是否正确？
- 相等边界如何处理？合并并集和选择不相交区间不是同一任务。

## 有意义的对拍

| 优化程序 | 独立基准 | 小规模生成 |
|---|---|---|
| 一维/二维前缀 | 直接求区间或矩形和 | 含负数、触边查询 |
| 一维/二维差分 | 每次逐元素加 | 单点、整段、重复覆盖 |
| 离散化 | 排序去重后比较相等与顺序 | 巨大值、重复、全相同 |
| 合并并集 | 小整数坐标上标记每段单位区间 | 嵌套、相接、分离 |
| ST/分块 | 朴素数组查询与更新 | 多种长度、整块与边角交错 |
| 矩阵最优 | 枚举所有矩形直接累加 | 单格、全负、小矩阵 |

随机种子固定，保存第一个失败输入；减少元素或操作后重新确认失败。构造输出按合法性核对，不能只比较参考输出文本。公开可复现的脚本方法见 [[19-错误解法与最小反例]]。
