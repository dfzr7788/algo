## 完整例子：区间加与区间和交错执行

教学输入 n≥1、q、数组。操作 `1 l r c` 给闭区间加 c，`2 l r` 输出当前区间和。假设所有累加、块和及乘积都在长整数范围内。

维护 raw[i]、每块 tag 和当前真实总和 sum。真实单点是 raw[i]+tag[block]。整块加 c 时 tag+=c，sum+=c·块长；边角更新 raw 与 sum，保留原 tag。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 100005;
long long raw[N], tag[N], block_sum[N];
int n, block_size;
void range_add(int l, int r, long long value)
{
    for (int i = l; i <= r;)
    {
        int b = i / block_size, end = min(n, (b + 1) * block_size);
        if (i == b * block_size && end - 1 <= r)
        {
            tag[b] += value;
            block_sum[b] += value * (end - i);
            i = end;
        }
        else
        {
            raw[i] += value;
            block_sum[b] += value;
            i++;
        }
    }
}
long long range_sum(int l, int r)
{
    long long answer = 0;
    for (int i = l; i <= r;)
    {
        int b = i / block_size, end = min(n, (b + 1) * block_size);
        if (i == b * block_size && end - 1 <= r)
        {
            answer += block_sum[b];
            i = end;
        }
        else
        {
            answer += raw[i] + tag[b];
            i++;
        }
    }
    return answer;
}
int main()
{
    int q;
    cin >> n >> q;
    block_size = max(1, (int)sqrt(n));
    for (int i = 0; i < n; i++)
    {
        cin >> raw[i];
        block_sum[i / block_size] += raw[i];
    }
    while (q--)
    {
        int type, l, r;
        cin >> type >> l >> r;
        l--;
        r--;
        if (type == 1)
        {
            long long value;
            cin >> value;
            range_add(l, r, value);
        }
        else
            cout << range_sum(l, r) << '\n';
    }
}
```

不变量：sum 为本块所有 raw 加上 tag·实际块长。整块与单点更新都保持该等式；查询按不相交的整块和边角拆分，没有遗漏或重复。

每次 O(B+n/B)，取 B≈√n 得 O(√n)，初始化 O(n)，存储 O(n)。最后一块长度可能小于 B，不能统一乘 B。查询单块、跨块、整段以及 tag 非零后再更新边角都需要测试。

分块能处理交错操作，但不是所有操作都可以用一个加法 tag 表示。拓展：[洛谷 P3870 — 开关](https://www.luogu.com.cn/problem/P3870)，原题是区间翻转与亮灯数量，需维护翻转标记及 count←块长-count，不能直接提交本加法程序。动态结构的系统学习仍放在数据结构模块。
