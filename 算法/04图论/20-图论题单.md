## 自编练习

| 题目 | 层次 | 训练重点 |
| --- | --- | --- |
| 建图 | 应用 | [[02-图的存储]] 的无向邻居输出；自编题；改成有向图、加零权重边，核对双向存储与顺序 |
| DFS / BFS | 应用 | [[03-DFS与BFS]] 的分量与距离输入；自编题；加孤立点、自环、平行边，再恢复路径 |
| 双向与 A* | 应用 | [[04-双向BFS与A星]] 的链、障碍网格；自编题；与普通 BFS 对比长度，起终点同点应为 0 |
| 负权最短路 | 应用 | [[07-Bellman-Ford与SPFA]] 的自编图；区分源可达负环与不可达负环，不拿 SPFA 作非负大图默认解法 |
| Floyd | 应用 | [[08-Floyd与多源最短路]] 的自编小图；无负环，要求全部点对距离；带重边和不可达点 |
| MST | 应用 | [[09-最小生成树]] 的三角形输入；自编题；加负边、相同权边、不连通图，再枚举树子集核对 |
| 匹配 | 应用 | [[10-二分图与匹配]] 的重新配对输入；自编题；先证明不能只选空闲邻居，再找增广路径 |
| 桥割点 | 应用 | [[12-桥与割点]] 的三角形加尾链；自编题；增加平行边，核对桥的消失及根的特殊情况 |
| 树与 LCA | 应用 | [[13-树的遍历与子树信息]] 到 [[16-LCA与树上距离]]；自编题；链、星、单点、多根，注意 LCA 改变但两点距离不变 |
