## 无根树为什么要先选根

无根树只有邻接关系。选 root 后每个非根点都有唯一父亲，其他邻居是孩子；子树、祖先、深度才有明确含义。不同根会改变子树大小和祖先，但不会改变任意两点的原树距离。

朴素地对每个 u 单独遍历它的后代求大小要 O(n²)。一次确定父子关系，再让孩子把大小交给父亲，就能在线性时间处理全部点。

## 先父后子，再反序聚合

维护 order，保证父亲在孩子之前。每点先 size=1，然后倒序让 `size[parent[u]]+=size[u]`，此时孩子已经收齐所有后代。order 可以由 DFS 先序或 BFS 得到，不一定要用递归退出事件；关键是这个先后关系。

例：边 `1—2,1—3,3—4,3—5`，根 1。顺序 `1,2,3,4,5`，初始大小都是 1；倒序 5、4 使 size[3]=3；3 把 3 加给 1；2 再加 1，最终 size[1]=5。root 的父亲设为 0，不把根再交给 0。

## 完整模板

输入 `n root`，n−1 条无向边，**保证是一棵树**，`n<=200000`。输出每点 `父亲 深度 子树大小`，根深度 0、父亲 0。由于树无环，只跳过父亲足够；普通图不能这样写，必须访问标记。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200000 + 5;
vector<int> g[MAXN];
int parent_node[MAXN], depth_node[MAXN], size_node[MAXN];

int main()
{
    int n, root;
    cin >> n >> root;
    for (int i = 1; i < n; i++)
    {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    vector<int> order;
    order.push_back(root);
    for (int index = 0; index < (int)order.size(); index++)
    {
        int u = order[index];
        size_node[u] = 1;
        for (int v : g[u])
        {
            if (v != parent_node[u])
            {
                parent_node[v] = u;
                depth_node[v] = depth_node[u] + 1;
                order.push_back(v);
            }
        }
    }
    for (int index = n - 1; index > 0; index--)
    {
        int u = order[index];
        size_node[parent_node[u]] += size_node[u];
    }
    for (int u = 1; u <= n; u++)
    {
        cout << parent_node[u] << ' ' << depth_node[u] << ' ' << size_node[u] << '\n';
    }
}
```

教学样例输入：

```text
5 1
1 2
1 3
3 4
3 5
```

输出：

```text
0 0 5
1 1 1
1 1 3
3 2 1
3 2 1
```

## 正确性与复杂度

树上从根到每点的简单路径唯一，父子关系不会冲突。反序处理 u 时，它所有孩子及后代已完成，所以 `1+sum(size[child])` 等于子树大小。建树和两次扫描 O(n)，总空间 O(n)，显式 order 不受递归栈限制。

删去 u 后，每个孩子 v 形成大小 size[v] 的分量，另有父亲方向的分量 n−size[u]；根的父亲方向大小为 0。这是重心与三元组计数的共同工具。

## DFS 序与树形 DP 的区别

真正 DFS 的进入时间 tin、退出时间 tout 能让子树对应连续区间；本模板的广度式 order 只保证父亲在前，不能直接当作 DFS 子树区间。若要子树区间查询，需要使用保留邻居进度的 DFS 栈框架（强连通分量章第一遍可参考），进入时编号、退出时确定区间。

树形 DP 在反序中合并孩子状态，不一定是相加；“节点只访问一次”也不意味着所有树形 DP 都 O(n)，背包合并还要计每个状态组合的成本。
