## 题解一：每点能到的最大编号

[洛谷 P3916 — 图的遍历](https://www.luogu.com.cn/problem/P3916) 给有向图，要求每个点能到达的最大编号，包括自己。官方 $n,m\le 100000$；下面容量扩大为 200000，接口相同。题目可能有环，不保证 DAG。

### 暴力与瓶颈

从每个点 DFS，取访问到的最大编号，每次 $O(n+m)$，总 $O(n(n+m))$。大量源点访问同一批后继，重复计算是瓶颈。若正向按编号降序搜索并给访问点赋当前编号，会把“能被当前点到达”错当“能到当前点”。

### 改变方向与处理顺序

反图中从 x 出发能到的点，恰好是原图里能到 x 的点。按 x 从 n 到 1 处理，第一次赋值一定是该点所有可达编号中的最大者。某点已经赋值更大答案后，无需再扩展：沿反图更远的点也能到此前更大源，已被那次完整传播覆盖。于是全局 seen 可用 $\mathrm{answer}\ne 0$，不能每轮清空。

例：`1→2,2→3,4→2`。反图从 4 无出边，只定 $\mathrm{answer}[4]=4$；再从 3 传播到 2、1、4，4 已经有更大的 4，无需覆盖。最终 `[3,3,3,4]`。

### 完整程序

输入有向图 n m 和 m 条边，输出每点最大可达编号。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200000 + 5;
vector<int> reverse_g[MAXN];
int answer[MAXN];

void spread(int start)
{
    stack<int> st;
    st.push(start);
    answer[start] = start;
    while (!st.empty())
    {
        int u = st.top();
        st.pop();
        for (int v : reverse_g[u])
        {
            if (answer[v] == 0)
            {
                answer[v] = start;
                st.push(v);
            }
        }
    }
}

int main()
{
    int n, m;
    cin >> n >> m;
    for (int e = 0; e < m; e++)
    {
        int u, v;
        cin >> u >> v;
        reverse_g[v].push_back(u);
    }
    for (int u = n; u >= 1; u--)
    {
        if (answer[u] == 0)
        {
            spread(u);
        }
    }
    for (int u = 1; u <= n; u++)
    {
        cout << answer[u] << (u == n ? '\n' : ' ');
    }
}
```

教学样例输入：

```text
4 3
1 2
2 3
4 2
```

输出：

```text
3 3 3 4
```

### 正确性与复杂度

第一次赋值 x 时，能到比 x 更大编号的点已经在之前的反图传播中赋值，因此未赋值点不可能有更大答案；反图路径又证明它可以到 x，故答案恰为 x。全局每点入栈一次，每条反边扫描一次，$O(n+m)$ 时间、$O(n+m)$ 空间。图有环仍成立，不需要先做 SCC；若改问可达点权和等信息，排序传播并不自动适用。

## 题解二：含负边的最长路线

[洛谷 P1807 — 最长路](https://www.luogu.com.cn/problem/P1807) 给 DAG，问 1 到 n 的最长路，不可达输出 −1。官方 $n\le 1500,m\le 50000$，边权绝对值 $\le 10^{5}$。所有边已保证无环，所以不要照搬一般图最长简单路径的困难性，也不要因为存在负边就认为不能拓扑递推。

### 暴力与优化

枚举所有路线即使 DAG 也可能指数多；同一后缀会重复计算。最长路状态 $\mathrm{dist}[v]$ 保存从 1 到 v 的最大权，按拓扑顺序将它传播出去。只有 $\mathrm{dist}[1]=0$，其他为 −INF。如果全设为 0，一条合法负权路线会被错误的“凭空从这里开始”覆盖。

边 `1→2(−5),2→3(1),1→3(−10)`，到 3 的最大权为 −4，而不是 0。不从 1 可达的点仍要参与拓扑队列、正常删出边，以免其后继的入度无法归零；只是它不产生有效距离候选。

### 完整程序

输入 n m、带权有向边，容量 $n\le 2000$、$m\le 50000$、$\lvert w\rvert \le 10^{5}$，输出 1 到 n 的最长权，无法到达 −1。额外检测 CYCLE 便于自设错误输入；官方保证 DAG 不会触发。教学样例不是官方样例。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 2000 + 5;
const long long NEG_INF = -(1LL << 60);
vector<pair<int, long long>> g[MAXN];
int indegree[MAXN];
long long dista[MAXN];

int main()
{
    int n, m;
    cin >> n >> m;
    for (int e = 0; e < m; e++)
    {
        int u, v;
        long long w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});
        ++indegree[v];
    }
    fill(dista, dista + n + 1, NEG_INF);
    dista[1] = 0;
    queue<int> q;
    for (int u = 1; u <= n; u++)
    {
        if (indegree[u] == 0)
        {
            q.push(u);
        }
    }
    int processed = 0;
    while (!q.empty())
    {
        int u = q.front();
        q.pop();
        ++processed;
        for (auto [v, w] : g[u])
        {
            if (dista[u] != NEG_INF)
            {
                dista[v] = max(dista[v], dista[u] + w);
            }
            --indegree[v];
            if (indegree[v] == 0)
            {
                q.push(v);
            }
        }
    }
    if (processed != n)
    {
        cout << "CYCLE\n";
    }
    else
    {
        cout << (dista[n] == NEG_INF ? -1 : dista[n]) << '\n';
    }
}
```

教学样例输入：

```text
3 3
1 2 -5
2 3 1
1 3 -10
```

输出：

```text
-4
```

所有前驱比当前点早完成，最优路线最后一条边来自某个前驱，取全部候选的最大值就得到最优。时间 $O(n+m)$，空间 $O(n+m)$。有限答案可能恰好是 −1，与不可达同数值是题面输出约定，不影响内部 −INF 的区分。

## 第三种优化路线：先缩点

若原图带环，问题允许反复经过点且非负点权只计一次，可先按 SCC 合并，构建 DAG 后对分量权递推，对应洛谷 P3387。这里不能为了套用 DAG 就任意压环：路径限制、负点权、只允许简单路径会改变“可把整个分量都收集”的前提。完整 SCC 程序与聚合条件见前章，组合步骤是“求分量→合并权→建跨分量边→全 DAG 拓扑递推”，应分别验证四步。


## CF2276D Caveman：从染色数量刻画星图

[官方题面](https://codeforces.com/contest/2276/problem/D)。给无自环、无重边的无向图，每个点染红或蓝，要求每个点至少有一个异色邻居。按合法方案数输出 0 对应的 Brain Melt、1、2 或超过 2 对应的 Many。$3\le n\le3\times10^5$，$m\le3\times10^5$，多测的 n、m 总和分别不超过该上限。

层次：提高。训练重点是证明唯一结构，而不只是检查例图；源码用并查集计分量，再扫描边的两个端点度数。

> [!tip]- 提示一：先判断有没有方案
> 孤立点必然无法满足条件。若没有孤立点，每个分量选一棵生成树，按树深度奇偶染色，树边就能给每个点提供异色邻居。因此没有孤立点也足以保证有解。

> [!tip]- 提示二：什么时候只能有两种？
> 一个合法染色整体反色仍然合法，因而答案不会是 1。多个非平凡分量可以独立反色，至少有四种。接着只需考虑连通图：星图的每片叶子被中心颜色强制确定，恰好两种；其余连通图能否构造出互不相同的四种？

> [!tip]- 提示三：把“不是星图”变成局部结构
> 在连通图中，若每条边都有一个度为 1 的端点，则全图是星图。反过来，只要有一条边 u-v 的两端度数都至少为 2，就能在它附近找到三角形或一条含四个不同点的路径，分别构造两种不互为反色的合法局部染色。

> [!example]- 详细题解：按 ltk、deg 与边扫描的分类
> **1. 为什么不枚举全部染色？**
>
> n 个点有 $2^n$ 种染色，但题目只区分 0、1、2 和大于 2，不要求精确计数。应先寻找让方案被强制确定的结构。源码读边时维护 deg[u]、deg[v]；并查集 father 表示分量，find 做路径压缩，unio 合并不同根。ltk 从 n 开始，每次真正合并两个分量才减一，所以读完后它就是连通分量数。sz 记录集合大小，但不参与答案判断，也未被用于选择合并方向。
>
> **2. 对应前两个返回分支。**
>
> deg 为 0 的点没有任何邻居，无法满足要求，直接输出 Brain Melt。若所有点的度数均正，每个分量至少有两个点；取各分量生成树并交替染色，可以保证每个点有一条异色树边。原图额外的边不会破坏“至少有一个”的条件，所以此时必然存在合法染色。
>
> 若 ltk≥2，各分量互不约束，每个分量都可独立保持或翻转颜色，总数至少 $2^{ltk}\ge4$，因此输出 Many。注意必须先排除孤立点，不能一看到不连通就认定有四种。
>
> **3. 连通图为何只需检查边两端度数？**
>
> 假设找不到两端度数均至少为 2 的边。由于 n≥3 且图连通，必有某个点 c 的度数至少为 2。它的每个邻居度数只能为 1，否则相连边就会被检出。若还有点不与 c 相邻，从 c 走到它的路径上，c 后的第一个点就需要连接路径中的下一个点，度数至少为 2，矛盾。因此所有点都是中心 c 或它的叶子，全图正是星图。
>
> 星图中，中心选红后所有叶子只能选蓝；中心选蓝后所有叶子只能选红。两种都合法，且没有其他选择，故最后输出 2。
>
> **4. 找到内部边为什么必然超过两种？**
>
> 对边 u-v，若两端有共同邻居 w，就有三角形。固定 u 红、v 蓝，w 可取红或蓝，这两种局部染色都让三个点具有异色邻居。否则，从 u 选一个非 v 邻居 x，从 v 选一个非 u 邻居 y；没有共同邻居保证 x、u、v、y 是四个不同点，组成路径 x-u-v-y。
>
> 路径上按顺序染成“红蓝红蓝”或“红蓝蓝红”，每个点都已有异色邻居。这两种局部染色不互为整体反色。即使四点之间还有额外边，也不影响已有的异色邻居。
>
> 在连通图里，局部染色可扩展到全图：只要还有未染点，就选一个与已染集合相邻的点，把它染成该邻居的反色。新点立刻满足条件，原来点已有的异色邻居不会丢失。重复即可染完。得到的两种完整方案保留局部差异，再各取整体反色，形成四种不同方案。因此边扫描命中时输出 Many 正确。
>
> **5. 手算与实现细节。**
>
> 图中只有边 1-2、1-3 时，deg=(2,1,1)，ltk=1，每条边都接叶子，输出 2。路径 1-2-3-4 中 deg=(1,2,2,1)，边 2-3 命中双端度数条件，输出 Many；上面的两种路径染色就给出了证明。两个独立的单边分量即使每条边都接叶子，也应由 ltk 分支输出 Many。
>
> edges 大小为 m+1，实际边填在 1 到 m，范围循环还会读到零号元素 (0,0)。deg[0] 初始化为 0，所以它不会误判，但它不是实际图边。father、sz 的容量要求 n≤300000；每组只需要重置点 1 到 n，其他图数据在 solve 内重建。
>
> **6. 按当前实现分析复杂度。**
>
> 初始化、度数检查和边扫描共 $O(n+m)$，有效存储为 $O(n+m)$，另有两个固定容量的全局数组。并查集只有路径压缩，没有按大小或按秩合并，不能套用两者结合时的逆阿克曼界；这里采用保守的总时间上界 $O((n+m)\log n)$。递归 find 的单次调用深度仍可能为 $O(n)$：依次读入 (2,1)、(3,2)、…、(n,n-1)，再访问点 1，可形成长父链。按大小合并或改用迭代 find 可缓解栈风险，这是当前实现的注意事项。
>
> 选读对照：已知答案恰为 2 当且仅当整图为星图，也可直接用最大度 n-1 且其余点度为 1 判定，不再需要并查集；上文保留源码按分量与内部边分类的主线。
