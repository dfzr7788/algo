## 题解一：每点能到的最大编号

[洛谷 P3916 — 图的遍历](https://www.luogu.com.cn/problem/P3916) 给有向图，要求每个点能到达的最大编号，包括自己。官方 n,m<=100000；下面容量扩大为 200000，接口相同。题目可能有环，不保证 DAG。

### 暴力与瓶颈

从每个点 DFS，取访问到的最大编号，每次 O(n+m)，总 O(n(n+m))。大量源点访问同一批后继，重复计算是瓶颈。若正向按编号降序搜索并给访问点赋当前编号，会把“能被当前点到达”错当“能到当前点”。

### 改变方向与处理顺序

反图中从 x 出发能到的点，恰好是原图里能到 x 的点。按 x 从 n 到 1 处理，第一次赋值一定是该点所有可达编号中的最大者。某点已经赋值更大答案后，无需再扩展：沿反图更远的点也能到此前更大源，已被那次完整传播覆盖。于是全局 seen 可用 answer!=0，不能每轮清空。

例：`1→2,2→3,4→2`。反图从 4 无出边，只定 answer[4]=4；再从 3 传播到 2、1、4，4 已经有更大的 4，无需覆盖。最终 `[3,3,3,4]`。

### 完整程序

输入有向图 n m 和 m 条边，输出每点最大可达编号。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200000 + 5;
vector<int> reverse_g[MAXN];
int answer[MAXN];

void spread(int start)
{
    stack<int> st;
    st.push(start);
    answer[start] = start;
    while (!st.empty())
    {
        int u = st.top();
        st.pop();
        for (int v : reverse_g[u])
        {
            if (answer[v] == 0)
            {
                answer[v] = start;
                st.push(v);
            }
        }
    }
}

int main()
{
    int n, m;
    cin >> n >> m;
    for (int e = 0; e < m; e++)
    {
        int u, v;
        cin >> u >> v;
        reverse_g[v].push_back(u);
    }
    for (int u = n; u >= 1; u--)
    {
        if (answer[u] == 0)
        {
            spread(u);
        }
    }
    for (int u = 1; u <= n; u++)
    {
        cout << answer[u] << (u == n ? '\n' : ' ');
    }
}
```

教学样例输入：

```text
4 3
1 2
2 3
4 2
```

输出：

```text
3 3 3 4
```

### 正确性与复杂度

第一次赋值 x 时，能到比 x 更大编号的点已经在之前的反图传播中赋值，因此未赋值点不可能有更大答案；反图路径又证明它可以到 x，故答案恰为 x。全局每点入栈一次，每条反边扫描一次，O(n+m) 时间、O(n+m) 空间。图有环仍成立，不需要先做 SCC；若改问可达点权和等信息，排序传播并不自动适用。

## 题解二：含负边的最长路线

[洛谷 P1807 — 最长路](https://www.luogu.com.cn/problem/P1807) 给 DAG，问 1 到 n 的最长路，不可达输出 −1。官方 n<=1500,m<=50000，边权绝对值<=10^5。所有边已保证无环，所以不要照搬一般图最长简单路径的困难性，也不要因为存在负边就认为不能拓扑递推。

### 暴力与优化

枚举所有路线即使 DAG 也可能指数多；同一后缀会重复计算。最长路状态 dist[v] 保存从 1 到 v 的最大权，按拓扑顺序将它传播出去。只有 dist[1]=0，其他为 −INF。如果全设为 0，一条合法负权路线会被错误的“凭空从这里开始”覆盖。

边 `1→2(−5),2→3(1),1→3(−10)`，到 3 的最大权为 −4，而不是 0。不从 1 可达的点仍要参与拓扑队列、正常删出边，以免其后继的入度无法归零；只是它不产生有效距离候选。

### 完整程序

输入 n m、带权有向边，容量 n<=2000、m<=50000、|w|<=10^5，输出 1 到 n 的最长权，无法到达 −1。额外检测 CYCLE 便于自设错误输入；官方保证 DAG 不会触发。教学样例不是官方样例。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 2000 + 5;
const long long NEG_INF = -(1LL << 60);
vector<pair<int, long long>> g[MAXN];
int indegree[MAXN];
long long dista[MAXN];

int main()
{
    int n, m;
    cin >> n >> m;
    for (int e = 0; e < m; e++)
    {
        int u, v;
        long long w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});
        ++indegree[v];
    }
    fill(dista, dista + n + 1, NEG_INF);
    dista[1] = 0;
    queue<int> q;
    for (int u = 1; u <= n; u++)
    {
        if (indegree[u] == 0)
        {
            q.push(u);
        }
    }
    int processed = 0;
    while (!q.empty())
    {
        int u = q.front();
        q.pop();
        ++processed;
        for (auto [v, w] : g[u])
        {
            if (dista[u] != NEG_INF)
            {
                dista[v] = max(dista[v], dista[u] + w);
            }
            --indegree[v];
            if (indegree[v] == 0)
            {
                q.push(v);
            }
        }
    }
    if (processed != n)
    {
        cout << "CYCLE\n";
    }
    else
    {
        cout << (dista[n] == NEG_INF ? -1 : dista[n]) << '\n';
    }
}
```

教学样例输入：

```text
3 3
1 2 -5
2 3 1
1 3 -10
```

输出：

```text
-4
```

所有前驱比当前点早完成，最优路线最后一条边来自某个前驱，取全部候选的最大值就得到最优。时间 O(n+m)，空间 O(n+m)。有限答案可能恰好是 −1，与不可达同数值是题面输出约定，不影响内部 −INF 的区分。

## 第三种优化路线：先缩点

若原图带环，问题允许反复经过点且非负点权只计一次，可先按 SCC 合并，构建 DAG 后对分量权递推，对应洛谷 P3387。这里不能为了套用 DAG 就任意压环：路径限制、负点权、只允许简单路径会改变“可把整个分量都收集”的前提。完整 SCC 程序与聚合条件见前章，组合步骤是“求分量→合并权→建跨分量边→全 DAG 拓扑递推”，应分别验证四步。
