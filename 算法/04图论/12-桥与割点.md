## 删除一条边或一个点会怎样

道路网络中某条边一旦损坏就让连通分量数增加，它是桥；某个点删除并移除全部关联边后让分量数增加，它是割点。二者针对无向图，与最小生成树中的“跨割候选边”不是同一个定义。

逐条删除再 BFS 要 O(m(n+m))；逐点删除要 O(n(n+m))。DFS 的 low 信息能一次看出“子树是否还有绕回上面的通路”。

## dfn 与 low 的含义

dfn[u] 是首次访问时间。low[u] 表示从 u 的 DFS 子树出发，沿树边向下走，再至多使用一条非父边返回，能到达的最小 dfn。树边 u→v 返回后用 low[v] 更新 low[u]；遇到已访问邻居用 dfn[v] 更新。

对于树边 u—v：若 low[v]>dfn[u]，v 子树不能绕回 u 或其祖先，删这条边必断开，所以是桥。非根点 u 若有孩子满足 low[v]>=dfn[u]，删 u 后该子树不能连向 u 的祖先，所以 u 是割点。等号意味着能绕回 u 本人：这足以让边不成为桥，却救不了被删除的 u。

DFS 根没有祖先，必须单独看树孩子数，至少两个才是割点；这里数的是 DFS 树孩子，不是原图度数。

## 手算与平行边

三角形 `1—2—3—1` 再接 `3—4`。回边 3—1 使 low[3]=dfn[1]，三角形内边都非桥；4 没有回边，low[4]>dfn[3]，3—4 是桥，3 是割点。根 1 只有一个 DFS 孩子，虽度数 2 也不是割点。

若 1 和 2 有两条平行边，删一条仍然连通，两条都不是桥。因此必须跳过“进入 u 的那条原始边 id”，不能跳过所有终点等于父亲的边。

## 完整教学模板

输入 `n m` 与 m 条无向边，原始边编号为读入顺序 1..m。输出桥数、每条桥 id（升序），然后割点数、每个割点（升序），各独占一行。`n<=2000,m<=10000`，允许自环和重边。本篇递归用于清楚展示返回更新，深度最多 n；扩大到 200000 点时应改为带进入、退出状态的显式栈，不能只扩大 MAXN。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 2000 + 5;
vector<pair<int, int>> g[MAXN];
int dfn[MAXN], low[MAXN], timer;
bool cut[MAXN];
vector<int> bridge_ids;

void dfs(int u, int parent_edge)
{
    dfn[u] = low[u] = ++timer;
    int children = 0;
    for (auto [v, id] : g[u])
    {
        if (id == parent_edge)
        {
            continue;
        }
        if (dfn[v] == 0)
        {
            ++children;
            dfs(v, id);
            low[u] = min(low[u], low[v]);
            if (low[v] > dfn[u])
            {
                bridge_ids.push_back(id);
            }
            if (parent_edge != 0 && low[v] >= dfn[u])
            {
                cut[u] = true;
            }
        }
        else
        {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (parent_edge == 0 && children >= 2)
    {
        cut[u] = true;
    }
}

int main()
{
    int n, m;
    cin >> n >> m;
    for (int id = 1; id <= m; id++)
    {
        int u, v;
        cin >> u >> v;
        g[u].push_back({v, id});
        g[v].push_back({u, id});
    }
    for (int i = 1; i <= n; i++)
    {
        if (dfn[i] == 0)
        {
            dfs(i, 0);
        }
    }
    sort(bridge_ids.begin(), bridge_ids.end());
    cout << bridge_ids.size() << '\n';
    for (int id : bridge_ids)
    {
        cout << id << '\n';
    }
    vector<int> cuts;
    for (int i = 1; i <= n; i++)
    {
        if (cut[i])
        {
            cuts.push_back(i);
        }
    }
    cout << cuts.size() << '\n';
    for (int u : cuts)
    {
        cout << u << '\n';
    }
}
```

教学样例输入：

```text
4 4
1 2
2 3
3 1
3 4
```

输出：

```text
1
4
1
3
```

## 正确性与复杂度

树边和回边的更新覆盖 low 定义中的所有选择。无向 DFS 不存在不同已完成子树之间的横叉连接，否则先访问的子树会沿那条边发现另一侧；所以是否越过父节点由上述 low 条件完整决定。DFS 判定 O(n+m)，本程序为按序输出桥另排序 O(b log(b+2))，b 是桥数；总空间 O(n+m)。不连通图逐根启动，孤立点删掉后分量数减少而非增加，因此不是割点。

## 扩展选读

去掉桥后可得到边双连通块，压成桥树；按割点划分点双连通块可构建圆方树。它们与有向 SCC 不同，SCC 的栈和无向 low 的父边处理不能直接混用，后续按题目需要学习。
