## 两种问题：能否分组，最多配多少对

二分图把点分为左右两侧，所有边都跨侧。染色问题给一般无向图，问能否这样分；匹配问题已给两侧及允许配对的边，问最多选多少条互不共享端点的边。能二分不代表可以完美匹配；两者状态和输出不同。

### 染色从局部约束到奇环

取一个未染色点为颜色 1，邻居必须为颜色 2，再交替传播。一条偶环可交替闭合，奇环闭合时必然遇到同色边。反之若所有边两端异色，按颜色直接得到二分划分。每个连通分量都需启动，自环立即冲突。

例：边 `1—2,2—3,3—4,4—1` 得颜色 `1,2,1,2`。增加 `1—3` 后这条边两端同色，且出现三角形，输出 NO。

输入 `n m` 与无向边，`n,m<=200000`。输出 NO 或 YES 加每点颜色（不要求唯一）。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200000 + 5;
vector<int> g[MAXN];
int color[MAXN];

bool check_component(int start)
{
    queue<int> q;
    color[start] = 1;
    q.push(start);
    while (!q.empty())
    {
        int u = q.front();
        q.pop();
        for (int v : g[u])
        {
            if (color[v] == 0)
            {
                color[v] = 3 - color[u];
                q.push(v);
            }
            else if (color[v] == color[u])
            {
                return false;
            }
        }
    }
    return true;
}

int main()
{
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++)
    {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    for (int i = 1; i <= n; i++)
    {
        if (color[i] == 0 && !check_component(i))
        {
            cout << "NO\n";
            return 0;
        }
    }
    cout << "YES\n";
    for (int i = 1; i <= n; i++)
    {
        cout << color[i] << (i == n ? '\n' : ' ');
    }
}
```

教学样例输入：

```text
4 4
1 2
2 3
3 4
4 1
```

输出：

```text
YES
1 2 1 2
```

染色 O(n+m) 时间、O(n+m) 总空间。若边为有向“互斥”关系，应按互斥的无向语义处理；有向图的有向环不是这里的奇环条件。

## 匹配为什么不能只挑空闲邻居

左点 L1、L2，右点 R1、R2；边 `L1—R1,L1—R2,L2—R1`。先让 L1 占 R1 后，L2 看似没空邻居，但可以把 L1 改配 R2，让 L2 配 R1。交替使用未选边、已选边、未选边的路径能增加一条匹配，称增广路。

match_right[v] 表示右点 v 当前属于哪个左点。augment(u) 尝试为 u 找位置：空右点直接占用；非空则递归为原占用者找新位置，成功后才覆盖当前匹配。seen_right 是本次尝试访问过的右点，每个新左点启动前必须清空，防止环状递归和重复尝试。

### 完整增广路模板

输入 `nl nr m` 和 m 条 `左编号 右编号`，两侧分别从 1 编号，`nl,nr<=500,m<=20000`。输出最大匹配边数；本输入已保证边跨侧，不先做染色。递归深度不超过左侧点数，小容量下使用递归；更大匹配应学 Hopcroft-Karp。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 500 + 5;
vector<int> g[MAXN];
int match_right[MAXN];
bool seen_right[MAXN];

bool augment(int u)
{
    for (int v : g[u])
    {
        if (seen_right[v])
        {
            continue;
        }
        seen_right[v] = true;
        if (match_right[v] == 0 || augment(match_right[v]))
        {
            match_right[v] = u;
            return true;
        }
    }
    return false;
}

int main()
{
    int nl, nr, m;
    cin >> nl >> nr >> m;
    for (int i = 0; i < m; i++)
    {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
    }
    int answer = 0;
    for (int u = 1; u <= nl; u++)
    {
        fill(seen_right, seen_right + nr + 1, false);
        if (augment(u))
        {
            ++answer;
        }
    }
    cout << answer << '\n';
}
```

教学样例输入：

```text
2 2 3
1 1
1 2
2 1
```

输出：

```text
2
```

## 为什么没有增广路就最大

把当前匹配与某个更大匹配放在一起，每点在这两组边中的度数至多 2，因此它们的差异形成交替路径或环。更大匹配多出的边必落在一条以未匹配端点开始和结束的交替路径上，正是一条增广路。故若找不到增广路，不能有更大的匹配。逐个左点扩充已处理子图的最大匹配，每次新点只可能让答案增加 1。

模板最坏 O(nl·(m+nr))，每次清空 nr 个标记并扫描至多 m 条边，常写 O(nl·m)（非空且 m 主导时）；总空间 O(nl+nr+m)。最大匹配不是最大权匹配；给边收益后不能按收益排序贪心套用此程序。

## 扩展选读

Kőnig 定理：二分图最小点覆盖数等于最大匹配数。最大独立集大小等于总点数减最小点覆盖数，但图不是二分图时不能用匹配数代替一般点覆盖数。Hopcroft-Karp 与带权匹配属于后续选学。
