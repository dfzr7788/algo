## 为什么遍历要有访问状态

从每个点枚举相邻点，若无访问标记，边 `1—2` 就会让搜索不断往返。DFS 用栈保存待探索点，倾向于深入；BFS 用队列保存待扩展点，按离源点的边数分层。两者都能判断可达，只有 BFS 的首次发现距离直接保证无权最短路。

不要把遍历访问标记与回溯搜索混淆：枚举所有简单路径可能在退出时撤销标记，普通可达性遍历不撤销，否则会重复大量状态。

## DFS：连通分量

图有 `1—2,2—3,4—5`。从 1 出发访问 1、2、3 得大小 3；外层继续找未访问点，从 4 出发得到 2。只从 1 开始无法发现第二个分量。下面是显式栈的可达性 DFS，入栈即标记，保证每个点只压一次。它不模拟递归退出事件；需要后序计算时见树的遍历章。

输入无向图 `n m` 和 m 条边，输出分量数，然后每个分量大小，按最小编号启动次序。`1<=n<=200000,m<=200000`，允许孤立点、重边、自环。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200000 + 5;
vector<int> g[MAXN];
bool seen[MAXN];

int component_size(int start)
{
    stack<int> st;
    st.push(start);
    seen[start] = true;
    int total = 0;
    while (!st.empty())
    {
        int u = st.top();
        st.pop();
        ++total;
        for (int v : g[u])
        {
            if (!seen[v])
            {
                seen[v] = true;
                st.push(v);
            }
        }
    }
    return total;
}

int main()
{
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++)
    {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    vector<int> sizes;
    for (int i = 1; i <= n; i++)
    {
        if (!seen[i])
        {
            sizes.push_back(component_size(i));
        }
    }
    cout << sizes.size() << '\n';
    for (int s : sizes)
    {
        cout << s << '\n';
    }
}
```

教学样例输入：

```text
5 3
1 2
2 3
4 5
```

输出：

```text
2
3
2
```

## BFS：从最少边数推导分层

源点距离为 0，第一次发现的邻居距离为 1。队首距离为 k 时，队列里尚未处理的点距离只会是 k 或 $k+1$；因此先发现的路线不会比以后发现的路线更长。距离数组 −1 同时表示未发现和不可达，必须在入队时更新，而不是等出队再标记。

对 `1—2,1—3,2—4,3—4`，初始队列 `[1]`；扩展 1 得 `[2,3]`；扩展 2 发现 4 得 `[3,4]`；扩展 3 时 4 已被发现，无需再进队，$\mathrm{dist}[4]=2$。

输入无向图 `n m s`，随后 m 条边，输出 s 到 $1\ldots n$ 的最少边数，不可达为 −1。容量同上。parent_node 保存一条最短路径的前驱；沿目标回溯到 s 再反转即可输出路径，但不保证字典序最小。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200000 + 5;
vector<int> g[MAXN];
int dista[MAXN], parent_node[MAXN];

void bfs(int n, int s)
{
    fill(dista, dista + n + 1, -1);
    queue<int> q;
    dista[s] = 0;
    q.push(s);
    while (!q.empty())
    {
        int u = q.front();
        q.pop();
        for (int v : g[u])
        {
            if (dista[v] == -1)
            {
                dista[v] = dista[u] + 1;
                parent_node[v] = u;
                q.push(v);
            }
        }
    }
}

int main()
{
    int n, m, s;
    cin >> n >> m >> s;
    for (int i = 0; i < m; i++)
    {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    bfs(n, s);
    for (int i = 1; i <= n; i++)
    {
        cout << dista[i] << (i == n ? '\n' : ' ');
    }
}
```

教学样例输入：

```text
5 4 1
1 2
1 3
2 4
3 4
```

输出：

```text
0 1 1 2 -1
```

## 正确性与复杂度

访问标记保证每点至多一次；每点处理时枚举自己的全部邻接记录，所以邻接表上 DFS、BFS 都为 $O(n+m)$ 时间、$O(n+m)$ 总空间，辅助栈或队列 $O(n)$。若改为矩阵，枚举邻居变为 $O(n^{2})$。DFS 递归深度在链上可能为 n，C++ 不保证能承受 200000 层，模板用显式栈规避。

多源 BFS 把所有源点距离设为 0 并一起入队，求到最近源的距离。网格 BFS 只生成合法邻居而不显式存边，必须检查越界与障碍。边权不等时首次到达不再保证最短，见 Dijkstra 及 0-1 BFS。

## ABC453D Go Straight

[官方题面](https://atcoder.jp/contests/abc453/tasks/abc453_d)

网格中 o 必须沿进入方向继续走，x 必须改变方向（允许掉头），求 S 到 G 的可行路线，长度不超过 5×10⁶；H,W≤1000。

> [!tip]- 提示一
> 同一格从不同方向进入，后续可走的边并不相同。

> [!tip]- 提示二
> 把进入方向加入状态；起点用第五种“尚无方向”状态，并记录前驱恢复路线。
>
> 复习：[[04图论/03-DFS与BFS]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码以 `(x,y,dir)` 入队，dir=0..3 表示最后一步，起点 dir=4。出队后按当前格类型筛选下一步，再检查边界、墙和 `vis[nx][ny][k]`。首次发现合法状态就记录 `par` 与 `moves`；到 G 后沿前驱走回起点并反转字符。
>
> **正确性与适用条件。** 所有影响未来选择的信息都包含在位置和进入方向中，其他历史不影响合法性，因此可合并同状态。每条状态边就是一次合法移动，状态路径与实际路线相互对应。BFS 首次发现给出最短状态路径，长度小于状态数上界 4HW+1，因此满足官方输出长度限制。
>
> **手算与边界。** 一行网格 SxG：从 S 向右到 x 后不能继续向右，只能向左退回 S，最终无解；一行 SoG 则可沿 RR 到达。若只给格子做访问标记，会丢掉其他方向进入后的不同后继。
>
> **实际复杂度与实现。** 至多 4HW+1 个状态，每个考察四方向，时间和有效空间均 O(HW)。源码固定数组按 1005×1005×5 分配，par 含三个 int，不能只按一个 visited 数组估计内存。

## 牛客137267D 走迷宫

[官方题面](https://ac.nowcoder.com/acm/contest/137267/D)

a×b矩形角色整体平移，不能碰墙或越界，S、E标记身体左上角，判断能否到达；起终区域保证合法。

> [!tip]- 提示一
> 角色形状不变，只需记录左上角，不能把它当一个格子的角色。

> [!tip]- 提示二
> 把障碍做二维前缀和，每次O(1)判断整个身体区域。
>
> 复习：[[04图论/03-DFS与BFS]]。

> [!example]- 详细题解
> **建模与源码主线。** 源码sum存墙格前缀和，状态(x,y)占[x,x+a−1]×[y,y+b−1]。DFS枚举四个新左上角，先确保整个矩形在地图内，再用四次前缀相减判断墙数为0。vis记录左上角状态，dfs到E的左上角即成功。
>
> **正确性与适用条件。** 一个左上角唯一确定整个身体，不同到达历史不影响下一步合法性。一次平移只要新区域没有障碍且不越界，就是合法动作；隐式状态图的边与实际移动一一对应，遍历所有可达状态即可判定。
>
> **手算与边界。** 角色宽2，要穿过仅宽1的竖直通道，即使左上角的路径全为点也不能通过；区域和检查会发现身体另一列压到墙。S与E是左上角目标，不是只要求身体某部分覆盖E。
>
> **实际复杂度与实现。** 前缀和与搜索O(NM)，空间O(NM)，源码递归深度最坏同阶。源码先读vis[nx][ny]再检查范围，目前固定数组留边界但写法脆弱，建议逻辑上先界内再访问；重复的墙判断可删但不影响结果。
