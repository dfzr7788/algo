## 三种存储分别解决什么问题

同一张图可以按“点对”或“每个点的出边”存储。矩阵查 `u,v` 是否相邻只需一次访问，但枚举 u 的邻居要扫 n 列。邻接表直接存真正的出边，适合遍历；检查某指定点对通常需扫描 `degree(u)` 条记录。链式前向星也是邻接表，只是用数组编号模拟链表。

| 表示 | 初始化与空间 | 加一条记录 | 枚举 u 的邻居 | 查点对 |
|---|---|---|---|---|
| 矩阵 | O(n²) | O(1) | O(n) | O(1) |
| vector 邻接表 | O(n+m) 空间 | 均摊 O(1) | O(degree(u)) | O(degree(u)) |
| 链式前向星 | O(n+m) 空间 | O(1)，预分配 | O(degree(u)) | O(degree(u)) |

链式前向星避免逐条分配，但不保证比 vector 更快：同一顶点的边在数组中未必连续，vector 的邻居连续布局也有优势。固定容量分配量按 MAXN、MAXE 计，不是按实际输入自动精准分配。

## 邻接矩阵：零边与重边

下面是局部片段，依赖 `n<=500`、`u,v∈[1,n]`、`|w|<=10^9`。每次新图重新初始化；对角线 0 表示长度为 0 的空路径，不代表真的存在自环。最短路保留重边的最小权；如果统计边数，不能这样压缩。

```cpp
const long long INF = (1LL << 60);
long long adj[505][505];

void init_matrix(int n)
{
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= n; j++)
        {
            adj[i][j] = (i == j ? 0 : INF);
        }
    }
}

void add_matrix_edge(int u, int v, long long w)
{
    adj[u][v] = min(adj[u][v], w);
}
```

有向边只更新一次；无向边再更新 `adj[v][u]`。完整矩阵程序见 Floyd 章。

## vector 邻接表

局部片段依赖 `n<=200000`，每个 `pair` 记录终点和边权。无向边加两次。多测调用 `g[i].clear()`；零权、自环、重边均能保留。完整用法见 Dijkstra 章。

```cpp
vector<pair<int, long long>> g[200005];

void add_list_edge(int u, int v, long long w)
{
    g[u].push_back({v, w});
}
```

## 链式前向星：头插过程

初始 `head[1]=0,cnt=0`。先加 `1→2`：边号 1 的 nxt=0，head[1]=1。再加 `1→3`：边号 2 的 nxt=1，head[1]=2。沿 `2→1→0` 枚举，得到邻居 3、2，顺序与读入相反。`to[e]` 是终点编号，`e` 是边记录编号，两者不能混用。

`add_edge` 先申请新编号，再把它链接到旧表头。这里 0 是哨兵、边号从 1 开始；因此不能直接用 `e^1` 找反向边。若要异或配对，可改为边号从 0 开始、表头以 −1 为空，或边号从 2 开始且正反连续加入；必须整套统一。

### 完整教学程序

输入 `n m s`，随后 m 条无向带权边，输出 s 的邻居及边权，按头插后的顺序。`1<=n<=200000,m<=200000,|w|<=10^9`；MAXE 要容纳 2m 条记录加哨兵。全局数组首次为 0；多测应清空 head 并将 cnt 归零。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200000 + 5;
const int MAXE = 400000 + 5;
int head[MAXN], to[MAXE], nxt[MAXE], cnt;
long long weight[MAXE];

void add_edge(int u, int v, long long w)
{
    ++cnt;
    to[cnt] = v;
    weight[cnt] = w;
    nxt[cnt] = head[u];
    head[u] = cnt;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, s;
    cin >> n >> m >> s;
    for (int i = 0; i < m; i++)
    {
        int u, v;
        long long w;
        cin >> u >> v >> w;
        add_edge(u, v, w);
        add_edge(v, u, w);
    }
    for (int e = head[s]; e != 0; e = nxt[e])
    {
        cout << to[e] << ' ' << weight[e] << '\n';
    }
}
```

教学样例输入：

```text
3 2 1
1 2 5
1 3 0
```

输出：

```text
3 0
2 5
```

## 正确性、复杂度与易错点

每条边只改变起点的表头，并保留原链作为后继，所以旧边不丢失。建图 O(n+m)，枚举全部记录 O(n+m)，固定数组实际空间取决于容量。删除边可用标记跳过，但不会回收容量；不能对有向图额外加反向边，也不能把无向边容量仍开成 m。
