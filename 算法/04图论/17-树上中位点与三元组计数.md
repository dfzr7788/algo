## 三条路径共同经过的唯一交点

树上三个不同点 u、v、w 的两两简单路径有唯一公共点 c，称它们的中位点。把三条路径合起来是三叉形或某一分支长度为 0 的退化形。c 依赖这三个点，与整树的中心、重心不同，也不是任意选择根得到的 $LCA(u,v)$ 本身。

任意定根后，求 $LCA(u,v)$、$LCA(v,w)$、$LCA(w,u)$，其中深度最大的就是 c；三个候选中浅的两个相同或三个都相同。若输入点可重复，需要单独明确题意，本章计数要求三个不同点。

## 原有题解的模型与条件

[Codeforces 2241E — Fair and Square](https://codeforces.com/contest/2241/problem/E) 给每个树点正整数 $a_{i}$，问无序三元组 {u,v,w} 的两两路径点值乘积相乘后为完全平方数的数量。路径包含两端。官方范围：$3\le n\le 200000$，$1\le a_i\le 10^{6}$，所有测试 n 的总和 $\le 200000$。

令 $B_{u}$ 为 u 到 c 的分支上**不含 c**的点值乘积，其余两支同理。若某点就是 c，对应 $B=1$。则

$$
p(u,v)=B_uB_va_c,\qquad
p(v,w)=B_vB_wa_c,\qquad
p(w,u)=B_wB_ua_c.
$$

因此

$$
P=a_c^3(B_uB_vB_w)^2
 = a_c(a_cB_uB_vB_w)^2.
$$

正整数各质因子指数中，除了 c 之外都出现偶数次，所以 P 是平方数当且仅当 $a_{c}$ 是平方数。这个结论依赖正整数条件：如果允许 0，某个分支出现 0 就让 $P=0$，不能只看 c；负数还涉及符号。本题无需实际计算巨大乘积，也无需对每个点值分解质因数。

## 从枚举三元组转为枚举中位点

暴力枚举 $C(n,3)$ 个三元组，再求路径信息，$n=200000$ 完全不可行。每个三元组的 c 唯一，反过来枚举平方点 c，统计多少三元组以它为中位点。

删掉 c 后的连通块大小为 $s1\ldots sk$，再把 c 自己视作大小 $s0=1$ 的一组。三点以 c 为中位点，当且仅当它们来自三组不同的组：若两个来自同一个删点分量，它们之间的路径不会经过 c；若三组不同，两两路径必须经过 c。因为自身组只有一个点，不会重复选 c。

所需数量是 `sum(s_x*s_y*s_z)`，$x<y<z$。星形 $n=4$，中心 c 的组大小为 1、1、1、1，贡献 $C(4,3)=4$：三个叶子的三元组以及含中心加两个叶子的三元组均符合，不能漏掉中心自己。

## 顺序累计 e1、e2、e3

已处理组的 e1 为选一个点数量，e2 为选两组各一个点数量，e3 为选三组各一个点数量。加入大小 s 的新组：先 `e3+=e2*s`，再 `e2+=e1*s`，最后 `e1+=s`。更新必须从三元到一元，反过来会把新组重复选入同一组合。

例：先处理自身组，$(e1,e2,e3)=(1,0,0)$；加第一片大小 2 后为 $(3,2,0)$；再加大小 3 后为 $(6,11,6)$。三组大小 1、2、3，三元组确实只有 $1\times 2\times 3=6$。

## 完整改进实现

输入输出遵循该平台题的多测格式：t，每组 n、n 个正点值、$n-1$ 条边，输出答案。定根和子树大小迭代处理，避免长链递归；平方检测先 sqrtl 再整数校正，当前 $x\le 10^{6}$，校正乘法不会溢出。答案至多 $C(200000,3)<1.34\times 10^{15}$，long long 足够。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200000 + 5;
vector<int> g[MAXN];
int parent_node[MAXN], size_node[MAXN];
long long value[MAXN];

bool is_square(long long x)
{
    long long r = sqrtl((long double)x);
    while ((r + 1) * (r + 1) <= x)
    {
        ++r;
    }
    while (r * r > x)
    {
        --r;
    }
    return r * r == x;
}

void solve()
{
    int n;
    cin >> n;
    for (int u = 1; u <= n; u++)
    {
        cin >> value[u];
        g[u].clear();
        parent_node[u] = 0;
        size_node[u] = 1;
    }
    for (int i = 1; i < n; i++)
    {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    vector<int> order = {1};
    for (int index = 0; index < (int)order.size(); index++)
    {
        int u = order[index];
        for (int v : g[u])
        {
            if (v != parent_node[u])
            {
                parent_node[v] = u;
                order.push_back(v);
            }
        }
    }
    for (int index = n - 1; index > 0; index--)
    {
        int u = order[index];
        size_node[parent_node[u]] += size_node[u];
    }
    long long answer = 0;
    for (int u = 1; u <= n; u++)
    {
        if (!is_square(value[u]))
        {
            continue;
        }
        // 将 u 自身视为大小 1 的一组；e1,e2,e3 是已扫组的选择数。
        long long e1 = 1;
        long long e2 = 0;
        long long e3 = 0;
        for (int v : g[u])
        {
            long long s = (parent_node[v] == u ? size_node[v] : n - size_node[u]);
            e3 += e2 * s;
            e2 += e1 * s;
            e1 += s;
        }
        answer += e3;
    }
    cout << answer << '\n';
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--)
    {
        solve();
    }
}
```

教学样例输入：

```text
2
3
1 1 1
1 2
2 3
3
1 2 1
1 2
2 3
```

输出：

```text
0
```

## 正确性与复杂度

每个三元组恰好归属一个中位点；平方条件与中心点值等价；分组选择与中位点定义等价；累计式逐组计入首次包含新组的组合，所以无漏计或重复。子树信息 $O(n)$，各点邻接表总长 $2(n-1)$，贡献计算 $O(n)$，本题点值范围的平方检测可视作 $O(1)$，总时间 $O(n)$、空间 $O(n)$。

## 扩展选读：保留牛顿恒等式的原推导

原笔记用 [[18-牛顿恒等式与对称和]] 计算相同的三阶初等对称和。包括自身组后，$p1=sum s=n$，$p2=sum s^{2}$，$p3=sum s^{3}$；

$$
e_1=p_1,\qquad
e_2=\frac{e_1p_1-p_2}{2},\qquad
e_3=\frac{e_2p_1-e_1p_2+p_3}{3}.
$$

它同样按每个 c 的度数线性计算。当前 n 范围的 $n^{3}$ 及这些中间式可由 long long 容纳，但顺序累计更直接且不需要立方与整除。更大容量应重新估计中间值，而不只估计最终答案。

## 原有解题记录

原记录的原理和牛顿恒等式已整理到正文。以下保留原程序，原笔记标为“AC代码”；本轮没有访问提交记录核实这个标签，也没有进行平台提交。它在长链上有递归深度风险，sqrt 未作整数校正，主学习模板建议使用上面的迭代版本。原程序代码内容保留，仅补齐了单行条件语句的大括号并统一代码格式。

```cpp
#include <bits/stdc++.h>
using namespace std;
#define ll long long
ll n;
ll a[200005];
ll head[400005];
ll nxt[400005];
ll to[400005];
ll sz[200005];
ll father[200005];
ll cnt = 1;
void addedge(ll u, ll v)
{
    nxt[cnt] = head[u];
    to[cnt] = v;
    head[u] = cnt++;
}
void dfs(ll u, ll fa)
{
    sz[u] = 1;
    father[u] = fa;
    for (ll ei = head[u]; ei > 0; ei = nxt[ei])
    {
        if (to[ei] != fa)
        {
            dfs(to[ei], u);
            sz[u] += sz[to[ei]];
        }
    }
}
bool issquare(ll i)
{
    ll r = sqrt(i);
    return r * r == i;
}
void solve()
{
    cin >> n;
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
        head[i] = 0;
    }
    cnt = 1;
    for (int i = 1, u, v; i < n; i++)
    {
        cin >> u >> v;
        addedge(u, v);
        addedge(v, u);
    }
    dfs(1, 0);
    ll ans = 0;
    for (int i = 1; i <= n; i++)
    {
        if (issquare(a[i]))
        {
            ll p1 = n;
            ll p2 = 1;
            ll p3 = 1;
            for (int ei = head[i]; ei > 0; ei = nxt[ei])
            {
                ll s = 0;
                if (to[ei] == father[i])
                {
                    s = n - sz[i];
                }
                else
                {
                    s = sz[to[ei]];
                }
                p2 += s * s;
                p3 += s * s * s;
            }
            ll e1 = p1;
            ll e2 = (e1 * p1 - p2) / 2;
            ll e3 = (e2 * p1 - e1 * p2 + p3) / 3;
            ans += e3;
        }
    }
    cout << ans << '\n';
}
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--)
    {
        solve();
    }
}
```
