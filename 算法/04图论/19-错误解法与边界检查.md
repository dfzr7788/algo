## 用反例定位错误

| 错误 | 最小输入或情境 | 为什么错、如何修正 |
|---|---|---|
| 有向边加两次 | 只有 1→2，查询 2 到 1 | 原本不可达，不能自动补反向边 |
| 权值 0 代表没边 | 1→2 权 0 | 零代价可达，缺边要用独立标记或 INF |
| BFS 求任意权最短路 | 1→2(10),1→3(1),3→2(1) | 最少边数不是最小总权，用 Dijkstra |
| 入堆即永久访问 | 上一行同图 | 2 首次入堆为 10，还能改成 2 |
| INF 直接加负权 | 源 1 孤立，2→3(−1) | $INF-1$ 看似更小，先确认出发点有限 |
| 单源判负环等于全图判负环 | 1 孤立，2 有负自环 | 从 1 看不到 2，全图需超级源 |
| SPFA 统计松弛次数判环 | 1→2 多条递减正权重边 | 没环也可连续改善很多次，使用路线边数 |
| SPFA 永久 visited | 1→2(2),1→3(5),3→2(−10),2→4(1) | 2 需再次传播 −5，队列标记出队后清除 |
| Floyd 对重边覆盖最后值 | 1→2 先权 1 再权 9 | 应保留最小边 1 |
| Floyd 循环顺序随便换 | 1→3→4→2，各权 1 | i 外层单轮可能在 1→4 被补齐前已错过 1→2 |
| Prim 用累计路径权更新 | 三角形 1—2(2),1—3(2),2—3(1) | Prim best 是跨界单边，$MST=3$ |
| 拓扑排序只看有输出 | 1 孤立，2↔3 | 只输出 1 不能算成功，要检查输出数 n |
| 每点作为源都搜索一次 | 有向长链 | 能做反图降序传播的问题不要 $O(n^{2})$ 重搜 |
| 树只跳父亲用于一般图 | 三角形 | 会经非父边重新发现点，普通图加访问状态 |
| 割点根按普通点条件 | 两点一条边 | 根只有一个 DFS 孩子，不是割点 |
| 桥检查跳过所有父亲边 | 两点两条平行边 | 另一条是回路，按边 id 跳进入边 |
| 忘掉重心的父亲方向 | 链的叶点 | balance 不是 0，是 $n-1$ |
| 树中心等同重心 | 1—2—3—4—5，1 接三叶 | 中心 2、3，重心 1、2 |
| 任意树两次远点求直径 | 允许负权边 | 非负权前提被破坏，改树形 DP 并明确空路径 |
| 中位点计数忘 c 自身 | 三点链 | 唯一三元组包含中间点，还需大小 1 的自身组 |
| 更新 e1 后再更新 e2、e3 | 分组大小 1、2、3 | 同一新组会被重复使用，应 e3→e2→e1 |
| 平方中位点条件忽略 0 | 分支存在 0，中心值 2 | 整体乘积为 0，是平方；原推导要求正数 |

## 模板提交前检查表

1. 写清点编号、输入方向、权值范围、是否允许重边、自环、负环，以及允许重复行走还是简单路径。
2. 无向图邻接记录为 2m，静态容量加哨兵。LOG 覆盖最大深度差，long long 既能装最终值也能装中间候选。
3. 单点、孤立点、不连通、重边、零权、自环各按算法合同检查；树模板只接收合法树。
4. 多测不仅清距离，还需清 head/cnt、邻接表、入度、done、父节点、分量、全局时间等状态。本模块除中位点程序外，完整模板默认单组。
5. 先跑示例，再用小图独立暴力对拍。构造输出如拓扑序、染色、分量编号，验证约束和分组关系，不要求与另一个程序字符串完全相同。
6. 教学不可达标记和平台输出可能不同；代码编译、随机检查不等于已在平台 AC。

## 可独立构造的对拍模型

- 最短路：小图 Floyd 或按边数 Bellman-Ford，与堆最短路、0-1 BFS 对比；负环只比较合同明确的结果。
- 最小生成树：小图枚举所有 $n-1$ 条边子集，检查连通并求最小总权；不只用两个相近贪心互比。
- 染色：枚举 $2^{n}$ 个颜色划分；匹配：枚举每个左点配哪个空右点。
- SCC：每点独立搜索，检查两点分量相同当且仅当互达。
- 桥与割点：删除对应原边 id 或顶点，重新统计分量数；覆盖平行边。
- 树：每点 BFS 求两点距离和最大距离，删除点统计最大分量；LCA 用父亲逐层提升对比。
- 中位点：小树枚举三元组，真实计算三条路径点值乘积，用任意精度整数判断平方，避免验证器本身溢出。
