## 算法选择与边界

| 需求 | 先看 | 关键条件 |
|---|---|---|
| 可达性、普通无向分量 | DFS / BFS | 不要漏不可达分量 |
| 最少步数 | BFS | 所有边等价；多源可一起入队 |
| 非负最短路 | $\mathrm{Dijkstra} / 0-1 BFS$ | 0-1 BFS 只允许两种权值 |
| 负边、负环 | Bellman-Ford / SPFA | 单源负环与全图负环区别 |
| 所有点对距离 | Floyd | 平方空间、立方时间，无负环模板 |
| 依赖调度 | 拓扑排序 | 输入为有向图，判环后再做 DAG 递推 |
| 最小总成本连通 | MST | 无向图；不等于最短路树 |
| 两类配对 | 二分图与匹配 | 染色与最大匹配是不同问题 |
| 有向互达集合 | SCC | 缩点聚合信息需额外条件 |
| 删除道路或节点的影响 | 桥与割点 | 无向边 id 处理平行边 |
| 路径最远距离 / 切分点数 | 直径中心 / 重心 | 目标不同 |
| 重复查询树路径 | LCA | 先定根，距离与深度区分 |

## 评分尺度

评分是本项目学习路线的主观建议，不是平台官方评级或题目频率统计。难度和重要程度分别为 1–10，难不自动意味着重要。

- 难度：1–3 基础操作；4–6 状态、不变量与实现边界；7–8 多机制组合；9–10 高阶算法或理论。选读高级证明不全部计入入门难度。
- 重要程度：9–10 优先熟练；7–8 主线；5–6 按需；1–4 后置。结合基础性、应用范围、后续依赖与复用价值。
- 合并篇中每种算法独立评分；题单、反例、综合练习不对整页打混合分。标为后续选学的专题不代表已有完整教程。

## 阅读、代码与验证约定

正文先说明用途、适用条件与暴力瓶颈，再讲状态、手算示例、完整模板和正确性。详细进阶机制在篇末选读。完整程序写出输入范围、下标、容量、类型、输出；局部片段明确依赖，不能作为完整提交程序。教学样例不同于官方样例，不会宣称未经提交的代码已 AC。

代码四空格缩进、左花括号单独一行、一条语句一行，优先静态数组和具名函数；允许必要的标准库容器。默认只处理一组，需多测时清全部状态。桥与匹配的递归模板限制在较小容量，其他长链敏感模板优先显式栈或遍历顺序。

总空间复杂度按有效图规模描述，固定数组实际分配量仍取决于 MAXN、MAXE、LOG。比较算法时分清最坏、摊还与需要前提的经验效果。
