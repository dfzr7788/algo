## 最远的一对点与最好的服务点

树的直径是最大两点距离，树的中心是让“到所有点的最远距离”最小的点。例如给树上所有住户提供统一服务，追求最坏路程最小，就需要中心。逐点 BFS 求离心率要 O(n²)，直径端点提供一个线性捷径。

本章主模板为**无权树，距离是边数**。有负边时，两次最远点遍历不保证直径；带权中心若允许选在边内部，还可能不是顶点，不能用路径中间下标直接取。

## 两次遍历与手算

从任意点 s 求一个最远点 a，再从 a 求最远点 b，a—b 是一条直径。树中路径唯一，BFS 用于无权距离；非负带权树可通过父子遍历累计边权，不需要 Dijkstra。

链 `1—2—3—4—5`，从 3 找到的最远点可以是 1；从 1 找到 5，直径长度 4。路径上正中为 3，中心只有一个，半径 2。链只有 4 点时直径长度 3，中心为 2、3，半径 2。

保存第二次遍历的 parent，从 b 回溯到 a 得直径路径。注意长度是边数 D，路径含 D+1 个点；D 偶数取一个中点，D 奇数取相邻两个中点。

## 完整模板

输入 n 和 n−1 条无向边，保证树，`1<=n<=200000`。第一行输出直径边数，第二行输出所有顶点中心（升序）。单点树输出长度 0、中心 1。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200000 + 5;
vector<int> g[MAXN];
int dista[MAXN], parent_node[MAXN];

int farthest(int n, int s)
{
    fill(dista, dista + n + 1, -1);
    queue<int> q;
    q.push(s);
    dista[s] = 0;
    parent_node[s] = 0;
    int endpoint = s;
    while (!q.empty())
    {
        int u = q.front();
        q.pop();
        if (dista[u] > dista[endpoint])
        {
            endpoint = u;
        }
        for (int v : g[u])
        {
            if (dista[v] == -1)
            {
                dista[v] = dista[u] + 1;
                parent_node[v] = u;
                q.push(v);
            }
        }
    }
    return endpoint;
}

int main()
{
    int n;
    cin >> n;
    for (int i = 1; i < n; i++)
    {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    int a = farthest(n, 1);
    int b = farthest(n, a);
    vector<int> path;
    for (int u = b; u != 0; u = parent_node[u])
    {
        path.push_back(u);
    }
    int length = dista[b];
    cout << length << '\n';
    vector<int> centers;
    centers.push_back(path[length / 2]);
    if (length % 2 == 1)
    {
        centers.push_back(path[length / 2 + 1]);
    }
    sort(centers.begin(), centers.end());
    for (int i = 0; i < (int)centers.size(); i++)
    {
        cout << centers[i] << (i + 1 == (int)centers.size() ? '\n' : ' ');
    }
}
```

教学样例输入：

```text
5
1 2
2 3
3 4
4 5
```

输出：

```text
4
3
```

## 正确性与复杂度

树的唯一通路与非负边权使从任意点取得的最远点可以成为某条直径端点；再从该端点取得全树最远点就是直径另一端。这里并不要求直径唯一；任选距离并列的最远点均可。

对无权树的一条直径端点 a、b，有 `ecc(v)=max(dist(v,a),dist(v,b))`。所以任何点到两端的最大距离至少 ceil(D/2)，而直径中点能达到这个下界，得到半径 ceil(D/2)。离开直径中点增加到某一端的路程，不会产生更好的顶点中心。

两次 BFS 与路径恢复 O(n)，空间 O(n)。两端各求完整距离数组，还可在线性时间得到每点离心率。中心优化最远距离；重心优化删点后的最大分量规模，下一章单独解释。

## 扩展选读：负权树与直径端点性质

负权会破坏“最远点是端点”的性质，例如长正路径被大负边隔开，第一次搜索可能停在另一侧。树形 DP 可以每点保存向下最大、次大链再合并，但需先明确是否允许空路径；全负且必须两点不同的答案应是某条负边，不能用 0 替代。

下面给出端点性质的分情况证明，不依赖直径唯一。固定任意直径 x—y，长度 D，以搜索起点 s 定根，令 t=LCA(x,y)，depth 表示到 s 的距离。a 是距 s 最远点，所以 depth[a]>=depth[x] 且 depth[a]>=depth[y]。

1. 若 a 不在 t 的子树，令 z=LCA(a,t)，z 是 t 的祖先。由非负权，depth[z]<=depth[t]，于是 `dist(a,x)=depth[a]+depth[x]−2depth[z]>=depth[y]+depth[x]−2depth[t]=D`。
2. 若 a 在 t 的子树，x、y 位于 t 的不同孩子分支（或者一个就是 t），至少有一个端点，例如 x，满足 LCA(a,x)=t。于是 `dist(a,x)=depth[a]+depth[x]−2depth[t]>=depth[y]+depth[x]−2depth[t]=D`。若某端点就是 t，取那个端点，使用 a 比另一个端点更深也得到同样结论。

任何两点距离都不超过直径 D，因此上面的距离只能等于 D，a 是某条直径端点；从 a 取得最远点 b 便得到长度 D。非负权让祖先距离不增的比较成立，负权会破坏这一点。

再证明直径端点支配所有点的最远距离。把直径 a—b 视作长度 D 的线段，v 的投影坐标为 l、离投影高度为 h；任意 x 的投影为 t、高度为 r。由于 `dist(x,a)<=D` 且 `dist(x,b)<=D`，有 `r<=min(t,D−t)`。即使 v、x 在同一分支，仍有 `dist(v,x)<=h+|l−t|+r`。若 t<=l，后两项不超过 l；若 t>=l，后两项不超过 D−l。因此 `dist(v,x)<=h+max(l,D−l)=max(dist(v,a),dist(v,b))`，而端点本身达到右侧上界。这证明离心率公式和无权中点结论。普通有环图没有唯一投影和唯一通路，不能据此用两次 BFS 精确求图直径。
