## 要连通全部点，不是从源点走得最短

铺设道路希望总造价最小且所有城市互通，要求选出覆盖全部 n 点的 $n-1$ 条边。最短路树关心一个源到各点的路程；最小生成树关心所选边权总和。边 `1—2(2),1—3(2),2—3(1)`：最短路树可能花 4，MST 花 3，不能混用。

普通 MST 针对无向图；可以有负权、重边。自环不能连接新分量。图不连通时只能得到最小生成森林，不能称为整图生成树。

## Kruskal：按边从小到大合并

初始每点一组。依权排序，若一条边的端点在不同集合，就选它并合并，否则会成环而跳过。并查集只判断当前连通关系，父指针不是实际道路。上述三角形先选 2—3 权 1，再选 1—2 权 2，最后一条在同集合而跳过，总权 3。

### 完整模板

输入 `n m` 和 m 条无向边 `u v w`，输出 MST 权值，不连通输出 DISCONNECTED。`n,m<=200000,|w|<=10^9`，点 $1\ldots n$。tuple 只是边的记录，不是类封装；排序首项为权值。find_root 路径压缩，merge_sets 按大小合并。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200000 + 5;
int parent_node[MAXN], size_node[MAXN];

int find_root(int x)
{
    if (parent_node[x] == x)
    {
        return x;
    }
    return parent_node[x] = find_root(parent_node[x]);
}

bool merge_sets(int u, int v)
{
    u = find_root(u);
    v = find_root(v);
    if (u == v)
    {
        return false;
    }
    if (size_node[u] < size_node[v])
    {
        swap(u, v);
    }
    parent_node[v] = u;
    size_node[u] += size_node[v];
    return true;
}

int main()
{
    int n, m;
    cin >> n >> m;
    vector<tuple<long long, int, int>> edges;
    for (int i = 1; i <= n; i++)
    {
        parent_node[i] = i;
        size_node[i] = 1;
    }
    for (int e = 0; e < m; e++)
    {
        int u, v;
        long long w;
        cin >> u >> v >> w;
        edges.push_back({w, u, v});
    }
    sort(edges.begin(), edges.end());
    long long total = 0;
    int chosen = 0;
    for (auto [w, u, v] : edges)
    {
        if (merge_sets(u, v))
        {
            total += w;
            ++chosen;
        }
    }
    if (chosen != n - 1)
    {
        cout << "DISCONNECTED\n";
    }
    else
    {
        cout << total << '\n';
    }
}
```

教学样例输入：

```text
3 3
1 2 2
1 3 2
2 3 1
```

输出：

```text
3
```

排序 $O(m \log (m+2))$，并查集 $O((n+m)\alpha (n))$ 摊还，空间 $O(n+m)$。$n=1$、$m=0$ 时选 0 条边，权值为 0；不能把没有选边一律判失败。

## Prim：从已选集合向外扩张

维护 $\mathrm{best}[v]$ 为从当前树集合 S 到 v 的最便宜单条边，而不是源点到 v 的路径距离。初始 S 空，选起点时付 0；此后取 best 最小的外部点加入，再用新点的边更新其他点。三角形从 1 开始，$\mathrm{best}[2]=2,\mathrm{best}[3]=2$；加入 2 后 $\mathrm{best}[3]$ 改成 1，总权 3。

与 Dijkstra 最关键的差别：Prim 更新 `min(best[v],w(u,v))`，Dijkstra 更新 `min(dist[v],dist[u]+w)`。Prim 不怕负边。

### 完整矩阵模板

输入输出同上，但 `n<=500,m<=200000`，适合小规模稠密图。矩阵重边保留最小权；单点同样输出 0。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 500 + 5;
const long long INF = (1LL << 60);
long long adj[MAXN][MAXN], best[MAXN];
bool used[MAXN];

int main()
{
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++)
    {
        best[i] = INF;
        for (int j = 1; j <= n; j++)
        {
            adj[i][j] = INF;
        }
    }
    for (int e = 0; e < m; e++)
    {
        int u, v;
        long long w;
        cin >> u >> v >> w;
        adj[u][v] = min(adj[u][v], w);
        adj[v][u] = min(adj[v][u], w);
    }
    best[1] = 0;
    long long total = 0;
    for (int count = 0; count < n; count++)
    {
        int u = 0;
        for (int v = 1; v <= n; v++)
        {
            if (!used[v] && (u == 0 || best[v] < best[u]))
            {
                u = v;
            }
        }
        if (best[u] == INF)
        {
            cout << "DISCONNECTED\n";
            return 0;
        }
        used[u] = true;
        total += best[u];
        for (int v = 1; v <= n; v++)
        {
            if (!used[v])
            {
                best[v] = min(best[v], adj[u][v]);
            }
        }
    }
    cout << total << '\n';
}
```

教学样例输入：

```text
3 3
1 2 2
1 3 2
2 3 1
```

输出：

```text
3
```

时间 $O(n^{2}+m)$，空间 $O(n^{2})$。若用邻接表与堆优化，需保存跨界最便宜边并跳过已选点，可以做到 $O(n+m \log (m+2))$；该变体依照相同 best 不变量实现，矩阵版更便于入门区分距离与边权。

## 为什么贪心安全：割与交换

把点分成两个集合，跨越分界的边称为割边候选。若某最轻跨界边 e 不在一棵最优树中，把 e 加进去会形成环，环上至少另有一条跨界边 f。删掉 f 后仍是生成树，且 e 不比 f 贵，总权不增。于是当前最轻跨界边可包含在某个最优解中。Prim 的 S 与外部正是一个割；Kruskal 当前分量的跨界候选也满足该性质。

## 扩展选读

相同权值可能产生不同 MST，不影响最小总权，但影响唯一性判断。次小生成树、最大边替换与动态 MST 是后续选学，不能仅靠“换掉任意一条边”处理。路径上最大边可结合 LCA 扩展维护。
