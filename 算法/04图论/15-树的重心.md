## 什么叫规模最平衡

删去 u 后，剩余树被分成若干连通块。记最大块大小为 $\mathrm{balance}[u]$，让它最小的点称重心。用于分治时，希望每次切出的子问题最多原规模一半；用于无权树上最小化到各点距离之和时，也会得到重心。

不要与中心混淆。举一条 1—2—3—4—5 链，在 1 上再接 6、7、8 三个叶子。直径长度 5，中心为 2、3；重心为 1、2。中心关注长分支的距离，重心关注点数量。

## 从 n 次删点遍历到一次子树统计

直接对每个 u 删除再遍历是 $O(n^{2})$。定根并得到 size 后，删 u 的各块是每个孩子 v 的 $\mathrm{size}[v]$，以及父亲方向 $n-\mathrm{size}[u]$，取最大即可。不能漏父亲方向：在一条长链的末端，孩子为空，但删末端还留 $n-1$ 个点。

链 1—2—3—4—5 根为 1，size 为 5、4、3、2、1；balance 为 4、3、2、3、4，重心是 3。星形树中心 1 的每个分量为 1，叶子却留下 $n-1$，重心为 1。

## 完整模板

输入 n 和 $n-1$ 条边，保证无权树，`n<=200000`。先输出最小最大分量大小，再输出全部重心编号（升序）。单点 $\mathrm{balance}=0$。父子定根与逆序聚合和前章一致，全程迭代。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200000 + 5;
vector<int> g[MAXN];
int parent_node[MAXN], size_node[MAXN];

int main()
{
    int n;
    cin >> n;
    for (int i = 1; i < n; i++)
    {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    vector<int> order = {1};
    for (int index = 0; index < (int)order.size(); index++)
    {
        int u = order[index];
        size_node[u] = 1;
        for (int v : g[u])
        {
            if (v != parent_node[u])
            {
                parent_node[v] = u;
                order.push_back(v);
            }
        }
    }
    for (int index = n - 1; index > 0; index--)
    {
        int u = order[index];
        size_node[parent_node[u]] += size_node[u];
    }
    int optimum = n;
    vector<int> answer;
    for (int u = 1; u <= n; u++)
    {
        int largest = n - size_node[u];
        for (int v : g[u])
        {
            if (parent_node[v] == u)
            {
                largest = max(largest, size_node[v]);
            }
        }
        if (largest < optimum)
        {
            optimum = largest;
            answer.clear();
        }
        if (largest == optimum)
        {
            answer.push_back(u);
        }
    }
    cout << optimum << '\n';
    for (int i = 0; i < (int)answer.size(); i++)
    {
        cout << answer[i] << (i + 1 == (int)answer.size() ? '\n' : ' ');
    }
}
```

教学样例输入：

```text
5
1 2
2 3
3 4
4 5
```

输出：

```text
2
3
```

## 正确性、复杂度与重要性质

上述分量彼此不相交且覆盖除 u 外全部点，所以计算的最大值准确。扫描每点及邻居，总时间 $O(n)$，总空间 $O(n)$。树至少有一个重心，最多两个；两个重心相邻。重心每个删点分量不超过 n/2，可证明若某块更大，向该块走一步会改善最大块规模，沿此方向移动终会停止。

设 F(u) 为到所有点的无权距离和，沿边 u→v 走一步，v 侧有 s 个点距离减 1，其余 $n-s$ 个加 1，因此 `F(v)−F(u)=n−2s`。当所有方向 $s\le n/2$ 时无法再降低，说明重心也是距离和最小点。点权不均等时要把“点数”替换为总点权；边权需非负才能沿同一方向比较距离和。
