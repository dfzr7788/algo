## 为什么一般有向图不能直接做 DAG 递推

若 `1→2,2→1,2→3`，1 与 2 互相依赖，拓扑排序失败。但 1、2 内部可以互相到达，把它们压成一个点后，图变成 `{1,2}→{3}`，可以做拓扑递推。强连通分量 SCC 是互相可达的极大集合；不是忽略方向得到的普通连通块。

两点相互可达可用每点 BFS 求可达矩阵，但需要 O(n(n+m)) 时间且可能需要平方空间。Kosaraju 用两次线性遍历获得这些集合。

## 第一遍记退出顺序，第二遍走反图

第一遍在原图 DFS，必须在“所有邻居处理完后”把 u 加入 order，不能用简单入栈或弹栈顺序代替。第二遍将 order 反转，按完成时间从大到小在反图启动遍历，每次拿到一个 SCC。

在 `1↔2,2→3` 上，从 1 开始，递归退出顺序可以是 `3,2,1`，反转为 `1,2,3`。反图从 1 能到 2，却到不了 3，因此先标 `{1,2}`，再标 `{3}`。如果第一遍只从 1 开始，另一个不可达分量会缺失，外层必须扫描全部点。

## 完整迭代模板

输入有向图 `n m` 和 m 条边，`n,m<=200000`；输出 SCC 个数和每点分量编号，编号由遍历决定，不是固定标准答案。finish_order 用 `(点,下一条邻居位置)` 的栈帧模拟退出事件，assign_component 只需普通可达性栈。允许重边、自环，单点也属于某个 SCC。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200000 + 5;
vector<int> g[MAXN], reverse_g[MAXN];
bool seen[MAXN];
int component[MAXN];
vector<int> order;

void finish_order(int start)
{
    vector<pair<int, int>> st;
    st.push_back({start, 0});
    seen[start] = true;
    while (!st.empty())
    {
        int u = st.back().first;
        int index = st.back().second;
        if (index == (int)g[u].size())
        {
            order.push_back(u);
            st.pop_back();
            continue;
        }
        ++st.back().second;
        int v = g[u][index];
        if (!seen[v])
        {
            seen[v] = true;
            st.push_back({v, 0});
        }
    }
}

void assign_component(int start, int id)
{
    stack<int> st;
    st.push(start);
    component[start] = id;
    while (!st.empty())
    {
        int u = st.top();
        st.pop();
        for (int v : reverse_g[u])
        {
            if (component[v] == 0)
            {
                component[v] = id;
                st.push(v);
            }
        }
    }
}

int main()
{
    int n, m;
    cin >> n >> m;
    for (int e = 0; e < m; e++)
    {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        reverse_g[v].push_back(u);
    }
    for (int i = 1; i <= n; i++)
    {
        if (!seen[i])
        {
            finish_order(i);
        }
    }
    int count = 0;
    reverse(order.begin(), order.end());
    for (int u : order)
    {
        if (component[u] == 0)
        {
            assign_component(u, ++count);
        }
    }
    cout << count << '\n';
    for (int i = 1; i <= n; i++)
    {
        cout << component[i] << (i == n ? '\n' : ' ');
    }
}
```

教学样例输入：

```text
3 3
1 2
2 1
2 3
```

输出：

```text
2
1 1 2
```

## 为什么正确与复杂度

先假想每个 SCC 已压成点：缩点图不可能有环，否则环上的分量互相可达，应合成同一个 SCC。若原图分量 A→B，则第一遍 A 的最大完成时间大于 B 的最大完成时间：从 A 先访问会把 B 处理完才退出 A，若 B 先访问也会先完成 B。故最大完成时间所在分量在当前缩点 DAG 中没有未处理前驱；在反图中无法进入别的未处理分量，恰好取出自己。删除这个分量后归纳。

两遍每点与每边只处理常数次，时间 O(n+m)，总空间 O(n+m)。用显式栈避免长链递归溢出；多测清理两套邻接表、seen、component、order。

## 缩点后的转移，什么时候可以合并点权

扫描原边 u→v，若 component[u]!=component[v]，添加分量间边；内部分量边丢弃。若保留重边，入度按记录次数增加且删除时按相同次数减少；若统计不同路径，必须明确是否把平行边当不同选择。

洛谷 P3387 点权非负，允许重复访问但每点仅计一次，因此进入 SCC 后可用内部路线访问所有点再从需要的出口离开，分量权取点权和，然后在 DAG 求最大权路径。如果存在负点权或限制简单路径，不能直接把 SCC 中所有权值相加。

## 扩展选读：Tarjan 与 low

Tarjan 一遍 DFS 维护 dfn、low 和“仍在分量栈中”的标记。当 low[u]=dfn[u] 时弹到 u 得到一个 SCC。已经归属其他 SCC 的点不能降低当前 low。它的栈用途不同于桥割点的 DFS 树；本章选 Kosaraju 作为完整主模板，Tarjan 留作后续选学，避免混用两个 low 定义。
